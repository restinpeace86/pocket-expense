다모온 설정 UX 검토

처음 가입한 회사 상태로 운영 사이트(damo-on.com)의 설정 탭 24개를 PC·휴대폰으로 모두 열어 보고, "앱을 처음 보는 관리자"가 이해하고 바꿀 수 있는지 봤어요. 기본값은 우리가 미는 표준 설정이라는 전제예요. 고를 항목은 번호(U-1…)로 알려 주세요.

한눈에

이미 고친 것 배포됨

  • PC 노란 [1:1 문의] 버튼이 근무 기준·세무사무소 화면 맨 아래 [저장] 버튼을 가림 → 화면 아래 여백 추가
  • 근무 기준의 옛 문구 "연차 화면은 곧 열려요" → 이미 있는 [직원별 연차] 탭 안내로

가장 큰 문제 3가지

  • 탭에 순서가 없음 — 처음 온 관리자가 어디부터 무엇을 하고 언제 끝난 건지 모름 (U-1)
  • 저장 방식이 섞임 — 바로 저장되는 화면과 [저장]을 눌러야 하는 화면이 섞여 있고, 저장 안 하고 탭을 옮겨도 경고가 없음 (U-2)
  • 기본값이 "추천"인지 안 보임 — 그대로 둬도 되는지, 바꾸면 직원에게 뭐가 달라지는지가 화면마다 다름 (U-3)

U-1 처음 1회 단계 안내

말씀하신 방식이에요. 메뉴(그룹) 안의 탭을 처음 한 번은 순서대로 안내하고, [완료하고 다음]으로 넘어가게 해요. 끝낸 뒤에는 지금처럼 자유롭게 탭을 오가요.

처음 설정 · 회사 자산 ✓ 법인카드 2 회사차량 3 회의실
회사차량 등록 화면(지금과 같음). 차량이 없으면 등록하지 않고 넘어가도 돼요.
이 단계 건너뛰기 완료하고 다음 (회의실) →

A. 메뉴별 처음 1회 단계 안내 추천

회사 자산·경비 정책·근태 정책·양식·결재처럼 탭이 여러 개인 메뉴만, 처음 들어오면 위 모형처럼 안내해요. 마지막 탭에서 [설정 완료]를 누르면 메뉴 옆에 ✓가 붙어요. 완료 기록은 회사 단위라 다른 관리자가 이미 끝냈으면 다시 안내하지 않아요. 관리자 홈 '처음 설정' 체크리스트도 이 완료 기록으로 채워요.

B. 가입 직후 전체 마법사

회사 등록 뒤 설정 전부를 한 번에 거치게 해요. 놓치는 것은 없지만 20단계가 넘어 첫날 이탈이 걱정돼요.

C. 탭 아래 [다음 탭 →] 버튼만

가장 간단해요. 완료 기록과 체크 표시가 없어서 "다 했는지"는 여전히 알 수 없어요.

A를 하면 회사별 완료 기록을 남길 작은 DB 표가 하나 필요해요. 만들 때 운영 DB 변경 승인을 따로 받을게요.

모든 화면에 걸친 문제

U-2높음 저장 방식 통일 + 저장 안 한 변경 경고

지금: 법인카드·회사차량·회의실·부서·회사 위치·기능 스위치는 누르면 바로 저장. 회사정보·경비 정책·근무 기준·결재라인·양식은 [저장]을 눌러야 저장. 바꾸고 [저장] 없이 다른 탭으로 가면 아무 말 없이 사라져요.

제안: [저장]이 있는 화면은 바꾼 게 생기면 화면 아래에 "저장하지 않은 변경이 있어요 [저장]" 줄을 띄우고, 그대로 다른 탭·메뉴로 가려 하면 한 번 물어요. 바로 저장되는 화면은 저장될 때 "저장했어요"를 잠깐 보여 줘요.

U-3높음 기본값에 "추천" 표시 + 바꾸면 달라지는 것 한 줄

식대 한도·자차 유류비는 예시와 근거가 잘 돼 있어요(예: "2명이 25,000원 먹으면 회사 20,000원 · 직원 부담 5,000원", "기본 200원은…"). 다른 화면은 이 수준이 아니에요. 모든 선택지에 [기본·추천] 표시를 같은 모양으로 붙이고, 고를 때마다 "직원 화면에서는 이렇게 보여요" 한 줄을 붙여요. 식대 화면을 기준 모양으로 삼아요.

U-4중간 저장 버튼 옆 문구를 화면에 맞게

회사정보(회사명·사업자번호)의 [저장] 옆에도 "변경 내용은 이후 상신되는 경비부터 적용돼요"가 나와요. 회사정보와 상관없는 말이라 헷갈려요. 경비 정책 화면에만 남기고, 회사정보는 "저장하면 직원 화면 회사 이름도 바로 바뀌어요"처럼 바꿔요.

U-5중간 휴대폰 탭 줄이 잘리는데 더 있다는 표시가 없음

경비 정책(탭 6개)·근태 정책(5개)은 휴대폰에서 "정기…"처럼 잘려 보여요. 옆으로 밀면 되지만 처음 보는 사람은 몰라요. 오른쪽 끝을 흐리게 하고 › 표시를 붙여요. U-1을 하면 처음 1회는 단계 줄이 대신 보여서 더 나아져요.

U-6중간 관리자 홈에 같은 안내가 두 번

'처음 설정 (2/3)' 체크리스트 안에 [정산 정책 확인]이 있고, 바로 아래에 '정산 정책을 확인해 주세요' 카드가 또 있어요. 카드의 내용(지금 기본값 요약)은 체크리스트 항목을 펼치면 보이게 합치고 카드는 없애요.
