# 안드로이드 설치 앱(감싸는 앱) — D-228

> 사용자 결정 2026-11-06: "안드로이드는 감싸는 앱으로, QR 설치로 먼저. 아이폰은 지금 웹앱 알림 그대로. 홈 화면 웹앱도 계속 쓸 수 있게 하고, 안드로이드에서는 설치해서 쓰는 것의 장점을 설명. 사용자가 좀 늘면 사업자 계정으로 플레이스토어."

## 1. 목적
- 웹 알림은 안드로이드 8 이상에서 진동 모양·세기·알림음을 앱이 정할 수 없어(D-227) 채팅 알림을 놓치기 쉽다.
- 설치 앱은 알림을 앱 방식(FCM)으로 받아 **진동·알림음·중요도(헤드업)를 앱이 정한다**.

## 2. 범위 (Phase 1)
- 안드로이드 전용. 우리 웹(운영 주소)을 그대로 여는 껍데기 앱(Capacitor). 화면·기능은 웹과 같고, 웹을 고치면 앱도 바로 바뀐다(다시 설치 불필요).
- 앱만 하는 일: 알림 받기(FCM) · 알림 누르면 그 화면 열기 · 알림 채널(채팅 = 중요도 높음·긴 진동·소리).
- 배포: 스토어 없이 **APK 파일**. PC 화면의 QR → 휴대폰에서 받기 → 설치. 플레이스토어(사업자 계정)는 사용자가 늘면 별도 결정.
- 아이폰: 바뀌지 않음(홈 화면 웹앱 + 웹 알림).
- 홈 화면 웹앱(D-219)도 그대로 둔다. 둘 중 하나를 고를 수 있게 한다.

## 3. 설치 안내 화면
- 안드로이드에서 "앱 설치 vs 홈 화면 추가"를 고를 수 있게, 설치 앱의 장점을 짧게 설명한다:
  - 알림이 더 확실하게, 길고 강한 진동·알림음(휴대폰 설정에서 채팅 알림만 따로 조절)
  - 화면·기능은 웹과 같고 업데이트는 자동
- 설치할 때 휴대폰이 "출처를 알 수 없는 앱 허용"을 묻는다는 안내, 구글 보안 경고가 뜰 수 있다는 안내.
- PC: [내 정보] 알림 칸(또는 설치 안내)에 QR. 휴대폰 안드로이드: [앱 받기] 버튼.
- (D-229) 관리자 직원 초대: 카카오톡 공유에 [웹으로 가입하기]·[앱 설치 안내]를 같이, 초대 링크 카드에 [앱 설치 QR 저장] — spec/screens/admin-team-members.md 끝.

## 4. 알림 보내기
- 기존 웹푸시(`push_subscriptions`)는 그대로. 설치 앱 기기는 FCM 토큰을 `push_app_tokens`(migration 123)에 따로 등록하고, 같은 알림을 FCM으로도 보낸다(`src/lib/push/fcm.ts`, `server.ts` pushToMembers·pushToCompany·pushToAll).
- 중복 방지: 설치 앱 토큰이 있는 사람은 **브라우저 정보가 안드로이드인 웹 구독**을 건너뛴다(같은 휴대폰의 크롬 알림). PC 웹 알림은 그대로 받는다.
- 채널: urgency high(채팅·회의) = `chat`(중요도 높음·진동 0.5초×3·알림음), 나머지 = `general`. 채널은 앱(MainActivity)이 만들고, 사용자는 휴대폰 설정 › 애플리케이션 › WORKON › 알림에서 채널별로 바꿀 수 있다.
- FCM이 토큰이 없어졌다고 하면(UNREGISTERED·잘못된 토큰) 그 토큰을 지운다.
- 보안: FCM 서버 키(서비스 계정)는 Vercel 환경변수에만. 회사 분리(D-115 계열)는 기존 알림과 같다 — 받는 사람 선택은 지금 알림 로직 그대로.

## 5. 사용자가 할 일(구현 전 준비)
- Firebase 프로젝트 만들기 → 안드로이드 앱 등록(패키지 이름) → `google-services.json` 받기 → 서비스 계정 키 만들어 Vercel 환경변수에 넣기.
- 이 PC에 Android Studio 설치(JDK·SDK 포함) — APK 빌드용.
- APK 서명 키는 한 번 만들고 잃어버리지 않게 보관(업데이트 때 같은 키 필요).

## 6. 확정 (2026-11-06)
- 패키지 이름 `kr.damounlab.app`(상호 기준 — 서비스 이름이 바뀌어도 그대로). 앱에 보이는 이름은 `WORKON`(바꿀 수 있음).
- APK 보관: Supabase 공개 저장소 `app-downloads/android/workon.apk`(새 버전은 덮어씀). 안내 화면 `/download`(PC = QR, 휴대폰 = 받기·설치 순서).
- 설치 파일을 올리기 전에는 `ANDROID_APK_READY = false`로 받기 버튼·안내 링크를 숨긴다(`src/lib/app-download.ts`). v1.0.0 올림(2026-11-06) → true.
- 앱 껍데기: `mobile/`(Capacitor 8). 운영 주소를 연다 — 도메인을 바꾸면 `mobile/capacitor.config.json` server.url을 바꿔 앱을 다시 만들어야 한다.
- 서명 키 `mobile/android/workon-release.jks` + `keystore.properties`는 저장소에 올리지 않는다. 잃어버리면 업데이트를 설치할 수 없다(사용자가 따로 보관).

## 7. 로그인·화면 (D-230)
- 앱에서 카카오·Google 로그인: 로그인 끝 주소 = `kr.damounlab.app://auth/callback`(앱 주소). 로그인은 휴대폰 크롬에서 하고(Google은 앱 안 화면 로그인 금지), 끝나면 앱이 다시 열려 그 코드를 우리 `/auth/callback`으로 넘겨 앱 안에서 로그인을 마친다. Supabase Authentication › Redirect URLs에 이 앱 주소가 있어야 한다.
- 로그인 창에서 그냥 돌아오면(뒤로 가기·취소) 로그인 버튼이 다시 눌리게 돌아온다.
- 밝은 화면 전용: 웹 `color-scheme: only light`(크롬 자동 다크 끔), 앱 테마 Light·흰 바탕·상단바 흰색.
- Supabase Site URL = 운영 주소(2026-11-07). 도메인을 바꾸면 Site URL·Redirect URLs·앱 server.url을 같이 바꾼다.
