> **승인 전에는 구현하지 않는다.**

## 1. 범위
- **같은 회사의 승인된 멤버끼리만**. 다른 회사·세무사무소는 볼 수 없다(DB에서 강제).
- 회사 안에서는 **모든 일정이 모두에게 보인다**(비공개 없음). 개인 사정(휴가·조퇴·외출)은 근태 쪽 일(O-11)이라 일정 종류에 넣지 않는다.
- 1차 기능
  - 일정 만들기·고치기·지우기(만든 사람만), 참석자 초대, 참석자의 [참석]/[불참] 응답
  - 달력 보기(직원·관리자 같은 화면, 폭으로만 바뀜): **PC(md 이상) = 월 달력 / 휴대폰 = 그 달 날짜별 목록**(주간 시간표는 1차에 없음)
  - **기본은 내 일정만**. **사람 고르기**: 부서별 직원 목록에서 체크한 사람의 일정만 겹쳐 보기(사람마다 색). 처음부터 회사 전체가 뜨지 않는다
  - **마감일 자동 표시**(만들지 않아도 보이는 날짜, 고칠 수 없음): §2-1
- **보류**(이번에 안 함): 채팅 연결(채팅방에서 일정 만들기·일정 카드·공지 띠), 반복 일정, 알림(푸시·10분 전), 외부 캘린더(구독 링크·구글·톡캘린더), 회의실 예약·회의 10분 전 안내(§8 구상), 휴가·근태 표시

## 2. 일정
- 항목: 제목(100자), 종류(**회의 / 외근 / 출장 / 기타**), 시작·끝(날짜+시각, 또는 **종일** — 여러 날 가능), 장소(200자, 선택), 메모(2,000자, 선택), 참석자(선택).
- **누구의 일정인가**: 만든 사람 + 참석자. 예) A팀 김A가 회의를 만들고 B팀 이B를 참석자로 넣으면, 이B를 고르면 그 회의가 이B의 일정으로 보인다.
- 만든 사람 = 자동으로 참석(응답 '참석'). 참석자 응답: 대기 / 참석 / 불참. 불참한 사람 일정에도 흐리게 보인다(줄 그은 제목).
- 고치기·지우기는 **만든 사람만**. 참석자는 응답만. 관리자도 남의 일정은 고치지 않는다(같은 회사라 보기는 가능).
- 시간을 바꾸면 참석자 응답은 다시 '대기'(만든 사람 제외).
- 퇴사(비활성) 멤버: 지난 일정에는 이름 뒤 "(퇴사)", 사람 목록·참석자 고르기에서는 빠진다.
- 시간대: 한국 시간 기준. 종일 일정은 날짜로 저장.

## 2-1. 마감일 자동 표시 (안)
- 고정 마감 규칙(D-161, `src/lib/expense/deadline.ts`)으로 계산해 달력에 띄운다(일정 표에 저장하지 않음). 종일 표시, 다른 색 + "마감" 표시. 모든 회사 같은 규칙.
  - **청구(정산) 마감일**(직원·관리자 모두): 매달 2일(전월 사용분), 쉬는 날(주말·공휴일)이면 앞 영업일 — `claimCutoff`.
  - **세무(월말) 마감일**(관리자만): 매달 5일, 쉬는 날이면 앞 영업일 — `taxCloseDue`. 세무사무소 전달 기한.
- 마감일을 누르면 그 화면으로: 정산 마감 → 직원 정산 화면 / 세무 마감 → 관리자 월말 마감 화면.
- 사람 고르기와 관계없이 늘 보인다(끄기 체크 하나: [마감일 보기]).

## 2-2. 주말·공휴일 색 (안, 사용자 질문 2026-11-04)
- 공휴일: 기존 `kr_holidays` 표(D-161, migration 088 — 운영자 화면 `/app-admin/holidays`에서 해마다 확인·추가, 2026·2027 들어 있음)를 그대로 쓴다. 해마다 지정되는 관공서 공휴일(설·추석 연휴, 대체공휴일·선거일 포함). 임시공휴일은 운영자가 따로 넣지 않으면 표시하지 않는다. 설·추석·부처님오신날은 음력이라 코드로 계산하지 않고 표에서 읽는다.
- 색: 일요일·공휴일 = 빨강(날짜 숫자 + 공휴일 이름 작게 "추석"), 토요일 = **결정 필요**(§7 ④ — 한국 달력 관례 파랑 / 빨강). 요일 머리줄도 같은 색. 휴대폰 날짜별 목록의 날짜 줄도 같은 색.
- 색만으로 구분하지 않게 공휴일은 이름을 같이 쓴다.

## 3. 화면
- 주소: `/workspace/{회사}/calendar`. 직원·관리자 공통 화면.
- 들어가는 곳: 관리자 왼쪽 메뉴 [캘린더](채팅 아래), 직원 — **결정 필요**(§7 ①).
- **사람 고르기**
  - PC: 왼쪽 칸에 부서별 접이식 목록(▸ 영업팀 김A·이B …, 부서 없음은 맨 아래). 이름 옆 체크 = 그 사람 일정 보기, 부서 이름 체크 = 그 부서 전체. 사람 이름 앞 색 점 = 달력 색.
  - 휴대폰: 위쪽 [사람 선택 (3)] → 아래에서 올라오는 같은 목록.
  - 기본은 **나만** 체크(처음 열면 내 일정 + 마감일만). 고른 사람은 기억(다른 기기에서도 같게 — DB에 저장).
- **달력**
  - **PC(md 이상) 월 달력**: 월요일 시작, 날짜 칸에 일정(하루 최대 3개 + "+n개"), 여러 날 일정은 날마다 표시, 오늘 표시, 이전/다음 달·[오늘]. 날짜 칸을 누르면 그날 일정 목록.
  - **휴대폰 날짜별 목록**: 그 달의 날짜를 하루 한 줄씩 위에서 아래로("11월 4일 (화) [오늘]" + 그날 일정 "14:00~15:00 주간회의 · 김A, 이B 외 1", 종일·마감일은 맨 위, 일정 없는 날은 "일정 없음" 흐리게). 처음 열면 오늘 줄로 스크롤. 위쪽에 이전/다음 달·[오늘]·[사람 선택], 오른쪽 아래 [+]로 일정 만들기.
  - **구조**: local-open-spaces 파트너 월간 화면(`src/app/partner/(tabs)/monthly/page.tsx` — `MonthCalendarGrid` + `DayBookingRow`)과 같은 방식 — 한 번 불러온 같은 데이터를 CSS(`hidden md:block` / `md:hidden`)로만 바꿔 보여 준다(기기 판별 없음). 관리자는 PC가 기본이라 달력, 직원은 휴대폰이라 목록으로 보이게 된다.
  - PC 왼쪽에 사람 고르기 칸, 휴대폰은 [사람 선택] 버튼.
  - 일정 색 = 그 일정이 보이는 사람의 색(여러 명이면 만든 사람 색), 종류는 작은 글자/아이콘(회의·외근·출장·기타). 마감일은 주황 + "마감" 글자(빨강은 일요일·공휴일 몫, §2-2).
- **일정 상세**(누르면): 제목·종류·시간·장소·메모·만든 사람·참석자별 응답. 참석자면 [참석]/[불참], 만든 사람이면 [수정]/[삭제].
- **일정 만들기**: [+ 일정] 또는 PC 달력 날짜 칸의 [+](그 날짜로 채움). 참석자 고르기는 부서별 목록 + 검색, 고른 시간에 이미 일정이 있는 사람 옆에 "일정 있음".
- 모든 화면 반응형(휴대폰 390·PC 1280 확인).

## 4. 데이터 (안)
- `calendar_events(id, company_id, created_by_member_id, title, kind meeting|outside|trip|other, all_day, starts_at, ends_at, start_date, end_date, location, memo, created_at, updated_at)` — 종일이면 start_date·end_date, 아니면 starts_at·ends_at(끝 > 시작).
- `calendar_attendees(event_id, company_id, member_id, response pending|accepted|declined, responded_at)` — 만든 사람도 한 줄.
- `calendar_view_prefs(member_id, company_id, member_ids uuid[])` — 고른 사람 기억.
- 모두 company_id + 복합 FK(회사 섞임 방지), 회사 삭제 시 연쇄 삭제, 멤버 삭제 시 참석 줄 삭제.
- 쓰기는 security definer 함수만(스위치·회사·권한 확인): 만들기·고치기·지우기·응답·사람 고르기 저장. 읽기: 기간 + 고른 사람으로 일정 목록(만든 사람 또는 참석자), 같은 회사 + 스위치 켜짐.
- 스위치: `company_features`에 `calendar`(메신저와 같은 표, 기본 꺼짐, 운영자만 DB로). 꺼지면 메뉴·주소·DB 함수 모두 막힘.

## 5. 성능
- 한 번에 보는 기간(월간 6주) × 고른 사람만 불러온다. (company_id, starts_at) / (member_id) 인덱스.
- 실시간 반영은 1차에 없음 — 화면을 열 때·다시 보일 때 다시 불러옴(채팅 연결 때 같이 검토).

## 6. 확인 방법
- DB 격리 테스트: 다른 회사 일정 안 보임 / 스위치 꺼짐 / 만든 사람만 고치기·지우기 / 참석자만 응답 / 표 직접 쓰기 불가 / 시간 바꾸면 응답 대기로.
- 화면 E2E(휴대폰 390·PC 1280): 만들기 → 참석자 캘린더에 보임 → 응답 → 사람 고르기 → 월·주 보기, 스크린샷 확인.

## 7. 승인 전에 정할 것
1. **직원 화면에서 들어가는 곳**(추천: 홈 화면 [캘린더] 카드 — 오늘 일정 수·다음 마감일): 하단 메뉴가 이미 5칸(홈·정산·결재함·채팅·내 정보). 6칸으로 늘리기 / 홈 화면에 [캘린더] 카드 / 채팅 탭 안에 넣기 중 무엇?
2. **주 시작 요일**: 월요일(local-open-spaces 파트너 달력과 같음, 추천) / 일요일.
3. **마감일 범위**: 청구 마감 2일(직원·관리자) + 세무 마감 5일(관리자만)으로 맞는지.
4. **토요일 색**: 파랑(한국 달력 관례, local-open-spaces 파트너 달력도 토=파랑·일=빨강) / 빨강.

## 8. 다음 단계 구상 (1차 아님, 사용자 2026-11-04)

  - 메신저 쪽: 시스템 알림방 종류 추가, 시스템 메시지(보낸 사람 없음) 표시.
