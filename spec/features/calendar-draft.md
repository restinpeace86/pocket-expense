# 사내 캘린더 (초안 — 사용자 승인 대기, O-12)

> 사용자 논의 2026-11-04: 회사 안 업무 일정(회의·외근·출장) 공유. 외부 캘린더 연동 없음.
> "왼쪽에 팀별 직원 나열, 선택한 인원들 일정만 뜨게", "일정은 직원 누구나 — 나의 일정, 내가 포함된 회의",
> "회사 내 일정에 개인 병원 예약이 보이나?" → 비공개 옵션 없음. 채팅 연결·반복 일정·알림은 보류.
> **승인 전에는 구현하지 않는다.**

## 1. 범위
- **같은 회사의 승인된 멤버끼리만**. 다른 회사·세무사무소는 볼 수 없다(DB에서 강제).
- 회사 안에서는 **모든 일정이 모두에게 보인다**(비공개 없음). 개인 사정(휴가·조퇴·외출)은 근태 쪽 일(O-11)이라 일정 종류에 넣지 않는다.
- 1차 기능
  - 일정 만들기·고치기·지우기(만든 사람만), 참석자 초대, 참석자의 [참석]/[불참] 응답
  - 달력 보기: 휴대폰 = 월 달력 + 고른 날 목록 / PC = 월간·주간(시간표)
  - **사람 고르기**: 부서별 직원 목록에서 체크한 사람의 일정만 겹쳐 보기(사람마다 색)
- **보류**(이번에 안 함): 채팅 연결(채팅방에서 일정 만들기·일정 카드·공지 띠), 반복 일정, 알림(푸시·10분 전), 외부 캘린더(구독 링크·구글·톡캘린더), 회의실 예약, 휴가·근태 표시

## 2. 일정
- 항목: 제목(100자), 종류(**회의 / 외근 / 출장 / 기타**), 시작·끝(날짜+시각, 또는 **종일** — 여러 날 가능), 장소(200자, 선택), 메모(2,000자, 선택), 참석자(선택).
- **누구의 일정인가**: 만든 사람 + 참석자. 예) A팀 김A가 회의를 만들고 B팀 이B를 참석자로 넣으면, 이B를 고르면 그 회의가 이B의 일정으로 보인다.
- 만든 사람 = 자동으로 참석(응답 '참석'). 참석자 응답: 대기 / 참석 / 불참. 불참한 사람 일정에도 흐리게 보인다(줄 그은 제목).
- 고치기·지우기는 **만든 사람만**. 참석자는 응답만. 관리자도 남의 일정은 고치지 않는다(같은 회사라 보기는 가능).
- 시간을 바꾸면 참석자 응답은 다시 '대기'(만든 사람 제외).
- 퇴사(비활성) 멤버: 지난 일정에는 이름 뒤 "(퇴사)", 사람 목록·참석자 고르기에서는 빠진다.
- 시간대: 한국 시간 기준. 종일 일정은 날짜로 저장.

## 3. 화면
- 주소: `/workspace/{회사}/calendar`. 직원·관리자 공통 화면.
- 들어가는 곳: 관리자 왼쪽 메뉴 [캘린더](채팅 아래), 직원 — **결정 필요**(§7 ①).
- **사람 고르기**
  - PC: 왼쪽 칸에 부서별 접이식 목록(▸ 영업팀 김A·이B …, 부서 없음은 맨 아래). 이름 옆 체크 = 그 사람 일정 보기, 부서 이름 체크 = 그 부서 전체. 사람 이름 앞 색 점 = 달력 색.
  - 휴대폰: 위쪽 [사람 선택 (3)] → 아래에서 올라오는 같은 목록.
  - 기본은 **나만** 체크. 고른 사람은 기억(다른 기기에서도 같게 — DB에 저장).
- **달력**
  - 월간: 날짜 칸에 일정 막대(하루 최대 3개 + "+n개"), 여러 날 일정은 이어진 막대, 오늘 표시, 이전/다음 달·[오늘].
  - 주간(PC): 요일 × 시간(기본 08~20시가 보이게, 위아래 스크롤로 0~24시), 위쪽 줄에 종일 일정, 겹치는 일정은 나란히.
  - 휴대폰: 월 달력(일정 있는 날 점) + 고른 날 시간순 목록 "14:00~15:00 주간회의 · 김A, 이B 외 1".
  - 일정 색 = 그 일정이 보이는 사람의 색(여러 명이면 만든 사람 색), 종류는 작은 글자/아이콘(회의·외근·출장·기타).
- **일정 상세**(누르면): 제목·종류·시간·장소·메모·만든 사람·참석자별 응답. 참석자면 [참석]/[불참], 만든 사람이면 [수정]/[삭제].
- **일정 만들기**: [+ 일정] 또는 PC 주간 빈칸 누르기(그 시간으로 채움). 참석자 고르기는 부서별 목록 + 검색, 고른 시간에 이미 일정이 있는 사람 옆에 "일정 있음".
- 모든 화면 반응형(휴대폰 390·PC 1280 확인).

## 4. 데이터 (안)
- `calendar_events(id, company_id, created_by_member_id, title, kind meeting|outside|trip|other, all_day, starts_at, ends_at, start_date, end_date, location, memo, created_at, updated_at)` — 종일이면 start_date·end_date, 아니면 starts_at·ends_at(끝 > 시작).
- `calendar_attendees(event_id, company_id, member_id, response pending|accepted|declined, responded_at)` — 만든 사람도 한 줄.
- `calendar_view_prefs(member_id, company_id, member_ids uuid[])` — 고른 사람 기억.
- 모두 company_id + 복합 FK(회사 섞임 방지), 회사 삭제 시 연쇄 삭제, 멤버 삭제 시 참석 줄 삭제.
- 쓰기는 security definer 함수만(스위치·회사·권한 확인): 만들기·고치기·지우기·응답·사람 고르기 저장. 읽기: 기간 + 고른 사람으로 일정 목록(만든 사람 또는 참석자), 같은 회사 + 스위치 켜짐.
- 스위치: `company_features`에 `calendar`(메신저와 같은 표, 기본 꺼짐, 운영자만 DB로). 꺼지면 메뉴·주소·DB 함수 모두 막힘.

## 5. 성능
- 한 번에 보는 기간(월간 6주) × 고른 사람만 불러온다. (company_id, starts_at) / (member_id) 인덱스.
- 실시간 반영은 1차에 없음 — 화면을 열 때·다시 보일 때 다시 불러옴(채팅 연결 때 같이 검토).

## 6. 확인 방법
- DB 격리 테스트: 다른 회사 일정 안 보임 / 스위치 꺼짐 / 만든 사람만 고치기·지우기 / 참석자만 응답 / 표 직접 쓰기 불가 / 시간 바꾸면 응답 대기로.
- 화면 E2E(휴대폰 390·PC 1280): 만들기 → 참석자 캘린더에 보임 → 응답 → 사람 고르기 → 월·주 보기, 스크린샷 확인.

## 7. 승인 전에 정할 것
1. **직원 화면에서 들어가는 곳**: 하단 메뉴가 이미 5칸(홈·정산·결재함·채팅·내 정보). 6칸으로 늘리기 / 홈 화면에 [캘린더] 카드 / 채팅 탭 안에 넣기 중 무엇?
2. **주 시작 요일**: 일요일(휴대폰 기본 캘린더와 같음) / 월요일(업무용).
