# [Spec] 월말 마감 및 세무사무소 전달용 패키지 출력

## 1. 개요
매월 말일, 관리자가 사내 경비 정산을 일괄 마감하고 세무사무소(기장 대행)나 내부 감사를 위해 필요한 **표준 지출결의서 엑셀(Excel/CSV)**과 **원본 영수증 PDF 패키지**를 단 한 번의 클릭으로 다운로드하는 기능.

## 2. 출력물 명세
1. **세무사무소용 표준 지출결의서 엑셀 (`.xlsx` 또는 `.csv`)**:
   - 대상: 해당 월에 `approved` 또는 `paid` 상태인 모든 청구 건.
   - 컬럼 구조: 사용 일자, 직원명, 부서, 카테고리(식대/출장비/미팅비), 가맹점명, 총금액, 회사 지원금, 개인 부담금, 적요/목적.
2. **영수증 원본 지출결의서 패키지 (`.pdf` 또는 압축 파일)**:
   - 각 청구 건별로 [지출결의서 요약본 + Supabase Storage에 저장된 영수증 원본 이미지]가 깔끔하게 매칭된 PDF 문서 또는 일괄 다운로드 압축 파일 제공.
