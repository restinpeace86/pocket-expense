# [Spec] 월말 마감 · 세무사무소 전달 패키지 출력

관련: D-016, D-017, O-02 / 데이터: `expenses`, `expense_approvals`, `form_templates`, `members`

## 1. 개요
관리자가 월을 고르면 그 달의 승인된 경비를 세무사무소 전달용 엑셀, 영수증 원본, 지출결의서 PDF로 한 번에 내려받는다.

## 2. 대상
- 기준월: **결제일자(`expense_date`)** 가 해당 월인 경비 (D-016).
- 상태: `approved`, `paid`.
- 정렬: 결제일자 오름차순 → 사용자 이름.
- 출력 전 화면에 같은 달 미완료 건수를 경고로 보여 준다: "이 달 결제 건 중 작성중 2건, 결재중 3건, 반려 1건은 포함되지 않습니다." 각 건은 목록으로 펼쳐 볼 수 있다.
- 출력 이후 늦게 승인된 건은 다시 출력하면 포함된다. 월 마감 잠금 기능은 현재 범위가 아니다.

## 3. 출력물
### 3.1 다운로드 버튼
1. [엑셀만 다운로드] → `지출내역_{YYYY-MM}.xlsx`
2. [전체 패키지 다운로드(ZIP)] → 아래 구조

```
PocketExpense_{회사명}_{YYYY-MM}.zip
├─ 지출내역_{YYYY-MM}.xlsx
├─ 지출결의서_{YYYY-MM}.pdf
└─ receipts/
   └─ {YYYYMMDD}_{사용자}_{카테고리}_{expenseId 앞 8자리}.{ext}
```

### 3.2 엑셀 컬럼 (내부 표준, O-02 확정 전 잠정)
| 컬럼 | 값 |
|---|---|
| 결제일자 | `expense_date` |
| 부서 / 사용자 / 사번 | 청구자 정보 |
| 카테고리 / 세부유형 | 식대·출장비·미팅비 / 출장 세부 유형 |
| 결제수단 | 개인카드 / 법인카드 |
| 가맹점명 | `merchant_name` |
| 공급가액 / 부가세 / 합계금액 | `supply_amount` / `vat_amount` / `amount` |
| 회사지원금 / 개인부담금 | 계산값 |
| 정산구분 / 정산금액 | 지급(회사→직원) 또는 납부(직원→회사) / 금액 (`expense-lifecycle.md` §5.4) |
| 지출목적(적요) | `purpose` |
| 인원수 / 참석자 / 거래처 | 식대·미팅 정보 |
| 출발지 / 도착지 / 주행거리(km) / 거리입력방식 | 자차 정보 |
| 상태 / 최종승인일 / 정산완료일 | 결재 생략 건은 상태를 "승인(결재생략)"으로 표기 |
| 영수증파일명 | ZIP `receipts/` 안의 파일명 (영수증 없으면 빈칸) (D-016) |
| (회사 고유 항목들) | 포함된 경비들이 참조하는 양식의 바인딩 없는 필드. 키 기준 합집합, 라벨은 최신 버전 라벨 |

- 마지막 행에 합계(공급가액, 부가세, 합계금액, 회사지원금, 개인부담금).
- 시트2 "요약": 사용자별·카테고리별 합계, 정산구분별 합계.
- 금액 셀은 숫자 형식(천 단위 구분), 날짜 셀은 날짜 형식.
- **더존/세무사랑 업로드 호환 매핑은 O-02(템플릿 미확보)로 구현 보류.** 템플릿 확보 시 별도 시트 또는 별도 버튼으로 추가한다.

### 3.3 지출결의서 PDF
- 경비 1건당 1페이지(영수증이 길면 다음 페이지로): `spec/features/form-template.md` §5 렌더러 + 결재란 + 영수증 이미지. PDF 영수증은 첫 페이지를 이미지로 넣는다.
- 한글 폰트를 내장한다.

## 4. 처리
- 서버(Route Handler)에서 생성해 스트리밍 다운로드한다. 영수증은 service role로 Storage에서 읽는다.
- 생성 중 진행 표시. 실패 시 "출력에 실패했어요. 다시 시도해 주세요" + 재시도.
- 영수증 파일을 못 읽은 건은 엑셀 영수증파일명 칸에 "(파일 없음)"을 적고 나머지는 계속 생성한다.
