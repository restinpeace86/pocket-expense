# [Spec] 월말 마감 · 세무사무소 전달 패키지 출력

관련: D-016, D-017, D-034, O-02 / 데이터: `expense_claims`, `expense_items`, `claim_approvals`, `form_templates`, `members`

## 1. 개요
관리자가 월을 고르면 그 달의 승인된 경비를 세무사무소 전달용 엑셀, 영수증 원본, 지출소명서 PDF로 한 번에 내려받는다. 결재는 소명서 단위지만 **엑셀은 영수증 항목 1건 = 1행**으로 쪼개서 출력한다.

## 2. 대상
- 기준월: 항목의 **결제일자(`expense_items.expense_date`)** 가 해당 월인 항목 (D-016).
- 상태: 소속 소명서가 `approved`, `paid`.
- 한 소명서의 항목이 여러 달에 걸치면(예: 10/30~11/2 출장) 항목은 각 결제월에 나뉘어 출력된다. 엑셀의 소명서번호·제목 컬럼으로 묶음을 확인할 수 있다.
- 정렬: 결제일자 오름차순 → 사용자 이름 → 소명서번호.
- 출력 전 화면에 같은 달 미완료 항목을 경고로 보여 준다: "이 달 결제 항목 중 작성중 2건, 결재중 3건, 반려 1건(소명서 기준 n건)은 포함되지 않습니다." 소명서 목록으로 펼쳐 볼 수 있다.
- 출력 이후 늦게 승인된 건은 다시 출력하면 포함된다. 월 마감 잠금 기능은 현재 범위가 아니다.

## 3. 출력물
### 3.1 다운로드 버튼
1. [엑셀만 다운로드] → `지출내역_{YYYY-MM}.xlsx`
2. [전체 패키지 다운로드(ZIP)] → 아래 구조

```
PocketExpense_{회사명}_{YYYY-MM}.zip
├─ 지출내역_{YYYY-MM}.xlsx
├─ 지출소명서_{YYYY-MM}.pdf
└─ receipts/
   └─ {YYYYMMDD}_{사용자}_{카테고리}_{itemId 앞 8자리}.{ext}
```

### 3.2 엑셀 시트1 "지출내역" — 전체 데이터 컬럼
원칙: **소명서·항목에 저장된 모든 업무 데이터를 빠짐없이 담는다.** 1행 = 영수증 항목 1건. 세무사무소가 어떤 양식을 요구하든 이 시트에서 골라 쓸 수 있어야 한다. (내부용 기술 컬럼 `ai_parsed_payload`, `receipt_path`, `parse_status`, 좌표는 제외)

| 그룹 | 컬럼 | 값 |
|---|---|---|
| 식별 | 소명서번호 / 소명서 제목 / 소명 내용 | `expense_claims.id` 앞 8자리 / `title` / `description` |
| 출장 | 출장여부 / 출장지 / 출장기간 / 출장목적 | 소명서의 `is_business_trip` / `trip_destination` / `trip_start_date~trip_end_date` / `trip_purpose` |
| 식별 | 항목번호 | `expense_items.id` 앞 8자리 (영수증 파일명과 동일) |
| 거래 | 결제일자 | `expense_date` |
| 거래 | 가맹점명 | `merchant_name` |
| 거래 | 공급가액 / 부가세 / 합계금액 | `supply_amount` / `vat_amount` / `amount` |
| 거래 | 결제수단 | 개인카드 / 법인카드 |
| 분류 | 카테고리 / 출장 세부유형 | 일반 식대·출장비·외부 미팅비 / `trip_type` 표시명 (출장 식비, 대중교통, 택시, 통행료·주차, 숙박, 자차 유류비, 기타) |
| 청구자 | 부서 / 사용자 / 직급 / 사번 | `members`, `departments` |
| 내용 | 지출목적(적요) | `purpose` |
| 내용 | 인원수 / 참석자 / 거래처 | `headcount` / `attendees` / `client_name` |
| 출장 | 숙박 체크인 / 체크아웃 | 항목의 `trip_start_date` / `trip_end_date` (`lodging`) |
| 출장 | 출발지 / 도착지 / 왕복여부 / 주행거리(km) / 거리입력방식 / 차량번호 | 자차 정보 (`is_round_trip`, `distance_source`: 자동·직접, `members.vehicle_number`) |
| 계산기준 | 적용 1인 식대한도 / 적용 km당 유류비 단가 | `applied_meal_limit_per_person` / `applied_fuel_rate_per_km` |
| 정산 | 회사지원금 / 개인부담금 | `company_supported_amount` / `personal_burden_amount` |
| 정산 | 정산구분 / 정산금액 | 지급(회사→직원) 또는 납부(직원→회사) / 금액 (`expense-lifecycle.md` §5.5) |
| 결재 | 상태 | 승인 / 승인(결재생략) / 정산완료 |
| 결재 | 상신일 / 최종승인일 / 정산완료일 | 소명서의 `submitted_at` / `approved_at` / `paid_at` |
| 결재 | 결재자 | 소명서 최종 회차 승인 단계를 "김팀장(10/12) → 이대표(10/13)" 형식으로. 결재 생략 건은 "결재 생략" |
| 증빙 | 영수증파일명 | ZIP `receipts/` 안의 파일명 (영수증 없으면 빈칸) (D-016) |
| 회사 양식 | (회사 고유 헤더 항목들) | 소명서 `header_custom_payload`. 같은 소명서의 모든 행에 반복 표기 |
| 회사 양식 | (회사 고유 항목 필드들) | 항목 `item_custom_payload` |
| | | 회사 양식 컬럼은 포함된 소명서들이 참조하는 양식 필드의 키 기준 합집합, 라벨은 최신 버전 라벨 |

- 마지막 행에 합계(공급가액, 부가세, 합계금액, 회사지원금, 개인부담금, 정산구분별 정산금액).
- 금액 셀은 숫자 형식(천 단위 구분), 날짜 셀은 날짜 형식. 첫 행 고정, 자동 필터 적용.

### 3.3 엑셀 시트2 "요약"
- 사용자별 합계, 카테고리별 합계(출장비는 세부 유형별 소계 포함), 결제수단별 합계, 정산구분별(지급/납부) 합계, 소명서별 합계(제목·건수·합계·상태).

### 3.4 회계 프로그램 호환 매핑 — ⛔ 보류(O-02)
- 더존/세무사랑 등 업로드 전용 양식으로 컬럼을 바꿔 담는 매핑만 보류한다. 템플릿 확보 시 시트1 데이터에서 변환하는 별도 시트로 추가한다. 시트1·시트2 출력은 보류 대상이 아니다.

### 3.5 지출소명서 PDF
- 해당 월 항목이 1건 이상 포함된 소명서마다: 1페이지 = 소명서 문서(`spec/features/form-template.md` §5: 헤더 + 항목 표 + 결재란 + 정산 요약), 이어서 항목별 영수증 이미지 페이지(항목번호 표기). PDF 영수증은 첫 페이지를 이미지로 넣는다.
- 여러 달에 걸친 소명서는 각 달 PDF에 소명서 전체가 들어가고, 다른 달 항목은 표에서 회색으로 표시한다.
- 한글 폰트를 내장한다.

## 4. 처리
- 서버(Route Handler)에서 생성해 스트리밍 다운로드한다. 영수증은 service role로 Storage에서 읽는다.
- 생성 중 진행 표시. 실패 시 "출력에 실패했어요. 다시 시도해 주세요" + 재시도.
- 영수증 파일을 못 읽은 건은 엑셀 영수증파일명 칸에 "(파일 없음)"을 적고 나머지는 계속 생성한다.
