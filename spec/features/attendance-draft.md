# 출퇴근 체크 (근태) — 구상 기록 (미승인 · 구현 보류)

> ⛔ **구현 보류 (O-11)**: 이 문서는 2026-11-03 사용자와 나눈 구상만 기록한 것이다. 승인된 Spec이 아니다.
> 사용자가 근태 기능 개발을 다시 꺼낼 때 이 문서를 바탕으로 남은 결정을 확인한 뒤 Spec으로 확정한다. 그 전에는 구현하지 않는다.
> 확정되면 완성 후 회사별 기능 스위치로 꺼서 숨겨 둔다(사용자 방침).

## 1. 목표
- 하드웨어 장비 없이, 소프트웨어만으로 가볍게 동작하는 출퇴근 체크.
- 막을 대상: **혼자서 하는 원격·대리 출근**(집·카페에서 출근, QR 사진 재사용, 위치 조작).
- 막지 않을 대상: **사무실에 있는 공범이 실시간으로 도와주는 경우**. 네이버웍스 등 일반 근태 서비스도 막지 않는 수준이라 우리도 다루지 않는다(사용자 결정).

## 2. 검토한 방향과 결론

| 방향 | 결론 | 이유 |
|---|---|---|
| 회사 공인 IP 허용(PC·휴대폰 와이파이) | 기본으로 쓰지 않음(선택 기능 후보) | 유동 IP가 바뀌면 그날 전원 출근 불가 → 관리자 재등록 필요. 휴대폰 IP 검사가 없으면 QR 사진을 카톡으로 보내 뚫림. IPv6·공유오피스 공인 IP 공유 문제 |
| 와이파이 이름(SSID)/공유기 번호(BSSID) | 불가 | 웹 브라우저는 와이파이 정보를 읽을 수 없음(설치형 앱만 가능) |
| 휴대폰 GPS만 (회사 위치 반경) | 기본으로 쓰지 않음 | 가짜 GPS를 웹에서 못 잡음, 건물 안 오차 수백 m, PC는 GPS 없음. 위치정보법(위치기반서비스사업 신고 여부·직원 동의) 검토 필요 |
| 회사 위치 + 아무 PC의 QR | 불가 | QR이 회사 PC에서 나왔다는 보장이 없어 집 PC + 가짜 GPS로 뚫림. PC 위치는 수백 m~수 km 오차 |
| 단말 카메라가 직원 폰 QR을 찍기 | 보류 | 카메라 있는 기기가 필요 |
| NFC(사원증처럼 대기) | 불가(지금) | 웹 NFC는 안드로이드 크롬만, 아이폰 불가. 앱을 만들면 그때 검토 |
| **등록 단말에 동적 QR → 직원 폰 기본 카메라로 찍기** | **채택안** | 추가 기기·IP 관리 불필요. QR은 등록 단말에서만 나오므로 혼자서는 원격 출근 불가 |

## 3. 채택안 구성
- **등록 단말**: 회사 PC·태블릿·공기계. 관리자가 그 기기에서 "출근 화면으로 등록"을 한 번 누르면 그 기기에만 단말 열쇠가 저장된다. 여러 대(지점별) 등록, 이름 붙이기, 해제 가능.
- **출근 화면(상시 켜 둠)**: 부팅·로그인 대기 없이 바로 찍을 수 있어야 한다(사원증처럼 "띡"). 화면 꺼짐 방지(Wake Lock), QR 자동 갱신, 끊기면 자동 재연결, 재부팅 뒤 브라우저만 열면 바로 출근 화면.
- **동적 QR**: 30초마다 바뀜(직전 칸까지 허용). 서버 비밀키로 서명(회사·단말·시간 칸) — DB 저장 불필요. 한 QR을 여러 명이 찍을 수 있고 같은 사람은 하루 출근 1건.
- **직원**: 휴대폰 **기본 카메라**로 QR → 링크 → 출근 기록(로그인 유지, 앱 열 필요 없음). 확인 화면 "출근 08:57 ✔". 같은 QR로 퇴근도 기록(안). 홈 화면 바로가기 선택.
- **출근 화면 피드백**: 찍으면 "김OO 출근 ✔"를 잠깐 표시.
- **시간**: 항상 서버 시간(한국 시간).
- **찍지 못한 날**: 직원 정정 요청 → 관리자 승인(기존 결재 방식 재사용)(안).
- **오류 기록**: QR 생성·인증 실패를 자동 기록(시간·실패 코드·기기 정보). 화면 캡처는 자동으로 하지 않고 직원이 "문제 신고"에서 직접 첨부(직원 화면 몰래 캡처는 개인정보 문제).
- **숨김**: 회사별 기능 스위치. 꺼지면 메뉴 숨김·주소 직접 접근 404.

## 4. 보안 원칙(구현 시)
- 출근 기록은 서버 라우트에서만 서비스 키로 적재. 직원 권한(authenticated)으로 기록 테이블·적재 함수에 직접 쓰지 못하게(우회 기록 방지).
- 모든 테이블 company_id + RLS(강제), 회사 간 섞임 없음(테넌트 격리 원칙). 단말 열쇠·QR 토큰의 회사와 찍은 직원의 소속 회사가 같아야 함.
- 단말 해제 즉시 그 단말 QR 무효. QR 발급·체크 API는 요청 횟수 제한.
- 출퇴근 기록·기기 정보는 개인정보 → 수집 안내·보존 기간을 약관·개인정보처리방침에 반영.

## 5. 데이터 구상(초안)
- `attendance_terminals`(company_id, 이름, 단말 열쇠 해시, 등록자, 등록·마지막 사용·해제 시각)
- `attendance_logs`(company_id, member_id, 근무일, 출근/퇴근, 서버 시각, 단말, 방법 qr/정정)
- `attendance_attempts`(실패 기록, 90일 보관 안)
- 정정 요청 테이블(또는 기존 결재 구조 재사용)

## 6. 다시 시작할 때 확인할 것
1. 퇴근 체크를 같이 만들지(추천: 예, 기록만 — 지각·근무시간 집계는 제외)
2. 정정 요청 → 관리자 승인 흐름(추천: 예)
3. 지점·외근(추천: 지점은 단말 추가, 외근은 정정 요청)
4. 선택 기능 후보: 회사 IP 동시 확인, 위치(GPS) 기록 — 위치는 위치정보법 검토 뒤
5. 기능 스위치 단위(회사별) 및 요금제 포함 여부

## 7. 사용자 결정 (2026-11-08) — 아직 구현 보류, 시안·Spec 확정 후 착수
- **범위(1단계)**: QR 출퇴근 · 홈 오늘 카드 · 월 근태 현황 · 근무시간 정정 신청(결재, 원본 보존) · 휴가 신청 · 승인 휴가 캘린더 자동 표시 · 관리자 근태 설정/QR 띄우기/직원별 연차 일수/오늘 출근 현황
- **퇴근**: 출근과 같이 회사 QR을 다시 찍는다
- **휴가 차감 단위**: 일 단위 + **시간차(1시간 단위)**. 반반차는 따로 두지 않는다. 1일 = 회사 소정근로시간(기본 8시간, 근태 설정에서 변경)
- **연차 일수**: 입사일로 근로기준법 제60조 **법 기준 추천값**을 보여 주고 **관리자가 확정(수정 가능)**. 5인 미만 회사는 추천값 없이 직접 입력. 출근율(80%) 판단·수당·퇴사 정산은 하지 않는다
- **휴가 종류**: 법에서 정한 코드가 아니므로 관리자가 관리(기본 템플릿 제공), 종류마다 유급/무급·연차 차감 여부
- **근무시간 표시**: 찍힌 시각과 머문 시간만("8시간 20분"). 연장·심야·휴일 계산 안 함
- **범위 밖(하지 않음)**: 연장·심야·휴일 수당 계산, 급여 연동, 유연근무제, 연차 사용 촉진, 엑셀 내보내기(1단계 제외), 식당·통근버스·좌석예약, 재직증명서 신청, 공지 읽음 확인, 직원 주소록(현재 제외)
- **화면 순서**: 직원 홈 개편(A1 허브·A2 지출결의 목록 이동·A3 하단 바) → 근태 설정 → 회사 QR → QR 출퇴근 → 월 근태 현황 → 정정 신청 → 연차 일수 → 휴가 신청 → 오늘 출근 현황
