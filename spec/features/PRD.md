# PocketExpense - Product Requirements Document (PRD) & Master Specification

## 1. 서비스 개요 및 타겟 (Overview & Target)
- **서비스명**: `PocketExpense` (소기업·스타트업용 초간편 AI 경비 정산 SaaS)
- **타겟 고객**: 
  - 직원 5~30인 규모의 소기업, 스타트업, 현장 중심 기업.
  - 사내에 전문 회계 담당자가 없고, **대표님이 직접 최종 결재**를 수행하는 조직.
- **해결하는 페인포인트**:
  - 대기업용 그룹웨어(인당 월 15,000원 선)나 복잡한 금융망 연동 솔루션은 비용과 도입 장벽이 너무 높음.
  - 실무자들의 영수증 처리 및 양식 작성 피로도 극대화, 월말마다 세무사무소와 주고받는 귀찮은 소통 비용 발생.
- **핵심 USP (차별화 포인트)**:
  - 금융망 직접 연동이 없어 **초기 도입비 0원**.
  - 복잡한 사내 메신저는 다 빼고, **[템플릿 사진 업로드 ➔ 영수증 촬영/파싱 ➔ 카카오 알림톡 원클릭 결재 ➔ 세무사무소 엑셀 출력]**이라는 뾰족한 단일 파이프라인에 집중.

---

## 2. 비즈니스 및 가격 전략 (Business & Pricing Model)
- **도입 비용**: 금융망 연동 비용 및 구축비 제거로 **도입비 0원**.
- **구간제 구독 요금제 (LLM 비용 리스크 방지형)**: 
  - 대기업형 인당 과금 구조를 배제하고, 서버 및 LLM API 토큰 비용을 방어할 수 있는 고정 월 구독형 모델 적용.
  - 예시: `5인 이하 소호 팩` (월 3만 원) / `20인 이하 스탠다드 팩` (월 7만 원) 등.

## 3. 핵심 킬러 기능 상세 명세 (Core Features)

### ① 템플릿 사진 업로드로 '사내 양식 자동 빌드'
- **기능**: 회사가 평소에 쓰던 지출결의서 양식(종이 문서나 기존 엑셀/이미지)을 관리자가 스마트폰으로 찍어 올리면, **Gemini Vision LLM이 양식을 분석해 사내 맞춤형 웹 양식 스키마(`custom_schema`)로 자동 변환**.
- **효과**: 관리자가 복잡한 폼 빌더를 수동으로 만질 필요 없이 3초 만에 우리 회사만의 정산 폼이 구축됨.

### ② Vision LLM 영수증 파싱 + Human-in-the-Loop
- **기능**: 직원이 QR/웹링크로 접속해 영수증을 촬영하면, LLM이 가맹점(`merchant_name`), 금액(`amount`), 결제 일자(`expense_date`), 부가세를 자동 추출.
- **UX 보완**: AI가 1차로 채워준 초안을 모바일 화면에서 유저가 직접 가볍게 눈으로 확인하고 수정할 수 있는 수동 보정 에디터 UI 제공.

### ③ 카카오 알림톡 원클릭 전자결재 (Approval Workflow)
- **신청 단계**: 직원이 모바일에서 [관리자에게 제출하기] 클릭 ➔ 사장님(결재권자) 카카오톡으로 청구 요약 + **[웹에서 검토하기 링크]** 전송.
- **검토 단계**: 사장님은 별도 앱 설치나 로그인 없이 링크를 눌러 영수증 원본과 내역을 확인한 뒤 **[승인 / 반려(사유 입력)]**을 원클릭으로 해결.
- **결과 안내**: 승인/반려 시 당사자 카카오톡으로 실시간 결과 및 후속 안내 톡 발송.

### ④ 식대 스마트 분할 정산
- **기준**: `companies.max_meal_amount` (예: 10,000원) 설정.
- **로직**: 
  - 한도 내 결제: 전액 회사 지원.
  - 초과 결제: 회사 지원금 = 한도 금액 / 개인 부담금 = 총액 - 한도 금액.
  - UI에서 실시간으로 분할 내역 인폼 ("회사 지원 10,000원 + 개인 부담 3,000원").

### ⑤ 카카오내비 연동 자차 출장비 산정
- **로직**: 출발지/도착지 주소를 카카오 모빌리티 API로 연동해 실제 주행 거리(`distance_km`) 산출 ➔ 회사 설정 단가(`companies.fuel_rate_per_km`, 기본 200원)와 곱하여 청구 유류비 자동 계산. (API 실패 시 수동 입력 Fallback 제공)

### ⑥ 세무사 제출용 표준 엑셀 다운로드 (마감 킬러 기능)
- **목적**: 월말에 외부 기장 세무사에게 넘겨줄 더존/세무사랑 회계 프로그램 업로드 완벽 호환 표준 증빙 자료 제공.
- **엑셀 컬럼 구조**: 
  `결제일자 | 사용 부서 | 사용자 | 가맹점명 | 금액 | 부가세 | 지출 목적(사유) | 영수증 이미지 링크`
- **기대 효과**: 세무사무소 직원이 엑셀 파일만 보고 더존/세무사랑에 3초 만에 전표 입력 완료 가능.

## 4. 데이터베이스 아키텍처 (Supabase PostgreSQL)
*멀티테넌트 구조 적용: 회사별 커스텀 양식과 데이터는 물리적 테이블을 쪼개지 않고 `JSONB` 컬럼으로 유연하게 처리.*

### ① `companies` (회사 테이블)
- `id` (UUID, PK), `name` (회사명), `invite_code` (직원 가입용 코드)
- `max_meal_amount` (식대 기본 한도), `fuel_rate_per_km` (자차 유류비 단가)
- `custom_schema` (JSONB) - Vision LLM이 추출한 회사별 커스텀 양식 필드 정의서

### ② `users` (직원/관리자 테이블)
- `id` (UUID, PK), `auth_id` (Supabase Auth UID 연동), `company_id` (FK)
- `name` (실명), `department` (부서), `role` ('employee' | 'admin'), `status` ('pending' | 'approved')

### ③ `expenses` (지출결의서 청구 테이블)
- `id` (UUID, PK), `company_id` (FK), `user_id` (FK)
- `category` ('meal' | 'trip' | 'meeting'), `amount` (총금액), `merchant_name` (상호명), `expense_date` (사용일자)
- `receipt_url` (Supabase Storage 영수증 이미지 주소)
- `status` ('draft' | 'submitted' | 'approved' | 'rejected' | 'paid')
- `company_supported_amount`, `personal_burden_amount`, `trip_distance_km`
- `custom_payload` (JSONB) - 회사의 `custom_schema`에 맞춰 입력된 커스텀 필드 값
- `rejection_reason` (반려 사유)

## 5. UI/UX 및 반응형 레이아웃 가이드
- **직원용 모바일 웹 (`< 768px`, 모바일 퍼스트)**: 
  - 하단 고정 CTA (`+ 새 경비 청구하기`), 터치 최적화 버튼 (`min-height: 44px` 이상).
- **관리자용 PC 대시보드 (`>= 768px`, 2단 Split View)**: 
  - 좌측 사이드바 + 우측 메인 콘텐츠. 전체 청구 현황 요약, 경비 승인/반려 검토, 사내 규칙 설정, 월말 세무 패키지 출력(`export`).
- **상태 배지 표준 커스텀**: 
  - `draft` (작성중: 회색) ➔ `submitted` (제출완료: 파랑) ➔ `approved` (승인완료: 초록) ➔ `rejected` (반려: 빨강) ➔ `paid` (정산완료: 보라).
