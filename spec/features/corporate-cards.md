# [Spec] 법인카드 등록 (선택 기능) · 카드번호 앞 6자리·뒤 4자리 자동 판별

관련: D-048, D-055(일부 대체), **D-083** / 데이터: `corporate_cards`(`bin6`, `last4`), `expense_items.corporate_card_id`, `expense_items.card_last4`, `expense_items.ai_parsed_payload.card_number_masked` / 화면: `/admin/corporate-cards`(`admin-dashboard.md` ⑫), E-02(`worker-tax-processing.md` 2단계) / 규칙 코드: `src/lib/cards/match.ts` = DB `private.mask_card_number`, `private.card_number_matches`(migration 038)

## 1. 목적
- 법인카드를 **별칭 + 카드번호 앞 6자리(BIN) + 뒤 4자리**로 등록해 두면, AI가 영수증에 찍힌 카드번호를 읽어 **법인카드인지 개인(사비)인지, 어떤 법인카드인지 자동으로 골라 준다.**
- 결제수단 기본값이 법인카드라서 사비 결제를 법인카드로 잘못 올려 돌려받을 돈이 빠지는 실수를 줄인다.
- 뒤 4자리만 같은 카드(카드사가 다른 카드)를 앞 6자리로 구분한다.
- 세무사무소가 카드사 사용내역과 대조할 때 카드 끝 4자리를 쓸 수 있다.
- **선택 기능**이다. 등록된 법인카드가 없으면 이 기능과 관련 UI는 모두 숨겨지고, 직원은 법인카드 / 개인(사비)만 고른다.

## 2. 등록 (관리자 이상, `/admin/corporate-cards`)
| 항목 | 필수 | 비고 |
|---|---|---|
| 별칭 | 필수 | 예: "대표 법인카드", "영업팀 공용카드" |
| 카드번호 앞 6자리 | 필수(새 카드) | 숫자 6자리. 카드사·상품을 나타내는 번호(BIN) |
| 카드번호 뒤 4자리 | 필수 | 숫자 4자리. 등록 후 바꿀 수 없음(바꾸려면 새 카드로 등록) |
| 담당자 | 선택 | 주로 쓰는 멤버. 표시용 |
| 사용 여부 | — | 해지한 카드는 [사용 안 함]으로 바꾼다(과거 항목 연결 보존을 위해 삭제 대신 비활성) |
- 입력 모양: `ㅁㅁㅁㅁ-ㅁㅁ**-****-ㅁㅁㅁㅁ`. 앞 4칸 → 2칸 → 뒤 4칸만 입력란이 있고 가운데(`**-****`)는 입력란 자체가 없다. 칸이 차면 다음 칸으로 넘어가고, 빈 칸에서 지우기를 누르면 앞 칸으로 돌아간다. 카드번호 전체를 붙여 넣으면 앞 6자리·뒤 4자리만 나눠 넣고 나머지는 버린다(서버로 보내지 않음). 숫자 키패드, 브라우저 카드번호 자동 채우기는 끈다.
- 같은 회사 활성 카드끼리 (앞 6자리, 뒤 4자리)가 같으면 등록할 수 없다.
- **카드번호 전체(가운데 6자리)·유효기간·CVC는 받지도 저장하지도 않는다.**
- 예전에 뒤 4자리만 등록한 카드는 그대로 쓰고(목록에 "앞 6자리 미등록" 표시, 뒤 4자리로만 비교), [수정]에서 앞 6자리를 채울 수 있다.
- 목록 표시: `5327-12**-****-4321` (앞 6자리 없으면 `****-****-****-4321`).

## 3. 자동 판별 (영수증 업로드 시, 처음 읽을 때만)
1. AI가 영수증에 찍힌 카드번호를 **보이는 그대로** 읽는다(가려진 자리는 `*`, 가려진 숫자를 추측하지 않음, `receipt-parser.md` §3). 예: `5327-12**-****-432*`.
2. 저장 전에 **앞 6자리·뒤 4자리 말고는 숫자가 있어도 `*`로 바꾼다**(브라우저와 서버 두 곳에서). 짧게 찍힌 번호(예: `****7890`)는 뒤 4자리만 남긴다. → 카드번호 전체가 저장되는 일이 없다.
3. 회사의 **활성 법인카드**와 **보이는 숫자만** 비교한다. 가려진 자리(`*`)는 비교하지 않는다(예: 뒤 4자리가 `432*`이면 `432`만 비교). 앞 6자리는 카드번호 전체 자리(13자 이상)가 찍힌 경우에만 비교한다.
   | 결과 | 결제수단 | 표시 |
   |---|---|---|
   | 등록 카드 1장과 맞음 | 법인카드 + 해당 카드 자동 선택 | "💳 대표 법인카드(7890)로 인식했어요" |
   | 2장 이상과 맞음(예: 뒤 4자리만 보이는데 끝자리가 같은 카드가 둘) | 법인카드, 카드는 비워 둠 | "영수증 카드번호(****-4321)와 맞는 법인카드가 여러 장이에요. 사용한 카드를 골라 주세요." |
   | 보이는 숫자가 어느 등록 카드와도 다름 | 개인(사비) 추천 | "영수증 카드번호(…)가 등록된 법인카드와 달라 개인(사비)으로 골랐어요. 법인카드였다면 바꿔 주세요." |
   | 보이는 숫자가 없음(현금, 배달앱 캡처, 전부 가림 등) | 결의서 기본값 유지 | 법인카드면 직원이 카드 선택(카드가 1장뿐이면 자동 선택) |
4. 자동 선택은 **확정이 아니라 추천**이다. 직원은 결제수단과 카드를 바꿀 수 있고, 바꾸면 그 값이 최종값이 된다. 다시 읽기를 해도 직원이 고른 값은 바꾸지 않는다.
5. 법인카드를 고른 항목은 사용한 카드(`corporate_card_id`)가 상신 시 필수다(등록 카드가 있을 때만).
6. 항목의 `card_last4`는 영수증 뒤 4자리가 모두 보이면 그 값, 카드 1장과 맞았는데 뒤 자리가 일부 가려졌으면 그 카드의 뒤 4자리.

## 4. 표시와 출력
- 지출 승인 관리·결재 화면: 결제수단 뱃지 옆에 카드 별칭·끝 4자리(예: `[💳 법인 · 대표 7890]`). AI 인식 결과와 직원 선택이 다르면 "직원 수정" 표시(D-037).
- 세무 마감 엑셀: 시트1에 "법인카드(끝 4자리)" 컬럼, 세무 업로드(법인카드) 시트에 "카드 끝 4자리" 컬럼(`tax-upload-format.md`, 개인 사비 시트에는 없음 — D-136). 카드 내역 대조는 같은 날·같은 금액이면 가맹점 사업자번호로 구분(D-136). 앞 6자리는 넣지 않는다.
- 운영자 화면(`app-admin.md`): AI가 읽은 카드번호를 가린 모양 그대로(`5327-12**-****-432*`).
- 대시보드 요약(선택): 카드별 이번 달 사용 합계.
