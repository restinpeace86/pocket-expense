# [Spec] 법인카드 등록 (선택 기능) · 끝 4자리 자동 판별

관련: D-048, D-055 / 데이터: `corporate_cards`, `expense_items.corporate_card_id`, `expense_items.card_last4` / 화면: `/admin/corporate-cards`(`admin-dashboard.md` ⑫), E-02(`worker-tax-processing.md` 2단계)

## 1. 목적
- 법인카드를 **별칭 + 끝 4자리**로 등록해 두면, AI가 영수증에서 카드 끝 4자리를 읽어 **법인카드인지 개인(사비)인지, 어떤 법인카드인지 자동으로 골라 준다.**
- 결제수단 기본값이 법인카드라서 사비 결제를 법인카드로 잘못 올려 돌려받을 돈이 빠지는 실수를 줄인다.
- 세무사무소가 카드사 사용내역과 대조할 때 카드 끝 4자리를 쓸 수 있다.
- **선택 기능**이다. 등록된 법인카드가 없으면 이 기능과 관련 UI는 모두 숨겨지고, 직원은 법인카드 / 개인(사비)만 고른다.

## 2. 등록 (관리자 이상, `/admin/corporate-cards`)
| 항목 | 필수 | 비고 |
|---|---|---|
| 별칭 | 필수 | 예: "대표 법인카드", "영업팀 공용카드" |
| 카드 끝 4자리 | 필수 | 숫자 4자리. 회사 안에서 중복 불가(활성 카드 기준) |
| 담당자 | 선택 | 주로 쓰는 멤버. 표시용 |
| 사용 여부 | — | 해지한 카드는 [사용 안 함]으로 바꾼다(과거 항목 연결 보존을 위해 삭제 대신 비활성) |
- **카드번호 전체(16자리)·유효기간·CVC는 받지도 저장하지도 않는다.** 입력란 자체를 두지 않는다.
- 화면 안내: "영수증에 찍히는 카드 끝 4자리만 등록합니다. 카드번호 전체는 저장하지 않습니다."

## 3. 자동 판별 (영수증 업로드 시)
1. AI가 영수증의 마스킹된 카드번호(예: `1234-56**-****-7890`)에서 **끝 4자리만** 추출한다(`receipt-parser.md` §3). 카드번호 전체는 추출하지 않는다.
2. 추출한 끝 4자리를 회사의 **활성 법인카드**와 비교한다.
   | 결과 | 결제수단 | 표시 |
   |---|---|---|
   | 등록 카드와 일치 | 법인카드 + 해당 카드 자동 선택 | "💳 대표 법인카드(7890)로 인식했어요" |
   | 끝 4자리는 읽었지만 등록 카드와 불일치 | 개인(사비) 추천 | "등록되지 않은 카드(1234)예요. 개인카드라면 사비로 정산됩니다" 노란 확인 문구 |
   | 끝 4자리를 읽지 못함(현금, 배달앱 캡처 등) | 소명서 기본값(법인카드) 유지 | 법인카드면 직원이 카드 선택(카드가 1장뿐이면 자동 선택) |
3. 자동 선택은 **확정이 아니라 추천**이다. 직원은 결제수단과 카드를 바꿀 수 있고, 바꾸면 그 값이 최종값이 된다.
4. 법인카드를 고른 항목은 사용한 카드(`corporate_card_id`)가 상신 시 필수다(등록 카드가 있을 때만).

## 4. 표시와 출력
- 지출 승인 관리·결재 화면: 결제수단 뱃지 옆에 카드 별칭·끝 4자리(예: `[💳 법인 · 대표 7890]`). AI 인식 결과와 직원 선택이 다르면 "직원 수정" 표시(D-037).
- 세무 마감 엑셀: 시트1에 "법인카드(끝 4자리)" 컬럼, 시트3(세무 업로드 초안)에 "카드 끝 4자리" 컬럼(`tax-upload-format.md`).
- 대시보드 요약(선택): 카드별 이번 달 사용 합계.
