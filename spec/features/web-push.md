# [Spec] 웹푸시 리마인더·공지 (D-116)

## 1. 받는 방법
- 직원 [내 정보], 관리자 [설정 › 지출 한도·정책] 맨 위 **이 기기에서 알림 받기** → [알림 켜기](브라우저 권한 허용) → [시험 알림].
- 기기(브라우저)마다 켠다. [끄기]하면 그 기기 구독을 지운다. 구독이 끝난 기기(404·410)는 서버가 지운다.
- 아이폰(iOS 16.4+): Safari [공유 › 홈 화면에 추가]로 연 앱에서만 켤 수 있다(화면에 안내). 앱 이름·아이콘은 manifest.
- 비용 없음(VAPID 웹푸시). 키: `NEXT_PUBLIC_VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`(운영 주소) — 서버 환경 변수.

## 2. 자동 리마인더 (매일 07:00 KST, `/api/cron/morning`)
| 종류 | 대상 | 시점 | 문구 |
|---|---|---|---|
| 정산 마감 | 작성 중·반려 결의서(영수증 1장 이상)가 있는 활성 직원 | 회사 청구 기한(D-031)이 **말일** 또는 **다음 달 N일**일 때, 이번 달 마감일 3일 전·당일 | "이번 달 지출 정산 마감이 3일 남았어요(10/31까지). 작성 중인 결의서 n건을 상신해 주세요." |
| 결재 대기 | 사전 검토 단계 = 지정 검토자, 최종 단계 = 청구자 외 관리자·최고 관리자 | 상신 뒤 24시간 넘게 처리 안 됨, 하루 한 번 | "현재 결재 대기 중인 지출결의서가 n건 있어요. 확인해 주세요." |
- 같은 날 같은 알림은 한 번만(`push_logs`). 청구 기한이 "사용일 + N일"·"없음"이면 회사 공통 마감일이 없어 마감 리마인더를 보내지 않는다.

## 3. 공지 (2채널, 서로 분리)
| | 채널 A 전체 공지 | 채널 B 사내 공지 |
|---|---|---|
| 쓰는 사람 | 앱 운영자(`app_admins`) — `/app-admin/announcements` | 그 회사 관리자·최고 관리자 — [설정 › 사내 공지] |
| 받는 사람 | 모든 회사의 대표·직원 | **그 회사 직원만**(RLS 회사 격리) |
| 용도 | 서비스 업데이트·신기능·정기 점검 | 식대 단가 변경·사내 정산 규칙·내부 마감일 |
- 보내면 홈 화면 공지(최근 30일 3건, 펼쳐 보기)에 보이고, 알림을 켠 기기에는 바로 푸시. 보낸 공지는 고치지 않는다(목록에 보낸 기기 수).
