# [Spec] 영수증 여러 장 한 번에 청구 (다중 업로드 → 경비 N건 일괄 상신)

관련: D-020, D-029 / 단건 작성 화면: `spec/screens/employee-mobile.md` ② / 파싱: `spec/features/receipt-parser.md`

## 1. 개요
출장 등으로 영수증이 여러 장일 때, 직원이 한 장씩 따로 작성하지 않고 **여러 장을 한 번에 올려 한 화면에서 검토하고 일괄 상신**한다.
- 데이터 구조는 바꾸지 않는다: **영수증 1장 = 경비 1건 = 결재 1건**(D-020). 다중 업로드는 경비 N건을 한 번에 만드는 입력 편의 기능이다.
- 묶음(소명서 헤더) 단위 결재·묶음 제목은 범위가 아니다.

## 2. 흐름
### Step 1. 다중 업로드 (`/workspace/[id]/employee/new/batch`)
- 직원 홈의 [+ 새 경비 청구하기] → [영수증 여러 장 올리기] 선택.
- 카메라 연속 촬영 또는 갤러리 다중 선택(최대 20장). 결제수단은 이 화면에서 한 번 고르고 모든 건에 기본값으로 적용(건별 변경 가능).

### Step 2. 일괄 파싱
- 영수증마다 `draft` 경비 1건을 만들고 원본을 저장한 뒤, 건별로 Gemini 파싱을 수행한다(동시 최대 3건). 파싱 규칙과 실패 처리는 `receipt-parser.md`와 같다.
- 파싱 결과의 카테고리 추천(`receipt-parser.md` §3)을 카테고리 기본값으로 채운다.

### Step 3. 검토 목록
- 카드 리스트: 썸네일, 가맹점, 결제일자, 금액, 카테고리, 입력 상태("확인 필요" / "입력 완료").
- 카드를 누르면 단건 작성 화면(`employee-mobile.md` ②)에서 해당 건을 수정한다. 식대 인원수, 미팅 목적, 출장 세부유형, 회사 양식 항목 등 카테고리별 입력은 단건 화면에서 한다.
- 상신 검증(`expense-lifecycle.md` §2)을 통과하지 못한 건은 "확인 필요" 배지와 누락 항목을 표시한다.
- 하단 합계: "6건 · 합계 132,000원 (입력 완료 4건)".

### Step 4. 일괄 상신
- [입력 완료 n건 상신하기] → 확인 다이얼로그 → 건마다 독립적으로 상신 처리(`expense-lifecycle.md` §1). 일부가 실패하면 성공 건은 상신되고 실패 건은 사유와 함께 남는다.
- "확인 필요" 건은 `draft`로 남아 홈에서 계속 작성할 수 있다.

## 3. 결재와 출력
- 결재자에게는 경비별로 결재 요청이 간다(알림톡 묶음 발송은 범위가 아님).
- 월말 엑셀은 영수증 1장 = 1행으로 출력된다(`tax-export.md`).
