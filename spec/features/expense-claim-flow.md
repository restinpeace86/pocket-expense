# [Spec] 지출결의서 작성 흐름 (영수증 여러 장 → 결의서 1건 → 일괄 결재)

관련: D-034, D-035 / 데이터: `expense_claims`, `expense_items` / 규칙: `spec/data/expense-lifecycle.md` / 화면: `spec/screens/worker-tax-processing.md`(E-02)

## 1. 개요 및 목적
- 출장이나 여러 건의 지출이 생겼을 때 직원이 영수증마다 따로 결재를 올리지 않도록, **지출결의서 1건(헤더) 안에 영수증 항목 N건(행)** 을 담아 한 번에 상신한다.
- 직원: 영수증 여러 장을 연속 촬영·다중 선택으로 한 번에 올리고, AI가 채운 표를 확인만 하고 상신.
- 결재자: "10/15 부산 출장 (3건, 72,000원)" 같은 결의서 1건을 보고 한 번에 승인/반려.
- 세무사무소: 월말 엑셀은 영수증 1장 = 1행으로 쪼개져 나간다(`tax-export.md`).
- 영수증이 한 장뿐이면 항목 1건짜리 결의서다. 단건과 다건은 같은 흐름이다. 화면: E-02(`spec/screens/worker-tax-processing.md`).
- 결제수단 기본값은 법인카드(D-048), 결의서 적요(지출 사유)는 필수다.

## 2. 구조: 1 Header + N Line Items
| 구분 | 내용 |
|---|---|
| 결의서 (헤더, `expense_claims`) | 제목(예: "10/15 부산 출장"), 청구자, 지출 사유(선택), 출장 정보(출장 결의서일 때: 출장지·기간·목적), 회사 양식 헤더 항목, 합계, 상태, 결재 |
| 영수증 항목 (행, `expense_items`) | 가맹점, 사용일자, 금액(공급가액·부가세), 카테고리, 결제수단, 카테고리별 입력, 영수증 원본, 회사 양식 항목 필드 |

## 3. 단계별 흐름
### Step 1. 결의서 시작 + 영수증 일괄 업로드
- 직원 홈 [+ 새 경비 청구하기] → `draft` 결의서 생성 후 결의서 편집 화면으로 이동.
- [영수증 추가]: 카메라 연속 촬영 또는 갤러리 다중 선택(결의서당 최대 30장, PDF 포함). 이후에도 계속 추가할 수 있다.
- 자차 출장비처럼 영수증이 없는 항목은 [영수증 없이 항목 추가]로 만든다.
- 결제수단 기본값을 결의서 편집 화면에서 한 번 고르면 새 항목에 적용된다(항목별 변경 가능).
- **출장이면 헤더의 [출장 경비] 스위치를 켜고 출장지·기간·목적을 입력한다.** 이후 올리는 영수증은 모두 출장비로 분류되고 세부 유형(출장 식비, 대중교통, 택시, 통행료·주차, 숙박, 자차, 기타)이 추천된다. 출장 중 식비는 일반 식대와 달리 출장 식비로 들어간다(`trip-expense.md` §1, D-035).

### Step 2. Gemini Vision 일괄 파싱
- 한 번에 고를 수 있는 영수증은 최대 10장(D-073). 영수증마다 항목 1건을 만들고(`parse_status='parsing'`) 보관본·썸네일을 저장한 뒤, 건별로 Gemini 파싱을 수행한다(업로드·파싱 동시 최대 3건, 실패 시 자동 1회 재시도).
- 추출: 가맹점, 사용일자, 합계·공급가액·부가세, 카테고리 추천(일반 식대/출장비/외부 미팅비/회사 물품 구매)과 세부 유형 추천(출장비·회사 물품 구매). 출장 결의서면 카테고리는 출장비로 고정. 규칙과 실패 처리는 `receipt-parser.md`.
- 파싱이 끝난 항목부터 표에 값이 채워진다. 실패한 항목은 "직접 입력 필요"로 표시한다.

### Step 3. 결의서 양식 자동 장착 및 검토
- 파싱 결과가 회사 지출결의서 양식(헤더 + 항목 표, `form-template.md`)에 자동으로 채워진다.
- **제목 자동 제안**: 비어 있으면 출장 결의서는 "{시작일 M/D} {출장지} 출장", 그 외는 "{첫 사용일 M/D} {첫 가맹점} 외 n건"을 제안한다. 직원이 수정할 수 있다.
- 항목 표 각 행: 썸네일, 가맹점, 사용일자, 금액, 카테고리, 입력 상태("확인 필요" / "입력 완료").
- 행을 누르면 항목 편집 화면에서 카테고리별 입력(식대 인원수, 미팅 목적, 출장 세부유형·자차 거리 등)과 양식 항목 필드를 채운다.
- 상단 합계: "3건 · 합계 72,000원 · 회사 지원 66,000원 · 개인 부담 6,000원", 정산 요약 "지급 60,000원 / 납부 6,000원".

### Step 4. 결재 요청(상신)
- [결재 요청] → 결재선 미리보기 확인 → 상신. 검증은 결의서 전체 기준(`expense-lifecycle.md` §2)이며, 실패하면 문제 항목으로 안내한다.
- 결재는 결의서 단위로 결재라인을 따라 진행되고(`approval-workflow.md`), 결재자는 결의서 1건을 한 번에 승인한다.
- 반려되면 결의서 전체가 `rejected`가 되고, 결재자가 지목한 문제 항목을 강조해 보여 준다. 직원은 해당 항목을 고치거나 삭제한 뒤 재상신한다.

## 4. 범위 밖
- 항목별 부분 승인/부분 반려, 결의서 간 항목 이동, 공통 태그.
