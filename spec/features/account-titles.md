# [Spec] 계정과목 매핑 (내부 분류 → 회계 계정과목)

관련: D-035, D-036, O-02 / 데이터: `account_titles`, `account_title_mappings`, `expense_items.account_title_*`

## 1. 개요
PocketExpense는 영수증(항목) 단위로 **내부 분류**(카테고리 + 출장 세부 유형)를 갖는다. 세무사무소는 **회계 계정과목** 단위로 장부를 입력한다. 두 분류를 매핑해서, 결재는 결의서 단위로 묶어 받되 월말에는 영수증 1장 = 1행으로 다시 풀어 **계정과목과 함께** 세무사무소에 전달한다.

```
[영수증 항목]  내부 분류(세분화)            →  계정과목(회계)
 점심 식대       일반 식대                    →  복리후생비
 부산 출장 점심   출장비 › 출장 식비           →  여비교통비
 KTX            출장비 › 대중교통             →  여비교통비
 톨게이트        출장비 › 통행료·주차          →  여비교통비
 호텔            출장비 › 숙박                →  여비교통비
 자차 기름값      출장비 › 자차 유류비          →  여비교통비
 거래처 식사      외부 미팅비                  →  기업업무추진비
        ↓ 결의서 1건으로 묶어 사내 결재
        ↓ 월말: 영수증 1행씩 [계정과목 | 내부 분류 | 금액 …] 로 세무사무소 전달
```

## 2. 계정과목 목록 (`account_titles`)
- 회사별로 관리한다. 회사 생성 시 기본값으로 아래 3개를 만든다(코드는 비워 둔다).
| 이름 | 코드 | 비고 |
|---|---|---|
| 복리후생비 | 811 | 일반 식대 |
| 여비교통비 | 812 | 출장비 전체 |
| 기업업무추진비 | 813 | 외부 미팅비. 2024년부터 "접대비"에서 명칭 변경 |
| 소모품비 | 830 | 회사 물품 구매 › 사무용품·소모품 (D-076) |
| 비품 | 212 | 회사 물품 구매 › 비품(오래 쓰는 물건: 책상·의자·노트북·프린터·복합기·에어컨 등 — 금액이 아니라 비품대장에 적을 물건, D-136) |
| 도서인쇄비 | 826 | 업무용 도서 구입 (D-102) |

- 관리자는 계정과목을 추가·이름 변경·코드 입력(세무사무소 회계 프로그램의 계정코드)·삭제할 수 있다. 매핑에 쓰이는 계정과목은 삭제할 수 없다.
- 계정과목명·코드는 세무사무소 기준을 따르는 것이 원칙이며, 화면에 "담당 세무사와 확인 후 설정하세요" 안내를 둔다.

## 4. 항목에 계정과목을 정하는 시점
- **상신 시** 서버가 각 항목의 내부 분류로 매핑을 찾아 `account_title_id`와 이름·코드 스냅샷(`account_title_name`, `account_title_code`)을 저장한다. 이후 매핑을 바꿔도 이미 상신된 항목은 바뀌지 않는다(D-018과 같은 원칙).
- **관리자 개별 조정**: 관리자는 결의서 상세에서 항목별 계정과목을 다른 계정과목으로 바꿀 수 있다(상태 무관). 계정과목 외의 값(금액 등)은 바꿀 수 없다. 조정된 항목은 "계정 조정됨" 표시.
- 직원과 결재자 화면에는 계정과목을 보여 주지 않는다(내부 분류로 충분). 관리자 화면과 월말 출력에만 표시한다.

## 5. 월말 출력에서의 사용
- 엑셀 시트1 각 행(영수증 1건)에 계정과목명·계정코드·내부 분류(카테고리·세부 유형)를 함께 적는다(`tax-export.md` §3.2).
- 요약 시트에 계정과목별 합계와 계정과목 안의 세부 유형별 소계를 둔다(예: 여비교통비 = 출장 식비 + 대중교통 + 통행료·주차 + …).
- 더존/세무사랑 업로드 양식 변환(O-02)은 이 계정과목·코드를 그대로 사용한다.

> (D-138) 기본 계정코드는 **더존(Smart A·위하고) 기본 계정코드**다: 복리후생비 811 · 여비교통비 812 · 기업업무추진비 813 · 차량유지비 822 · 교육훈련비 825 · 도서인쇄비 826 · 소모품비 830 · 지급수수료 831 · 비품 212. 법정 표준이 아니므로 세무사무소 번호가 다르면 관리자가 바꾼다. 위 표의 코드 칸이 (빈칸)인 행도 이 값을 쓴다.
> (D-139) 계정코드는 [계정과목] 목록과 세무 마감 엑셀에만 보인다. 지출 승인 화면·분류별 연결 고르기에서는 이름만(승인자에게 번호는 필요 없음).
