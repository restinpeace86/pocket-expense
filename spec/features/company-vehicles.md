# [Spec] 회사차량 (D-105)

## 1. 목적
회사 명의 차량에 쓴 돈(주유·정비·세차 등, 계정과목 차량유지비)을 차량별로 모아 세무사가 업무용 승용차 관련 비용으로 정리할 수 있게 한다.
직원 개인 차량으로 출장 이동한 유류비(자차 유류비)는 이 기능이 아니다(`trip-expense.md` §4, 직원 [내 정보] 차량번호).

## 2. 관리자 설정 (`/admin/vehicles`, 설정 › 회사차량)
- 등록: 별칭(1~30자, 예: 영업 1호차) + 차량번호(2~20자, 공백은 지움). 사용 중인 차량끼리 차량번호가 겹칠 수 없다.
- 수정: 별칭·차량번호. 처분·반납한 차량은 삭제 대신 **사용 안 함**(지난 결의서 연결 보존), 다시 사용 가능.
- 목록: 차량마다 이번 달 차량유지비(그 차량을 고른 결의서의 영수증 합계, 사용일 기준).
- 권한: 같은 회사 멤버는 열람(결의서에서 고르기), 쓰기는 관리자 이상. 다른 회사 차량은 보이지도 고를 수도 없다(RLS, 복합 FK).

## 3. 결의서
- 지출 카테고리 [그 밖의 경비 › 회사차량]을 고르면 차량 칩이 나온다. 등록된 사용 중 차량이 있으면 **필수**(상신 검증 `vehicle`), 없으면 "관리자가 [설정 › 회사차량]에 등록하면 여기서 고를 수 있어요" 안내만.
- 저장은 `set_claim_category(p_vehicle_id)`로만(직원 직접 update 불가). 회사차량이 아닌 카테고리로 바꾸면 차량은 비운다. 이미 고른 차량이 나중에 사용 안 함이 돼도 그 결의서에는 남는다.
- 결재 화면·직원 결의서 상세: "📂 회사차량 · 🚙 {별칭} ({차량번호})".

## 4. 하지 않는 것 (현재 범위 밖)
- 주행거리·운행일지(업무용 승용차 운행기록부), 보험·자동차세 관리, 차량별 세무 엑셀 열 — 필요하면 별도 Spec.
