## A. 서류 → 엑셀 변환 (누구나)

### A-1. 들어가는 곳
- 채팅 사진·PDF 메시지 메뉴(길게 누르기·오른쪽 클릭) **[엑셀로 변환]** — 모든 대화방.
- 직원 홈 메뉴 **[서류 → 엑셀]** — 기기에서 사진·PDF 고르기, 휴대폰은 바로 찍기.
- [내 변환] 목록(같은 화면 위 탭).

### A-2. 비용·제한 (8-94 결정 그대로)
- **1쪽 1크레딧**, 한 번에 5쪽까지, 파일 20MB. **직원 화면에는 크레딧을 표시하지 않는다**(2026-11-11). 확인 창은 파일·업무 서류 안내·[변환하기]만.
- 회사 크레딧이 모자라면 "지금은 변환할 수 없어요. 관리자에게 문의해 주세요"(숫자 없이).
- 쓴 크레딧은 관리자 **[요금제 › 크레딧 사용 내역]**(날짜·사람·내용·크레딧, 이번 달 합계: 영수증 읽기 / 서류 → 엑셀)에서 본다. 돌려준 건 "돌려줌 0"으로 남김.
- 업무 문서만: 확인 창에 "회사 업무 서류만 변환해 주세요(개인 서류는 피해 주세요)".
- AI가 표를 못 찾으면 크레딧을 돌려준다(직원에게는 "표를 찾지 못했어요"만).

### A-3. 결과 보기·고치기
- AI(Gemini 비전)가 쪽마다 **표 모델**을 만든다: 행·열, 합친 칸, 열 너비·행 높이, 테두리, 글자(굵게·맞춤·크기), 칸 글자.
- **PC(md 이상)**: 왼쪽 원본(쪽 넘기기·확대), 오른쪽 엑셀 같은 표 — 칸을 눌러 글자 고치기, Tab/화살표 이동, 되돌리기, **행 추가/삭제**(2026-11-11 범위 확정).
- 열 추가/삭제·칸 합치기/나누기·글꼴·색·테두리는 앱에서 하지 않는다 → 안내 "더 손보려면 [엑셀 받기] 후 엑셀에서 고쳐 주세요". (행을 지우면 그 행에 걸친 합친 칸은 한 행 줄어든다.)
- **휴대폰**: 미리보기(확대·좌우 스크롤) + 받기만. "고치기는 PC에서 할 수 있어요" 안내.
- 쪽이 여러 개면 시트 탭(1쪽, 2쪽 …).

### A-4. 받기·확정
- **[PDF 받기]**, **[엑셀 받기]** — 같은 표 모델로 만든다(PDF는 한글 글꼴 포함, A4 맞춤).
- 확정: **[회사에 공유하고 확정]**(기본) / **[나만 보기로 확정]**. 확정하면 [내 변환]·회사 공유 목록에 남는다(파일 보관함과 같은 회사 저장 공간을 쓴다).
- 확정하지 않은 초안은 **30일 뒤 삭제**(원본 포함).
- 결과물 아래 "AI가 만든 표예요. 숫자·글자를 꼭 확인해 주세요."

### A-5. 정확도 안내
- 표로 된 서식은 잘 됨. 손글씨·도장·표 없는 자유 배치는 틀릴 수 있어 고치기 단계가 있다.

## B. 회사 양식 등록 (관리자)

### B-1. 들어가는 곳
- 채팅 사진·PDF 메뉴 **[회사 양식으로 등록]**(관리자 이상만 보임).
- 관리자 설정 › **[회사 양식]** — 등록된 양식 목록·칸 사용(예: 1/3장)·[양식 추가].
- **등록 작업은 PC(md 이상)에서만**(2026-11-11). 휴대폰에서 [회사 양식으로 등록]을 누르면 "양식 등록은 PC에서 해 주세요" + [담아 두고 PC에서 이어 하기] → 파일이 [회사 양식]의 '등록 대기'에 들어가고, PC에서 열면 그 파일로 바로 시작. 휴대폰의 [회사 양식] 화면은 목록 보기만.

### B-2. 흐름
1. 파일·사진 고르기(또는 채팅에서 바로).
2. **어떤 문서인가요?** — 휴가신청서 / 일반 결재 문서(품의서·구매요청서·시말서 등) / (지출결의서는 기존 [지출결의서 양식] 화면으로 안내). 나중에: 연장·휴일근무 신청서, 출장신청서.
3. AI가 레이아웃 읽기(A-3과 같은 표 모델) + **칸 찾기**: 값이 들어갈 칸마다 이름("성명", "휴가 기간" …)과 연결할 우리 데이터를 제안.
4. **칸 연결 화면**(PC): 왼쪽 양식 미리보기(칸에 색 표시), 오른쪽 칸 목록.
   - ✅ **연결됨** — 우리 데이터(아래 B-3). 다른 데이터로 바꾸기 가능.
   - ⚠️ **우리 데이터에 없어요** — 관리자가 고름:
     1. **신청할 때 직원이 입력** — 종류(글·긴 글·날짜·숫자·선택지), 필수 여부, 선택지. 휴가 최대 5개, 일반 결재 문서 최대 15개
     2. **고정 값** — 회사 공통 문구
     3. **비워 두기** — 출력 뒤 손으로 씀
     4. **빼기** — 양식에서 그 칸을 지움
   - 결재란은 결재라인 자동(이름·직급·날짜 — 서명 이미지는 이번 범위 아님).
   - 모든 ⚠️ 칸을 정해야 [등록] 가능.
5. 레이아웃도 A-3처럼 고칠 수 있음(글자·칸).
6. 이름 정하기(기본: AI가 읽은 제목, 예: "휴가신청서") → **[등록]**.
7. AI 다시 읽기는 1장당 2번까지(잘못 읽었을 때).

### B-3. 연결할 수 있는 우리 데이터
- 공통: 회사명, 신청자 이름·부서·직급·사번(있으면), 신청일, 문서 번호, 결재란.
- 휴가: 휴가 종류, 시작일·종료일(기간), 일수/시간, 반차 구분, 사유, 남은 연차(신청 시점), 증빙 첨부 여부.
- 일반 결재 문서: 공통만(나머지는 직원 입력).

### B-4. 개수·비용
- 칸: 스타터 0 · 프로 1 · 비즈니스 3(지출결의서 양식은 별도). **결제가 꺼진 동안은 모든 회사 1장**(D-250) — 목록 칸 막대에 [칸 추가 신청], 운영자 [양식 칸 신청]에서 +1장.
- **칸을 다 쓰면**(2026-11-11): [양식 추가]·채팅 [회사 양식으로 등록]을 누를 때 "회사 양식 등록 횟수를 다 썼어요(n/n장). 양식을 더 등록하려면 추가 결제가 필요해요(1장 2만 원, 한 번 결제). 이미 등록한 양식을 고치거나 새 버전으로 바꾸는 것은 무료예요." + [추가 신청](결제가 꺼진 동안 운영자에게) / [등록된 양식 바꾸기]. 스타터는 "프로 요금제부터 회사 양식을 등록할 수 있어요". 추가 1장 **2만 원(한 번 결제)** — 결제가 꺼진 동안은 [추가 신청] → 운영자가 칸을 늘려 줌.
- 같은 칸의 양식 고치기·새 버전 올리기 무료, 양식을 지우면 칸이 빈다.
- 등록 과정의 AI는 **크레딧을 쓰지 않음**.

### B-5. 버전
- 양식을 고치면 새 버전. 이미 낸 문서는 **낼 때의 버전**으로 계속 나온다(칸이 다를 수 있어서 — 지출결의서와 다름).

## C. 휴가신청서를 회사 양식으로 (B 다음 첫 적용)
- 직원 휴가 신청 화면은 그대로. 회사 휴가신청서 양식에 '직원 입력' 칸이 있으면 신청 화면 아래 **[회사 추가 항목]**(최대 5개, 지난 값 미리 채움, 필수 비면 신청 안 됨).
- 값은 휴가 신청 줄의 `custom_payload`(JSON, 키 = 칸 key) + 쓴 양식 버전.
- 받기: 직원 휴가 상세, 관리자 근태 승인 상세 → **[휴가신청서 PDF]·[엑셀]**(회사 양식 모양). 결재란 = 승인한 사람·날짜. 승인 전이면 "결재 전" 표시.
- 회사 양식이 없으면 지금처럼(기본 모양 PDF는 이번 범위 아님).
- 구현 세부(D-253): 결재란 1번째 = 신청한 사람, 2번째 = 승인한 사람(승인 전 "결재 전"·반려 "반려"), 3~5번째 빈칸. 남은 연차는 신청할 때 값을 저장. 직원 고르기는 이름으로 저장.

- 관리자 요금제: [이번 달 서류 → 엑셀 변환 n / 한도] 막대 + 다시 채워지는 날, [크레딧 사용 내역]에는 한도 넘은 변환만
- 요금 카드·요금 기준에 한 줄씩

## G. 회사 양식 확장 — 근태 양식 · 양식 종류 · [결재 문서] 한 화면 (D-279, 2026-11-14 · 시안 승인 대기)

### G-0. 원칙
- 양식은 두 종류.
  - **앱 기록이 바뀌는 양식**(휴가·근태 정정·휴일/연장근무·지출결의): 직원은 지금 앱 신청 화면 그대로 쓴다. 회사 양식은 **결재 끝난 문서의 모양(출력)**과 **회사 추가 항목(최대 5칸)**만. 일반 결재 문서로 등록해 쓰면 연차·출퇴근 기록이 안 바뀌므로 허용하지 않는다(등록 때 종류를 '근태'로 안내).
  - **문서만 오가는 양식**(품의서·구매요청서 등): 종류별 표준 칸 + 직원 쓰기 한 화면([결재 문서]).
- 회사마다 화면을 따로 만들지 않는다. 회사 전용 화면이 필요하면 **유료 맞춤 지원(건당 3만 원 정도, VAT 별도, 확정 전)** — 안내·문의만, 운영자가 받아 처리.

### G-1. 1단계 — 근태 정정·휴일근무 회사 양식
- `company_forms.kind`에 `correction`(근태 정정 신청서), `overtime`(휴일·연장근무 신청서) 추가. 등록·칸 연결은 휴가신청서(§B·§C)와 같음.
- 자동 채움 칸: 공통(회사명·신청자·부서·직급·사번·신청일·문서 번호·결재란 1~5) +
  - 근태 정정: 정정 날짜, 원래 출근·퇴근, 바꿀 출근·퇴근, 정정 사유, 정정 후 머문 시간
  - 휴일·연장근무: 근무 날짜, 출근·퇴근(QR 기록), 근무 시간, 한 일
- 신청 화면(정정·휴일 근무 시트) 아래 [회사 추가 항목](최대 5개, §C와 같음). 값은 `attendance_requests.custom_payload` + `form_id`.
- 받기: 직원 그날 상세, 관리자 근태 승인 상세 → [근태 정정 신청서 PDF]·[엑셀] / [휴일근무 신청서 PDF]·[엑셀]. 결재란 1 = 신청자, 2 = 승인자(승인 전 "결재 전", 반려 "반려").
- 근태 양식(휴가·정정·휴일근무)은 요금 칸 수에 안 센다.

### G-2. 2단계 — 양식 종류와 종류별 표준 칸
- 등록 첫 단계에서 **종류 고르기**(AI가 양식 제목으로 먼저 골라 둠, 관리자가 바꿀 수 있음).
  - 근태(앱 신청 흐름): 휴가신청서 · 근태 정정 신청서 · 휴일·연장근무 신청서
  - 결재 문서: 품의서 · 구매요청서 · 출장신청서 · 외근신청서 · 재택근무 신청서 · 조퇴·외출 신청서 · 시말서(경위서) · 사직서 · 휴직·복직원 · 기타(이름 직접)
- 종류별 **표준 칸**(입력 방식 포함). 예:
  - 품의서: 제목(글) · 품의 내용(긴 글) · 금액(금액) · 기간(기간) · 거래처(글) · 지급 방법(고르기)
  - 구매요청서: 품목 표(품목·규격·수량·단가·금액, 줄 추가) · 구매 사유(긴 글) · 납기(날짜) · 구매처(글)
  - 출장신청서: 출장지 · 기간 · 목적 · 동행자(직원 고르기) · 예상 경비(금액) · 교통수단(고르기)
  - 재택근무: 날짜·기간 · 사유 · 업무 내용 / 조퇴·외출: 날짜 · 시각(부터~까지) · 사유
  - 시말서: 발생일 · 경위 · 원인 · 재발 방지 대책 / 사직서: 퇴직 희망일 · 사유 / 휴직·복직원: 종류(고르기) · 기간 · 사유
  - 기타: 표준 칸 없음(모두 직원 입력)
- AI가 회사 양식의 빈칸을 표준 칸에 짝짓고, 짝이 없는 칸은 '직원 입력'(글·날짜·숫자 중 추정) → 관리자가 PC에서 확인·수정(§B 칸 연결 화면에 '표준 칸' 열 추가).
- 입력 방식: 글 · 긴 글 · 숫자 · 금액 · 날짜 · 기간 · 시각 범위 · 고르기 · 체크 · 직원 고르기 · 표(줄 추가) · 첨부.

### G-3. 3단계 — [결재 문서] 직원 쓰기 한 화면
- 들어가는 곳: 직원 홈 메뉴 [결재 문서], 하단 [+] 시트에 [결재 문서 쓰기]. 회사가 결재 문서 양식을 하나도 등록 안 했으면 메뉴를 숨긴다.
- 화면: 위 탭 = 등록된 결재 문서 종류(품의서 | 구매요청서 | …) → 탭마다 [내 문서] 목록(작성 중·결재 중·승인·반려) + [새로 쓰기].
- 쓰기: 양식의 '직원 입력' 칸만 위→아래 순서로, 자동 채움 칸은 회색으로 보여 줌, 첨부(사진·PDF 최대 5개), 자동 임시저장, [미리보기](회사 양식 모양), 상신 확인 창에 결재선.
- 결재선: 양식마다 지정(기본 = 회사 기본 결재라인). 여러 단계 가능(지출결의 결재라인과 같은 방식).
- 결재: 결재함에 함께(종류 칩), 상세는 회사 양식 모양 미리보기 + 첨부 + 승인/반려(사유). 반려되면 고쳐서 다시 상신(회차). 이미 처리된 건은 막고 안내(D-277과 같음).
- 알림: 결재 요청·승인·반려 → 앱 알림 + 채팅 [알림]방 카드(D-247).
- 받기: 회사 양식 모양 PDF·엑셀, 결재란 자동(단계별 이름·날짜).
- 관리자: [결재 문서] 목록 — 종류·달·상태·사람 필터, 검색.
- 데이터: `approval_documents(id, company_id, member_id, form_id, form_version, doc_type, title, payload jsonb, status draft|submitted|approved|rejected, current_round, submitted_at, decided_at)`, `approval_document_steps(document_id, company_id, round, step_order, approver_member_id, status, reason, acted_at)`, `approval_document_files`. 모두 company_id 복합 FK·RLS 강제·쓰기는 함수, 격리 테스트 필수.
- 쓸 수 있는 사람: 처음엔 모든 직원(부서 제한은 나중).

### G-4. 4단계 — 요금·랜딩·맞춤 지원 안내
- 요금(운영 DB 승인 필요): 스타터 = 지출결의서만 / 프로 = 근태 양식 + 결재 문서 3개 / 비즈니스 = 근태 양식 + 결재 문서 5개. `form_slots` 3·5, `form_slots_unlimited` 끔, 칸 수는 결재 문서만 센다.
- 랜딩·요금표: "회사 양식: 지출결의서 · 근태 양식(휴가·정정·휴일근무) · 결재 문서 n개" + [다른 점] "쓰던 양식 그대로" 문구를 실제 목록으로. 그 아래 작게 "우리 회사 전용 화면이 필요하면 유료 맞춤 지원(건당 3만 원, VAT 별도)".
- 관리자 [회사 양식] 화면 아래 안내 카드: "이 양식만의 전용 화면이 필요하면 맞춤 제작을 요청하세요(건당 3만 원·VAT 별도)" → [맞춤 제작 문의](운영자에게 요청, 결제 붙기 전에는 문의로).
- 지금(1~3단계 전) 요금표는 "회사 양식: 지출결의서·휴가신청서"(D-279 ⑦, 반영됨).
