> - 추가 데이터는 지출결의서처럼 JSON(`custom_payload`)
> - 연 결제·견적서 화면은 실제 결제를 붙일 때(보류)
>
> 사용자 결정 2026-11-11(시안 1차 피드백):

> - **회사 양식 등록(칸 연결)은 PC에서만**. 휴대폰에서 누르면 "PC에서 해 주세요" + 파일을 [회사 양식]에 담아 두기
> - 엑셀 변환 앱 안 고치기 = **글자 고치기 + 행 추가/삭제 + 되돌리기**. 그 이상(칸 합치기·나누기·글꼴·색)은 **[엑셀 받기] 후 엑셀에서** — 앱에서 고치고 바로 [PDF 받기], 더 손보려면 [엑셀 받기]
>

## A. 서류 → 엑셀 변환 (누구나)

### A-1. 들어가는 곳
- 채팅 사진·PDF 메시지 메뉴(길게 누르기·오른쪽 클릭) **[엑셀로 변환]** — 모든 대화방.
- 직원 홈 메뉴 **[서류 → 엑셀]** — 기기에서 사진·PDF 고르기, 휴대폰은 바로 찍기.
- [내 변환] 목록(같은 화면 위 탭).

### A-2. 비용·제한 (8-94 결정 그대로)
- **1쪽 1크레딧**, 한 번에 5쪽까지, 파일 20MB. **직원 화면에는 크레딧을 표시하지 않는다**(2026-11-11). 확인 창은 파일·업무 서류 안내·[변환하기]만.
- 회사 크레딧이 모자라면 "지금은 변환할 수 없어요. 관리자에게 문의해 주세요"(숫자 없이).
- 쓴 크레딧은 관리자 **[요금제 › 크레딧 사용 내역]**(날짜·사람·내용·크레딧, 이번 달 합계: 영수증 읽기 / 서류 → 엑셀)에서 본다. 돌려준 건 "돌려줌 0"으로 남김.
- 업무 문서만: 확인 창에 "회사 업무 서류만 변환해 주세요(개인 서류는 피해 주세요)".
- AI가 표를 못 찾으면 크레딧을 돌려준다(직원에게는 "표를 찾지 못했어요"만).

### A-3. 결과 보기·고치기
- AI(Gemini 비전)가 쪽마다 **표 모델**을 만든다: 행·열, 합친 칸, 열 너비·행 높이, 테두리, 글자(굵게·맞춤·크기), 칸 글자.
- **PC(md 이상)**: 왼쪽 원본(쪽 넘기기·확대), 오른쪽 엑셀 같은 표 — 칸을 눌러 글자 고치기, Tab/화살표 이동, 되돌리기, **행 추가/삭제**(2026-11-11 범위 확정).
- 열 추가/삭제·칸 합치기/나누기·글꼴·색·테두리는 앱에서 하지 않는다 → 안내 "더 손보려면 [엑셀 받기] 후 엑셀에서 고쳐 주세요". (행을 지우면 그 행에 걸친 합친 칸은 한 행 줄어든다.)
- **휴대폰**: 미리보기(확대·좌우 스크롤) + 받기만. "고치기는 PC에서 할 수 있어요" 안내.
- 쪽이 여러 개면 시트 탭(1쪽, 2쪽 …).

### A-4. 받기·확정
- **[PDF 받기]**, **[엑셀 받기]** — 같은 표 모델로 만든다(PDF는 한글 글꼴 포함, A4 맞춤).
- 확정: **[회사에 공유하고 확정]**(기본) / **[나만 보기로 확정]**. 확정하면 [내 변환]·회사 공유 목록에 남는다(파일 보관함과 같은 회사 저장 공간을 쓴다).
- 확정하지 않은 초안은 **30일 뒤 삭제**(원본 포함).
- 결과물 아래 "AI가 만든 표예요. 숫자·글자를 꼭 확인해 주세요."

### A-5. 정확도 안내
- 표로 된 서식은 잘 됨. 손글씨·도장·표 없는 자유 배치는 틀릴 수 있어 고치기 단계가 있다.

## B. 회사 양식 등록 (관리자)

### B-1. 들어가는 곳
- 채팅 사진·PDF 메뉴 **[회사 양식으로 등록]**(관리자 이상만 보임).
- 관리자 설정 › **[회사 양식]** — 등록된 양식 목록·칸 사용(예: 1/3장)·[양식 추가].
- **등록 작업은 PC(md 이상)에서만**(2026-11-11). 휴대폰에서 [회사 양식으로 등록]을 누르면 "양식 등록은 PC에서 해 주세요" + [담아 두고 PC에서 이어 하기] → 파일이 [회사 양식]의 '등록 대기'에 들어가고, PC에서 열면 그 파일로 바로 시작. 휴대폰의 [회사 양식] 화면은 목록 보기만.

### B-2. 흐름
1. 파일·사진 고르기(또는 채팅에서 바로).
2. **어떤 문서인가요?** — 휴가신청서 / 일반 결재 문서(품의서·구매요청서·시말서 등) / (지출결의서는 기존 [지출결의서 양식] 화면으로 안내). 나중에: 연장·휴일근무 신청서, 출장신청서.
3. AI가 레이아웃 읽기(A-3과 같은 표 모델) + **칸 찾기**: 값이 들어갈 칸마다 이름("성명", "휴가 기간" …)과 연결할 우리 데이터를 제안.
4. **칸 연결 화면**(PC): 왼쪽 양식 미리보기(칸에 색 표시), 오른쪽 칸 목록.
   - ✅ **연결됨** — 우리 데이터(아래 B-3). 다른 데이터로 바꾸기 가능.
   - ⚠️ **우리 데이터에 없어요** — 관리자가 고름:
     1. **신청할 때 직원이 입력** — 종류(글·긴 글·날짜·숫자·선택지), 필수 여부, 선택지. 휴가 최대 5개, 일반 결재 문서 최대 15개
     2. **고정 값** — 회사 공통 문구
     3. **비워 두기** — 출력 뒤 손으로 씀
     4. **빼기** — 양식에서 그 칸을 지움
   - 결재란은 결재라인 자동(이름·직급·날짜 — 서명 이미지는 이번 범위 아님).
   - 모든 ⚠️ 칸을 정해야 [등록] 가능.
5. 레이아웃도 A-3처럼 고칠 수 있음(글자·칸).
6. 이름 정하기(기본: AI가 읽은 제목, 예: "휴가신청서") → **[등록]**.
7. AI 다시 읽기는 1장당 2번까지(잘못 읽었을 때).

### B-3. 연결할 수 있는 우리 데이터
- 공통: 회사명, 신청자 이름·부서·직급·사번(있으면), 신청일, 문서 번호, 결재란.
- 휴가: 휴가 종류, 시작일·종료일(기간), 일수/시간, 반차 구분, 사유, 남은 연차(신청 시점), 증빙 첨부 여부.
- 일반 결재 문서: 공통만(나머지는 직원 입력).

### B-4. 개수·비용
- 칸: 스타터 0 · 프로 1 · 비즈니스 3(지출결의서 양식은 별도). 추가 1장 **2만 원(한 번 결제)** — 결제가 꺼진 동안은 [추가 신청] → 운영자가 칸을 늘려 줌.
- 같은 칸의 양식 고치기·새 버전 올리기 무료, 양식을 지우면 칸이 빈다.
- 등록 과정의 AI는 **크레딧을 쓰지 않음**.

### B-5. 버전
- 양식을 고치면 새 버전. 이미 낸 문서는 **낼 때의 버전**으로 계속 나온다(칸이 다를 수 있어서 — 지출결의서와 다름).

## C. 휴가신청서를 회사 양식으로 (B 다음 첫 적용)
- 직원 휴가 신청 화면은 그대로. 회사 휴가신청서 양식에 '직원 입력' 칸이 있으면 신청 화면 아래 **[회사 추가 항목]**(최대 5개, 지난 값 미리 채움, 필수 비면 신청 안 됨).
- 값은 휴가 신청 줄의 `custom_payload`(JSON, 키 = 칸 key) + 쓴 양식 버전.
- 받기: 직원 휴가 상세, 관리자 근태 승인 상세 → **[휴가신청서 PDF]·[엑셀]**(회사 양식 모양). 결재란 = 승인한 사람·날짜. 승인 전이면 "결재 전" 표시.
- 회사 양식이 없으면 지금처럼(기본 모양 PDF는 이번 범위 아님).

## D. 일반 결재 문서 (2단계 — 이번 시안은 구조만)
- 직원 홈 [결재 문서 쓰기] → 회사가 등록한 일반 결재 문서 고르기 → **양식에서 자동으로 만든 입력 화면**(직원 입력 칸만, 순서 = 양식 위→아래) → 결재선(기존 결재라인) → 상신.
- 결재: 결재함에 함께(승인·반려·사유), 알림은 앱 알림 + 채팅 [알림]방(D-247).
- 출력: 회사 양식 모양 PDF·엑셀, 결재란 자동.
- 데이터: `approval_documents(company_id, member_id, form_id, form_version, payload jsonb, status, approval line)`.
