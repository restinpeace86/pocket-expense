## A. 도움말 지식 DB (1단계)
### A-1. 데이터
- `help_articles`(id 글자 키, category basic|expense|attendance|convert|together, audience all|admin, needs attendance|calendar|chat|bus|null, title, summary(한 줄), keywords text[], path·admin_path·path_label([이동]), sim(시뮬레이션 키 또는 없음), sort, published, updated_at, updated_by_name)
- `help_steps`(article_id, idx, body(단계 글, 해요체), image_path(공개 버킷 `help-images`, 없을 수 있음), image_alt)
- 읽기: 로그인한 사람 누구나(공개 글만, 관리자 글은 관리자만). 쓰기: 운영자(앱 운영자 화면)만.
- 처음 데이터: 지금 31편을 옮기고, 기능별 상세 글로 60~80편까지 늘림(단계 3~6개, 버튼 이름은 [ ]).
### A-2. 검색
- DB 함수 `help_search(q, admin, features)`: 키워드 일치 + 제목·요약·단계 글 trigram 유사도로 상위 4편(회사가 쓰지 않는 기능 글 뺌). 지금 코드의 글 고르기를 대신함
- 답변은 지금처럼 Gemini가 고른 글만 보고 짧게(지어내지 않음, 하루 20번, 크레딧 없음)
### A-3. 답변 화면(풍부하게)
- AI 답변 카드 아래 **가장 가까운 글 1편을 펼쳐서**: 단계 1·2·3…(글 + 화면 그림, 그림은 눌러 크게) + [▶ 화면으로 보기](그 글에 시뮬레이션이 있으면 그 자리에서 재생) + [해당 메뉴로 이동 ➔]
- 카테고리 탭·글 목록·글 펼치기도 같은 모양(단계 + 그림 + 시뮬레이션)
### A-4. 화면 그림
- 실제 화면을 예시 데이터로 자동 캡처(회사 이름 "예시 회사", 사람 이름은 예시) → `help-images`에 올림. 기능이 바뀌면 다시 캡처(스크립트 `scripts/help-shots.mjs`)
- 휴대폰 화면 기준(390), 관리자 글은 PC(1280) 일부 잘라서
### A-5. 운영자 화면
- 앱 운영자 › [도움말 글]: 목록(카테고리·대상·공개), 글 고치기(제목·요약·키워드·이동·시뮬레이션·단계 글/그림 올리기·순서), 미리보기, 공개 켜기·끄기

## B. 기능 시뮬레이션 (2단계)
- 지금 영수증 시뮬레이션과 같은 방식: 화면 안 시연(서버 호출 없음), 보이면 한 번 자동 재생, 단계 버튼으로 다시 보기, 움직임 줄이기면 멈춘 그림
- 6개: ① QR 출퇴근(출근 단말 QR → 휴대폰으로 찍기 → 출근 기록 → 퇴근·월 근태) ② 휴가 신청 → 회사 양식(신청·남은 연차 → 대표 승인 → 회사 휴가신청서 PDF) ③ 서류 → 엑셀(종이 표 사진 → AI가 표로 → 고치기 → 엑셀·PDF) ④ 회의실(빈 시간 눌러 예약 → 참석자 캘린더 → 10분 전 알림 카드) ⑤ 채팅(결의서 대화 → 서브 대화 → 파일 영구 보관) ⑥ 월말 마감(승인된 지출 → 카드 대조 → 마감 파일 → 세무사무소 화면)
- 공용 틀 `components/sims/`: 랜딩과 도움말이 같은 컴포넌트를 씀(도움말 글의 `sim` 키)

## C. 랜딩 개편 (3단계)
- 순서: 히어로 → 다섯 기둥(경비·결재 / 근태·휴가 / 협업(채팅·캘린더·회의실) / 문서·양식(서류 → 엑셀·회사 양식) / 세무 연계) → **기능 미리 보기**(탭 7개: 영수증(지금 것) + 새 6개, 탭을 누르면 그 시뮬레이션 재생) → 이어지는 부분 → 한 달 흐름 → 누구에게 좋은가 → 요금 → 후기 → FAQ
- 지금 있는 기능만 씀(D-200 원칙), 문구는 Moa-on

## D. 범위 밖
- 의미 검색(벡터·임베딩), 동영상, 사람 상담 채팅
