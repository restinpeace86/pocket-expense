# 채팅 파일 영구 보관 · 파일 보관함 (8-96) — 초안(승인 전, 시안 캔버스 "파일 영구 보관 시안")

> 출처: 사용자 결정(2026-11-09~10 대화): 채팅 첨부는 회사가 정한 기간(30·60·90일, D-204·D-212)이 지나면 그대로 자동 삭제 · 그중 오른쪽 클릭(PC)·길게 누르기(휴대폰) → **[영구 보관]**한 파일만 기간과 상관없이 계속 보관 · 보관 한도는 채팅 한도와 **따로**(요금제별) · 같은 Supabase 안 비공개 버킷 · 트래픽 안전장치(미리보기·기기 저장·크기 제한·예상 못 한 청구 막기).
> ⚠️ 아래 "정할 것"이 정해지기 전에는 구현하지 않는다.

## 1. 범위
- 채팅 메시지의 사진·파일 메뉴에 [영구 보관] → 보관함으로 **복사**(채팅 원본은 원래 보관 기간대로 지워짐).
- 보관할 때 공개 범위: **[나만 보기]**(보관한 사람만) / **[회사 공유]**(우리 회사 멤버 모두). 나중에 바꿀 수 있음(보관한 사람만).
- 직원 홈 메뉴 **[파일 보관함]**: 탭 [회사 공유] / [나만 보기], 검색(파일 이름·보관한 사람), 사용량 막대.
- 파일 메뉴: 열기 · 받기 · 공개 범위 바꾸기(보관한 사람) · 올라온 채팅으로 가기(그 방 참여자이고 메시지가 남아 있을 때) · 보관함에서 지우기(보관한 사람, 회사 공유는 관리자도).
- 범위 밖: 직접 파일 올리기(보관함에 채팅 없이 올리기), 폴더, 파일 버전, 외부 공유 링크, 서류→엑셀 변환 결과 보관(8-94 때 검토).

## 2. 한도·요금
| 요금제 | 채팅 사진·파일(그대로) | 영구 보관(새로) |
|---|---|---|
| 스타터 29,000원 | 1GB | **1GB** |
| 프로 49,000원 | 3GB | **3GB** |
| 비즈니스 89,000원 | 10GB | **10GB** |
- `billing_plans.vault_storage_mb`(1024/3072/10240). 무료 이용 = 스타터와 같음.
- 사용량 = 그 회사 보관 파일 원본 + 미리보기 합(나만 보기 포함, 회사 한도 하나).
- 다 차면 **새 보관만 막음**(`VAULT_FULL`) — 자동 삭제 없음. 시트에 "회사 보관 공간이 다 찼어요" + [파일 보관함에서 정리하기]. 채팅 보내기는 영향 없음.
- 70%·90%를 처음 넘을 때 관리자들에게 [알림]방 안내(하루 1번까지).
- 랜딩 요금 카드(D-205)에 "영구 보관 1GB/3GB/10GB" 줄 추가.

## 3. 데이터
- 비공개 버킷 `vault-files/{회사}/{보관 id}.{확장자}`(+ 사진은 `…_thumb.jpg`), 20MB(채팅과 같음).
- 표 `vault_files`: id, company_id, owner_member_id, scope('private'|'company'), name, size, content_type, path, thumb_path, source_room_id, source_message_id, created_at, scope_changed_at. 회사·멤버 복합 외래키(회사 격리).
- 보관은 서버(service role)가 채팅 원본을 **복사**: 요청한 사람이 그 방 참여자이고, 메시지가 지워지지 않았고 보관 기간 안이며, 한도 안일 때만. 같은 메시지를 같은 사람이 두 번 보관하면 이미 있는 것으로 안내.
- 읽기 권한(RLS): `scope='company'` = 같은 회사 멤버, `scope='private'` = 보관한 사람만. 파일 주소는 서명 주소(짧은 시간)로만.
- 지우기: 보관한 사람 / 관리자는 회사 공유만. 지우면 원본·미리보기 바로 삭제.
- 사람별 사용량 함수(관리자): 직원별 회사 공유·나만 보기 개수·용량만(나만 보기 파일 이름·내용은 안 보임).
- 회사 해지: 다른 자료와 같이 30일 뒤 삭제(약관 제17조).

## 4. 트래픽 안전장치
- 목록: 사진은 480px 미리보기만, 파일은 이름·크기만(트래픽 없음). 원본은 [열기]·[받기] 때만.
- **기기 저장**: 한 번 받은 보관 파일 원본은 브라우저 저장소(Cache Storage)에 보관 id로 저장 → 다음엔 서버에 가지 않고 바로 엶. 로그아웃하면 지움, 보관함에서 지워졌거나 볼 수 없게 된 파일은 목록을 받을 때 같이 지움.
- 파일 하나 20MB까지.
- **예상 못 한 청구 막기**: ① Supabase Pro의 Spend Cap 켜 두기(사용자, 8-97) ② 새벽 작업이 전체 저장 용량을 세어 Pro 포함량(100GB)의 70%를 넘으면 운영자 디스코드(`DISCORD_WEBHOOK_URL`)로 알림. 트래픽(egress)은 Supabase 사용량 화면에서 확인(자동 수집은 범위 밖).

## 5. 화면 (시안 캔버스 ①~⑥)
- ① 채팅 파일 메뉴: 받기 · **영구 보관**(설명 한 줄) · 읽음 확인(단체방) · 취소. 보관된 메시지는 말풍선에 작은 "보관됨" 표시.
- ② 영구 보관 시트: 파일 이름·크기·방·올린 사람, 설명("90일 뒤 자동 삭제 ↔ 보관하면 지울 때까지"), 누가 볼 수 있나요(나만 보기/회사 공유), 개인정보 경고, 회사 보관 공간 막대, [나만 보기로 보관]/[회사에 공유해 보관].
- ③ 파일 보관함: 탭·검색·목록(아이콘/미리보기, 이름, 크기·보관한 사람·날짜·방 이름)·사용량.
- ④ 보관 파일 메뉴: 열기(기기 저장 안내) · 받기 · 공개 범위 바꾸기 · 올라온 채팅으로 · 지우기.
- ⑤ 다 찼을 때 시트.
- ⑥ 관리자 설정 › [파일 보관]: 채팅 사용량(지금 있는 것) 옆에 영구 보관함 사용량, 사람별 사용량 표.

## 6. 정할 것
1. 보관 시트 기본 선택: **나만 보기**(추천) / 회사 공유
2. 관리자와 '나만 보기' 파일: **이름·내용은 못 보고 사람별 사용량만**(추천)
3. 퇴사(비활성) 멤버의 '나만 보기' 파일: **퇴사 처리 30일 뒤 삭제, 그 전에 관리자에게 안내**(추천) / 계속 보관 / 관리자에게 넘김
