# WORKON 도우미 1단계 (D-222 — 사용자 승인 2026-11-05)

> 사용자: "나만 보이는 글 끼워 넣기는 어려우면 도우미 방으로 가자. 도우미 방에서는 @WORKON 안 쳐도 대화처럼."
> 승인 범위: 조회와 화면 이동만 · AI는 Gemini · 실제 데이터는 지금 DB 함수가 권한을 확인해서 · 한 사람이 하루 30번.

## 1. 방
- 채팅 목록 맨 위 고정 줄 **[WORKON 도우미]**(AI 표시). 누르면 내 도우미 방 — 사람마다 하나(`chat_rooms.kind = 'assistant'`, `assistant_member_id`), 처음 누를 때 생김(`chat_assistant_room()`).
- 주인만 들어가고 주인만 글을 쓴다(다른 사람 초대·다른 사람 보기 불가 — DB가 막음 `ASSISTANT_ROOM`). 사진·파일은 보낼 수 없다(입력창의 사진·파일 버튼 없음).
- 그냥 대화하듯 친다(@WORKON 필요 없음). 처음 열면 안내 + 예시 버튼 [오늘 일정] [내일 회의실 빈 시간] [반려된 결의서] [승인 대기 몇 건?].
- 머리글 "조회·화면 이동 · 하루 30번". 답을 찾는 동안 "확인하고 있어요…".
- 메신저 스위치가 꺼진 회사는 없음(채팅 자체가 없음).

## 2. 할 수 있는 것 (조회·화면 이동만)
| 질문 예 | 하는 일 | 답 아래 버튼 |
|---|---|---|
| 오늘/내일/모레/11월 7일 일정 | 내 일정(만든 것 + 참석, 불참 제외) 그날 목록 | 캘린더에서 보기 |
| 내일 회의실 빈 시간 / 3층 회의실 오늘 언제 비어? | 회의실마다 08~20시 빈 시간(오늘은 지금 이후), 이름이 있으면 그 방만 | 회의실 예약 열기 |
| 임시저장한 결의서 / 반려된 결의서 / 내 경비 남은 거 | 내 작성 중·반려 결의서(제목·금액·반려 사유) | 결의서 열기(1건) / 내 결의서 보기 |
| 승인 대기 몇 건? | 관리자: 상신된 결의서(오래된 순) / 사전 검토자: 내 검토 차례 / 그 밖: 없음 | 결재하러 가기 |
| 회의실 예약 열어줘 / 새 결의서 쓰기 / 캘린더 열어줘 | 그 화면 바로가기 | 그 화면 |
| 도움말 / 뭐 할 수 있어? | 할 수 있는 것 안내 | — |
| 그 밖(분석·작성·검색·예약하기·승인하기 등) | "아직 도와드리지 못해요" + 할 수 있는 것 | — |

- 예약·승인·작성처럼 **바꾸는 일은 하지 않는다**(2단계 — 확인 절차 설계 뒤).

## 3. 어떻게 답하나
- **알아듣기**: 흔한 말(일정·회의실·결의서·반려·승인 대기·열어 줘·날짜 말)은 규칙으로 바로(`src/lib/assistant/intent.ts`, AI 비용 없음). 못 알아들은 질문만 Gemini에 "어느 도구인지"만 묻는다(JSON, 정해진 값만 받음 — 모르는 값은 unsupported).
- **데이터**: 질문한 사람 로그인 권한으로 지금 쓰는 함수·표에서 꺼낸다(`calendar_events_range`, `calendar_rooms`·`calendar_room_bookings`, 내 `expense_claims`, 결재 대기). 회사 분리·권한(RLS)이 그대로 지킨다. **AI에는 회사 데이터를 보내지 않는다**(질문 글만).
- **답 글**: 코드가 정해진 모양으로 쓴다(숫자·일정을 AI가 지어내지 않음). 서버(service role)만 'bot' 글로 넣는다.
- 같은 질문 글에 답은 한 번(`pushed_at`).

## 4. 하루 30번
- 한국 시간 오늘, 내 도우미 방에 내가 보낸 글 수. 31번째부터 "오늘은 도우미를 30번 다 썼어요. 내일 다시…"(AI 부르지 않음).

## 5. 데이터 (migration 120)
- `chat_rooms.kind 'assistant'` + `assistant_member_id`(회사 안 사람마다 하나, 복합 FK) / `chat_messages.kind 'bot'`(도우미 방에만, 보낸 사람 없음).
- 방 종류별 글 막기(트리거): 알림방 = notice만, 도우미 방 = 주인 text + bot만, bot은 도우미 방에만.
- 함수: `chat_assistant_room()`. 표 추가 없음.
- 확인: DB `supabase/tests/075_assistant_room.sql`, 단위 `src/lib/assistant/intent.test.ts`, 화면 `.responsive/live/e2e-assistant.mjs`.
