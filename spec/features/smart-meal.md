# [Spec] 식대 인원수 기반 스마트 분할

관련: D-009, D-010, D-018 / 계산 규칙 원본: `spec/data/expense-lifecycle.md` §5.1, §5.4

## 1. 개요
식대 영수증에는 식사 인원이 나오지 않으므로 직원이 인원수를 입력하고, 회사의 1인 한도 × 인원수를 기준으로 회사 지원금과 개인 부담금을 자동으로 나눈다.

## 2. 입력
- `headcount`(인원수): 필수, 기본값 1, 1~99 정수. 스테퍼(−/+) UI.
- `payment_method`: 개인카드/법인카드 선택(필수).

## 3. 계산 (요약)
```
한도 = 1인 한도 × 인원수
회사 지원금 = min(총액, 한도)
개인 부담금 = max(총액 − 한도, 0)
```
예) 1인 한도 10,000원, 3명, 총액 36,000원 → 한도 30,000원 → 회사 지원 30,000원 + 개인 부담 6,000원.

## 4. 실시간 안내 UI
- 금액·인원수가 바뀔 때마다 즉시 다시 계산해 표시한다.
  - "1인 한도 10,000원 × 3명 = 30,000원"
  - "회사 지원 30,000원 + 개인 부담 6,000원"
- 결제수단별 정산 안내 문구:
  - 개인카드: "회사가 30,000원을 지급합니다"
  - 법인카드: "개인 부담 6,000원을 회사에 납부해야 합니다" (부담금 0원이면 "추가 정산 없음")
- 한도 초과 시 개인 부담금을 주황색으로 강조한다.

## 5. 스냅샷
- 화면 계산은 현재 회사 한도로 하고, 상신 시 서버가 그 시점 한도로 재계산해 `applied_meal_limit_per_person`과 함께 저장한다. 상신 후 회사 한도가 바뀌어도 해당 경비 금액은 바뀌지 않는다.
