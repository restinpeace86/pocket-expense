# [Spec] 카카오내비 연동 자차 출장비 산정 기능

## 1. 개요
직원이 자차로 출장할 때, 출발지와 도착지 주소를 입력하면 카카오 모빌리티/내비 API를 활용해 실제 주행 거리(km)를 산출하고, 회사 설정 유류비 단가와 곱하여 투명하게 출장비를 계산하는 기능.

## 2. 요구사항 및 제약 사항 (Guardrails)
- **API 연동**: 서버 액션 또는 API Route를 통해 Kakao Mobility API(또는 길찾기/거리 측정 관련 엔드포인트)를 호출할 것 (`KAKAO_REST_API_KEY` 환경변수 사용).
- **자동 계산 로직**: 
  - 산출된 주행 거리 (`distance_km`) $\times$ 회사 설정 단가 (`companies.fuel_rate_per_km`, 기본 200원) = 청구 유류비 금액.
- **Fallback 처리**: 주소 검색이나 API 호출에 실패할 경우, 직원이 주행 거리(km)를 직접 수동으로 입력할 수 있는 입력 필드를 예외적으로 제공할 것.
