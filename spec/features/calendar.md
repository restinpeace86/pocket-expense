# 사내 캘린더 (D-206 — 사용자 승인 2026-11-04, migration 109)

> 사용자 논의 2026-11-04: 회사 안 업무 일정(회의·외근·출장) 공유. 외부 캘린더 연동 없음.
> "왼쪽에 팀별 직원 나열, 선택한 인원들 일정만 뜨게", "일정은 직원 누구나 — 나의 일정, 내가 포함된 회의",
> "회사 내 일정에 개인 병원 예약이 보이나?" → 비공개 옵션 없음. 채팅 연결(일정 카드)·반복 일정은 보류.
> "본인 일정만 보이는 게 기본, 사람 고르기에서 체크했을 때만", "결산 마감 일자도 넣자".
> "휴대폰에선 일자별로 리스트로 내리게, 웹에서 볼 때는 달력 형태로 — 구조는 local-open-spaces에 있어".
> 승인(2026-11-04): ① 직원은 홈 화면 [캘린더] 카드로 들어감(사용자가 보고 바꿀 수 있음) ② 월요일 시작 ③ 청구 마감(모두)·세무 마감(관리자만), 쉬는 날이면 앞 영업일 ④ 토요일 파랑, 일요일·공휴일 빨강 + 공휴일 이름(임시공휴일은 별도) ⑤ 마감일은 굵게 눈에 띄게 ⑥ 회의 10분 전 안내 = 채팅 [알림]방, Supabase 예약 작업 10분마다, 일정은 10분 단위로만.

## 1. 범위
- **같은 회사의 승인된 멤버끼리만**. 다른 회사·세무사무소는 볼 수 없다(DB에서 강제).
- 회사 안에서는 **모든 일정이 모두에게 보인다**(비공개 없음). 개인 사정(휴가·조퇴·외출)은 근태 쪽 일(O-11)이라 일정 종류에 넣지 않는다.
- 기능
  - 일정 만들기·고치기·지우기(만든 사람만), 참석자 초대, 참석자의 [참석]/[불참] 응답
  - 달력 보기(직원·관리자 같은 화면, 폭으로만 바뀜): **PC(md 이상) = 월 달력 / 휴대폰 = 그 달 날짜별 목록**
  - **기본은 내 일정만**. **사람 고르기**: 부서별 직원 목록에서 체크한 사람의 일정만 겹쳐 보기(사람마다 색)
  - **마감일 자동 표시**(§2-1), **주말·공휴일 색**(§2-2)
  - **회의 10분 전 안내**(§2-3)
- **보류**: 채팅 연결(채팅방에서 일정 만들기·일정 카드·공지 띠), 반복 일정, 외부 캘린더(구독 링크·구글·톡캘린더), 휴가·근태 표시

## 2. 일정
- 항목: 제목(100자), 종류(**회의 / 외근 / 출장 / 기타**), 시작·끝(날짜+시각, 또는 **종일** — 여러 날 가능, 시간 일정 14일·종일 31일까지), 장소(200자, 선택), 메모(2,000자, 선택), 참석자(선택, 100명까지).
- **시각은 10분 단위**(00:00 … 23:50). DB도 10분 단위가 아니면 받지 않는다(`TIME_UNIT_10MIN`).
- **누구의 일정인가**: 만든 사람 + 참석자. 예) A팀 김A가 회의를 만들고 B팀 이B를 참석자로 넣으면, 이B를 고르면 그 회의가 보인다.
- 만든 사람 = 자동으로 참석(응답 '참석'). 참석자 응답: 대기 / 참석 / 불참. 불참한 사람 일정에는 흐리게(줄 그은 제목).
- 고치기·지우기는 **만든 사람만**. 참석자는 응답만. 관리자도 남의 일정은 고치지 않는다.
- 시간을 바꾸면 참석자 응답은 다시 '대기'(만든 사람 제외), 10분 전 안내도 다시.
- 퇴사(비활성) 멤버: 지난 일정에는 이름 뒤 "(퇴사)", 사람 목록·참석자 고르기에서는 빠진다. 10분 전 안내도 받지 않는다.
- 시간대: 한국 시간 기준. 종일 일정은 날짜로 저장.

## 2-1. 마감일 자동 표시
- 고정 마감 규칙(D-161, `src/lib/expense/deadline.ts`)으로 계산해 달력에 띄운다(저장하지 않음). 모든 회사 같은 규칙. 쉬는 날(주말·공휴일)이면 앞 영업일 — 앞 달 말로 넘어가도 표시.
  - **청구 마감**(직원·관리자 모두): 매달 2일(전월 사용분).
  - **세무 마감**(관리자만): 매달 5일(전월분). 세무사무소 전달 기한.
- **굵게 눈에 띄게**: 주황 굵은 테두리 + 굵은 글씨 + 시계 아이콘, 늘 그날 맨 위. (빨강은 일요일·공휴일 몫)
- 누르면: 청구 마감 → 직원 [정산] / 관리자 [지출 승인 관리], 세무 마감 → 관리자 [세무 마감].
- 사람 고르기와 관계없이 보인다. [마감일 보기] 체크로 끌 수 있고, DB에 기억.

## 2-2. 주말·공휴일 색
- 요일 머리줄·날짜 숫자: **토요일 = 파랑, 일요일·공휴일 = 빨강**(공휴일이 토요일이면 빨강).
- 공휴일은 기존 `kr_holidays` 표(D-161, 운영자 화면 `/app-admin/holidays`에서 해마다 확인·추가)를 쓴다. 해마다 정해진 관공서 공휴일(설·추석 연휴, 대체공휴일·선거일 포함). 임시공휴일은 운영자가 따로 넣을 때만. 음력 공휴일은 계산하지 않고 표에서 읽는다.
- 공휴일 이름을 작게 같이 쓴다("성탄절", "추석") — PC는 날짜 아래 줄, 휴대폰은 날짜 옆.

## 2-3. 회의 10분 전 안내
- **Supabase 예약 작업(pg_cron) 10분마다**(00·10·20…분) `private.calendar_reminder_tick()`: 15분 안에 시작하는(1분 넘게 남은) **회의** 중 아직 안 보낸 것 → 참석자(불참·퇴사 제외, 만든 사람 포함)의 채팅 **[알림]방**에 한 줄. 회의가 10분 단위라 정확히 10분 전에 들어간다. 한 회의에 한 번(`reminded_at`), 시간을 바꾸면 다시.
- 글: "회의 시작 10분 전입니다. / 14:00~15:00 주간회의 / 장소: 3층 회의실" + [캘린더에서 보기](그 날짜·그 일정 상세로).
- **[알림]방**(`chat_rooms.kind = 'notice'`): 사람마다 하나, 처음 알림 때 생김. 시스템만 글을 쓴다 — 보내기·초대·나가기 불가(`NOTICE_ROOM`), 입력창 대신 안내 한 줄. 안 읽은 수·메뉴 배지에 들어간다. 그 사람만 볼 수 있다.
- 회사의 캘린더·메신저 스위치가 둘 다 켜져 있을 때만 보낸다. 외근·출장·기타·종일 일정은 안내 없음.
- **휴대폰 알림(웹푸시)**: 알림 글을 넣은 뒤 pg_net이 `/api/cron/reminder-push`를 부르고(비밀값 `REMINDER_PUSH_SECRET` = Supabase Vault `reminder_push_secret`, 주소 = Vault `reminder_push_url`), 서버가 `chat_notice_push_due()`(서버 전용, 한 번만)로 받아 보낸다. Vault 값이 없으면 채팅 [알림]방에만 남는다.

## 3. 화면
- 주소: `/workspace/{회사}/calendar`. 직원·관리자 공통 화면(관리자는 관리자 틀, 직원은 직원 틀 + 하단 메뉴). `?month=YYYY-MM`, `?date=…&event=…`(알림에서 열기).
- 들어가는 곳: 관리자 왼쪽 메뉴 [캘린더](채팅 아래), 직원 — **홈 화면 [캘린더] 카드**(오늘 일정 수·다음 일정·다음 청구 마감 굵게). 하단 메뉴는 그대로.
- **사람 고르기**: PC 왼쪽 칸에 부서별 접이식 목록(부서 없음은 맨 아래), 이름 체크 = 그 사람 일정, [전체] = 그 부서 전체, 색 점 = 달력 색, [나만 보기]. 9명 넘으면 이름 검색. 휴대폰은 [사람 선택 (n)] → 아래에서 올라오는 같은 목록. 기본은 **나만**, 고른 사람은 DB에 기억(다른 기기에서도 같게).
- **PC 월 달력**: 월요일 시작, 그 달 1일이 있는 주 ~ 말일이 있는 주. 날짜 칸에 마감일 + 일정(합쳐 3개, 넘으면 "+n개"), 여러 날 일정은 날마다, 오늘은 동그라미, 칸에 올리면 [+]. 날짜·"+n개"를 누르면 그날 목록 창.
- **휴대폰 날짜별 목록**: 그 달 날짜를 하루 한 줄씩("11월 4일 (수) [오늘]" + 마감일 줄 + "14:00~15:00 주간회의 / 회의 · 김A, 이B · 3층 회의실", 일정 없는 날 "일정 없음"). 처음 열면 오늘 줄로 스크롤. 오른쪽 아래 [+].
- **구조**: local-open-spaces 파트너 월간 화면(`MonthCalendarGrid` + `DayBookingRow`)과 같은 방식 — 한 번 불러온 같은 데이터를 CSS(`hidden md:block` / `md:hidden`)로만 바꿔 보여 준다.
- 일정 색 = 그 일정이 보이는 사람의 색(만든 사람이 골라져 있으면 만든 사람), 나는 브랜드 색.
- **일정 상세**: 종류·제목·시간·장소·메모·참석자별 응답. 참석자면 [불참]/[참석], 만든 사람이면 [삭제]/[수정]. 회의면 "10분 전 [알림]방 안내" 문구.
- **일정 만들기**: [+ 일정](PC)·[+](휴대폰)·날짜 칸 [+]. 기본 시작 = 고른 날 10:00(날짜 없으면 다음 정시), 1시간. 시작을 옮기면 끝도 같은 길이로. 참석자 고르기 = 이름·부서 검색 + 그 시간에 일정이 있는 사람 "일정 있음".
- 모든 화면 반응형(휴대폰 390·PC 1280 확인).

## 9. 회의실 설정·예약 (D-207, migration 110)
- **설정(관리자)**: 관리자 메뉴 › 설정 › **캘린더·회의실**(`/admin/calendar-settings`, 늘 보임 — §10). 이름 추가·변경·순서·삭제, 회사마다 0~30개. 0개면 캘린더에 회의실 칸·[회의실 현황]이 아예 안 보이고 장소는 글자로 적는다(작은 회사).
- **삭제**: 잡힌 일정은 지우지 않고 회의실 이름을 그 일정의 장소 글자로 옮긴다(삭제 전 "앞으로 예약 n건" 안내).
- **예약 = 캘린더 일정에 회의실을 붙이는 것**(따로 예약 표 없음): 시간 일정만(종일 불가 `ROOM_ALL_DAY`), 어떤 종류든 가능. 회의 종류면 10분 전 안내의 "장소:"에 회의실 이름(+ 적은 장소).
- **겹침 막기**: 같은 회의실 × 겹치는 시간은 DB가 한 건만 받는다(exclusion constraint, 동시에 눌러도 하나만) → `ROOM_TAKEN`. 끝 = 다음 시작은 OK.
- **화면**: ~~캘린더 [회의실 현황] 창~~ → §13 회의실 예약 전용 화면(D-215). (옛 설명: 캘린더 [회의실 현황](PC 위쪽, 휴대폰 [회의실]) = 하루 단위로 회의실마다 잡힌 시간·제목·만든 사람(회사 전체, 고른 사람과 상관없음) + 방마다 [예약] → 그 방이 골라진 새 일정. 일정 만들기의 회의실 칸은 고른 시간에 이미 잡힌 방을 "예약됨 10:00~11:00"으로 막고, 고른 방이 겹치면 빨간 안내 + [저장] 꺼짐.
- 함수: `calendar_rooms()`, `calendar_room_bookings(시작, 끝)`(31일까지), `calendar_room_save/reorder/delete`(관리자), `calendar_save_event`에 `room_id`.

## 10. 켜기·끄기 = 관리자가 앱에서 (D-208, migration 111)
- 관리자 메뉴 › 설정 › **캘린더·회의실** 맨 위 [사내 캘린더 사용] 스위치. 이 메뉴는 캘린더가 꺼져 있어도 늘 보인다(켤 곳이 있어야 하므로).
- 켜면 바로: 관리자 왼쪽 메뉴 [캘린더], 직원 홈 [캘린더] 카드, 같은 화면 아래 회의실 등록. 끄면(확인 창) 메뉴·주소·홈 카드만 숨고 일정·회의실은 그대로, 끈 동안 회의 10분 전 안내 없음.
- `calendar_set_enabled(boolean)` — 관리자만, 자기 회사만. 메신저·근태 스위치는 그대로 운영자만(DB).

## 11. 직원이 들어가는 곳 = 하단 [캘린더] 탭 (D-209)
- 직원(·관리자 직원 모드) 하단 메뉴: 홈 · 정산 · (결재함) · 채팅 · **캘린더** · 내 정보. 회사 캘린더 스위치가 켜졌을 때만 탭이 생긴다.
- 직원 홈의 [캘린더] 카드(D-206)는 뺐다 — 홈은 정산 내용만.

## 12. 일정 ↔ 경비 연결 (D-210, migration 112)
- **출장·회의 일정**의 상세에 [이 일정 경비] 칸. 외근·기타 일정에는 없다(난잡하지 않게 — 달력 칸에는 아무것도 늘지 않음).
- **[출장 경비 올리기]**(출장) / **[회의 경비 올리기]**(회의): 그 일정의 참석자(불참 제외)만. 누르면 작성 중 결의서를 만들고 편집 화면으로.
  - 출장: 출장 결의서(출장비) — 출장지 = 회의실 이름·장소, 기간 = 일정 날짜(종일이면 그 날짜들, 시간 일정이면 그 날), 목적 = 일정 제목. 제목은 비워 두어 "11/15 부산 출장"이 제안된다.
  - 회의: 제목 "11/20 신제품 회의", 회의 목적 = 일정 제목, 참석자 = 일정 참석자 이름(불참 제외). 카테고리는 직원이 고른다(외부 미팅비를 고르면 목적·참석자가 이미 채워져 있음 — 세무사 적요 증빙).
  - 같은 일정으로 여러 건 올릴 수 있다(사람마다, 또는 한 사람이 여러 건).
- **묶인 경비 보기**: "이 일정 경비 n건 · 합계" + 결의서마다 제목·금액·상태. 직원은 내 결의서만, 관리자는 다른 사람이 올린 결의서도(작성 중 제외 — 관리자 화면 규칙과 같음). 누르면 그 결의서로.
- **결의서 쪽**: 직원 편집·상세, 관리자 상세, 사전 검토 결재 화면에 "연결된 일정 · 출장 · 날짜 · 제목" → 누르면 캘린더 그 일정 상세.
- 연결은 이 버튼으로만 생긴다(`expense_claims.calendar_event_id`는 직접 쓰기 권한 없음). 일정을 지우면 결의서는 그대로, 연결만 끊긴다. 캘린더를 끄면 연결 표시만 숨는다.
- 함수: `calendar_create_claim(일정)`, `calendar_event_claims(일정)`.

## 13. 회의실 예약 전용 화면 (D-215)
- 들어가기: 캘린더 화면 [회의실 예약](PC 머리글, 휴대폰 위 버튼 — 회의실이 1개 이상일 때만) → `/workspace/{회사}/calendar/rooms?date=YYYY-MM-DD&room=…`. 하단 메뉴(홈·정산·채팅·캘린더·내 정보)는 그대로, [캘린더] 탭이 켜진 상태. 회의실 0개면 안내(관리자는 [회의실 등록하기]).
- 위: [←캘린더] · 날짜(전날·다음 날·누르면 달력·[오늘]) · 안내 한 줄.
- **PC(md 이상)**: 회의실마다 한 줄, 가로 시간축(기본 08~20시, 그 밖 예약이 있으면 넓힘, 1시간 눈금). 잡힌 예약 = 가로 막대(제목·시간·만든 사람).
- **휴대폰**: 위에 회의실 칩(이름 + "n건"/"비어 있음") 하나 고르기 → 세로 시간표(1시간 = 4rem). 잡힌 예약 = 세로 막대.
- **고르기**: 빈 칸 누르기 = 그 10분부터 1시간(다음 예약·자정 앞에서 멈춤). 끌기 = 끈 만큼 10분 칸, 잡힌 칸을 넘지 못함. 마우스는 누르자마자, 손가락은 0.28초 꾹 누른 뒤(그냥 밀면 화면 스크롤). 끄는 동안 "10:00~11:00" 점선 표시 → 떼면 예약 폼(그 방·날짜·시작·끝 채워짐, 종류 기본 회의).
- 잡힌 막대를 누르면 일정 상세(수정·삭제·응답은 캘린더와 같음). 지난 시간(오늘은 지금까지, 지난 날은 전체)은 회색, 고를 수 없음.
- 예약 = 회의실을 붙인 캘린더 일정(§9) → 저장 즉시 만든 사람·참석자 캘린더에 회의로 보임. 겹침 최종 판단은 DB(ROOM_TAKEN).
- 계산: `src/lib/calendar/calendar.ts` `busyRanges`·`dragRange`·`tapRange`·`boardHours`(단위 테스트). 화면 `src/components/calendar/room-board.tsx`. 확인 `.responsive/live/e2e-rooms.mjs`(PC 마우스 끌기·휴대폰 누르기·꾹 눌러 끌기).

## 14. 결의서 쓰기에서 출장·외근 일정 불러오기 (D-216, migration 115)
- 어디: 직원 결의서 편집 › 카테고리 [출장비] › 출장 정보 칸 맨 위 **[캘린더 일정에서 불러오기]**(작성 중·반려 결의서만, 캘린더가 켜진 회사만).
- 목록: 내가 참석(불참 아님)하는 **출장·외근** 일정, 오늘 기준 60일 전 ~ 30일 뒤, 오늘과 가까운 순(진행 중이면 맨 위), 3개 + [일정 n개 더 보기](20개까지). 줄 = [출장]/[외근] · 제목 · 날짜 · 장소.
- 누르면: 출장지 = 회의실 이름 · 장소(없으면 그대로 둠), 출장 기간 = 일정 날짜(시간 일정은 그날 하루), 출장 목적 = 일정 제목 → 평소 자동 저장. 결의서에 그 일정이 연결되어 위에 "연결된 일정" 줄. 다른 일정을 누르면 바꿔 연결, [일정 연결 끊기] = 연결만 없앰(채운 글은 그대로).
- 캘린더 등록은 선택: 목록이 비면 "캘린더에 출장·외근을 등록해 두면 여기서 눌러 바로 채울 수 있어요(선택)" 한 줄, 직접 적기는 그대로.
- 외근은 별도 경비 카테고리가 없어 [출장비]에서 불러온다(당일 출장). 회의 일정은 D-210의 [회의 경비 올리기]로.
- 함수: `calendar_my_trip_events()`, `claim_link_calendar_event(결의서, 일정|null)` — 내 결의서·작성 중만(NOT_EDITABLE), 참석자만(NOT_ATTENDEE), 출장·외근만(EVENT_KIND_NO_CLAIM), 다른 회사 불가.
- 확인: DB `supabase/tests/072_claim_trip_events.sql`, 화면 `.responsive/live/e2e-tripfill.mjs`.

## 15. 회의 안건·자료 + 10분 전 알림 카드 (D-217, migration 116·117)
- **어디**: 일정 만들기·수정 폼(캘린더 [+ 일정], 회의실 예약 화면 둘 다 같은 폼). 종류가 **회의**이거나 **회의실을 잡은 시간 일정**이면 [안건 및 자료] 칸이 보인다.
- **안건**: 글 2,000자(선택). 첫 줄은 10분 전 알림 카드에도 나온다.
- **자료**: [파일 첨부] — 일정마다 10개, 파일마다 20MB, PDF·doc/docx·xls/xlsx/csv·ppt/pptx·hwp/hwpx·txt·이미지(png/jpg/gif/webp/heic)·zip. 안 되는 파일은 고를 때 안내하고 뺀다. 고른 파일은 "저장하면 올라가요" → [저장] 때 일정 저장 뒤 올린다(일부 실패 시 "일정은 저장했어요. 다만 자료 일부를…" 안내). 수정에서 × = 저장할 때 지움.
- **권한**: 올리기·빼기 = 일정 만든 사람만(NOT_OWNER). 보기·내려받기 = 같은 회사 사람(캘린더는 회사 안 모두 공개). 다른 회사 불가. 표 직접 읽기·쓰기 없음(함수만).
- **저장 한도**: 회사 첨부 저장 공간(요금제 1/3/10GB, 채팅과 함께)에 더해 센다 → 넘치면 STORAGE_FULL "회사 저장 공간이 다 찼어요". 관리자 설정 › 채팅의 사용량에 함께 보인다("채팅 사진·파일과 회의 자료를 함께 세요"). 회의 자료는 채팅 보관 기간으로 지우지 않는다.
- **상세**: 회의 안건(줄바꿈 그대로) + 회의 자료 n(이름·크기) — 누르면 새 창에서 바로 보기(PDF·이미지·글) 또는 내려받기. 주소는 5분짜리 서명 주소.
- **취소(삭제)**: 확인 창에 "올린 회의 자료 n개도 함께 지워져요" → 자료 줄은 DB 연쇄 삭제, 파일은 화면이 바로 지움(올린 사람은 자기 파일을 볼 수 있어 지울 수 있음, migration 117). 못 지운 파일은 새벽 작업(`meeting_files_orphans` → `purgeMeetingOrphans`)이 하루 뒤 지운다.
- **10분 전 알림 카드**: 예약 작업 글 = "회의 시작 10분 전입니다. / 시간 제목 / 장소: … / 안건: 첫 줄 / 자료: n개". 채팅 [알림]방은 이 글을 카드로 그린다: ⏰ 회의 시작 10분 전 · 제목 · 시간 · 장소 · 안건 · 회의 자료 n개 · [안건·자료 보기](안건·자료 없으면 [캘린더에서 보기]) → 그 회의 상세. 휴대폰 알림(웹푸시)에도 같은 줄이 이어서 나온다.
- 함수: `calendar_save_event`(agenda), `calendar_event`/범위 JSON에 `agenda`·`files`, `calendar_event_file_add(일정, 경로, 이름, 형식)`, `calendar_event_file_delete(자료)`, `meeting_files_orphans()`(서버 전용). 확인: DB `supabase/tests/073_meeting_agenda_files.sql`, 화면 `.responsive/live/e2e-meeting.mjs`.
- (D-218) **보관 기간**: 회의 자료도 회사 보관 기간(30·60·90일)을 따른다. 기준일 = 올린 날·회의 끝난 날 중 늦은 날. 지나면 새벽 작업(`meeting_files_due` → `purgeMeetingExpired`)이 파일을 지우고 `purged_at` — 상세·폼에 이름만 흐리게 "보관 기간이 지나 지워졌어요", 저장 공간·10개 한도에서 빠짐.
