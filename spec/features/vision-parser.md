# [Spec] Vision LLM 영수증 파싱 기능

## 1. 개요
직원이 모바일 웹에서 업로드한 영수증 이미지(사진/캡처)를 Vision LLM API(OpenAI GPT-4o 또는 Anthropic Claude 3.5 Sonnet 등)로 전송하여, 핵심 거래 정보를 구조화된 텍스트로 자동 추출하는 기능.

## 2. 요구사항 및 제약 사항 (Guardrails)
- **추출 필드**: 상호명 (`merchant_name`), 결제 금액 (`amount`), 결제 일자 (`expense_date`).
- **속도 및 UX**: 파싱에는 약 1~3초가 소요되므로 업로드 직후 로딩 스켈레톤 UI를 반드시 표시할 것.
- **Editable Input 원칙**: AI가 파싱한 결과는 100% 완벽하지 않을 수 있으므로, 추출된 값을 입력 폼에 자동으로 채워주되 **유저가 직접 수정(Editable)할 수 있는 에디터 UI**를 반드시 제공할 것.
- **오버엔지니어링 금지**: 법인카드 번호 매칭, 승인번호 추출 등 MVP 범위를 벗어나는 복잡한 필드는 파싱 대상에서 제외한다.
