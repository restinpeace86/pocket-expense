# [Spec] 세무 회계 프로그램 일괄 업로드용 표준 엑셀 포맷 (Data Columns)

## 1. 개요 및 목적
- **목적**: 세무사무소가 사용하는 대표적인 회계 프로그램(더존 Smart A, 위하고(WEHAGO) 등)의 전표 일괄 업로드(Import) 규격에 맞춰, 수기 타이핑 없이 한 번에 전표 데이터를 꽂아넣을 수 있는 표준 엑셀 포맷을 정의한다.
- **특징**: 부가세 매입세액 공제 검토가 가능하도록 공급가액과 부가세를 분리하고, 가맹점 사업자등록번호 및 1:1 매칭 키(증빙파일명)를 포함하여 경리와 세무사무소 양쪽의 업무 리소스를 제로(0)로 만든다.

---

## 2. 표준 엑셀 컬럼 구조 (Data Columns Schema)

| 컬럼 순서 | 필드명 (Column Name) | 데이터 타입 | 설명 및 기재 형식 예시 | 필수 여부 |
| :---: | :--- | :--- | :--- | :---: |
| **1** | **전표일자 (증빙일자)** | Date (`YYYY-MM-DD` 또는 `YYYYMMDD`) | 지출이 발생한 실제 결제일 (예: `2026-10-15`) | **필수** |
| **2** | **구분 (매입/매출)** | String | 지출결의서이므로 기본값 **'매입'** (또는 출금/지출) | **필수** |
| **3** | **증빙구분 (결제수단)** | String | `법인카드`, `개인카드(사비)`, `현금영수증`, `세금계산서` 등 | **필수** |
| **4** | **계정 과목** | String | 사내 템플릿 매핑 과목 (예: `식대`, `소모품비`, `여비교통비`) | **필수** |
| **5** | **거래처명** | String | 돈을 쓴 가맹점명 (예: `스타벅스 강남점`) | **필수** |
| **6** | **사업자등록번호** | String | 가맹점 사업자번호 (예: `120-88-12345` - 거래처 자동 매칭용) | **필수** (카드/현금) |
| **7** | **공급가액** | Number (Integer) | 부가세를 제외한 순수 공급가액 (예: `40909`) | **필수** |
| **8** | **부가세액 (VAT)** | Number (Integer) | 부가가치세액 (예: `4091`) | **필수** |
| **9** | **합계 금액** | Number (Integer) | 총 결제금액 = 공급가액 + 부가세액 (예: `45000`) | **필수** |
| **10** | **적요 (적요내용)** | String | 직원이 작성한 사용 목적 및 소명 (예: `거래처 미팅 식사 진행`) | **필수** |
| **11** | **프로젝트 / 부서** | String | (선택) 비용을 발생시킨 부서명 또는 프로젝트명 | 선택 |
| **12** | **증빙파일명 (매칭키)** | String | **[핵심]** ZIP 폴더 안의 원본 파일명 (`2026-10-001_스타벅스강남점.jpg`) | **필수** |

## 3. 세무 마감 패키지 연동 규칙
1. **엑셀 + ZIP 세트 구성**: 
   - 관리자가 마감 패키지를 다운로드할 때, 위 규격에 맞춘 `.xlsx` 파일 1개와 12번 컬럼의 파일명과 100% 일치하는 영수증 원본 이미지들이 담긴 `.zip` 폴더가 동시에 생성되어 압축 다운로드된다.
2. **세무사무소 호환성**: 
   - 공급가액과 부가세가 분리되어 있고 사업자등록번호가 명시되어 있어, 회계 프로그램의 엑셀 임포트 기능을 통해 수기 입력 오류와 부가세 신고 누락 리스크를 완벽하게 방지한다.
