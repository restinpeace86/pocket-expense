# [Spec] 세무 회계 프로그램 일괄 업로드용 표준 엑셀 포맷 — 초안 (Data Columns)

관련: D-036, D-045, D-050, D-051, D-052, **D-136(세무사무소 답변 반영 2026-10-27)**, O-02(남은 질문) / 출력 위치: `spec/features/tax-export.md` §3.4 (엑셀 시트3 "세무 업로드")

> **상태: 일부 확정(D-136).** 계정코드·거래처코드·사비/법인카드 시트 분리·카드 대조·계정과목 기준은 세무사무소 답변으로 확정. 컬럼 순서·날짜/금액 형식·프로그램 양식 파일(§4의 1·2·5·8·9·10·14번)은 아직 미확인 — 세무사무소 추가 확인이 어려워 **양식 파일을 입수하면 그때 반영**(D-145). 계정코드는 더존 기본값 + "회계 프로그램과 다를 수 있으니 확인" 안내로 운영.
> (예전 상태: 초안.) 실제 세무사무소에서 받은 업로드 양식이 아니라 일반적인 전표 업로드 형태를 기준으로 만든 포맷이다. 이 초안으로 출력해 세무사무소에 보여 주고 §4 질문으로 수정 사항을 받아 확정한다(O-02). 확정 전까지 화면·마케팅 문구에 "완벽 호환"을 쓰지 않는다.

## 1. 개요 및 목적
- **목적**: 세무사무소가 쓰는 대표 회계 프로그램(더존 Smart A, 위하고(WEHAGO) 등)의 전표 일괄 업로드(Import) 규격에 맞춰 수기 타이핑 없이 전표 데이터를 넣을 수 있는 엑셀 포맷을 정의한다.
- **특징**: 부가세 매입세액 공제 검토가 가능하도록 공급가액과 부가세를 분리하고, 가맹점 사업자등록번호와 1:1 매칭 키(증빙파일명)를 포함한다.
- 1행 = 영수증 1장(항목 1건). 결의서 묶음은 풀어서 출력한다.

## 2. 표준 엑셀 컬럼 구조
- **시트를 결제수단으로 나눈다(D-136)**: `세무 업로드(법인카드)` / `세무 업로드(개인 사비)`. 개인 사비는 카드번호도 다르고 법인카드 사용이 아니라 따로 입력한다(세무사무소). 사비 시트에는 4-1 카드 끝 4자리 칸이 없다. 자차 유류비는 사비 시트.

| :---: | :--- | :--- | :--- | :---: |
| 1 | 전표일자 (증빙일자) | Date `YYYY-MM-DD` | 항목 `expense_date` (예: `2026-10-15`) | 필수 |
| 2 | 구분 | String | 고정값 `매입` | 필수 |
| 3 | 증빙구분 | String | 항목 증빙구분: `카드매출전표` / `현금영수증` / `세금계산서` / `간이영수증` / `기타` (D-051) | 필수 |

### 값 규칙
- **공급가액·부가세를 영수증에서 구분할 수 없을 때**(면세 품목, 간이과세자, 간이영수증 등): 부가세액 `0`, 공급가액 = 합계 금액으로 쓰고 엑셀 확인 컬럼(시트1)에 "부가세 미구분" 표시.
- **사업자등록번호를 읽지 못했을 때**: 빈칸으로 두고 시트1에 "사업자번호 없음" 표시(관리자 확인용).
- **영수증 없는 항목**(자차 유류비): 증빙구분 `기타`, 사업자등록번호·증빙파일명 빈칸, 적요에 "자차 128.4km × 200원".

## 3. 세무 마감 패키지 연동 규칙
1. 마감 패키지(ZIP)를 받을 때 이 시트가 포함된 `.xlsx` 1개와, 15번 컬럼 파일명과 100% 일치하는 영수증 원본 이미지 폴더가 함께 들어간다(`tax-closing.md` §4.B).
2. 공급가액·부가세 분리와 사업자등록번호 기재로, 회계 프로그램 엑셀 임포트 시 수기 입력 오류와 부가세 신고 누락 위험을 줄인다.

## 4. 세무사무소 확인 질문 (O-02 확정용)
초안으로 출력한 엑셀을 보여 주며 아래를 확인하고, 답에 따라 이 문서를 고친다.
1. 사용하시는 회계 프로그램과 버전(더존 Smart A, 위하고, 세무사랑 등)은? 해당 프로그램의 **전표 일괄 업로드 양식 파일**을 받을 수 있는지?
2. 컬럼 순서·이름을 프로그램 양식에 맞춰야 하는지, 이 초안 그대로 받아서 옮기는지?
3. 계정과목은 이름으로 충분한지, **계정코드**가 꼭 필요한지(필요하면 코드표 요청)?
4. 거래처는 사업자등록번호로 매칭하는지, 거래처 코드가 따로 필요한지?
5. 날짜 형식(`YYYY-MM-DD` / `YYYYMMDD`), 금액 형식(숫자만 / 콤마)은?
6. 법인카드 사용분을 카드사 내역과 대조할 때 **카드 끝 4자리**(초안에 4-1 컬럼으로 포함) 외에 더 필요한 카드 식별 정보가 있는지?
7. 개인(사비) 지출과 법인카드 지출을 같은 시트에 받아도 되는지, 나눠야 하는지?
8. 간이영수증·자차 유류비처럼 적격증빙이 아닌 항목은 어떻게 표시해 주면 좋은지?
9. 영수증 파일명 규칙(`2026-10-003_20261015_부산국밥_17000.jpg`)이 대조에 충분한지?
10. 직원에게 **자가운전보조금**(월 정액)을 주는 회사가 자차 출장 유류비(거리 × 단가)를 따로 정산해도 되는지? 둘 다 주면 보조금 비과세가 깨지는지? 자차 유류비 정산 근거로 출발지·도착지·거리·목적 기록이면 충분한지?
11. (확인용 — 2000px 보관은 확정 정책) 영수증 이미지를 **긴 변 2000px JPEG(약 250dpi)**로 줄여 전자 보관해도 증빙으로 충분한지? 종이 원본을 따로 보관해야 하는 항목이 있는지(간이영수증 등)?
12. 외부 미팅비(거래처 식사 등)를 **기업업무추진비 하나로** 넘겨도 되는지, 회의비와 나눠서 받아야 하는지? (적요에 미팅 목적·참석자·거래처명을 함께 넘김)
13. 회사 물품 구매: 탕비실 간식·커피 → 복리후생비, 사무용품·소액 비품 → 소모품비로 받아도 되는지? 회사 자산(비품)으로 따로 잡아야 하는 금액 기준은?
14. 자차 유류비(주유 영수증 없음)는 회사가 '출장 경로 및 거리 산정 요약' 이미지(출발·도착·주행 거리·km당 단가·금액, D-088)를 근거로 보관한다. 세무사무소 장부 입력·검토에 이 이미지를 ZIP으로 함께 받을 필요가 있는지, 아니면 회사 보관(세무조사·비과세 실비 소명 대비)만 하면 되는지? 받는다면 지출결의서 PDF에 함께 넣을지, 따로 파일로 줄지?
