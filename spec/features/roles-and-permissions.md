# [Spec] 역할 · 권한 체계

관련: CLAUDE.md 제4장 제3조, D-004, D-005, D-038, D-039, D-042~D-045 / 데이터: `members.role`, `approval_line_steps`

## 1. 설계 원칙
- 모든 사람은 **각자의 카카오/Google 계정**으로 가입한다. 대표 계정을 경리 담당자에게 공유하지 않도록, 권한은 계정 공유가 아니라 역할 부여로 위임한다.
- 로그인(카카오/Google)은 "누구인지"만 확인한다. 회사 안에서의 권한은 역할(`role`)로 정한다.
- 역할은 3단계: **최고 관리자(`super_admin`) ⊃ 관리자(`admin`) ⊃ 직원(`employee`)**.
- **지출결의서 최종 승인 권한은 관리자 이상**에게 있다(D-039). 결재라인은 관리자 승인 전 선택형 사전 검토 단계를 정한다.
- 이 문서에서 "관리자 이상"은 `super_admin`과 `admin`을 함께 뜻한다.

## 2. 역할
| 역할 | 정해지는 방식 | 할 수 있는 일 |
|---|---|---|
| `super_admin` 최고 관리자 | **회사를 등록한 계정**이 자동으로 된다. 회사당 정확히 1명 | 관리자의 모든 권한 + **관리자 지정·해제** + **최고 관리자 넘기기** + 관리자 계정 비활성화 |
| `admin` 관리자 (경리·총무 등) | 최고 관리자가 멤버 관리에서 지정 | **모든 직원의 지출결의서 승인·반려(본인 것 제외)**, 회사 설정·정책, 부서, 결재라인, 사내 양식, 계정과목, 직원 가입 승인·부서 배정·직원 비활성화, 전체 결의서 열람, 정산완료 처리, 월말 출력, 알림 이력 |
| `employee` 직원 | 초대 링크/QR로 가입 | 본인 지출결의서 작성·상신·조회, 내 정보 관리 |
| 세무사무소 관리자·소속 세무사 (회사 멤버 아님, D-149) | 회사 관리자가 [설정 › 세무사무소]에 사무소 이메일을 넣으면 그 사무소의 고객사가 됨. 사무소는 직접 등록(관리자), 세무사는 초대 링크로 합류 | 사무소 관리자 = 모든 고객사, 세무사 = 배정된 고객사의 승인·지급된 지출·영수증·세무용 엑셀 열람, 계정과목·코드·분류 연결 추가·수정(삭제 불가) — 연결된 동안 회사 관리자는 계정과목을 보기만(D-152). 회사 워크스페이스·결재·마감 불가. D-004와 별개, 무료 (`spec/screens/tax-office.md`) |
| 사전 검토자 (역할 아님) | 결재라인 사전 검토 단계에 지정된 멤버 | 자기 차례 결의서 검토 승인·반려, 결재함 |

- 관리자 이상은 **관리자 워크스페이스**(`/workspace/[id]/admin`, 사이드바 관리 메뉴·설정)로 들어가고, 직원은 **직원 워크스페이스**(`/workspace/[id]/employee`)로 들어간다(`spec/common/routes.md` §1).
- 관리자 이상도 본인 결의서를 청구할 수 있다(헤더의 [내 경비]).
- 관리자 이상은 본인 결의서를 승인할 수 없다. 최고 관리자 본인 결의서는 결재 생략, 관리자 본인 결의서는 다른 관리자 이상이 승인한다(`expense-lifecycle.md` §3-3).

## 3. 최고 관리자 규칙
- 회사당 최고 관리자는 항상 정확히 1명이다.
- 최고 관리자는 강등·비활성화할 수 없다. 바꾸려면 먼저 **최고 관리자 넘기기**를 한다.
- 관리자(`admin`)는 다른 사람의 역할을 바꿀 수 없고, 다른 관리자를 비활성화할 수 없다.

### 3.1 최고 관리자 넘기기
- 쓰임: 경리 담당자가 대신 회사를 등록한 뒤 대표에게 넘기는 경우, 담당자가 퇴사하는 경우 등.
- 조건: 받는 사람은 같은 회사의 `approved` 멤버(역할 무관).
- 흐름: 멤버 관리 → 대상 멤버 [최고 관리자 넘기기] → 확인 다이얼로그("○○님이 최고 관리자가 되고, 나는 관리자가 됩니다. 되돌리려면 ○○님이 다시 넘겨야 합니다") → 한 트랜잭션으로 대상 `super_admin`, 본인 `admin`.
- 결재라인은 자동으로 바뀌지 않는다. 대표 직통 결재로 바꾸려면 결재라인에서 결재자를 수정하도록 완료 화면에서 안내한다.

## 4. 권한 위임 흐름 (경리 담당자에게 관리 맡기기)
1. 경리 담당자가 초대 링크/QR로 들어와 본인 계정으로 로그인하고 가입 신청(`employee`, `pending`).
2. 관리자 이상이 [멤버 관리]에서 가입 승인.
3. 최고 관리자가 역할을 [관리자로 지정].
4. 경리 담당자가 다시 들어오면 관리자 워크스페이스가 보인다.
