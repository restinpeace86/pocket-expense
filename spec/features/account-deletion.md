# 계정 삭제 · 설치 앱 결제 숨김 — D-314

> 사용자 결정 2026-11-25: 안드로이드 앱을 APK 대신 Play 스토어에 올린다. Play 정책에 맞춰
> ① 앱 안에서는 요금제·결제 화면을 숨기고 결제는 웹에서만, ② 계정 삭제 기능을 만든다(필수).
> 계정 삭제 세부: 회사에 남긴 기록은 회사에 남김(추천안) · 최고 관리자는 먼저 넘기기 안내(추천안).

## 1. 계정 삭제
- 주소: `/account/delete` (앱 안·웹 공통, Play Console '계정 삭제 URL'로도 씀). 로그인 안 했으면 로그인 뒤 돌아옴.
- 들어가는 길: 직원 [내 정보] 맨 아래, 세무사무소 [내 사무소/사무소 관리] 맨 아래, 가입 화면(시작하기·승인 대기) 맨 아래.
- 지워지는 것: 로그인 계정(auth), 휴대폰·이메일·차량번호·유종, 정산 계좌, 웹·앱 알림 연결, '나만 보기' 파일(퇴사와 같이 30일 뒤).
- 남는 것: 회사에 낸 지출결의서·영수증·출퇴근·휴가·결재·채팅 — 회사 자료(세무 5년·근태 3년 보관은 회사 의무). 기록에는 이름만 남음(멤버 행은 `inactive` + `account_deleted_at`, 로그인 연결 없음). 올린 파일의 '올린 사람' 연결만 끊음.
- 바로 지울 수 없을 때(막지 않고 할 일 안내):
  - 최고 관리자: 다른 멤버가 있으면 [최고 관리자 넘기기] 안내, 혼자면 운영자에게 회사 해지 요청 안내(메일).
  - 결재라인에 든 사람 / 내 차례 결의서가 남은 사람: 퇴사 처리와 같은 기준으로 안내.
  - 세무사무소 관리자: [사무소 관리자 바꾸기]·[세무사무소 삭제] 안내. 소속 세무사는 사무소에서 빠짐.
- 확인: [위 내용을 확인했어요] 체크 → [계정 삭제] → 한 번 더 확인 → 완료 화면.
- 관리자 화면: 멤버 상세 상태 '계정 삭제(퇴사)', [다시 활성화] 없음(로그인 계정이 없음 — 다시 함께하려면 새로 초대). 목록 휴대폰 자리 '계정 삭제'.
- DB: migration 174 (`account_deletion_check`, `prepare_account_deletion`, `reactivate_member` 막음).

## 2. 안드로이드 설치 앱 결제 숨김
- 앱이 UA 끝에 `DamoOnApp/android`를 붙인다(capacitor.config `android.appendUserAgent`, 1.0.7부터). 예전 APK는 Capacitor 다리로 알아봄.
- `<html data-store="android">`면 `[data-store-hide]` 숨김, `[data-store-only]` 보임.
- 숨기는 곳: 설정 메뉴 [요금제], 관리자 홈 미납·후기 쿠폰 배너, 할 일의 요금제 줄, 예산 [요금제 보기], 파일 보관 [저장 공간 늘리기], 요금제 화면의 요금제·결제 부분.
- 요금제 화면은 앱에서 "앱에서는 요금제·결제를 다루지 않아요" + 크레딧 사용 내역만. 웹으로 가라는 링크는 두지 않음(Play 안내 금지 규정).
- 아이폰 앱은 9-13f 결정(3.1.3(c) 기업용 예외로 웹 결제 유지)에 따라 이번 범위 밖.
