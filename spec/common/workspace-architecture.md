# [Spec] 아키텍처 및 UX 정의: 듀얼 워크스페이스 & AI 템플릿 온보딩

관련: D-049 / 화면 목록: `spec/common/app-architecture.md` / 라우트·권한: `spec/common/routes.md`, `spec/features/roles-and-permissions.md`

## 1. 개요 및 목적
- **목적**: 5~30인 소기업의 실무 현실(모바일 이동 환경, 기존 사내 양식 유지 필요성, 관리자와 직원의 겸직 구조)을 완벽히 수용하기 위한 **듀얼 워크스페이스 및 AI 기반 반응형 웹앱 아키텍처** 정의.
- **핵심 철학**: 모바일 퍼스트(Mobile-First) 기반의 빠르고 직관적인 현장 처리와 PC 기반의 파워풀한 관리 기능의 조화.

---

## 2. 핵심 기능 상세 스펙

### A. AI 기반 커스텀 지출결의서 템플릿 스냅샷 온보딩 (Admin)
- **배경**: 소기업들이 기존에 쓰던 고유의 지출결의서 양식(종이 서식 또는 사내 엑셀)을 버리지 않고 그대로 SaaS에 이식할 수 있도록 지원.
- **동작 방식**:
  1. 관리자(사장님/경리)가 모바일 웹 관리자 워크스페이스에서 **[ 📷 서식 촬영/업로드 ]** 기능 실행 가능해야함. 
  2. 스마트폰 카메라로 기존 회사 지출결의서 종이 양식을 찰칵 촬영하거나 이미지 파일 업로드. (PC에 저장된 서식이 있다면 PC에서 바로 업로드 할수도 있어야 함.)
  3. **Vision LLM**이 서식의 구조, 항목명, 결재란 배치를 파싱한다. 결재란은 필드로 만들지 않고, 실제 결재란은 결재 단계에서 자동으로 그린다(`spec/features/form-template.md` §2).
  4. 시스템이 이를 분석하여 우리 회사만의 **'커스텀 지출결의서 디지털 템플릿'** 초안을 만들고, 관리자가 3단 편집 화면에서 확인·보정 후 [적용하기]로 세팅을 완료한다(`spec/screens/template-configuration.md`).

### B. 듀얼 워크스페이스 및 상단 스위처 (Workspace Switcher)
- **구조 분리**: 서비스는 명확히 **[직원 워크스페이스]**와 **[관리자 워크스페이스]**의 두 가지 물리적/논리적 영역으로 분리됨.
- **역할 및 스위칭**:
  - 관리자 이상(최고 관리자·관리자: 대표, 경리 등) 관리 권한을 가진 사용자는 본인도 지출을 청구할 수 있어야 하므로 두 워크스페이스 모두 접근 가능해야 함. 
  - 화면 우측 상단(프로필 영역 인근)에 상시 노출되는 **`[ ⇄ 관리자/직원 모드 전환 ]` 버튼(Workspace Switcher)**을 통해 클릭 1초 만에 두 워크스페이스를 자유롭게 오갈 수 있음.
- **워크스페이스별 역할**:
  - **직원 워크스페이스**: 내 영수증 업로드, 지출결의서 상신, 결재 진행 상태 및 정산금 입금 내역 조회 등 경비관련 확인
  - **관리자 워크스페이스**: AI 템플릿 세팅, 지출결의서 승인 관리, 멤버 관리 및 독촉, 세무 마감 엑셀+ZIP 다운로드, 사내 정책 룰 설정.

### C. 전면 반응형 웹앱 (Universal Responsive Web App) 아키텍처
- **원칙**: 관리자와 직원 워크스페이스 모두 별도의 네이티브 앱 설치 없이, PC와 모바일 브라우저 환경 어디서나 최적화되어 작동하는 반응형 웹앱으로 설계.
- **기기별 최적화 UX**:
  - **모바일 환경 (스마트폰)**: 
    - 외근 및 이동 중 카카오톡 알림톡 링크를 통해 모바일에 최적화된 카드형 승인 슬라이드 뷰로 즉시 결재 처리 가능해야 함. ( pc에서 결재승인할수도 있고 모바일에서 할 수 도 있음)
    - 스마트폰 카메라를 활용한 실시간 영수증 촬영 및 AI 템플릿 스냅샷 세팅.
    
  - **PC 환경 (데스크톱/태블릿)**: 
    - 넓은 화면을 활용한 좌우 스플릿 뷰 검토, 대규모 데이터 테이블 조회, 월말 세무 마감 패키지 다운로드 등의 고도화된 업무 수행.
    - 카메라 촬영처럼 PC에서 쓸 수 없는 기능은 버튼 대신 "카메라 촬영은 모바일에서 사용 가능합니다" 안내를 보여 주고, 파일 업로드는 PC에서도 그대로 제공한다.

### D. 로그인 후 진입과 스위처 규칙 (보완)
- 로그인 후 기본 진입: 관리자 이상 → 관리자 워크스페이스(`/workspace/[id]/admin`), 직원 → 직원 워크스페이스(`/workspace/[id]/employee`).
- 스위처는 마지막으로 쓴 모드를 기억하지 않고 항상 위 기본 진입을 따른다. 알림톡 링크는 링크가 가리키는 화면으로 바로 연다.
- 직원 모드에서도 관리자 이상은 본인 결의서만 보인다(다른 직원 데이터는 관리자 모드에서만).
