# [Spec] 공통 UI 및 반응형 레이아웃 규칙

## 1. 화면 구조
- **직원·결재자 화면**: 모바일 퍼스트(`< 768px` 기준 설계). PC에서 열어도 가운데 정렬된 모바일 폭(`max-w-md`)으로 보인다.
- **관리자 화면**(`/workspace/[id]/admin/**`): PC 기준(`>= 768px`). 좌측 사이드바 + 우측 메인 콘텐츠의 2단 Split View.
  - `< 768px`에서 관리자 화면에 접근하면 사이드바를 상단 메뉴(햄버거)로 접고 테이블은 카드 리스트로 바꿔 보여 준다. 기능은 줄이지 않는다.
- 관리자도 본인 경비 청구·결재는 직원·결재자 화면을 쓴다. 관리자 화면 헤더에 "내 경비" 링크를 둔다.

## 2. 모바일 규칙
- 하단 고정 CTA 또는 하단 내비게이션 바를 쓴다.
- 버튼·터치 영역은 `min-height: 44px` 이상.
- 숫자 입력은 `inputmode="numeric"`, 금액은 천 단위 콤마로 표시한다.
- 영수증 업로드는 `accept="image/*,application/pdf"`와 카메라 촬영(`capture`)을 함께 지원한다.

## 3. 디자인 시스템
- TailwindCSS 기본, 일관된 색상 팔레트, `rounded-xl`, `shadow-sm`의 깔끔한 SaaS 톤.
- 아이콘: `lucide-react` (카테고리 아이콘: 식대 `Utensils`, 출장비 `Car`, 미팅비 `Users`).

## 4. 상태 배지 표준 (D-022)
| 상태 | 표시명 | 클래스 |
|---|---|---|
| `draft` | 작성중 | `bg-gray-100 text-gray-700` |
| `submitted` | 결재중 | `bg-blue-100 text-blue-700` |
| `approved` | 승인완료 | `bg-green-100 text-green-700` |
| `rejected` | 반려 | `bg-red-100 text-red-700` |
| `paid` | 정산완료 | `bg-purple-100 text-purple-700` |

- `submitted` 배지 옆에 결재 진행도(예: "1/2")를 함께 표시한다.

## 5. 로딩 · 에러
- 영수증 파싱, 양식 분석, 거리 계산, 엑셀/ZIP 생성 등 비동기 처리 중에는 스켈레톤 또는 스피너를 반드시 표시한다.
- 에러는 토스트 또는 인라인 안내 문구로 사용자 친화적으로 알리고, 가능한 경우 대체 경로(수동 입력, 재시도)를 함께 제시한다.
- 성공한 저장·상신·승인·반려는 토스트로 확인시킨다.
- 금액·결재 처리 같은 되돌릴 수 없는 액션(상신, 승인, 반려, 정산완료, 삭제)은 확인 다이얼로그를 거친다.
