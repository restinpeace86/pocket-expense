# [Spec] 공통 UI 및 반응형 레이아웃 규칙

## 1. 개요
`PocketExpense` 서비스는 직원용 **모바일 퍼스트(Mobile-First)** 웹 인터페이스와 관리자용 **PC 대시보드(Desktop)**가 공존하는 구조입니다. 디바이스 환경에 맞춘 명확한 UI 분기와 터치 친화적 디자인 시스템을 준수해야 합니다.

## 2. 반응형 브레이크포인트 및 레이아웃 분기
- **모바일 화면 (`< 768px`, 직원용 중심)**:
  - 스마트폰 모바일 브라우저 환경을 기준으로 최적화할 것.
  - 하단 고정 내비게이션 바 또는 풀사이즈 카드 형태의 리스트 레이아웃 적용.
  - 버튼 및 터치 영역은 손가락으로 누르기 편하도록 충분한 크기(`min-height: 44px` 이상) 확보.
- **PC 화면 (`>= 768px`, 관리자 대시보드 중심)**:
  - 데스크톱/태블릿 환경을 기준으로 좌측 사이드바 + 우측 메인 콘텐츠 영역의 2단 Split View 레이아웃 적용.
  - 테이블 데이터(경비 청구 리스트 등)는 가독성이 좋게 넓은 뷰로 배치.

## 3. 스타일링 및 디자인 시스템 규칙
- **CSS Framework**: TailwindCSS를 기본으로 사용하며, 일관된 색상 팔레트와 둥근 모서리(`rounded-xl`, `shadow-sm`)를 적용해 깔끔한 SaaS 감성을 유지할 것.
- **아이콘**: `lucide-react` 라이브러리를 활용하여 직관적인 아이콘(카테고리별 아이콘, 상태 배지 등)을 구성할 것.
- **상태 배지 (Status Badge) 색상 표준**:
  - `draft` (작성중): 회색 계열 (`bg-gray-100 text-gray-700`)
  - `submitted` (제출완료): 파란색 계열 (`bg-blue-100 text-blue-700`)
  - `approved` (승인완료): 초록색 계열 (`bg-green-100 text-green-700`)
  - `paid` (정산완료): 보라색 계열 (`bg-purple-100 text-purple-700`)

## 4. 로딩 및 인터랙션 규칙
- Vision LLM 영수증 파싱이나 카카오내비 거리 계산 등 비동기 API 통신 중에는 유저가 멈춰있다고 느끼지 않도록 **로딩 스켈레톤(Skeleton UI) 또는 스피너**를 반드시 표시할 것.
- 에러 발생 시 사용자 친화적인 토스트(Toast) 메시지 또는 안내 문구 출력.
