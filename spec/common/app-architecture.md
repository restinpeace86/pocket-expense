1. 직원 워크스페이스 (Employee Workspace - Mobile First)
사내 직원이 스마트폰에서 영수증을 찍고, 결재를 올리고, 사비 정산 현황을 확인하는 공간입니다.

[화면 E-01] 직원 메인 대시보드 (Home & Pipeline)

상단 헤더: 앱 로고, 환영 인사, 관리자 모드 스위처 ([ ⇄ 관리자 모드로 전환 ] - 관리자 권한자에게만 노출)

상단 요약 카드: 이번 달 사비 정산 대기금 총액 (클릭 시 정산 타임라인으로 이동)

메인 CTA: [ 📸 + 영수증 찍고 지출 올리기 ]

내 상신 내역 리스트 (실시간 상태 뱃지 및 인터랙션):

[ 📝 임시저장 ] (작성 중인 건 ➔ 클릭 시 편집 화면 복귀)

[ 🟡 검토 대기 ] (결재 대기 중)

[ ✅ 승인 완료 ] (법인카드 건 완료 / 사비 건은 지급 대기)

[ 🔴 반려됨 ] (클릭 시 하단 팝업으로 반려 사유 확인 ➔ [ 수정 후 재상신 ] 연동)

[ 💰 정산 지급 완료 ] (입금 완료 내역)

[화면 E-02] 영수증 스냅샷 & 지출결의서 작성 (Capture & Editor)

1단계: 캡처 및 업로드 (카메라 촬영 / 갤러리·PDF 선택) ➔ AI Vision 자동 파싱 (날짜, 가맹점, 금액 자동 입력)

2단계: 결제수단 선택 ([ 🔘 법인카드 (Default) ] / [ ⚪ 개인카드 (사비 정산) ])

3단계: 회사가 세팅한 템플릿 항목 작성

지출결의서 제목 (*)

지출 카테고리 셀렉트박스 (* - 관리자 설정 연동)

적요 / 소명 내용 (*)

하단 액션: [ 💾 임시저장 ] / [ 🚀 결재 상신 ] (카카오톡 알림톡 트리거 발생)

[화면 E-03] 개인 정산 내역 및 입금 타임라인 (Settlement Timeline)

상단 요약: 입금 대기 중인 사비 / 이번 달 지급받은 정산금

사비 지출 내역 타임라인:

[ 🟡 정산 대기 ] ➔ 경리/사장의 이체 대기 상태

[ 💰 지급 완료 ] ➔ 관리자 지급 처리 시 실시간 변경 및 카카오톡 알림톡 수신 내역 연동

🛠️ 2. 관리자 워크스페이스 (Admin Workspace - Responsive Web & Mobile)
사장님 또는 경리 담당자가 지출을 승인하고, 자금을 집행하고, AI 템플릿을 세팅하며, 세무 마감 패키지를 뽑아내는 공간입니다.

[화면 A-01] 관리자 대시보드 및 지출 결재 관리 (Approval Pipeline)

상단 헤더: 직원 모드 스위처 ([ ⇄ 직원 모드로 전환 ])

핵심 지표 요약: 이번 달 총 지출액, 승인 대기 건수, 미지급 사비 정산 총액

지출결의서 검토 및 승인 리스트:

직원별 상신 내역 카드

상세 보기 팝업 (영수증 원본 이미지 확대 + AI 파싱 데이터 대조)

액션 버튼: [ ✅ 승인 ] (법인카드는 마감 완료, 사비는 정산 대기열 이동 + 카톡 발송) / [ ❌ 반려 ] (반려 사유 입력 모달 팝업 + 카톡 발송)

[화면 A-02] 자금 집행 및 정산 지급 관리 (Settlement Payout)

개인카드(사비)로 청구되어 승인된 건들의 자금 집행 대기열

계좌 정보 확인 및 일괄/개별 이체 체크리스트

액션 버튼: [ 💰 정산 지급 완료 처리 ] (클릭 시 직원 화면 타임라인 갱신 및 카카오톡 알림톡 발송)

[화면 A-03] AI 템플릿 스냅샷 및 3단 레이아웃 설정 (Form Template Settings)

사내 종이/PDF 양식 촬영·업로드 ➔ Vision LLM 파싱

3단 레이아웃 인터페이스:

좌측: 원본 서식 뷰어

중앙: 필드 에디터 및 카테고리/항목 매핑 설정

우측: 직원들이 보게 될 실시간 모바일 미리보기 화면

[화면 A-04] 세무 마감 패키지 다운로드 (Tax Closing Export)

월별 마감 기간 필터 선택 (예: 2026년 10월)

마감 데이터 검수 요약

핵심 액션 버튼: [ 📦 세무사무소 마감 패키지 다운로드 (엑셀 장부 + 1:1 리네이밍 ZIP) ]

[화면 A-05] 요금제 및 구독 관리 (Billing & Subscription)

현재 플랜 상태 표시 (무료 체험 100장 잔여량 / 베이직·스탠다드·프로 구독 플랜)

💳 가상 결제(Mock Payment) UI: 카드 등록 및 플랜 업그레이드 체험 창 (현재는 프로모션 기간 면제 처리)

🔒 운영자 백엔드 연동: 사업자등록 전 수동 크레딧 연장(Manual Grant) 상태 확인
