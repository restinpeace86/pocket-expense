# [Spec] 직원용 모바일 웹 화면 명세

## 1. 목적 및 레이아웃 규칙
- **타겟 디바이스**: 스마트폰 모바일 브라우저 (Width < 768px 최적화, 터치 친화적 UI)
- **접속 방식**: 기업 전용 QR코드 또는 공유된 링크 접속 후 최초 1회 휴대폰 번호 인증으로 Workspace 매핑.

## 2. 주요 화면 구성
### ① 홈 / 청구 내역 리스트 화면 (`/workspace/[id]/employee`)
- **상단**: 내 소속 회사명, 내 이름, 이번 달 누적 청구 금액 요약 카드.
- **중앙**: 내가 올린 경비 목록 (상태 값 Badge 표시: `작성중(draft)`, `제출완료(submitted)`, `승인완료(approved)`, `정산완료(paid)`).
- **하단 고정 CTA 버튼**: [+ 새 경비 청구하기] (플로팅 버튼 또는 하단 내비게이션 바).

### ② 경비 청구 및 작성 화면 (`/workspace/[id]/employee/new`)
- **카테고리 선택 탭**: [식대], [출장비], [외부 미팅비] 3가지 선택 스위치.
- **영수증 업로드 영역**: 스마트폰 카메라 직접 촬영 또는 갤러리 이미지 업로드.
- **AI 파싱 로딩**: 업로드 즉시 "영수증 분석 중 (1~3초)..." 스켈레톤 UI 표시.
- **Editable Input Form (파싱 결과 에디터)**:
  - 상호명 (텍스트 입력)
  - 결제 금액 (숫자 입력)
  - 결제 일자 (날짜 선택)
- **카테고리별 동적 입력 필드**:
  - *식대 선택 시*: 회사 지원금(자동 계산) 및 개인 부담금 표시.
  - *출장비 선택 시*: [출발지 검색/입력], [도착지 검색/입력], 카카오내비 연동 버튼, 계산된 주행거리(km) 및 자동 산정 유류비 표시.
  - *외부 미팅비 선택 시*: 미팅 목적/사유 텍스트 입력 필수.
- **하단 버튼**: [임시저장] / [관리자에게 제출하기]
