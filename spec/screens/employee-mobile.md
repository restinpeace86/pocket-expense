## ④ 결의서 상세 (`/employee/claims/[claimId]`)
- 상단: 제목, 상태 뱃지(`ui-rules.md` §4), 합계, 건수, 기간. 반려 건이면 반려자·사유·지목 항목을 빨간 박스로 강조.
- 정산 안내: "회사가 60,000원 지급 예정 / 법인카드 한도 초과 6,000원 납부 필요" / 지급 완료 일시.
- 지출결의서 렌더링(헤더 + 항목 표 + 결재란) + 항목별 영수증 이미지(가로 스와이프).
- **결재 타임라인**: 결재 생략 건은 "본인 결재로 승인(결재 생략)" 한 줄. 그 외 회차별 — 상신(일시) → 단계별 처리자·상태(대기/승인/반려/스킵)·처리일시·코멘트·지목 항목 → 지급 완료.
- 하단 버튼: `draft` → [편집] / `rejected` → [수정 후 재상신하기] / 그 외 → 없음.

## ⑤ 내 정보 (`/employee/profile`)
- 이름, 휴대폰 번호(알림톡 수신 번호 안내), 부서(관리자만 변경 가능 — 읽기 전용), 직급, 사번, 차량번호, 정산 계좌(은행·계좌번호·예금주) 수정.
- **화면 색상**(개선사항 3, D-066): 팔레트 목록에서 고르면 즉시 화면에 적용되고 계정(`members.ui_theme`)에 저장돼 다시 접속해도 유지된다. 프로필 [저장] 버튼과 별개(누르는 즉시 저장). 직원 모드 헤더에는 색상 버튼을 두지 않는다.
- 로그인 계정(카카오/Google, 이메일) 표시, [로그아웃].
