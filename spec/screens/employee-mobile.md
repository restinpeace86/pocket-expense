# [Spec] 직원 모바일 화면

공통 규칙: `spec/common/ui-rules.md` / 라우트: `spec/common/routes.md` §2

## ① 홈 · 내 경비 리스트 (`/workspace/[id]/employee`)
- **상단 요약 카드**: 회사명, 내 이름·부서, 이번 달(결제일자 기준) 청구 합계, 상태별 건수(작성중/결재중/반려/승인/정산완료), "받을 돈" 합계(개인카드 승인 건 중 미정산 지급액).
- **반려 알림 배너**: `rejected` 건이 있으면 "반려된 경비 n건 — 수정이 필요해요" (누르면 필터 적용).
- **리스트**: 카드형. 카테고리 아이콘, 가맹점명(자차는 "출발지 → 도착지"), 금액, 결제일자, 상태 배지(결재중이면 진행도 "1/2").
  - 필터 탭: 전체 / 작성중 / 결재중 / 반려 / 완료(승인·정산완료). 월 선택(기본 이번 달).
- **하단 고정 CTA**: [+ 새 경비 청구하기].
- **하단 내비게이션**: 홈 / 결재함(결재자로 지정된 경우만 표시, 대기 건수 배지) / 내 정보.

## ② 경비 작성 · 수정 (`/employee/new`, `/employee/expenses/[expenseId]/edit`)
단일 스크롤 폼. 위에서 아래 순서:
1. **카테고리 선택**: [식대] [출장비] [외부 미팅비] 세그먼트.
   - 출장비 선택 시 세부 유형 칩: 자차 / 대중교통 / 택시 / 숙박 / 통행료·주차 / 기타.
2. **영수증**: [촬영] [갤러리/PDF] 버튼. 업로드 후 썸네일(탭하면 확대), [다시 올리기]. 자차는 "영수증 없이 진행 가능" 표시.
3. **영수증 정보** (AI 파싱 결과 에디터, `spec/features/receipt-parser.md`): 가맹점명, 결제일자, 합계금액, 공급가액, 부가세. 파싱 중 스켈레톤, AI 입력 표시.
   - 합계 ≠ 공급가액+부가세면 노란 경고: "합계와 공급가액+부가세가 다릅니다. 확인해 주세요."
4. **결제수단**: [개인카드] [법인카드] (자차는 개인카드 고정, 숨김).
5. **카테고리별 입력**:
   - 식대: 인원수 스테퍼, 실시간 분할 안내(`spec/features/smart-meal.md` §4).
   - 외부 미팅비: 미팅 목적(필수), 거래처명, 참석자, 인원수.
   - 출장비 공통: 출장 목적, 출장 기간(시작일, 숙박이면 종료일 필수).
   - 출장비/자차: 출발지·도착지 주소 검색, [거리 계산], 주행거리(수정 가능), 계산식 "128.4km × 200원 = 25,680원", 차량번호 표시(`spec/features/trip-expense.md`).
6. **회사 양식 항목**: 활성 양식의 바인딩 없는 필드 중 현재 카테고리에 적용되는 것(`spec/features/form-template.md`). 필수 표시. 없으면 섹션 숨김.
7. **지출결의서 미리보기** 버튼 → 바텀시트로 양식 렌더링(자동 채움 결과 확인).
8. **결재선 미리보기**: "김팀장 → 이대표". 결재라인이 없으면 "관리자에게 결재라인 설정을 요청하세요"와 함께 상신 버튼 비활성.
9. **하단 고정 버튼**: [임시저장] / [상신하기](반려 건 수정이면 [재상신하기]).
   - 상신 시 누락 필드가 있으면 첫 누락 필드로 스크롤하고 인라인 오류 표시.
- 페이지를 벗어날 때 저장되지 않은 변경이 있으면 확인 다이얼로그.
- `draft` 수정 화면에는 [삭제] 버튼.

## ③ 경비 상세 (`/employee/expenses/[expenseId]`)
- 상단: 상태 배지, 금액, 카테고리, 결제일자. 반려 건이면 반려자·반려 사유를 빨간 박스로 강조.
- 정산 안내: "회사가 30,000원 지급 예정" / "개인 부담 6,000원 납부 필요" / 정산완료일.
- 지출결의서 렌더링(양식 + 결재란) + 영수증 이미지.
- **결재 타임라인**: 회차별 — 상신(일시) → 단계별 결재자·상태(대기/승인/반려/스킵)·처리일시·코멘트.
- 하단 버튼: `draft` → [수정] [상신하기] / `rejected` → [수정하기] / 그 외 → 없음.

## ④ 내 정보 (`/employee/profile`)
- 이름, 휴대폰 번호(알림톡 수신 번호 안내), 부서(관리자만 변경 가능 — 읽기 전용), 직급, 사번, 차량번호, 정산 계좌(은행·계좌번호·예금주) 수정.
- 로그인 계정(카카오/Google, 이메일) 표시, [로그아웃].
