# [Spec] 직원 모바일 화면

공통 규칙: `spec/common/ui-rules.md` / 라우트: `spec/common/routes.md` §2 / 흐름: `spec/features/expense-claim-flow.md`

## ① 홈 · 내 소명서 리스트 (`/workspace/[id]/employee`)
- **상단 요약 카드**: 회사명, 내 이름·부서, 이번 달(항목 결제일자 기준) 청구 합계, 상태별 소명서 수(작성중/결재중/반려/승인/정산완료), "받을 돈" 합계(승인된 소명서의 미정산 지급액).
- **반려 알림 배너**: `rejected` 소명서가 있으면 "반려된 소명서 n건 — 수정이 필요해요" (누르면 필터 적용).
- **리스트**: 카드형. 소명서 제목, 항목 수·합계("3건 · 72,000원"), 카테고리 아이콘들, 기간(첫~마지막 사용일), 상태 배지(결재중이면 진행도 "1/2").
  - 필터 탭: 전체 / 작성중 / 결재중 / 반려 / 완료(승인·정산완료). 월 선택(기본 이번 달).
- **하단 고정 CTA**: [+ 새 경비 청구하기] → `draft` 소명서 생성 후 ② 화면으로 이동하며 바로 영수증 추가(카메라/갤러리) 시트를 연다.
- **하단 내비게이션**: 홈 / 결재함(결재자로 지정된 경우만 표시, 대기 건수 배지) / 내 정보.

## ② 소명서 편집 (`/employee/claims/[claimId]/edit`) — `draft`·`rejected`
1. **헤더**: 제목(자동 제안, 필수), 소명 내용(선택), 회사 양식 헤더 고유 항목(있을 때만), 결제수단 기본값.
2. **반려 정보**(반려 건): 반려자, 사유, 지목된 항목 수를 빨간 박스로 표시.
3. **영수증 항목 표**: 행마다 썸네일, 가맹점(자차는 "출발지 → 도착지"), 사용일자, 금액, 카테고리 아이콘, 상태("분석 중" 스켈레톤 / "확인 필요" / "입력 완료" / 반려 시 "지목됨").
   - 행 탭 → ③ 항목 편집. 왼쪽 스와이프 → 삭제.
   - [영수증 추가](카메라 연속 촬영 / 갤러리 다중 선택 / PDF) · [영수증 없이 항목 추가](자차 등).
4. **합계 · 정산 요약**: 건수, 합계, 회사 지원 / 개인 부담, "지급 n원 / 납부 m원".
5. **경고**: 기한 초과 항목 수(`admin-settings.md` §2.1), 합계 불일치 항목 수.
6. **지출소명서 미리보기** 버튼 → 바텀시트로 양식 렌더링(헤더 + 항목 표).
7. **결재선 미리보기**: "김팀장 → 이대표". 본인이 최종 결재자면 "결재 생략 — 바로 승인됩니다"(`approval-workflow.md` §3).
8. **하단 고정 버튼**: [임시저장] / [결재 요청](반려 건이면 [재상신]; 결재 생략이면 [제출하기(결재 생략)]).
   - 상신 시 검증 실패 항목이 있으면 표에서 해당 행을 강조하고 첫 문제 항목으로 스크롤.
   - 분석 중인 항목이 있으면 버튼 비활성("영수증 분석이 끝나면 요청할 수 있어요").
- `draft` 화면에는 [소명서 삭제] 버튼. 저장하지 않은 변경이 있으면 이탈 시 확인 다이얼로그.

## ③ 항목 편집 (`/employee/claims/[claimId]/items/[itemId]`) — 바텀시트 또는 전체 화면
위에서 아래 순서:
1. **영수증**: 썸네일(탭하면 확대), [다시 올리기]. 자차는 "영수증 없이 진행 가능" 표시.
2. **영수증 정보**(AI 파싱 결과 에디터, `receipt-parser.md`): 가맹점명, 사용일자, 합계금액, 공급가액, 부가세. AI 입력 표시.
   - 합계 ≠ 공급가액+부가세면 노란 경고. 청구 기한 초과면 노란 경고(상신 가능).
3. **카테고리**: [식대] [출장비] [외부 미팅비]. 비어 있으면 AI 추천값(D-032). 출장비면 세부 유형 칩(자차 / 대중교통 / 택시 / 숙박 / 통행료·주차 / 기타).
4. **결제수단**: [개인카드] [법인카드] (자차는 개인카드 고정, 숨김).
5. **카테고리별 입력**:
   - 식대: 인원수 스테퍼, 실시간 분할 안내(`smart-meal.md` §4).
   - 외부 미팅비: 미팅 목적(필수), 거래처명, 참석자, 인원수.
   - 출장비 공통: 적요, 출장 기간(숙박이면 종료일 필수).
   - 출장비/자차: 출발지·도착지 주소 검색, [거리 계산], 주행거리(수정 가능), 계산식, 차량번호(`trip-expense.md`).
6. **회사 양식 항목 필드**: 활성 양식의 항목(표) 고유 필드 중 현재 카테고리 적용분.
7. 하단: [이전 항목] [다음 항목] / [완료]. 반려 시 지목된 항목이면 상단에 결재자 코멘트 표시.

## ④ 소명서 상세 (`/employee/claims/[claimId]`)
- 상단: 제목, 상태 배지, 합계, 건수, 기간. 반려 건이면 반려자·사유·지목 항목을 빨간 박스로 강조.
- 정산 안내: "회사가 60,000원 지급 예정 / 개인 부담 6,000원 납부 필요" / 정산완료일.
- 지출소명서 렌더링(헤더 + 항목 표 + 결재란) + 항목별 영수증 이미지(가로 스와이프).
- **결재 타임라인**: 결재 생략 건은 "본인 결재로 승인(결재 생략)" 한 줄. 그 외 회차별 — 상신(일시) → 단계별 결재자·상태(대기/승인/반려/스킵)·처리일시·코멘트·지목 항목.
- 하단 버튼: `draft` → [편집] / `rejected` → [수정하기] / 그 외 → 없음.

## ⑤ 내 정보 (`/employee/profile`)
- 이름, 휴대폰 번호(알림톡 수신 번호 안내), 부서(관리자만 변경 가능 — 읽기 전용), 직급, 사번, 차량번호, 정산 계좌(은행·계좌번호·예금주) 수정.
- 로그인 계정(카카오/Google, 이메일) 표시, [로그아웃].
