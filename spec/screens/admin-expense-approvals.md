[Spec] 관리자 대시보드: 지출 승인 관리 (Expense Approvals)
1. 개요 및 목적
목적: 직원들이 다건의 영수증을 모아 하나의 청구 묶음(지출소명서)으로 상신한 내역을 관리자(사장님)가 데이터 테이블 형태로 한눈에 검토하고, 일괄 승인 또는 반려 처리하는 핵심 실무 운영 공간.

접근 경로: 관리자 대시보드 좌측 메뉴 ➔ [ 💳 지출 승인 관리 ]

2. 화면 레이아웃 구조 (Split-View Layout)
전체 화면은 좌우로 분할되어 불필요한 화면 이동을 최소화합니다.

좌측 영역 (약 25% 차지): 승인 대기 중인 [지출소명서 묶음 목록] (우편함/결재함 개념)

우측 영역 (약 75% 차지): 좌측에서 선택한 묶음의 상세 경비 데이터 및 회계 분류 내역을 보여주는 메인 뷰.

4. 컴포넌트별 상세 동작 규칙
A. 상단 상태 탭
[ 승인 대기 (N) ]: 아직 처리되지 않은 신규 청구 건 (기본 진입 탭)

[ 승인 완료 ]: 사장님이 일괄 승인하여 세무 마감 큐로 이관된 건

[ 반려됨 ]: 반려 사유와 함께 직원에게 재작성 요청된 건

B. 우측 메인 데이터 테이블 구성 (Line Items)
회계 계정과목 노출: 세무사무소의 회계 프로그램(더존 등)에 즉시 연동될 수 있도록, 친화적 용어가 아닌 세법상 표준 계정과목(여비교통비, 복리후생비 등)으로 표기.

사내 정책 검토 (한도 초과 뱃지):

관리자 설정(admin-settings.md)에서 지정한 기준 한도(예: 1식 10,000원)를 초과한 건이 감지될 경우, 시스템이 자동으로 ⚠️ [한도 초과] 주황색 뱃지와 초과 금액을 표기.

참고: '알림 및 자율 승인 모드'일 경우 영수증 원본 금액은 그대로 살려두되 사장님이 인지할 수 있도록 플래그 역할 수행.

결제 수단 구분 뱃지 (법인카드 vs 개인카드)

표 안의 가맹점 옆이나 행(Row)에 [ 💳 법인 ] 또는 [ 👤 개인(사비) ] 뱃지를 명시합니다.

이유: 사장님이 "이게 회사가 이미 법카로 긁은 건지, 아니면 직원이 사비로 쓰고 나중에 회사 통장에서 정산해 줘야 하는 돈인지"를 즉시 구분해야 하기 때문입니다.

C. 하단 액션 버튼
[ ❌ 소명서 반려 ]: 클릭 시 반려 사유 입력 팝업 노출. 입력 완료 시 묶음 단위로 반려 처리되며 직원 워크스페이스 및 카카오톡으로 반려 알림.

[ ✅ 일괄 승인 ]: 클릭 한 번으로 해당 소명서에 묶인 모든 영수증 행이 일괄 승인 처리되며, 월말 세무 마감 데이터 베이스로 안전하게 흡수됨.
