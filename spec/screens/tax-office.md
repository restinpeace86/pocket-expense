# 담당 세무사 연결 · 세무사 화면 (D-148)

> 근거: todo_improvement 개선사항 2 + 사용자 결정(2026-10-28): "세무사는 직원 계정과 다른 별도 계정, 한 계정은 한 회사에만(D-004)과 별개, 회사 직원이 아니고 관리자 워크스페이스에서 세무사무소를 세팅하면 외부 열람자가 되는 형식".

## 1. 원칙
- 세무사는 **회사 멤버가 아니다**(`members`에 없음, 멤버 목록·결재선·알림 대상 아님). D-004(한 계정 = 한 회사 멤버)는 멤버 소속 규칙이고, 세무사 연결은 별도라 **한 세무사 계정이 여러 회사와 연결**될 수 있다. 회사 멤버인 계정도 다른 회사의 세무사로 연결될 수 있다.
- 연결 = 회사가 넣은 **담당자 이메일**과 로그인 계정의 **확인된 이메일**(구글·카카오가 확인한 이메일, 대소문자 무시)이 같을 때. 승인 절차 없이 즉시 연결된다(요청 원문). 회사당 담당 세무사 1명.
- 볼 수 있는 것: 세무 마감과 **같은 행**(승인·지급된 지출만, `tax_month_export`와 같은 함수), 영수증 사진, 세무용 엑셀. 작성 중·결재 중·반려 지출은 건수만.
- 할 수 있는 것: 계정과목 추가·이름·코드 수정, 분류 → 계정과목 연결 변경. **못 하는 것**: 계정과목 삭제, 결의서 작성·결재·정산, 세무 마감(잠금)·해제, 회사 설정·멤버.
- 이메일을 바꾸거나 [연결 끊기] 하면 이전 계정은 **바로** 볼 수 없다.

## 2. 관리자: [설정 › 담당 세무사] (`/workspace/[id]/admin/tax-agent`, 관리자 이상)
- 입력: 세무사무소명(필수, 1~100자), 담당 세무사·직원 이름(필수, 1~50자), 담당자 이메일(필수, 로그인할 구글·카카오 계정 이메일), 담당자 연락처(선택, 02·010 등 숫자 9~11자리).
- 저장 전 안내: "저장하면 승인 절차 없이 바로 연결 … 이메일을 한 번 더 확인". 이메일을 바꿀 때는 확인 창.
- 연결 후 카드: 연결됨 · 사무소·담당자·이메일·연락처, [세무사 안내 복사](로그인 주소 `/login?next=/tax-office`와 이메일이 든 안내 문구 — 메일 발송 수단이 없어 직접 전달), [정보 바꾸기], [연결 끊기](확인 창).
- 오류 문구: INVALID_TAX_OFFICE / INVALID_TAX_AGENT_NAME / INVALID_TAX_AGENT_EMAIL / INVALID_TAX_AGENT_PHONE.

## 3. 세무사 화면 (`/tax-office`, 로그인 필요)
- 로그인 뒤: 회사 멤버가 아니고 연결된 회사가 있으면 `/tax-office`로(`destinationAfterLogin`의 `taxAgent`). `next=/tax-office…`는 소속과 관계없이 그대로 따른다. `/onboarding`에도 [세무사 화면으로 가기] 카드.
- 연결된 회사가 없으면: "연결된 회사가 아직 없어요" + 이메일 안내 + [로그아웃].
- 틀: 위 머리글(PocketExpense 세무사무소 · 로그아웃) + **담당 회사 목록** — 휴대폰·태블릿은 머리글 아래 가로로 미는 목록, PC(lg)는 왼쪽 목록. 누르면 새로고침 없이 그 회사로(보던 달 유지).
- `/tax-office`: 담당 회사 카드(회사명·사업자번호·담당자). 다른 고객사가 같은 이메일을 넣으면 자동으로 늘어난다.
- `/tax-office/[companyId]?month=YYYY-MM`(기본 지난달, 최근 12개월):
  - 달 선택, 상태 배지(회사 마감 완료 / 마감 전 · 승인분이 더 늘 수 있어요), [세무용 엑셀 다운로드](승인 지출이 없으면 꺼짐).
  - 요약: 승인 지출 건수·공급가액·부가세·합계. 승인 전 지출 건수 안내.
  - 계정과목별(이름(코드)·건수·합계, 큰 금액 순).
  - 지출 내역·증빙: 휴대폰은 카드, PC는 표(번호·전월 추가·사용일·가맹점·사업자번호·영수증 보기·계정과목·증빙·결제·공급가액·부가세·합계·사용자·승인 상태·확인 필요). 영수증 링크 10분.
- `/tax-office/[companyId]/xlsx?month=`: 관리자 세무 마감과 같은 장부(`buildTaxWorkbook`). 회사가 마감한 달은 정식, 아니면 미리보기. 파일명 `{회사}_{YYYY}년{M}월_세무기장용_장부(_마감전).xlsx`. 회사 프로그램별 양식은 O-02(양식 파일 입수 후).
- `/tax-office/[companyId]/account-titles`: 관리자 계정과목 화면과 같은 화면(삭제 버튼 없음).
- 연결되지 않은 회사 주소·엑셀은 "찾는 화면이 없어요"/404. 세무사는 회사 워크스페이스(`/workspace/…`)에 들어갈 수 없다(멤버가 아니므로).

## 4. 데이터 (migration 075, `spec/data/schema.md` 2.1a5)
- `tax_agent_links`: 회사당 1행. 쓰기는 `set_tax_agent`·`clear_tax_agent`(관리자 이상). 고객 쪽 읽기는 자기 회사 관리자만.
- 세무사 함수: `my_tax_agent_companies()`, `tax_agent_month_export(company, month)`. 계정과목·분류 연결은 RLS 정책(`*_tax_agent_*`, 조회·추가·수정)으로.
- 영수증 사진: 세무사는 저장소 권한이 없어, 연결을 확인한 함수가 돌려준 행의 사진(그 회사 폴더)만 서버가 운영 키로 10분 링크를 발급.
