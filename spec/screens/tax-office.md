# 세무사무소 워크스페이스 (D-149, D-148 대체)

> 근거: todo_improvement 개선사항 2 + 사용자 결정(2026-10-28): 회사가 계약하는 상대는 세무사 개인이 아니라 **세무사무소**이고, 그 회사의 담당 세무사는 **사무소가 배정**한다. 세무사무소는 회사 직원이 아닌 외부 열람자이며 "한 계정은 한 회사에만"(D-004)과 별개. 사무소 워크스페이스는 회사 워크스페이스처럼 따로 할당되고, 회사별 리스트로 확인·설정할 것만 보인다. 연결 방법: 회사가 사무소 이메일·담당 세무사를 넣으면 그 사무소 워크스페이스 목록에 회사가 뜬다(사무소가 아직 없으면 사무소가 등록되는 순간). 열람: 사무소 관리자 = 전체, 세무사 = 담당만. 사무소 등록: 사무소가 직접(국세청 확인, 첫 등록자 = 관리자, 소속 세무사는 초대 링크).

## 1. 원칙
- 세무사무소는 **회사 멤버가 아니다**(`members`에 없음, 멤버 목록·결재선·알림 대상 아님). 회사 멤버 계정도 다른 회사들을 맡는 세무사무소 구성원이 될 수 있다. 한 계정은 한 세무사무소에만 속한다.
- 회사 ↔ 사무소: 회사당 사무소 1곳. 연결 기준 = 회사가 넣은 **사무소 이메일** = 사무소를 등록한 계정의 **확인된 이메일**(구글·카카오가 확인한 이메일, 대소문자 무시). 승인 절차 없이 즉시(요청 원문).
- 담당 세무사: 사무소 관리자가 고객사마다 소속 세무사 1명을 배정·변경·해제. 회사가 적은 담당 세무사 이메일이 사무소 구성원 이메일과 같으면 자동 배정(구성원이 나중에 합류해도).
- 열람 범위: 사무소 관리자 = 사무소의 모든 고객사, 소속 세무사 = 배정된 고객사만. 볼 수 있는 것 = 세무 마감과 **같은 행**(승인·지급된 지출만), 영수증 사진, 세무용 엑셀. 작성 중·결재 중·반려는 건수만.
- 할 수 있는 것: 계정과목 추가·이름·코드 수정, 분류 → 계정과목 연결 변경. **못 하는 것**: 계정과목 삭제, 결의서 작성·결재·정산, 세무 마감(잠금)·해제, 회사 설정·멤버.
- 회사가 사무소를 바꾸거나 [연결 끊기] → 이전 사무소는 바로 못 봄. 사무소 관리자가 구성원을 [이용 중지] → 바로 못 보고 맡던 배정은 풀림.

## 2. 회사 관리자: [설정 › 세무사무소] (`/workspace/[id]/admin/tax-office`, 관리자 이상)
- 입력: 세무사무소명(필수), 세무사무소 이메일(필수, 사무소 대표·관리자가 로그인할 이메일), 담당 세무사 이름·이메일·연락처(선택, "배정은 사무소가 해요").
- 저장 전 안내: "저장하면 승인 절차 없이 바로 연결 … 이메일을 한 번 더 확인". 사무소 이메일을 바꿀 때는 확인 창.
- 상태 카드: **세무사무소 가입 대기**(사무소 미등록, "그 이메일로 로그인해 등록하면 바로 연결") / **연결됨**(등록된 사무소명) + 담당 세무사("OO (사무소 배정)" / "사무소에서 배정 전이에요" / "OO (사무소 가입 뒤 확인)"), [세무사무소 안내 복사](로그인 주소 `/login?next=/tax-office`), [정보 바꾸기], [연결 끊기].

## 3. 세무사무소 화면 (`/tax-office`, 로그인 필요)
- 로그인 뒤: 회사 멤버가 아니고 (사무소 구성원이거나 내 이메일로 들어온 연결 요청이 있으면) `/tax-office`로. `next=/tax-office…`·`/tax-join/…`는 소속과 관계없이 따른다. `/onboarding`에 [세무사무소 화면으로 가기].
- **구성원이 아닐 때**: 연결을 요청한 고객사 목록(내 이메일로 들어온 요청) + [세무사무소 등록](사무소명(요청에서 미리 채움)·사업자등록번호(회사 등록과 같은 국세청 확인)·내 이름·휴대폰(선택)·약관·개인정보 동의) + [초대 코드로 합류]. 등록하면 그 이메일로 들어온 요청이 모두 고객사가 된다.
- **이용 중지된 구성원**: "이용이 중지된 계정이에요" + 로그아웃.
- **틀**: 머리글(사무소명 · [고객사] · [사무소 관리](관리자) · 로그아웃) + 고객사 목록(휴대폰·태블릿은 머리글 아래 가로로 미는 목록, PC는 왼쪽). 누르면 새로고침 없이 그 회사로(보던 달 유지).
- `/tax-office`: 고객사 카드(회사명·사업자번호). 관리자는 카드마다 [담당 세무사] 선택(배정 안 함/구성원), 담당 없는 고객사 수 안내, 회사가 적은 담당자 참고 표시. 세무사는 "맡은 고객사"만.
- `/tax-office/manage`(관리자): 소속 세무사 초대 링크 `/tax-join/{코드}`·코드, [초대 안내 복사], [링크 새로 만들기], 구성원 목록(관리자/세무사, 이용 중지 배지, 이메일, 맡은 고객사 수) [이용 중지]/[다시 사용](본인 제외).
- `/tax-join/[code]`: 사무소명 표시 + 이름·휴대폰(선택)·동의 → 합류(세무사). 없는 코드면 안내. 이미 사무소 구성원이면 `/tax-office`.
- `/tax-office/[companyId]?month=` · `/xlsx` · `/account-titles`: 월별 세무 자료(요약·계정과목별·지출 내역·영수증 10분 링크)·세무용 엑셀(관리자 세무 마감과 같은 장부, 회사 마감 전이면 미리보기)·계정과목(삭제 버튼 없음). 볼 수 없는 회사는 "찾는 화면이 없어요"/404.

## 3a. 월말 결산 양식 (`/tax-office/templates`, D-150)
- 머리글 메뉴 [결산 양식]. 사무소 관리자만 추가·고치기·지우기, 세무사는 목록만. 사무소당 10개.
- **양식 파일 올리기**: .xlsx 또는 예전 .xls(Excel 97-2003), 5MB(D-151). .xls는 .xlsx로 바꿔 보관하고, 받을 때 다시 .xls로 만들어 준다(서식은 값 위주). 엑셀이 아니거나 암호가 걸린 파일은 안내. 첫 시트 위쪽 20줄에서 글자 칸이 가장 많은 줄(2칸 이상)을 머리글로 읽고, 칸마다 넣을 값을 추정 → **칸 연결 확인**: 칸(A·B…·머리글)마다 항목 선택(비워 두기·고정값 포함), 양식 이름, 넣을 지출(전체/법인카드만/개인(사비)만) → [양식 저장]. 머리글을 못 찾으면 안내.
- **초안으로 시작**(파일 없음): 더존 위하고 신용카드 매입(초안) · 일반 지출 목록(월·일 분리, 초안). 실제 프로그램 양식과 다를 수 있다는 안내.
- 항목: 순번, 거래일자(날짜 / 20261015 글자), 월, 일, 거래처명(가맹점), 거래처코드(빈칸), 사업자등록번호(하이픈 / 숫자만), 계정과목명, 계정코드, 적요, 공급가액, 부가세, 합계, 봉사료(0), 증빙구분, 결제수단, 카드 끝 4자리, 카드 별칭, 사용자, 부서·프로젝트, 결의서 제목, 분류, 지출 목적, 증빙 파일명(ZIP 매칭) (`src/lib/tax-office/template-fields.ts`).
- **받기**: 고객사 세무 자료 화면(`/tax-office/[companyId]/template?id=&month=`)과 회사 관리자 세무 마감 화면(`/workspace/[id]/admin/export/template?id=&month=`, 연결된 사무소 양식만)에 [OO 결산 양식으로 받기]. 올린 파일 그대로(머리글 위 줄·서식 유지, 머리글 아래 예시 줄은 지움) 세무 마감과 같은 행을 머리글 아래부터 채움. 날짜 = 엑셀 날짜(yyyy-mm-dd), 금액 = 숫자. 회사 마감 전이면 파일명 끝 "_마감전". 원본 양식이 .xls면 받는 파일도 .xls. 승인 지출이 없으면 버튼 꺼짐.

## 3b. 운영 보완 (D-152)
- **고객사 해제**(사무소 관리자): 고객사 카드 [고객사 해제](확인 창) → 목록에서 빠지고 즉시 못 봄. 회사 [설정 › 세무사무소]에 "세무사무소가 연결을 해제했어요"(빨강) + 안내, 담당 세무사 "없음 (연결 해제)". 회사가 [정보 바꾸기]로 다시 저장하기 전에는 다시 붙지 않음.
- **계정과목은 사무소가 관리**: 등록된 사무소와 연결된 회사는 계정과목·계정코드·분류 연결을 바꿀 수 없다(DB 정책). 회사 [계정과목] = 안내("OO이 우리 회사 계정과목을 관리해요…") + 보기만(추가·수정·삭제 없음, 연결 고르기 꺼짐) + **세무사무소 변경 이력**(최근 30건: 무엇·언제·누가(사무소)). 최근 7일 안에 변경이 있으면 관리자 홈 맨 위에 "세무사무소가 최근 7일 동안 계정과목을 N건 바꿨어요 [이력 보기 →]". 사무소 계정과목 화면에도 같은 이력. 가입 전·해제·닫기 뒤에는 회사가 다시 관리.
- **사무소 관리 / 내 사무소**: 머리글 메뉴는 관리자 "사무소 관리", 세무사 "내 사무소". 관리자: 구성원마다 [사무소 관리자 바꾸기](확인 창, 나는 세무사가 됨)·[이용 중지], 맨 아래 **세무사무소 삭제**(사무소명을 그대로 입력해야 버튼이 켜짐 → 구성원·결산 양식 삭제, 고객사는 가입 대기). 세무사: [사무소에서 탈퇴(퇴사)](맡던 배정 풀림). 관리자는 관리자를 바꾸거나 세무사무소를 삭제하기 전에는 탈퇴할 수 없음. 버튼 이름은 사용자 결정(2026-10-28).
- 세무사무소 이용은 무료(약관 제16조의2). 회사 화면과 사무소 화면을 오가는 링크는 두지 않는다.

## 3c. 세무사 전달 보완 (D-153)
- 고객사 세무 자료 화면: [증빙 묶음(ZIP) 받기] + [세무용 엑셀 다운로드]. ZIP = 장부(엑셀) + 영수증/(증빙번호 파일명) + 지출결의서_YYYY-MM.pdf(직원 정산 계좌 제외). 회사 마감 전이면 "{회사}_{YYYY}년{M}월_세무자료_마감전.zip". 못 받은 영수증은 [못 받은 영수증 다시 받기]. 마감(잠금)은 하지 않음.
- 받을 때마다 회사 세무 마감 화면의 "세무 자료 내려받은 기록"에 남음(사무소명·이름·달·건수·마감 여부).
