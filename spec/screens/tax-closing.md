# [Spec] 관리자 대시보드: 세무 마감 및 데이터 다운로드 (Tax Closing Export)

관련: D-016, D-017, D-034, D-036, D-045, D-052, O-02 / 라우트: `/workspace/[id]/admin/export` / 출력물 상세(엑셀 컬럼·PDF): `spec/features/tax-export.md`

## 1. 개요 및 목적
- **목적**: 사장님이 사내에서 최종 승인한 지출결의서 묶음들을 **세무 대리인(세무사무소)이 회계 프로그램에 즉시 기장할 수 있도록 표준 엑셀(`.xlsx`)과 1:1 매칭된 영수증 원본 이미지 모음(`.zip`) 패키지로 원클릭 변환·다운로드**하는 최종 관문.
- **접근 경로**: 관리자 대시보드 좌측 사이드바 ➔ **[ 📥 세무 마감 ]**

## 2. 화면 레이아웃 구조
- **상단 영역**: 마감 대상 연월 선택기(`[ 2026년 10월 ▼ ]`) 및 현재 마감 상태 뱃지(`🟡 마감 대기` / `🟢 마감 완료`).
- **중앙 요약 영역**: 해당 월의 총 세무 증빙 금액, 총 영수증 건수, 실제 통장 정산 지급액 요약 칩 + (보완) 직원 납부액, 계정과목별 합계 칩.
- **미포함 경고(보완)**: "이 달 사용 항목 중 작성중 2건, 결재중 3건, 반려 1건은 포함되지 않습니다" — 결의서 목록으로 펼쳐 보기.
- **메인 영역**: 해당 월에 승인된 낱개 영수증(Line Items) 기반의 마감 대기 리스트 미리보기 테이블.
- **하단 액션 영역**: `[ 📥 10월 세무 마감 패키지 다운로드 (.zip) ]` 메인 CTA 버튼 + (보완) `[엑셀만 미리 받기]`.

## 4. 컴포넌트별 상세 동작 규칙

### A. 마감 대상 데이터 자동 집계 기준
- **대상 범위**: 사장님이 승인 완료(`[ ✅ 일괄 승인 ]`) 처리한 모든 지출결의서(`approved`, `paid`) 내부의 낱개 영수증(Line Items) 중, **사용일자(`expense_date`)** 가 선택한 연월에 속하는 데이터가 마감 큐에 편입된다(D-016). 승인 완료일은 기준으로 쓰지 않는다.
- **전월 추가분(보완)**: 이미 마감 완료된 달의 사용일자를 가진 항목이 마감 이후에 승인되면, 다음에 다운로드하는 마감 대기 월의 패키지에 "전월 추가분"으로 포함한다(표 하단 구분, 엑셀 `마감구분` 컬럼).
- 회사 내부 결재용 '묶음 문서(지출결의서)' 형식은 해체되고, 세무사무소가 요구하는 영수증 낱개 기준의 평탄화된(Flat) 엑셀 테이블로 변환된다. 엑셀 컬럼은 `spec/features/tax-export.md` §3.2(계정과목·계정코드·내부 분류·결의서번호 포함).

### B. 영수증 엑셀과 이미지를 1:1로 묶어주는 '완벽 매칭 시스템'
- **증빙 파일명 자동 생성**: 엑셀 생성 시 각 행마다 고유한 파일명을 부여한다.
  - 규칙(D-052): `{마감월 YYYY-MM}-{일련번호 3자리}_{사용일자 YYYYMMDD}_{가맹점명}_{금액}.{확장자}` (예: `2026-10-003_20261015_부산국밥_17000.jpg`)
  - 앞부분 `2026-10-003`은 **증빙번호**로, 패키지 마감월 + 엑셀 행 순번(3자리, 1,000건 이상이면 4자리)이다. 달이 달라도 겹치지 않아 여러 달 파일을 한 폴더에 모아도 안전하고, 엑셀 매칭 키로 쓴다. 전월 추가분도 포함된 패키지의 마감월을 쓴다.
  - 뒷부분(사용일자·가맹점·금액)은 파일명만 보고 내용을 알 수 있게 하기 위한 정보다. 가맹점명은 파일명에 쓸 수 없는 문자(`\ / : * ? " < > |`)와 공백을 제거하고 20자로 자른다. PDF 영수증은 `.pdf` 그대로.
  - **자차 유류비**는 상신 때 만든 경로 요약 증빙 이미지(D-088)를 `{증빙번호}_{사용일자}_자차유류비_{금액}.png`로 넣는다. 영수증도 경로 요약도 없는 항목만 파일명 칸을 비우고 확인 필요에 "영수증 파일 없음".
  - **증빙 순번 고정(D-090)**: 마감할 때 항목마다 증빙 순번을 DB에 기록해(당월 항목 → 전월 추가분, 각각 사용일자·사용자·결의서번호·항목 순) 다시 받아도 같은 번호·같은 파일명이 나온다. 마감 전 화면·미리보기 엑셀의 번호는 지금 기준의 예상 번호다.
- **ZIP 패키지 동기화**: `.zip` 안 영수증 이미지 파일명이 엑셀의 증빙 파일명 컬럼과 100% 일치하도록 리네이밍하여 패키징한다.
- ZIP 구성: `{YYYY}년{M}월_세무기장용_장부.xlsx` + `영수증/` 폴더 + `지출결의서_{YYYY-MM}.pdf`(보완, `tax-export.md` §3.5 — **T10-3b로 다음 단계**: 결의서 양식 렌더러(T5-3)와 한글 PDF 글꼴이 필요해 이번 패키지에는 아직 없음).
- ZIP은 관리자 브라우저에서 묶는다(D-073): 장부는 서버가 만들고, 영수증은 10분짜리 링크로 4장씩 동시에 받아 넣는다. 진행률("영수증 120/350장")을 보여 주고, 실패한 장은 새 링크로 한 번 더 받은 뒤에도 못 받으면 [못 받은 영수증 다시 받기]로 `_누락분.zip`을 따로 만든다. 약 500MB를 넘으면 `_1.zip`, `_2.zip`으로 나눈다. 마감 대상 월은 기본 지난달, 이번 달까지 고를 수 있다.

### C. 마감 완료 상태 고정 (Lock) — D-045
- 사장님이 `[ 📥 세무 마감 패키지 다운로드 ]`를 수행하면 확인 다이얼로그("다운로드하면 10월이 마감 완료로 잠깁니다") 후 해당 월의 마감 상태가 **🟢 마감 완료**로 전환되고, 포함된 항목에 마감월이 기록된다.
- 이미 세무사무소에 전달된 월의 데이터는 무단으로 수정되거나 누락되지 않도록 **과거 승인 건 수정 락**이 작동한다: 마감된 항목은 계정과목 개별 조정이 불가하고, 해당 항목이 든 결의서는 삭제할 수 없다.
- 마감 완료 월을 다시 다운로드하면 마감 당시 포함된 항목으로 동일한 패키지를 다시 만든다(늦게 승인된 건은 §4.A 전월 추가분 규칙).
- **마감 해제(보완)**: 최고 관리자만 [마감 해제]할 수 있다(사유 입력). 해제하면 해당 월은 마감 대기로 돌아가고 다음 다운로드 때 다시 집계한다.
- `[엑셀만 미리 받기]`는 잠그지 않는다(검토용, 파일명에 "미리보기" 표기).
