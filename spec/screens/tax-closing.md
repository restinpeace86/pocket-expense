# [Spec] 관리자 대시보드: 세무 마감 및 데이터 다운로드 (Tax Closing Export)

## 1. 개요 및 목적
- **목적**: 사장님이 사내에서 최종 승인한 지출소명서 묶음들을 **세무 대리인(세무사무소)이 회계 프로그램에 즉시 기장할 수 있도록 표준 엑셀(`.xlsx`)과 1:1 매칭된 영수증 원본 이미지 모음(`.zip`) 패키지로 원클릭 변환·다운로드**하는 최종 관문.
- **접근 경로**: 관리자 대시보드 좌측 메뉴 ➔ **[ 📥 세무 마감 ]**

---

## 2. 화면 레이아웃 구조
- **상단 영역**: 마감 대상 연월 선택기 (`[ 2026년 10월 ▼ ]`) 및 현재 마감 상태 뱃지 (`마감 대기` / `마감 완료`).
- **중앙 요약 영역**: 해당 월의 총 세무 증빙 금액, 총 영수증 건수, 실제 통장 정산 지급액 요약 칩.
- **메인 영역**: 해당 월에 승인된 낱개 영수증(Line Items) 기반의 마감 대기 리스트 미리보기 테이블.
- **하단 액션 영역**: `[ 📥 10월 세무 마감 패키지 다운로드 (.zip) ]` 메인 CTA 버튼.

4. 컴포넌트별 상세 동작 규칙
A. 마감 대상 데이터 자동 집계 기준
대상 범위: 사장님이 승인 완료([ ✅ 일괄 승인 ]) 처리한 모든 지출소명서 내부의 낱개 영수증(Line Items) 중, 사용일자(또는 승인 완료일)가 선택한 연월(예: 2026년 10월)에 속하는 데이터가 자동으로 마감 큐에 편입됨.

내부적으로 회사 내부 결재용 '묶음 문서(지출소명서)' 형식은 해체되고, 세무사무소가 요구하는 영수증 낱개 기준의 평탄화된(Flat) 엑셀 테이블로 변환됨.

B. 영수증 엑셀과 이미지를 1:1로 묶어주는 '완벽 매칭 시스템'
세무사무소 담당자가 영수증 원본과 엑셀 장부를 대조할 때 겪는 혼선을 원천 차단하기 위해 다음 자동 규칙 적용:

증빙 파일명 자동 생성: 시스템이 엑셀을 생성할 때 각 행(Row)마다 고유한 규칙의 파일명 부여

규칙: [순번]_[사용일자]_[가맹점명]_[금액].jpg (예: [03]_20261015_부산국밥_17000.jpg)

ZIP 패키지 동기화: 다운로드되는 .zip 압축파일 내부에 포함된 영수증 이미지 파일명들이 엑셀의 증빙 파일명 컬럼과 100% 일치하도록 강제로 리네이밍되어 패키징됨.

C. 마감 완료 상태 고정 (Lock)
사장님이 [ 📥 세무 마감 패키지 다운로드 ]를 수행하면, 해당 월의 마감 상태가 🟢 마감 완료로 전환됨.

이미 세무사무소에 전달된 월의 데이터는 무단으로 수정되거나 누락되지 않도록 과거 승인 건 수정 락(Lock) 장치가 작동하여 회계 데이터의 무결성을 보호함.
