# [Spec] 관리자 PC 화면

대상: 관리자 이상 — 최고 관리자(`super_admin`) · 관리자(`admin`) (대표 또는 경리 담당) / 라우트: `spec/common/routes.md` §4 / 권한: `spec/features/roles-and-permissions.md`
관리자는 결재라인의 현재 결재자가 아닌 한 경비를 승인·반려할 수 없다(`expense-lifecycle.md` §3-8). 본인이 현재 결재자인 건은 [결재하기]로 결재 화면(`approver.md`)을 연다.

## 0. 레이아웃 · 사이드바
좌측 사이드바 + 우측 메인(Split View). 헤더: 회사명, [내 경비], [결재함(대기 n)], 계정 메뉴.

| 사이드바 메뉴 | 화면 |
|---|---|
| 📊 홈 대시보드 | ① `/admin` |
| 💳 지출 관리 | ② 소명서 목록 `/admin/claims`, ③ 소명서 상세 |
| 👥 멤버 관리 | ④ `/admin/members` |
| 📥 세무 마감 | ⑨ `/admin/export` |
| ⚙️ 설정 (하단 배치, 펼치면 하위 메뉴) | ⑧ 회사·정책 `/admin/settings`, ⑤ 부서, ⑥ 결재라인, ⑦ 사내 양식, ⑪ 계정과목, ⑩ 알림 이력 |

## ① 홈 대시보드 (`/admin`) — 관리자 로그인 직후 기본 화면
목적: 대표가 이번 달 경비 흐름과 처리할 일을 3초 안에 파악한다.

1. **초기 설정 체크리스트**(미완료 항목만, 모두 끝나면 숨김): 직원 초대 / 부서 확인 / 결재라인 확인 / 사내 양식 등록(선택) / 정산 정책 확인.
2. **직원 초대 카드**: [🔗 초대 링크 복사] [QR 다운로드]. 승인된 직원이 본인뿐이면 상단 고정, 이후에는 체크리스트 아래로.
3. **KPI 카드 3개**(결제일자 기준 이번 달)
   - 이번 달 총 청구 금액 + 전월 대비 증감(▲▼ %).
   - 결재 진행 중 소명서 수(가장 오래 대기한 일수 표시). 누르면 ② 소명서 목록(상태=결재중 필터)으로 이동.
   - 카테고리 비중: 일반 식대 / 출장비 / 외부 미팅비 %.
4. **할 일 카드**: 가입 승인 대기 n명 / 계정과목 미지정 항목 n건 / 정산 대기(approved) 소명서 n건·지급 합계·납부 합계 / 알림톡 실패 n건 / 기한 초과 항목이 있는 상신 소명서 n건.
5. **카테고리별 지출 막대 차트**: 일반 식대 / 출장비(세부 유형별 누적: 출장 식비·교통·통행료·숙박·자차 등) / 외부 미팅비 금액과 비율. 직원별 상위 5명 목록.

## ② 소명서 목록 (`/admin/claims`)
- 필터: 월(항목 결제일자 기준), 상태, 카테고리(포함 항목 기준), 부서, 직원, 검색(제목·가맹점명).
- 테이블 컬럼: 소명서 제목(출장 소명서는 "출장" 배지), 직원(부서), 건수, 기간, 합계, 회사지원/개인부담, 지급/납부, 상태(진행도, 결재 생략은 "결재 생략" 배지), 현재 결재자, 상신일, 확인 포인트 배지(한도 초과, 직접 입력 거리, 합계 불일치, 기한 초과 — 해당 항목 수).
- 행 펼치기 → 항목 행(사용일자, 가맹점, 카테고리, 결제수단, 금액, 영수증 썸네일 호버 확대).
- 행 클릭 → 우측 패널 또는 상세 페이지.
- **일괄 액션**: `approved` 소명서 선택 → [정산완료 처리] (지급/납부 합계 확인 다이얼로그).
- 엑셀 다운로드는 ⑨ 세무 마감으로 일원화한다.

## ③ 소명서 상세 (`/admin/claims/[claimId]`)
- 지출소명서 렌더링(헤더 + 항목 표 + 결재란) + 항목별 영수증 원본과 읽어낸 값 나란히 보기(결재자 화면과 같은 구성, "직원 수정" 표시 포함) + 결재 타임라인(전 회차, 지목 항목) + 항목별 계산 내역 + 해당 소명서의 알림톡 발송 이력.
- 항목 표에 **계정과목 열**을 표시하고, 항목별로 계정과목을 바꿀 수 있다(드롭다운, 상태 무관, "계정 조정됨" 표시). 규칙: `spec/features/account-titles.md` §4.
- 액션: `approved`면 [정산완료 처리]. 본인이 현재 결재자면 [결재하기].

## ④ 멤버 관리 (`/admin/members`)
- 상단: 초대 링크 복사, QR 보기/다운로드(PNG), [초대 코드 재발급].
- 탭: **승인 대기** / 활성 / 비활성.
- 승인 대기: 이름, 휴대폰, 부서, 직급, 가입 신청일 → [승인] [거절].
- 활성 테이블: 이름, 부서(인라인 변경), 직급, 휴대폰, 역할 배지(최고 관리자 / 관리자 / 직원), 포함된 결재라인, 정산 계좌 등록 여부 → [비활성화].
  - **최고 관리자에게만** 보이는 액션: [관리자로 지정] / [관리자 해제], 관리자 [비활성화], [최고 관리자 넘기기](확인 다이얼로그, `roles-and-permissions.md` §3.1).
  - 관리자에게는 역할 변경 버튼이 보이지 않고, 직원만 비활성화할 수 있다. 최고 관리자 행에는 비활성화 버튼이 없다.
- 규칙: `spec/features/auth-onboarding.md` §4, `spec/features/roles-and-permissions.md`.

## ⑤ 부서 관리 (`/admin/departments`)
- 부서 추가/이름 변경/순서 변경/삭제. 삭제 시 소속 인원 수 표시, 소속 멤버의 부서는 비워짐(멤버 화면에서 재지정 안내). 부서별 결재라인이 있으면 함께 삭제됨을 경고.

## ⑥ 결재라인 설정 (`/admin/approval-lines`)
- 좌측: 결재라인 목록(기본 + 부서별), 각 라인의 적용 부서·인원 수.
- 우측: 선택한 라인의 단계 편집(결재자 검색 추가, 드래그 순서 변경, 삭제), 결재선 미리보기 "김팀장 → 이대표".
- [부서별 결재라인 추가] → 결재라인이 없는 부서 중 선택.
- 상세 규칙: `spec/features/approval-workflow.md` §2.

## ⑨ 세무 마감 (`/admin/export`)
- 월 선택 → 대상 요약(항목 수, 소명서 수, 합계, 상태별) + 미포함 경고(작성중/결재중/반려 소명서 목록).
- 버튼: [엑셀만 다운로드] [전체 패키지(ZIP) 다운로드].
- 상세: `spec/features/tax-export.md`.

## ⑩ 알림 이력 (`/admin/notifications`)
- 테이블: 발송일시, 템플릿, 수신자, 관련 소명서(링크), 상태(성공/실패), 오류 메시지.
- 필터: 상태, 기간. 실패 건 [재발송].
- 개발 드라이버(`log`) 사용 중이면 상단에 "현재 실제 알림톡이 발송되지 않는 개발 모드입니다" 배너.

## ⑪ 계정과목 (`/admin/account-titles`)
- 상단 안내: "세무사무소 회계 계정과목에 맞춰 설정하세요. 담당 세무사와 확인 후 설정하는 것을 권장합니다."
- 좌측: 계정과목 목록(이름, 계정코드 인라인 편집, 추가, 매핑에 쓰이지 않는 항목만 삭제).
- 우측: 매핑 표 — 내부 분류(일반 식대 / 출장비 › 출장 식비·대중교통·택시·통행료·주차·숙박·자차 유류비·기타 / 외부 미팅비)별 계정과목 드롭다운.
- 저장 시 "변경 내용은 이후 상신되는 소명서부터 적용됩니다. 이미 상신된 항목은 소명서 상세에서 개별 조정하세요" 안내.
- 상세 규칙: `spec/features/account-titles.md`.
