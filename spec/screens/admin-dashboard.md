# [Spec] 관리자 PC 화면

대상: `role = 'admin'` (대표 또는 경리 담당) / 라우트: `spec/common/routes.md` §4
레이아웃: 좌측 사이드바(대시보드, 경비, 멤버, 부서, 결재라인, 양식, 설정, 월말 출력, 알림 이력) + 우측 메인. 헤더에 회사명, [내 경비], [결재함(대기 n)], 계정 메뉴.
관리자는 결재라인의 현재 결재자가 아닌 한 경비를 승인·반려할 수 없다(`expense-lifecycle.md` §3-8). 본인이 결재자인 건은 [결재하기]로 결재 화면(`approver.md`)을 연다.

## ① 대시보드 홈 (`/admin`)
- **초기 설정 체크리스트**(미완료 항목만 표시): 식대 한도·유류비 단가 확인 / 부서 등록 / 기본 결재라인 설정 / 사내 양식 등록 / 직원 초대.
- **할 일 카드**: 가입 승인 대기 n명 / 결재 진행 중 n건(가장 오래된 대기 일수) / 정산 대기(approved) n건·지급 합계·납부 합계 / 알림톡 실패 n건.
- **이번 달 요약**(결제일자 기준): 총 청구액, 카테고리별 금액, 상태별 건수, 직원별 상위 5명.

## ② 경비 목록 (`/admin/expenses`)
- 필터: 월(결제일자), 상태, 카테고리, 결제수단, 부서, 직원, 검색(가맹점명).
- 테이블 컬럼: 결제일자, 직원(부서), 카테고리/세부유형, 가맹점, 금액, 회사지원/개인부담, 결제수단, 상태(진행도), 현재 결재자, 영수증 썸네일(호버 확대), 확인 포인트 배지.
- 행 클릭 → 우측 패널(Split View) 또는 상세 페이지.
- **일괄 액션**: `approved` 건 선택 → [정산완료 처리] (정산 금액 합계 확인 다이얼로그).
- [CSV/엑셀]은 월말 출력 화면으로 일원화하며 여기서는 제공하지 않는다.

## ③ 경비 상세 (`/admin/expenses/[expenseId]`)
- 지출결의서 렌더링 + 영수증 원본(확대) + 결재 타임라인(전 회차) + 계산 내역 + 알림톡 발송 이력(해당 경비).
- 액션: `approved`면 [정산완료 처리]. 본인이 현재 결재자면 [결재하기].

## ④ 멤버 관리 (`/admin/members`)
- 탭: **승인 대기** / 활성 / 비활성.
- 승인 대기: 이름, 휴대폰, 부서, 직급, 가입 신청일 → [승인] [거절].
- 활성 테이블: 이름, 부서(인라인 변경), 직급, 휴대폰, 역할(관리자/직원 전환), 포함된 결재라인, 정산 계좌 등록 여부 → [비활성화].
- 규칙: `spec/features/auth-onboarding.md` §4 (마지막 관리자 보호, 결재라인 포함 시 비활성화 차단).
- 상단: 초대 링크 복사, QR 보기/다운로드(PNG), [초대 코드 재발급].

## ⑤ 부서 관리 (`/admin/departments`)
- 부서 추가/이름 변경/순서 변경/삭제. 삭제 시 소속 인원 수 표시, 소속 멤버의 부서는 비워짐(멤버 화면에서 재지정 안내). 부서별 결재라인이 있으면 함께 삭제됨을 경고.

## ⑥ 결재라인 설정 (`/admin/approval-lines`)
- 좌측: 결재라인 목록(기본 + 부서별), 각 라인의 적용 부서·인원 수.
- 우측: 선택한 라인의 단계 편집(결재자 검색 추가, 드래그 순서 변경, 삭제), 결재선 미리보기 "김팀장 → 이대표".
- [부서별 결재라인 추가] → 결재라인이 없는 부서 중 선택.
- 상세 규칙: `spec/features/approval-workflow.md` §2.

## ⑦ 사내 양식 (`/admin/form-template`)
- 좌: 원본 양식 이미지(업로드/교체) + [AI로 분석하기].
- 중: 필드 편집기(블록형).
- 우: 미리보기 탭(직원 입력 폼 / 지출결의서 문서).
- 하단: 현재 활성 버전 번호, [적용하기].
- 상세: `spec/features/form-template.md`.

## ⑧ 회사 설정 (`/admin/settings`)
- 회사 정보: 회사명, 사업자등록번호.
- 경비 규칙: 1인당 식대 한도(원), 자차 km당 유류비 단가(원). "변경 내용은 이후 상신되는 경비부터 적용됩니다" 안내(D-018).
- 초대: 초대 링크, QR, 재발급(멤버 관리와 같은 기능).

## ⑨ 월말 출력 (`/admin/export`)
- 월 선택 → 대상 요약(건수, 합계, 상태별) + 미포함 경고(작성중/결재중/반려 건 목록).
- 버튼: [엑셀만 다운로드] [전체 패키지(ZIP) 다운로드].
- 상세: `spec/features/tax-export.md`.

## ⑩ 알림 이력 (`/admin/notifications`)
- 테이블: 발송일시, 템플릿, 수신자, 관련 경비(링크), 상태(성공/실패), 오류 메시지.
- 필터: 상태, 기간. 실패 건 [재발송].
- 개발 드라이버(`log`) 사용 중이면 상단에 "현재 실제 알림톡이 발송되지 않는 개발 모드입니다" 배너.
