## ① 홈 대시보드 (`/admin`) — 관리자 로그인 직후 기본 화면
목적: 대표가 이번 달 경비 흐름과 처리할 일을 3초 안에 파악한다.

1. **초기 설정 체크리스트**(미완료 항목만, 모두 끝나면 숨김): 직원 초대 / 부서 확인 / 결재라인 확인 / 사내 양식 등록(선택) / 정산 정책 확인.
2. **직원 초대 카드**: [🔗 초대 링크 복사] [QR 다운로드]. 승인된 직원이 본인뿐이면 상단 고정, 이후에는 체크리스트 아래로.
3. **KPI 카드 3개**(결제일자 기준 이번 달)
   - 이번 달 총 지출액 + 전월 대비 증감(▲▼ %).
   - 승인 대기 중인 청구 건수(가장 오래 대기한 일수 표시). 누르면 [지출 승인 관리] › [승인 대기]로 이동.
   - **미지급 사비 정산 총액**(정산 대기 소명서의 지급액 합계). 누르면 [정산 지급 관리].
4. **할 일 카드**: 무료 크레딧 잔여 안내(20장 이하, D-046) / 이벤트 추가 지급 배너("무료 영수증 100장을 모두 사용했습니다. 현재 이벤트 기간이라 추가 100장을 무료로 더 드립니다" + [확인], D-054) / 가입 승인 대기 n명 / 계정과목 미지정 항목 n건 / 정산 대기(approved) 소명서 n건·지급 합계·납부 합계 / 알림톡 실패 n건 / 기한 초과 항목이 있는 상신 소명서 n건.
5. **카테고리 비중 · 카테고리별 지출 막대 차트**: 일반 식대 / 출장비(세부 유형별 누적: 출장 식비·교통·통행료·숙박·자차 등) / 외부 미팅비 금액과 비율. 직원별 상위 5명 목록.

## ⑤ 부서 관리 (`/admin/departments`)
- 부서 추가/이름 변경/순서 변경/삭제. 삭제 시 소속 인원 수 표시, 소속 멤버의 부서는 비워짐(멤버 화면에서 재지정 안내). 부서별 결재라인이 있으면 함께 삭제됨을 경고.

## ⑥ 사전 검토 결재라인 설정 (`/admin/approval-lines`) — 선택 기능
- 좌측: 결재라인 목록(기본 + 부서별), 각 라인의 적용 부서·인원 수.
- 우측: 선택한 라인의 사전 검토 단계 편집(검토자 검색 추가, 드래그 순서 변경, 삭제) + 마지막 고정 "관리자 최종 승인", 미리보기 "박영업팀장 검토 → 관리자 승인".
- [부서별 결재라인 추가] → 결재라인이 없는 부서 중 선택.
- 상세 규칙: `spec/features/approval-workflow.md` §2.

## ⑩ 알림 이력 (`/admin/notifications`)
- 테이블: 발송일시, 템플릿(결재 요청·승인·반려·초대·독촉), 수신자, 관련 소명서(링크), 상태(성공/실패), 오류 메시지.
- 필터: 상태, 기간. 실패 건 [재발송].
- 개발 드라이버(`log`) 사용 중이면 상단에 "현재 실제 알림톡이 발송되지 않는 개발 모드입니다" 배너.

## ⑪ 계정과목 (`/admin/account-titles`)
- 상단 안내: "세무사무소 회계 계정과목에 맞춰 설정하세요. 담당 세무사와 확인 후 설정하는 것을 권장합니다."
- 좌측: 계정과목 목록(이름, 계정코드 인라인 편집, 추가, 매핑에 쓰이지 않는 항목만 삭제).
- 우측: 매핑 표 — 내부 분류(일반 식대 / 출장비 › 출장 식비·대중교통·택시·통행료·주차·숙박·자차 유류비·기타 / 외부 미팅비 / 회사 물품 구매 › 탕비실·간식·사무용품·소모품·소액 비품)별 계정과목 드롭다운.
- 저장 시 "변경 내용은 이후 상신되는 소명서부터 적용됩니다. 이미 상신된 항목은 소명서 상세에서 개별 조정하세요" 안내.
- 상세 규칙: `spec/features/account-titles.md`.

## ⑫ 법인카드 (선택, `/admin/corporate-cards`)
- 카드 목록: 별칭, 카드번호(`5327-12**-****-7890`, 앞 6자리 없으면 "앞 6자리 미등록"), 담당자, 이번 달 사용 합계, 사용 여부. [카드 추가] [수정] [사용 안 함].
- 입력란은 별칭·카드번호 앞 6자리·뒤 4자리(`ㅁㅁㅁㅁ-ㅁㅁ**-****-ㅁㅁㅁㅁ`)·담당자뿐이며 가운데 자리 입력란은 두지 않는다(`corporate-cards.md` §2). 안내: "카드 앞 6자리와 뒤 4자리만 등록합니다. 카드번호 전체는 저장하지 않습니다."
- 규칙: `spec/features/corporate-cards.md`.
