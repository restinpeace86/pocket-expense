# [Spec] 관리자용 PC 대시보드 화면 명세

## 1. 목적 및 레이아웃 규칙
- **타겟 디바이스**: PC 웹 브라우저 (Width >= 768px, 좌측 사이드바 + 우측 메인 콘텐츠 2단 Split View).
- **대상 유저**: 회사 대표 또는 경리 담당자 (`role = 'admin'`).

## 2. 주요 화면 구성
### ① 관리자 대시보드 홈 (`/workspace/[id]/admin`)
- 이번 달 사내 전체 경비 청구 현황 요약 (총 청구액, 승인 대기 건수).

### ② 경비 승인 및 검토 관리 화면 (`/workspace/[id]/admin/expenses`)
- 직원들이 올린 청구 건 리스트 테이블.
- **컬럼**: 직원명, 카테고리, 사용일자, 가맹점명, 청구금액, 영수증 보기(썸네일 팝업), 상태.
- **액션**: [승인(Approve)] / [반려(Reject)] 버튼. 승인 시 상태가 `approved`로 변경.

### ③ 회사 규칙 설정 화면 (`/workspace/[id]/admin/settings`)
- 기본 식대 지원 한도 설정 (예: 10,000원).
- 자차 km당 유류비 단가 설정 (예: 200원).

### ④ 월말 마감 및 데이터 출력 화면 (`/workspace/[id]/admin/export`)
- **버튼 1**: [세무사무소용 표준 엑셀(CSV) 다운로드] (승인된 건 기준).
- **버튼 2**: [국세청/감사 대비 영수증 원본 지출결의서 PDF 패키지 다운로드] (지출결의서 양식 + 원본 이미지 연동).
