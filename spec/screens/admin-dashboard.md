대상: 관리자 이상 — 최고 관리자(`super_admin`) · 관리자(`admin`) (대표 또는 경리 담당) / 라우트: `spec/common/routes.md` §4 / 권한: `spec/features/roles-and-permissions.md`
관리자 이상은 [지출 승인 관리]에서 결의서를 최종 승인·반려한다(D-039, 본인 결의서 제외). 사전 검토 단계가 남은 건은 읽기 전용.

## 0. 레이아웃 · 사이드바
좌측 사이드바 + 우측 메인(Split View), 모바일에서는 햄버거 메뉴(`ui-rules.md` §1). 헤더: 회사명, **[ ⇄ 직원 모드로 전환 ]**(D-049), [결재함(대기 n)], 계정 메뉴.
- **관리자 1:1 문의**(D-127): 관리자 워크스페이스에서만(직원에게는 없음). PC(768px 이상)는 오른쪽 아래 떠 있는 노란 버튼 [💬 관리자 피드백](화면 아래 고정 버튼 줄이 있으면 그 위로 비켜 섬), 휴대폰은 떠 있는 버튼 없이 햄버거 메뉴 › 설정 맨 아래 [관리자 1:1 문의]. 누르면 새 창으로 카카오톡 채널 채팅(`NEXT_PUBLIC_KAKAO_CHANNEL_CHAT_URL`, 비었거나 `https://pf.kakao.com/_…/chat` 형식이 아니면 숨김).

## ① 홈 대시보드 (`/admin`) — 관리자 로그인 직후 기본 화면
목적: 대표가 이번 달 경비 흐름과 처리할 일을 3초 안에 파악한다.

1. **초기 설정 체크리스트**(미완료 항목만, 모두 끝나면 숨김): 직원 초대 / 부서 확인 / 결재라인 확인 / 사내 양식 등록(선택) / 정산 정책 확인.
2. **직원 초대 카드**: [🔗 초대 링크 복사] [QR 다운로드]. 승인된 직원이 본인뿐이면 상단 고정, 이후에는 체크리스트 아래로.
3. **KPI 카드 3개**(결제일자 기준 이번 달)
   - 이번 달 총 지출액 + 전월 대비 증감(▲▼ %).
   - 승인 대기 중인 청구 건수(가장 오래 대기한 일수 표시). 누르면 [지출 승인 관리] › [승인 대기]로 이동.
   - **미지급 사비 정산 총액**(정산 대기 결의서의 지급액 합계). 누르면 [정산 지급 관리].
4. **할 일 카드**: 무료 크레딧 잔여 안내(20장 이하, D-046) / 이벤트 추가 지급 배너("무료 영수증 100장을 모두 사용했습니다. 현재 이벤트 기간이라 추가 100장을 무료로 더 드립니다" + [확인], D-054) / 가입 승인 대기 n명 / 계정과목 미지정 항목 n건 / 정산 대기(approved) 결의서 n건·지급 합계·납부 합계 / 알림톡 실패 n건 / 기한 초과 항목이 있는 상신 결의서 n건.
5. **카테고리 비중 · 카테고리별 지출 막대 차트**: 일반 식대 / 출장비(세부 유형별 누적: 출장 식비·교통·통행료·숙박·자차 등) / 외부 미팅비 금액과 비율. 직원별 상위 5명 목록.

**집계 기준(D-091, 구현 2026-10-22)**: 숫자는 DB 함수 `admin_dashboard`(관리자만·자기 회사만)가 한 번에 낸다.
- 이번 달 지출·카테고리·상위 5명: 사용일자(결제일)가 이번 달인 항목 중 결의서가 상신·승인·지급완료인 것(작성중·반려 제외). 전월 대비는 지난달 같은 기준, 지난달이 0이면 "지난달 기록 없음".
- 승인 대기: 상신된 결의서(사전 검토 중 포함) 수와 가장 오래 기다린 일수(7일 이상이면 강조).
- 미지급 사비: 승인(정산 대기) 결의서의 개인카드 회사 지원금 합계, 받을 법인카드 개인 부담은 따로.
- 체크리스트: 데이터로 끝났는지 알 수 있는 것만 — 직원 초대(승인 직원 2명 이상), 부서(1개 이상), 정산 정책 확인, 사전 검토 결재라인(선택, 숨김 조건에 안 들어감). 사내 양식(T5)은 준비되면 추가.
- 할 일: 가입 승인 대기, 승인 대기, 정산 대기(지급·납부), 계정과목 미지정(상신 이후 항목), 최근 30일 알림 실패, 무료 영수증 20장 이하. 기한 초과 항목이 든 승인 대기 결의서 건수(상신일 기준, D-093).
- 차트는 별도 라이브러리 없이 비중 띠 + 막대 목록.

## ⑨-1 월별 지출 현황 (`/admin/spending`, D-160)
- 메인 메뉴(세무 마감 위). 달 고르기 → 승인 지출 합계 → 계정과목별 합계·비율 막대(큰 순) → 누르면 그 계정의 영수증(사용일·사용처·사용자·금액, "영수증별 조정" 표시). 수정 버튼 없음.
- 안내: 세무사무소 연결 회사는 "OO이 관리해요 · 결재 화면에서 [세무사 확인 요청]". [계정과목 분류 기준 보기]·계정과목 변경 이력.

- 보기 전환: [계정과목별 | 부서별](D-162, `?view=dept`). 부서별은 부서 없음 묶음, 펼치면 사용자 · 계정과목.

## ⑩ 알림 이력 (`/admin/notifications`) — 메뉴에서 숨김(D-159), 운영자 화면으로 이관
- 테이블: 발송일시, 템플릿(결재 요청·승인·반려·초대·독촉), 수신자, 관련 결의서(링크), 상태(성공/실패), 오류 메시지.
- 필터: 상태, 기간. 실패 건 [재발송] — 보낸 내용은 그대로, 받는 번호는 지금 멤버(초대면 초대) 번호로 다시 보내고 새 기록을 남긴다(예전 실패 기록은 이력으로 유지). 이미 가입·취소된 초대는 다시 보내지 않는다.
- 개발 드라이버(`log`) 사용 중이면 상단에 "현재 실제 알림톡이 발송되지 않는 개발 모드입니다" 배너.

## ⑪ 계정과목 (`/admin/account-titles`) — [설정]에서 빼고 월별 지출 현황에서 들어감(D-160)
- 상단 안내: "세무사무소 회계 계정과목에 맞춰 설정하세요. 담당 세무사와 확인 후 설정하는 것을 권장합니다."
- 좌측: 계정과목 목록(이름, 계정코드 인라인 편집, 추가, 매핑에 쓰이지 않는 항목만 삭제).
- 우측: 매핑 표 — 내부 분류(일반 식대 / 출장비 › 출장 식비·대중교통·택시·통행료·주차·숙박·자차 유류비·기타 / 외부 미팅비 / 회사 물품 구매 › 탕비실·간식·사무용품·소모품·소액 비품)별 계정과목 드롭다운.
- 저장 시 "변경 내용은 이후 상신되는 결의서부터 적용됩니다. 이미 상신된 항목은 결의서 상세에서 개별 조정하세요" 안내.
- 상세 규칙: `spec/features/account-titles.md`.
