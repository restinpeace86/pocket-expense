# [Spec] 화면 E-01: 직원 메인 대시보드 및 상신 내역

라우트: `/workspace/[id]/employee` / 관련: D-034, D-047, D-049 / 공통: `spec/common/workspace-architecture.md`, `spec/common/ui-rules.md`

## 0. 홈 개편 (D-235, 2026-11-08) — 홈 = 허브, 결의서 목록은 [지출결의] 화면으로
시안: claude.ai 캔버스 "WORKON 직원 홈 시안"(사용자 확인 2026-11-08). 위에서 아래로:
1. **헤더**: 회사명 줄을 누르면 지금 모드의 홈(직원 = `/employee`, 관리자 = `/admin`).
2. **메뉴 칸**(맨 위 고정, 휴대폰 3열 · PC 3열): 아이콘 + 이름만. 상태 글씨 없음, **처리할 것만 숫자 배지**. 회사가 켠 기능·내 역할에 맞는 칸만:
   - 지출결의(`/employee/claims`) · 정산(`/employee/settlements`) — 항상
   - 결재함(`/approvals`, 대기 건수 배지) — 관리자 이상이 아닌 사전 검토자만(§5 기존 규칙)
   - 회의실(캘린더 + 회의실 예약 창, D-234) — 캘린더가 켜져 있고 회의실이 1개 이상일 때
   - (근태·휴가 칸은 근태 기능을 만들 때 추가, `spec/features/attendance-draft.md` §7)
   - 캘린더·채팅은 하단 바에 있으므로 메뉴 칸에 넣지 않는다(같은 메뉴 두 곳 금지).
3. **오늘 · 내 현황 카드**(상태는 이 한 곳에만):
   - 캘린더가 켜져 있으면 제목 "오늘 · M월 D일 (요일)" + 오늘 내 일정 최대 3개(시간 · 제목 · 장소, 누르면 캘린더 그 날). 없으면 "오늘 잡힌 일정이 없어요".
   - 사비 정산 대기금(→ 정산), 반려된 결의서 n건(있을 때만, → 지출결의 반려 필터).
4. **공지 카드**: 기존 공지(D-116, 관리자만 작성·직원은 보기만). 공지가 없으면 카드 숨김. `#notices` 주소 유지.
- PC(md 이상): 왼쪽 = 메뉴 칸 + 공지, 오른쪽 = 오늘 · 내 현황.
- 예전 홈 주소에 `?month=`/`?status=`가 붙어 오면 `/employee/claims`로 같은 조건을 넘긴다(도우미·알림 링크 호환).

## 1. 상단 내비게이션 헤더 (Header & Switcher)
- 회사명(누르면 홈, D-235) / 관리자 이상이면 우측 상단 **[ ⇄ 관리자 모드로 전환 ]**(D-049).

## 2. 상단 요약 (→ §0-3 오늘 · 내 현황 카드로 이동, D-235)
- 사비 정산 대기금 = 승인되었지만 아직 지급 완료되지 않은 내 결의서들의 지급액 합계(`expense-lifecycle.md` §5.5). 누르면 [화면 E-03](`worker-timeline.md`).
- 반려된 결의서가 있으면 "반려된 결의서 n건".

## 3. 결의서 쓰기 버튼
- **하단 바 가운데 큰 [+ 결의서 쓰기]**(D-235): 어느 화면에서든 누르면 `draft` 결의서를 만들고 바로 촬영/선택 시트를 연다(E-02). 근태 기능이 켜진 회사는 이 자리가 [QR 출퇴근]이 된다(근태 구현 때).
- [지출결의] 화면 하단 고정 **[ 📸 영수증 찍고 지출 올리기 ]**는 그대로 둔다.
- 회사 무료 사용량을 다 썼고 이벤트도 꺼져 있으면(D-046, D-054) 두 버튼 모두 결의서를 만들지 않고 "회사 무료 사용량을 모두 사용했습니다. 관리자에게 문의하세요" 안내.

## 4. 내 상신 내역 리스트 & 상태 뱃지 (Submission Pipeline) — [지출결의] 화면 `/employee/claims` (D-235)
내가 올린 **지출결의서**들이 최신순으로 쌓이는 메인 피드. 카드 1장 = 결의서 1건(영수증 1장 또는 여러 장, D-034).
```text
┌────────────────────────────────────────────────────────┐
│ [식대] 거래처 미팅 식사 진행               [ 🟡 검토 대기 ] │
│ 2026.10.16  •  법인카드  •  영수증 1장                  │
│ 45,000 원                                              │
└────────────────────────────────────────────────────────┘
┌────────────────────────────────────────────────────────┐
│ [출장] 10/15 부산 출장                    [ ✅ 승인 완료 ] │
│ 2026.10.14~10.15  •  법인 2 · 사비 1  •  영수증 3장      │
│ 72,000 원  (사비 정산 대기 10,000원)                     │
└────────────────────────────────────────────────────────┘
```
- 카드 구성: 대표 카테고리 아이콘(여러 개면 "출장" 또는 아이콘 묶음), 제목, 사용일(기간), 결제수단 요약, 영수증 장수, 합계, 상태 뱃지.
- 필터(보완): 전체 / 임시저장 / 검토 대기 / 반려됨 / 완료. 월 선택(기본 이번 달).

### 상태 뱃지 종류 및 인터랙션 (D-047, `ui-rules.md` §4)
| 뱃지 | 상태 | 인터랙션 |
|---|---|---|
| **📝 임시저장** | `draft` | 누르면 편집 화면(E-02)으로 이동해 마저 작성 |
| **🟡 검토 대기** | `submitted` | 사장님/관리자(또는 사전 검토자) 승인 대기. 읽기 전용 상세(`employee-mobile.md` ④). 사전 검토 중이면 "팀장 검토 중" 보조 문구 |
| **✅ 승인 완료** | `approved` | 승인됨. 사비 지급(또는 법인카드 한도 초과분 납부)이 남아 정산 대기 중 |
| **🔴 반려됨** | `rejected` | 터치하면 하단 팝업(Bottom Sheet)에 반려 사유가 붉은 글씨로 표시(지목 항목 포함). 팝업 안 **[ 수정 후 재상신하기 ]** → E-02 편집 화면 |
| **💰 정산 지급 완료** | `paid` | 관리자가 지급 완료 처리한 순간 바뀜(지급 일시 표시). 법인카드만 있고 정산할 금액이 없는 결의서는 승인과 동시에 이 상태가 되며 "승인 완료 (정산 없음)"으로 표시 |

## 5. 하단 내비게이션 (D-235 개편)
- **홈 · 캘린더 · [+ 결의서 쓰기] · 채팅 · 내 정보**. 캘린더·채팅은 회사 스위치가 켜졌을 때만(D-203, D-209). 가운데는 항상 있음.
- 정산·결재함은 하단 바에서 빼고 홈 메뉴 칸으로 옮긴다(탭이 6개까지 늘어나던 문제). 결재함 자격 규칙(아래)은 그대로 메뉴 칸에 적용.
- 결재함은 관리자 이상이 **아닌** 사전 검토자에게만 보인다(D-082). 관리자 이상은 [관리자 모드]의 [지출 승인 관리]에서 결재한다.
- 결의서 목록·필터·월 선택은 [지출결의] 화면에만 있다(같은 목록 두 곳 금지).
