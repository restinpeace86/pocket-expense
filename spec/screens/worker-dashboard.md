1. 상단 네비게이션 헤더 (Header & Switcher)
앱 타이틀 / 로고: PocketExpense (직원 모드)

웰컴 메시지: 안녕하세요, 김개발님 👋

관리자 스위처 (조건부 노출):

만약 현재 로그인한 직원이 관리자 권한(사장님/경리)을 가진 사람이면, 우측 상단에 명확하게 노출됨:

[ ⇄ 관리자 모드로 전환 ] 버튼

일반 직원인 경우 이 버튼은 숨겨짐.

2. 상단 요약 카드 (Personal Settlement Summary)
직원이 가장 궁금해하는 "내 사비 언제 들어오지?"를 한눈에 보여주는 요약 영역입니다.

배경 카드 (그라데이션 또는 깔끔한 단색 톤):

타이틀: 이번 달 사비 정산 대기금

금액: 142,000 원 (내가 개인카드로 긁고 아직 입금 안 된 총액)

우측 작은 화살표(>)를 누르면 [화면 E-03: 정산 내역 및 입금 타임라인]으로 즉시 이동.

3. 메인 액션 버튼 (Floating 또는 하단 고정 CTA)
스마트폰 화면 하단(또는 우측 하단)에 엄지손가락이 닿기 가장 좋은 위치에 큼직하게 고정:

[ 📸 + 영수증 찍고 지출 올리기 ] (터치 시 [화면 E-02: 스냅샷 및 작성 화면]으로 진입)

4. 내 상신 내역 리스트 & 상태 뱃지 (Submission Pipeline)
내가 올린 지출결의서들이 타임라인 형태로 쪼르륵 쌓이는 메인 피드입니다. 각 카드 아이템의 구성은 다음과 같습니다.

카드 아이템 구성 예시:

┌────────────────────────────────────────────────────────┐
│ [식대] 거래처 미팅 식사 진행             [ 🟡 검토 대기 ] │
│ 2026.10.16  •  법인카드                                │
│ 45,000 원                                              │
└────────────────────────────────────────────────────────┘
실시간 상태 뱃지 종류 및 인터랙션:

[ 📝 임시저장 ]: 아직 상신 안 하고 폰에 묵혀둔 건 ➔ 누르면 편집 화면으로 바로 이동해서 마저 작성 가능.

[ 🟡 검토 대기 ]: 사장님/관리자 승인 기다리는 중 ➔ 읽기 전용 상태.

[ ✅ 승인 완료 ]: 승인 떨어짐 (법인카드 건은 여기서 완료, 사비 건은 지급 대기 중).

[ 🔴 반려됨 ] (핵심 인터랙션):

반려된 카드를 터치하면 화면 아래에서 팝업(Bottom Sheet)이 올라오며 반려 사유가 붉은 글씨로 뜸 (예: "영수증 하단 부가세 부분이 잘렸습니다. 다시 찍어주세요").

팝업 안에 [ 수정 후 재상신하기 ] 버튼이 딱 붙어 있어 곧바로 사진을 다시 찍거나 내용을 고쳐서 재상신 가능.

[ 💰 정산 지급 완료 ]: 경리/사장이 개인 계좌로 돈을 쏘고 관리자 모드에서 지급 완료 처리를 누른 순간 바뀜 (지급 일시 기록).
