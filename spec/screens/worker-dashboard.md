# [Spec] 화면 E-01: 직원 메인 대시보드 및 상신 내역

라우트: `/workspace/[id]/employee` / 관련: D-034, D-047, D-049 / 공통: `spec/common/workspace-architecture.md`, `spec/common/ui-rules.md`

## 1. 상단 내비게이션 헤더 (Header & Switcher)
- 앱 타이틀 / 로고: PocketExpense (직원 모드)
- 웰컴 메시지: "안녕하세요, 김개발님 👋"
- **관리자 스위처 (조건부 노출)**: 로그인한 사람이 관리자 이상(최고 관리자·관리자)이면 우측 상단에 **[ ⇄ 관리자 모드로 전환 ]** 버튼. 일반 직원에게는 숨김(D-049).

## 2. 상단 요약 카드 (Personal Settlement Summary)
직원이 가장 궁금해하는 "내 사비 언제 들어오지?"를 한눈에 보여 준다.
- 타이틀: **이번 달 사비 정산 대기금**
- 금액: 142,000원 = 승인되었지만 아직 지급 완료되지 않은 내 소명서들의 지급액 합계(개인카드(사비) 항목의 회사 지원금, `expense-lifecycle.md` §5.5)
- 우측 화살표(>) → [화면 E-03 정산 내역 및 입금 타임라인](`worker-timeline.md`).
- (보완) 반려된 소명서가 있으면 카드 아래에 "반려된 소명서 n건 — 수정이 필요해요" 배너.

## 3. 메인 액션 버튼 (하단 고정 CTA)
- 엄지손가락이 닿기 좋은 하단에 큼직하게 고정: **[ 📸 + 영수증 찍고 지출 올리기 ]** → [화면 E-02](`worker-tax-processing.md`). 누르면 `draft` 소명서를 만들고 바로 촬영/선택 시트를 연다.
- 회사 무료 100장을 모두 쓰면 이벤트 기간에는 자동으로 100장이 추가되어 버튼을 계속 쓸 수 있다(D-054). 이벤트가 꺼진 상태에서 0장이면 버튼 대신 "회사 무료 사용량을 모두 사용했습니다. 관리자에게 문의하세요" 안내(D-046).

## 4. 내 상신 내역 리스트 & 상태 뱃지 (Submission Pipeline)
내가 올린 **지출소명서**들이 최신순으로 쌓이는 메인 피드. 카드 1장 = 소명서 1건(영수증 1장 또는 여러 장, D-034).
```text
┌────────────────────────────────────────────────────────┐
│ [식대] 거래처 미팅 식사 진행               [ 🟡 검토 대기 ] │
│ 2026.10.16  •  법인카드  •  영수증 1장                  │
│ 45,000 원                                              │
└────────────────────────────────────────────────────────┘
┌────────────────────────────────────────────────────────┐
│ [출장] 10/15 부산 출장                    [ ✅ 승인 완료 ] │
│ 2026.10.14~10.15  •  법인 2 · 사비 1  •  영수증 3장      │
│ 72,000 원  (사비 정산 대기 10,000원)                     │
└────────────────────────────────────────────────────────┘
```
- 카드 구성: 대표 카테고리 아이콘(여러 개면 "출장" 또는 아이콘 묶음), 제목, 사용일(기간), 결제수단 요약, 영수증 장수, 합계, 상태 뱃지.
- 필터(보완): 전체 / 임시저장 / 검토 대기 / 반려됨 / 완료. 월 선택(기본 이번 달).

### 상태 뱃지 종류 및 인터랙션 (D-047, `ui-rules.md` §4)
| 뱃지 | 상태 | 인터랙션 |
|---|---|---|
| **📝 임시저장** | `draft` | 누르면 편집 화면(E-02)으로 이동해 마저 작성 |
| **🟡 검토 대기** | `submitted` | 사장님/관리자(또는 사전 검토자) 승인 대기. 읽기 전용 상세(`employee-mobile.md` ④). 사전 검토 중이면 "팀장 검토 중" 보조 문구 |
| **✅ 승인 완료** | `approved` | 승인됨. 사비 지급(또는 법인카드 한도 초과분 납부)이 남아 정산 대기 중 |
| **🔴 반려됨** | `rejected` | 터치하면 하단 팝업(Bottom Sheet)에 반려 사유가 붉은 글씨로 표시(지목 항목 포함). 팝업 안 **[ 수정 후 재상신하기 ]** → E-02 편집 화면 |
| **💰 정산 지급 완료** | `paid` | 관리자가 지급 완료 처리한 순간 바뀜(지급 일시 표시). 법인카드만 있고 정산할 금액이 없는 소명서는 승인과 동시에 이 상태가 되며 "승인 완료 (정산 없음)"으로 표시 |

## 5. 하단 내비게이션 (보완)
- 홈 / 정산(E-03) / 내 정보(`employee-mobile.md` ⑤) — 기본 3개(D-082).
- **결재함**은 관리자 이상이 **아닌** 사전 검토자(결재라인에 검토자로 들어 있거나 검토 차례가 있는 사람)에게만 정산과 내 정보 사이에 보인다(대기 건수 배지). 결재함은 직원 화면 틀 안에서 열려 하단 메뉴가 그대로 남는다.
- 관리자 이상은 직원 모드 하단 메뉴에 결재함이 없다. 결재는 헤더의 [관리자 모드]로 넘어가 [지출 승인 관리]에서 한다(관리자 화면으로 갑자기 넘어가 하단 메뉴가 사라지는 일을 없앰).
- 소명서 목록·상태별 필터·월 선택은 홈에 이미 있으므로 별도 [전체 내역] 탭은 두지 않는다(같은 목록이 두 곳에 생김).
