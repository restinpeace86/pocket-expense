# [Spec] 워크스페이스 설정 및 정책 관리 (Settings & Template Configuration)

## 1. 개요 및 접근 경로
- **목적**: 사내 정산 거버넌스(가입 보안 정책)와 영수증 제출 양식을 회사의 성향에 맞게 유연하게 세팅하는 관리자 전용 공간.
- **접근 경로**: 관리자 대시보드 (`/workspace/[id]/admin`) 상단 또는 사이드바의 **[ ⚙️ 설정 (Settings) ]** 메뉴.

---

## 2. 항목 ①: 직원 가입 보안 및 승인 정책 (Employee Join Policy)
소기업의 보안 성향에 따라 가입 허들을 유연하게 조절할 수 있는 토글 스위치 제공.

- **UI 구성**: `[ 🛡️ 가입 시 관리자 승인 필요 ]` 토글 스위치 (기본값: OFF)
- **모드별 동작 방식**:
  - **OFF 모드 (즉시 가입 - 소기업 권장 / 기본값)**:
    - 직원이 사장님이 공유한 초대 링크(`.../join/...`)로 접속 ➔ 소셜 로그인 ➔ 이름/부서 입력 후 **즉시 승인(`approved`)** 처리되어 직원용 모바일 웹앱으로 직행.
    - 불필요한 대기 병목을 없애 온보딩 성공률을 극대화.
  - **ON 모드 (승인 필수 - 보안 강화형)**:
    - 직원이 가입을 신청하면 DB 상에서 **승인 대기(`pending`)** 상태로 멈춤.
    - 관리자는 대시보드 [멤버 관리] 메뉴에서 신규 가입자의 정보를 확인하고 **[승인]** 버튼을 눌러야 비로소 서비스 이용 가능.

---

## 3. 항목 ②: 지출 정산 템플릿 시스템 (Dual Template Architecture)
초기 진입 장벽을 낮추면서도, 커스텀 양식이 필요한 기업을 흡수하기 위한 이원화 전략.

### A. 기본 제공 템플릿 (Default Standard Template) — *기본 장착*
- **철학**: "가입하자마자 양식 사진 찍어 올리라고 강제하지 않는다."
- **구성**: 시스템이 기본적으로 제공하는 가장 표준적이고 깔끔한 지출결의서/경비 정산 폼.
  - 필수 필드: `사용 일자`, `사용처(상호명)`, `금액`, `부서`, `지출 카테고리(식대, 교통비, 소모품 등)`, `적요(메모)`, `영수증 증빙 사진(필수 첨부)`
- **특징**: 별도의 세팅 없이 회사를 만들자마자 즉시 실무에 투입 가능.

### B. AI 맞춤형 커스텀 템플릿 빌더 (AI Custom Template Builder) — *선택적 확장*
- **철학**: "우리 회사는 평소에 쓰던 독특한 양식이 따로 있다."
- **작동 플로우**:
  1. 관리자 설정 화면에서 **[우리 회사 양식 등록하기]** 버튼 클릭.
  2. 기존에 회사가 쓰던 **엑셀 파일, 워드 문서, 혹은 종이 지출결의서 사진(이미지/PDF)**을 업로드.
  3. **Gemini Vision LLM**이 즉시 도큐먼트를 파싱하여 우리 회사만의 고유 필드 스키마(`custom_schema`)를 자동 추출 및 빌드.
  4. 관리자가 화면에서 추출된 필드들을 확인하고 가볍게 보정(`[저장]`)하면, 이후 직원들이 경비를 청구할 때 **우리 회사만의 커스텀 양식 폼**으로 렌더링됨.
