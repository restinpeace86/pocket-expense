# [Spec] 화면 A-02: 자금 집행 및 정산 지급 관리 (Settlement Payout)

라우트: `/workspace/[id]/admin/payouts` / 사이드바: [💰 정산 지급 관리] / 관련: D-010, D-047 / 짝 화면: 직원 E-03(`worker-timeline.md`)

## 1. 목적
승인된 지출소명서 중 **사비(개인) 지급 또는 법인카드 한도 초과분 납부가 남은 건**을 모아, 경리·사장님이 이체하고 지급 완료로 처리하는 대기열. 정산 단위는 **지출소명서**다(D-047).

## 2. 대상
- 상태 `approved`(정산 대기)인 소명서. 지급액 = 사비 항목 회사 지원금 합계, 납부액 = 법인카드 항목 개인 부담 합계(`expense-lifecycle.md` §5.5).
- 법인카드만 있고 지급·납부가 모두 0인 소명서는 승인과 동시에 `paid`가 되므로 이 목록에 나오지 않는다.

## 3. 화면 구성
- 상단 요약: 미지급 사비 총액, 대상 소명서 수, 미수 납부액 총액.
- 탭: [정산 대기] / [지급 완료](기간 필터).
- 직원별 묶음 테이블(정산 대기 탭):
  | 선택 | 직원(부서) | 정산 계좌(은행 / 계좌번호 / 예금주, 복사 버튼) | 소명서(제목·승인일) | 지급액 | 납부액 |
  - 직원 행을 펼치면 포함된 소명서와 사비 항목 목록.
  - 정산 계좌 미등록 직원은 "계좌 미등록" 배지(직원에게 등록 요청 안내 문구 복사 버튼).
- 체크박스로 직원/소명서 단위 일괄 또는 개별 선택 → 하단 **[ 💰 정산 지급 완료 처리 ]**.
  - 확인 다이얼로그: "직원 3명 · 소명서 5건 · 지급 132,000원 / 납부 확인 8,000원".
  - 처리 시 각 소명서 `paid`, `paid_at`, `paid_by_member_id` 기록 → 직원 E-03 갱신 → 지급액이 있는 소명서는 직원에게 알림톡(`notification-rule.md` 트리거 D).
- 실제 계좌 이체는 회사 은행에서 직접 하며, 이 화면은 이체 체크리스트와 처리 기록 역할만 한다(금융망 연동 없음, 도입비 0원 원칙).
