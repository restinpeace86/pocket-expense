# [Spec] 결재자 화면 (알림톡 링크 진입)

관련: `spec/features/approval-workflow.md`, `spec/features/kakao-alimtalk.md` / 라우트: `spec/common/routes.md` §3
이 화면을 쓰는 사람(D-039): **사전 검토자**(결재라인에 지정된 팀장 등, 역할 무관)와 **관리자 최종 승인자**(관리자 이상, 알림톡 링크로 모바일에서 승인할 때). 모바일 우선이며 PC에서도 같은 화면을 쓴다. 관리자의 PC 업무 화면은 `admin-expense-approvals.md`.
결재 단위는 **지출결의서 1건**이다(D-034). 결의서 안 모든 영수증 항목을 한 번에 승인하거나 결의서 전체를 반려한다.

## ① 결재 화면 (`/workspace/[id]/approvals/[claimId]`) — 알림톡 [결재하기] 도착지
진입: 알림톡 링크 → 로그인 확인(세션 유지 시 바로 표시, 미로그인 시 로그인 후 복귀).

- **상단 요약**: 결의서 제목, 출장 결의서면 출장지·출장 기간·출장 목적, 청구자 이름·부서, **합계(크게)**, 건수, 기간(첫~마지막 사용일), 정산 요약(지급 n원 / 납부 m원), 결재 진행도 "2단계 중 1단계 — 내 차례". 지출 사유가 있으면 표시. 주말·심야 사용이나 예외 소명 사유가 있으면 노란 칸으로 표시(D-084).
- **확인 포인트 요약**(해당 시 노란 배지와 건수): 일반 식대 한도 초과, 직접 입력 거리, 합계≠공급가액+부가세, 청구 기한 초과(D-031), 출장 기간 밖 결제(D-035).
- **영수증 항목 리스트**: 행마다 카테고리·세부 유형 아이콘(출장 식비와 일반 식대를 구분 표시), 가맹점, 사용일자, 금액, 결제수단, 확인 포인트 배지, 썸네일.
  - 행 탭 → 항목 상세: **영수증 원본과 읽어낸 값을 나란히** 표시(D-037). 모바일은 위 원본(확대/핀치 줌, PDF는 첫 페이지 + [원본 열기]) / 아래 값, PC(≥768px)는 왼쪽 원본 / 오른쪽 값. 값: 가맹점, 사용일자, 합계·공급가액·부가세, 카테고리·세부 유형, 결제수단, 카테고리별 입력, 계산 내역(식대 "1인 10,000원 × 3명 = 30,000원 한도", 자차 "128.4km × 200원"), 양식 항목 필드. [이전] [다음]으로 항목 넘김.
  - **"직원 수정" 표시**(D-037): AI가 읽은 값(`ai_parsed_payload`)과 최종 값이 다른 칸(가맹점, 사용일자, 합계, 공급가액, 부가세)에 표시하고 "AI 13,000 → 직원 15,000"처럼 두 값을 보여 준다. 파싱 실패로 직접 입력한 항목은 "직접 입력" 표시.
  - [영수증 모아보기]: 모든 영수증을 가로 스와이프로 연속 확인. 각 장 아래에 그 영수증의 핵심 값(가맹점·일자·금액·세부 유형)과 "직원 수정" 표시를 함께 보여 준다.
- **지출결의서**: 회사 양식 렌더링(헤더 + 항목 표 + 결재란). 접기/펼치기, 기본 접힘.
- **이전 회차 이력**: 재상신 건이면 이전 반려 사유·지목 항목과 반려자 표시.
- **하단 고정 버튼**(처리 권한이 있을 때만): 사전 검토자 → [반려] [검토 승인] / 관리자 최종 단계 → [결의서 반려] [일괄 승인 (3건 · 72,000원)]. 관리자에게는 항목 행에 계정과목과 마감 요약(세무 증빙 총액·통장 실지출·납부액)도 표시한다.
  - 승인: 확인 다이얼로그 + 코멘트(선택) → 완료 화면.
  - 반려: 바텀시트에서 사유 입력(필수, 5자 이상) + 문제 항목 체크(선택) → 완료 화면.
- **상태별 표시**:
  - 내 차례가 아님(앞 단계 대기): "앞 단계 검토 대기 중입니다(박영업팀장)" + 읽기 전용. 본인 결의서: "본인 결의서는 다른 관리자가 승인합니다".
  - 이미 처리함 / 다른 결과로 종료: "이미 처리된 결재입니다 (승인 · 10/13 14:02)" + 읽기 전용.
  - 열람 권한 없음: "접근 권한이 없습니다" + 홈 버튼.
- **완료 화면**: "승인했어요. 다음 결재자 이대표님께 전달됩니다" / "반려했어요. 청구자에게 사유가 전달됩니다" + [다음 결재 n건 보기] / [닫기].

## ② 내 결재함 (`/workspace/[id]/approvals`)
- 탭: **대기**(내가 처리할 수 있는 `pending`: 사전 검토자는 지정된 단계, 관리자는 관리자 승인 단계) / **처리완료**(내가 승인·반려한 결의서). 관리자는 PC의 [지출 승인 관리]와 같은 목록을 본다.
- 카드: 결의서 제목, 청구자, 건수·합계, 기간, 상신일, 확인 포인트 배지. 오래된 상신일 순.
- 대기 탭이 비면 "결재할 결의서가 없어요".
- 여러 결의서를 한 번에 승인하는 기능은 제공하지 않는다(결의서별 영수증 확인 원칙).
