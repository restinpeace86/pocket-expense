# [Spec] 결재자 화면 (알림톡 링크 진입)

관련: `spec/features/approval-workflow.md`, `spec/features/kakao-alimtalk.md` / 라우트: `spec/common/routes.md` §3
결재자 = 결재라인에 지정된 멤버(대표, 팀장 등). 관리자 여부와 무관하다. 모바일 우선이며 PC에서도 같은 화면을 쓴다.
결재 단위는 **지출소명서 1건**이다(D-034). 소명서 안 모든 영수증 항목을 한 번에 승인하거나 소명서 전체를 반려한다.

## ① 결재 화면 (`/workspace/[id]/approvals/[claimId]`) — 알림톡 [결재하기] 도착지
진입: 알림톡 링크 → 로그인 확인(세션 유지 시 바로 표시, 미로그인 시 로그인 후 복귀).

- **상단 요약**: 소명서 제목, 청구자 이름·부서, **합계(크게)**, 건수, 기간(첫~마지막 사용일), 정산 요약(지급 n원 / 납부 m원), 결재 진행도 "2단계 중 1단계 — 내 차례". 소명 내용이 있으면 표시.
- **확인 포인트 요약**(해당 시 노란 배지와 건수): 식대 한도 초과, 직접 입력 거리, 합계≠공급가액+부가세, 청구 기한 초과(D-031).
- **영수증 항목 리스트**: 행마다 카테고리 아이콘, 가맹점, 사용일자, 금액, 결제수단, 확인 포인트 배지, 썸네일.
  - 행 탭 → 항목 상세 바텀시트: 영수증 원본(확대/핀치 줌, PDF는 첫 페이지 + [원본 열기]), 입력값, 계산 내역(식대 "1인 10,000원 × 3명 = 30,000원 한도", 자차 "128.4km × 200원"), 양식 항목 필드. [이전] [다음]으로 항목 넘김.
  - [영수증 모아보기]: 모든 영수증을 가로 스와이프로 연속 확인.
- **지출소명서**: 회사 양식 렌더링(헤더 + 항목 표 + 결재란). 접기/펼치기, 기본 접힘.
- **이전 회차 이력**: 재상신 건이면 이전 반려 사유·지목 항목과 반려자 표시.
- **하단 고정 버튼**(내 차례일 때만): [반려] [전체 승인 (3건 · 72,000원)].
  - 승인: 확인 다이얼로그 + 코멘트(선택) → 완료 화면.
  - 반려: 바텀시트에서 사유 입력(필수, 5자 이상) + 문제 항목 체크(선택) → 완료 화면.
- **상태별 표시**:
  - 내 차례가 아님(앞 단계 대기): "앞 단계 결재 대기 중입니다" + 읽기 전용.
  - 이미 처리함 / 다른 결과로 종료: "이미 처리된 결재입니다 (승인 · 10/13 14:02)" + 읽기 전용.
  - 열람 권한 없음: "접근 권한이 없습니다" + 홈 버튼.
- **완료 화면**: "승인했어요. 다음 결재자 이대표님께 전달됩니다" / "반려했어요. 청구자에게 사유가 전달됩니다" + [다음 결재 n건 보기] / [닫기].

## ② 내 결재함 (`/workspace/[id]/approvals`)
- 탭: **대기**(내 차례 `pending`) / **처리완료**(내가 승인·반려한 소명서).
- 카드: 소명서 제목, 청구자, 건수·합계, 기간, 상신일, 확인 포인트 배지. 오래된 상신일 순.
- 대기 탭이 비면 "결재할 소명서가 없어요".
- 여러 소명서를 한 번에 승인하는 기능은 제공하지 않는다(소명서별 영수증 확인 원칙).
