# [Spec] 결재자 화면 (알림톡 링크 진입)

관련: `spec/features/approval-workflow.md`, `spec/features/kakao-alimtalk.md` / 라우트: `spec/common/routes.md` §3
결재자 = 결재라인에 지정된 멤버(대표, 팀장 등). 관리자 여부와 무관하다. 모바일 우선이며 PC에서도 같은 화면을 쓴다.

## ① 결재 화면 (`/workspace/[id]/approvals/[expenseId]`) — 알림톡 [결재하기] 도착지
진입: 알림톡 링크 → 로그인 확인(세션 유지 시 바로 표시, 미로그인 시 로그인 후 복귀).

- **상단 요약**: 청구자 이름·부서, 카테고리, **금액(크게)**, 결제일자, 가맹점, 결제수단, 결재 진행도 "2단계 중 1단계 — 내 차례".
- **영수증 원본**: 화면 폭 이미지, 탭하면 확대/핀치 줌. PDF는 첫 페이지 이미지 + [원본 열기].
- **확인 포인트**(해당 시 노란 배지): 식대 한도 초과(개인 부담 n원), 직접 입력 거리, 합계≠공급가액+부가세, 청구 기한 초과(회사가 기한을 설정한 경우, D-031).
- **지출결의서**: 회사 양식 렌더링(자동 채움 값 + 고유 항목 + 결재란). 접기/펼치기, 기본 펼침.
- **계산 내역**: 식대 "1인 10,000원 × 3명 = 30,000원 한도 / 회사 지원 30,000원 + 개인 부담 6,000원", 자차 "128.4km × 200원".
- **이전 회차 이력**: 재상신 건이면 이전 반려 사유와 반려자 표시.
- **하단 고정 버튼**(내 차례일 때만): [반려] [승인].
  - 승인: 확인 다이얼로그 + 코멘트(선택) → 완료 화면.
  - 반려: 바텀시트에서 사유 입력(필수, 5자 이상) → 완료 화면.
- **상태별 표시**:
  - 내 차례가 아님(앞 단계 대기): "앞 단계 결재 대기 중입니다" + 읽기 전용.
  - 이미 처리함 / 다른 결과로 종료: "이미 처리된 결재입니다 (승인 · 10/13 14:02)" + 읽기 전용.
  - 열람 권한 없음: "접근 권한이 없습니다" + 홈 버튼.
- **완료 화면**: "승인했어요. 다음 결재자 이대표님께 전달됩니다" / "반려했어요. 청구자에게 사유가 전달됩니다" + [다음 결재 n건 보기] / [닫기].

## ② 내 결재함 (`/workspace/[id]/approvals`)
- 탭: **대기**(내 차례 `pending`) / **처리완료**(내가 승인·반려한 건).
- 카드: 청구자, 카테고리, 금액, 결제일자, 상신일, 확인 포인트 배지. 오래된 상신일 순.
- 대기 탭이 비면 "결재할 경비가 없어요".
- 일괄 승인은 제공하지 않는다(영수증 확인 원칙).
