# [Spec] 화면 E-02: 영수증 스냅샷 & 지출소명서 작성

라우트: `/workspace/[id]/employee/claims/[claimId]/edit`(소명서), `/workspace/[id]/employee/claims/[claimId]/items/[itemId]`(영수증 항목) / 관련: D-034, D-035, D-046, D-048, D-050, D-051 / 흐름: `spec/features/expense-claim-flow.md` / 파싱: `spec/features/receipt-parser.md`

**영수증 1장으로 소명서 1건을 만들 수도 있고, 여러 장을 한 소명서에 담을 수도 있다**(D-034). DB에는 영수증마다 항목 1건씩 저장되고, 결재는 소명서 단위로 한 번 받는다.

## 1단계: 영수증 캡처 및 AI Vision 자동 채움 (Quick Capture & Auto-Fill)
E-01의 [ 📸 + 영수증 찍고 지출 올리기 ]를 누르면 `draft` 소명서가 만들어지고 입력 방식 선택 시트가 열린다.
- **[ 📷 카메라로 직접 촬영 ]**: 식당 종이 영수증, 택시 영수증 등. 연속 촬영으로 여러 장을 한 번에 담을 수 있다.
- **[ 🖼️ 갤러리에서 불러오기 ]**: 배달 앱 결제 캡처, KTX 예매증, 모바일 영수증 PDF 등. 다중 선택 가능(소명서당 최대 30장).
- **[ 영수증 없이 항목 추가 ]**(보완): 자차 유류비 등 영수증이 없는 항목.
- PC에서는 카메라 촬영 대신 파일 선택만 보이고 "카메라 촬영은 모바일에서 사용 가능합니다" 안내(`workspace-architecture.md` §2.C).
- 영수증 1장 업로드 = 무료 크레딧 1장 차감(D-046). 업로드 중 100장을 모두 쓰면 이벤트로 100장이 바로 추가되어 업로드가 이어지고 "회사 무료 영수증 100장을 모두 사용했습니다. 현재 이벤트 기간이라 추가 100장을 무료로 더 드립니다" 토스트를 보여 준다(D-054). 이벤트가 꺼져 있으면 남은 만큼만 올리고 안내한다.

**AI Vision 즉시 파싱 (Loading State)**: 영수증마다 "AI가 영수증을 읽고 있어요... 🪄" 로딩 후 항목에 자동 입력된다.
- 사용 일자, 가맹점명/사용처(예: "스타벅스 강남점"), **가맹점 사업자등록번호**(D-050)
- 공급가액 / 부가세 / 합계금액
- **증빙구분 추정**: 카드매출전표 / 현금영수증 / 세금계산서 / 간이영수증(D-051)
- 카테고리·출장 세부 유형 추천(D-032, D-035)
- 실패 시 "자동 인식에 실패했어요. 직접 입력해 주세요"(원본은 저장됨).

## 2단계: 결제수단 선택 (Default: 법인카드) — D-048
AI가 읽은 금액 바로 아래 토글. 소명서 헤더에서 정한 기본값이 새 항목에 적용되고 항목별로 바꿀 수 있다.
- **[ 🔘 법인카드 (Default) ]**: 회사 법인카드로 결제(별도 정산 불필요, 한도 초과분이 있으면 직원 납부).
- **[ ⚪ 개인(사비) ]**: 내 돈(개인카드·현금)으로 냈기 때문에 회사로부터 돌려받아야 하는 경우. 승인 후 사비 정산 대기열로 들어간다.
- 자차 유류비 항목은 개인(사비) 고정.

## 3단계: 필수 입력 항목 직접 작성 (신청자 작성 포인트)
AI나 회사 기본 세팅으로 채워지지 않는 항목. 누락 방지를 위해 붉은 별표(*)와 입력 가이드를 붙인다.

### 3-1. 소명서(헤더) — 한 번만 입력
- **지출소명서 제목 (*)**: 예 "클라이언트 미팅 간식 구입". 비어 있으면 자동 제안 — 영수증 1장이면 "{가맹점} 지출", 여러 장이면 "{첫 사용일 M/D} {첫 가맹점} 외 n건", 출장이면 "{시작일 M/D} {출장지} 출장". 직원이 수정 가능.
- **적요 / 소명 내용 (*)**: 예 "A사 프로젝트 킥오프 미팅 시 참석자 음료 제공". 관리자가 "이 돈을 왜 썼지?" 하고 물어볼 일이 없도록 한 줄 소명.
- **[출장 경비] 스위치**(보완): 켜면 출장지·출장 기간·출장 목적(필수)이 나타나고, 이후 영수증은 출장비로 분류된다(`trip-expense.md` §2).
- 회사 양식 헤더 고유 항목(있을 때만, `form-template.md`).

### 3-2. 영수증 항목 표 (보완)
- 행마다 썸네일, 가맹점(자차는 "출발지 → 도착지"), 사용일자, 금액, 카테고리 아이콘, 결제수단 배지, 상태("분석 중" / "확인 필요" / "입력 완료" / 반려 시 "지목됨").
- 행 탭 → 항목 편집, 왼쪽 스와이프 → 삭제, [영수증 추가]로 계속 추가.
- 영수증이 1장뿐이면 표 대신 항목 편집 내용을 바로 펼쳐 보여 준다.

### 3-3. 항목 편집 (영수증 1장 단위)
1. 영수증 썸네일(탭하면 확대), [다시 올리기](같은 항목 교체는 크레딧 추가 차감 없음).
2. 영수증 정보: 가맹점명, 사업자등록번호, 사용일자, 합계·공급가액·부가세, 증빙구분. "AI 입력" 표시. 합계 ≠ 공급가액+부가세, 청구 기한 초과, 출장 기간 밖이면 노란 경고.
3. **지출 카테고리 (*)**: [식대] [출장비] [외부 미팅비] 고정 3개(D-008). 출장비면 세부 유형 칩(출장 식비 / 대중교통 / 택시 / 통행료·주차 / 숙박 / 자차 유류비 / 기타).
4. **[조건부 확장 항목]**: 카테고리에 따라 추가 필드가 나타난다.
   - 식대·출장 식비: 인원수 스테퍼 + 1식 한도 분할 안내(`smart-meal.md`).
   - 외부 미팅비: 미팅 목적(필수), 거래처명, 참석자, 인원수.
   - 출장비/숙박: 체크인~체크아웃(필수). 출장비/자차: 출발지·도착지 주소 검색, [거리 계산], 주행거리, 계산식, 차량번호(`trip-expense.md`). 출장비/기타: 적요(필수).
5. 회사 양식 항목 필드(현재 카테고리 적용분).
6. [이전 항목] [다음 항목] / [완료].

### 3-4. 합계·미리보기 (보완)
- 합계, 회사 지원 / 개인 부담, "사비 지급 예정 n원 / 법인카드 한도 초과 납부 m원".
- [지출소명서 미리보기] → 양식 렌더링(헤더 + 항목 표).
- 결재선 미리보기: "관리자 승인" 또는 "박영업팀장 검토 → 관리자 승인". 최고 관리자 본인이면 "결재 생략 — 바로 승인됩니다".

## 4단계: 하단 액션 버튼 (Action Bar)
- **좌측 [ 💾 임시저장 ]**: 영수증만 우선 찍어 두고 사무실에 돌아와 마저 쓰거나, 나중에 영수증을 더 추가해 한꺼번에 올리고 싶을 때. 임시저장은 **서버에 저장**되어 다른 기기(PC)에서도 이어서 작성할 수 있다(`draft`). 저장한 소명서는 E-01에 [📝 임시저장]으로 남는다.
- **우측 [ 🚀 결재 상신 ]**: "결재를 상신하시겠습니까? (3건 · 72,000원)" 확인 후 상신. 검증 실패 항목이 있으면 해당 행을 강조하고 첫 문제 항목으로 이동(`expense-lifecycle.md` §2). 분석 중인 항목이 있으면 비활성.
  - 상신과 동시에 결재 대상자(관리자 이상, 또는 사전 검토자)에게 카카오 알림톡(`notification-rule.md` 트리거 A), 직원 화면은 E-01로 돌아가 해당 건이 [ 🟡 검토 대기 ]로 바뀐다.
  - 반려 건이면 버튼명 [ 🚀 재상신 ].

## 5. 승인 이후 흐름 (결제수단별, D-047 — 정산은 소명서 단위)
- **💳 법인카드 항목만 있고 정산할 금액이 없는 소명서**: 관리자가 [ ✅ 승인 ]하는 순간 처리가 끝나(`paid`, "승인 완료(정산 없음)") 곧바로 월말 세무 마감 데이터로 들어간다.
- **🧾 개인(사비) 항목이 포함된 소명서**(법인카드와 섞여도 됨): 승인 이후 소명서 단위로 **[ 🟡 정산 대기 ➔ 💰 지급 완료 ]** 자금 집행 루프가 돈다. 지급액 = 소명서 안 사비 항목의 회사 지원금 합계(`worker-timeline.md`, `admin-payouts.md`).
- 법인카드 한도 초과분(직원 납부액)이 있으면 같은 정산 단계에서 "납부 n원"으로 함께 표시·처리한다.
- 어느 경우든 세무 마감 엑셀에는 영수증 1장 = 1행으로 들어간다(`tax-closing.md`).
