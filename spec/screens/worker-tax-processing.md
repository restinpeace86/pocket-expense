# [Spec] 화면 E-02: 영수증 스냅샷 & 지출결의서 작성

라우트: `/workspace/[id]/employee/claims/[claimId]/edit`(결의서), `/workspace/[id]/employee/claims/[claimId]/items/[itemId]`(영수증 항목) / 관련: D-034, D-035, D-046, D-048, D-050, D-051, D-055 / 흐름: `spec/features/expense-claim-flow.md` / 파싱: `spec/features/receipt-parser.md`

**영수증 1장으로 결의서 1건을 만들 수도 있고, 여러 장을 한 결의서에 담을 수도 있다**(D-034). DB에는 영수증마다 항목 1건씩 저장되고, 결재는 결의서 단위로 한 번 받는다.

## 1단계: 영수증 캡처 및 AI Vision 자동 채움 (Quick Capture & Auto-Fill)
E-01의 [ 📸 + 영수증 찍고 지출 올리기 ]를 누르면 `draft` 결의서가 만들어지고 입력 방식 선택 시트가 열린다.
- **[ 📷 카메라로 직접 촬영 ]**: 식당 종이 영수증, 택시 영수증 등. 연속 촬영으로 여러 장을 한 번에 담을 수 있다.
- **[ 🖼️ 갤러리에서 불러오기 ]**: 배달 앱 결제 캡처, KTX 예매증, 모바일 영수증 PDF 등. 다중 선택 가능(결의서당 최대 30장).
- **[ 영수증 없이 항목 추가 ]**(보완): 자차 유류비 등 영수증이 없는 항목.
- PC에서는 카메라 촬영 대신 파일 선택만 보이고 "카메라 촬영은 모바일에서 사용 가능합니다" 안내(`workspace-architecture.md` §2.C).
- 영수증 1장 업로드 = 무료 크레딧 1장 차감(D-046). 업로드 중 100장을 모두 쓰면 이벤트로 100장이 바로 추가되어 업로드가 이어지고 "회사 무료 영수증 100장을 모두 사용했습니다. 현재 이벤트 기간이라 추가 100장을 무료로 더 드립니다" 토스트를 보여 준다(D-054). 이벤트가 꺼져 있으면 남은 만큼만 올리고 안내한다.

**AI Vision 즉시 파싱 (Loading State)**: 영수증마다 "AI가 영수증을 읽고 있어요... 🪄" 로딩 후 항목에 자동 입력된다.
- 사용 일자, 가맹점명/사용처(예: "스타벅스 강남점"), **가맹점 사업자등록번호**(D-050)
- 공급가액 / 부가세 / 합계금액
- **증빙구분 추정**: 카드매출전표 / 현금영수증 / 세금계산서 / 간이영수증(D-051)
- 카테고리·출장 세부 유형 추천(D-032, D-035)
- 실패 시 "자동 인식에 실패했어요. 직접 입력해 주세요"(원본은 저장됨).

## 2단계: 결제수단 선택 (Default: 법인카드) — D-048
AI가 읽은 금액 바로 아래 토글. 결의서 헤더에서 정한 기본값이 새 항목에 적용되고 항목별로 바꿀 수 있다.
- **[ 🔘 법인카드 (Default) ]**: 회사 법인카드로 결제(별도 정산 불필요, 한도 초과분이 있으면 직원 납부).
- **[ ⚪ 개인(사비) ]**: 내 돈(개인카드·현금)으로 냈기 때문에 회사로부터 돌려받아야 하는 경우. 승인 후 사비 정산 대기열로 들어간다.
- 자차 유류비 항목은 개인(사비) 고정.
- **법인카드 자동 판별(회사가 법인카드를 등록한 경우, D-083)**: AI가 읽은 카드번호의 보이는 숫자(가려진 자리 제외)가 등록 카드 1장과 맞으면 법인카드 + 해당 카드를 자동 선택("💳 대표 법인카드(7890)로 인식했어요"), 여러 장과 맞으면 법인카드로 두고 카드를 고르게 하며, 맞지 않으면 개인(사비)을 추천하고 확인 문구를 보여 준다. 법인카드를 고르면 [사용한 카드] 선택(카드가 1장이면 자동). 직원이 바꾸면 그 값이 최종값(`corporate-cards.md` §3).

## 3단계: 필수 입력 항목 직접 작성 (신청자 작성 포인트)
AI나 회사 기본 세팅으로 채워지지 않는 항목. 누락 방지를 위해 붉은 별표(*)와 입력 가이드를 붙인다.

### 3-1. 결의서(헤더) — 한 번만 입력
- (D-109) 맨 위 요약 한 줄: 영수증 n장 · 확인 필요 n장(누르면 그 영수증이 펼쳐짐) · 합계.
- **지출 카테고리 (*) — 결의서에 1개 (D-098)**: 맨 위에 [일반 식대] [외부 미팅비] [회사 물품 구매] [출장비]. 한 전표 = 한 계정과목이라 결의서 전체의 성격을 여기서 정하고, 모든 영수증(자차 유류비 제외)이 이 카테고리를 따른다(DB 트리거). 고르면 바로 저장된다. 고른 카테고리에 맞는 칸만 나온다:
  - 일반 식대: 인원(기본값). 저장하면 영수증 인원에 한 번 들어가고, 영수증마다 다르면 펼쳐서 고친다(1식 한도 계산은 영수증별).
  - 외부 미팅비: 미팅 목적(필수)·거래처명·참석자 — 결의서에 한 번. 인원(기본값).
  - 회사 물품 구매: 구매 세부 유형(필수)·구매 목적(필수)·품목(선택) — 결의서에 한 번. 영수증 적요에는 "목적 · 품목".
  - 출장비: 출장지·출장 기간·이동 수단·출장 목적(아래 출장 정보, 자차는 그 자리에서 경로 입력 D-097). 출장비를 고르면 출장 결의서(`is_business_trip`).
  - 자차 이동이 있는 출장 결의서는 다른 카테고리로 바꿀 수 없다(자차 이동을 먼저 지움).
  - (D-103) 카테고리를 아직 안 골랐으면 올린 영수증의 AI 카테고리가 하나로 모일 때 그 값으로 골라 두고 "✨ AI 추천"으로 표시(자동 저장). 정할 수 없으면 상신 불가.
  - (D-104) AI가 본 종류가 결의서 카테고리와 다른 영수증은 목록에 "카테고리 확인", 카드에 [새 {AI 카테고리} 결의서로 옮기기]·[이 결의서가 맞아요]. 고르기 전에는 상신 불가.
  - (D-105) 회사차량: 차량 고르기(등록된 차량이 있으면 필수, `company-vehicles.md`). 출장의 이동 수단 [회사차량]도 같은 차량 고르기(D-106).
  - (D-107) 식대·외부 미팅비·회식비를 고르면 판단 기준 한 줄: 회사 사람끼리 → 식대/회식비, 거래처·외부 사람이 함께 → 외부 미팅비.
  - (D-102) 4대 카테고리 아래 접힌 **[그 밖의 경비]**: 회식비·경조사비·세미나·컨퍼런스 참가·업무용 도서 구입·교육·훈련·회사차량·온라인 SaaS 구독료. 추가 입력 칸 없음, 전액 지원(1식 한도 없음).
  - 카테고리가 없는 예전 결의서: 출장 결의서면 출장비, 영수증 카테고리가 하나뿐이면 그것으로 미리 골라 두고, 섞여 있으면 직원이 고른다(그 전에는 상신 검증이 "지출 카테고리"를 묻는다).
- **지출결의서 제목 (*)**: 예 "클라이언트 미팅 간식 구입". 자동 제안(D-087, D-098) — 영수증 1장이면 "[카테고리] {가맹점}"(예: "[외부 미팅비] 메가커피 판교점"), 여러 장이면 "[카테고리] {대표 가맹점} 외 n건". 대표 = 사용일이 가장 빠른 영수증, 카테고리 = 결의서 대표 카테고리 이름(D-098, 예전 결의서는 대표 영수증의 카테고리, 둘 다 없으면 대괄호 없이). 카테고리를 고르거나 영수증이 늘면 제목이 바로 따라 바뀐다. 출장 결의서도 같은 모양("[출장비] {가맹점} 외 n건")이고, 영수증이 아직 없을 때만 "{시작일 M/D} {출장지} 출장". 직원이 제목을 직접 고쳐 쓰면 그 제목으로 고정(자동 모양으로 저장된 제목은 계속 자동). 규칙: `src/lib/expense/title.ts`.
- **적요 / 지출 사유 (*)**: 예 "A사 프로젝트 킥오프 미팅 시 참석자 음료 제공". 관리자가 "이 돈을 왜 썼지?" 하고 물어볼 일이 없도록 한 줄로.
  - **AI 초안(D-086)**: 직원이 쓰기 전까지 영수증 AI 인식 결과로 만든 초안을 칸에 채워 둔다("✨ AI 초안" 표시). 영수증마다 AI가 쓴 한 줄 사유(`suggested_purpose`)를 모으고(같은 문구는 한 번, 세 종류 이상이면 앞 두 개 + "등"), AI 사유가 없으면 분류별 표준 문구(식대 점심/저녁, 외부 미팅, 탕비실·비품, 출장 교통·숙박·식사), 출장 결의서는 "{출장 목적} 관련 출장 경비". 그대로 저장·상신할 수 있고, 누르는 순간 직원이 쓴 값이 최종값. 규칙: `src/lib/expense/purpose.ts`.
- **예외 소명 사유 (선택, D-084)** — (D-109) 주말·심야 사용이 있거나 이미 적었을 때만 보인다: 주말·심야 등 예외 건의 해명을 결의서 한 곳에 적는다(500자). 영수증 중 주말(토·일 사용일) 또는 심야(결제 시각 22:00~05:59)가 있으면 "주말 사용 n건 · 심야(22시~06시) 사용 m건이 있어요. 왜 이때 썼는지 적어 두면 결재가 빨라져요." 노란 안내. 비워도 상신은 막지 않는다. 공휴일은 따지지 않는다.
- ~~[출장 경비] 스위치~~ → (D-098) 지출 카테고리 [출장비]로 대체. 고르면 출장지·출장 기간·이동 수단·출장 목적(필수)이 나타난다(`trip-expense.md` §2).
- 회사 양식 헤더 고유 항목(있을 때만, `form-template.md`).

### 3-2. 영수증 항목 표 (보완)
- 행마다 썸네일, 가맹점(자차는 "출발지 → 도착지"), 사용일자, 금액, 카테고리 아이콘, 결제수단 배지, 상태("분석 중" / "확인 필요" / "입력 완료" / 반려 시 "지목됨").
- 행 탭 → 항목 편집, 왼쪽 스와이프 → 삭제, [영수증 추가]로 계속 추가.
- 영수증이 1장뿐이면 표 대신 항목 편집 내용을 바로 펼쳐 보여 준다.

### 3-3. 항목 편집 (영수증 1장 단위)
> (D-096) 별도 화면으로 이동하지 않고 결의서 화면의 영수증 카드 안에서 펼쳐(아코디언) 고친다. 카드 또는 아래 노치 탭 [펼쳐서 고치기/접기]로 열고 닫으며, 고치면 자동 저장(0.8초), 임시저장·상신 전에 펼친 내용을 먼저 저장한다. 상신 시 빠진 칸이 있는 영수증은 자동으로 펼친다. 자차 유류비만 경로 화면(개선사항 4에서 인라인화 예정).
1. 영수증 썸네일(탭하면 확대), [다시 올리기](같은 항목 교체는 크레딧 추가 차감 없음).
2. 영수증 정보: 가맹점명, 사업자등록번호, 사용일자, 합계·공급가액·부가세, 증빙구분(D-100: AI가 정하고 없으면 카드매출전표, "증빙 구분 {값} [바꾸기]" + 연한 회색 판별 이유). "AI 입력" 표시. 합계 ≠ 공급가액+부가세, 청구 기한 초과, 출장 기간 밖이면 노란 경고.
2-1. (D-108) **증빙 자료**: 사진이 있으면 "증빙 자료 {종류} [바꾸기]"(영수증·인보이스/결제 메일·앱 이용 내역·카드 결제 내역·청첩장/부고 안내·기타, AI 추천). 사진이 없으면 [사진·PDF 올리기] 또는 [자료가 정말 없어요] → 사유(5자 이상, 가산세 안내). 직원이 붙인 자료는 [자료 떼기].
3. ~~지출 카테고리~~ → (D-098) 영수증에는 카테고리 칸이 없다(결의서 대표 카테고리를 따름, 카테고리 이름만 한 줄로 보여 줌). 출장 결의서의 영수증은 출장비 세부 유형만 고른다(D-097). 결의서 카테고리를 아직 안 골랐으면 "결의서 위에서 지출 카테고리를 먼저 골라 주세요". 출장비면 세부 유형 칩(출장 식비 / 대중교통 / 택시 / 통행료·주차 / 숙박 / 자차 유류비 / 기타), 회사 물품 구매면 세부 유형 칩(탕비실·간식 / 사무용품·소모품 / 소액 비품).
4. **[조건부 확장 항목]**: 카테고리에 따라 추가 필드가 나타난다.
   - 식대·출장 식비: 인원수 스테퍼 + 1식 한도 분할 안내(`smart-meal.md`).
   - 외부 미팅비: 인원수(미팅 목적·거래처·참석자는 결의서에서 한 번, D-098).
   - 회사 물품 구매: 영수증별 추가 칸 없음(세부 유형·목적·품목은 결의서에서 한 번, D-098). 전액 지원.
   - 출장비/숙박: 체크인~체크아웃(필수). 출장비/자차: 출발지·도착지 주소 검색, [거리 계산], 주행거리, 계산식, 차량번호(`trip-expense.md`). 출장비/기타: 적요(필수).
5. 회사 양식 항목 필드(현재 카테고리 적용분).
6. ~~[이전 항목] [다음 항목] / [완료]~~ → (D-096) 한 화면에서 여러 카드를 펼쳐 고치므로 없음.
7. (D-079) 같은 영수증으로 보이는 항목이 있으면 맨 위에 "이미 올린 영수증 같아요" 경고(막지 않음, 목록 행에는 "중복 의심" 배지). 영수증 정보 아래에 접힌 "AI가 읽은 참고 정보"(결제 시각·승인번호·가맹점 주소·품목 표, 결의서에는 들어가지 않음).

### 3-4. 합계·미리보기 (보완)
- 합계, 회사 지원 / 개인 부담, "사비 지급 예정 n원 / 법인카드 한도 초과 납부 m원".
- [지출결의서 미리보기] → 양식 렌더링(헤더 + 항목 표).
- 결재선 미리보기: "관리자 승인" 또는 "박영업팀장 검토 → 관리자 승인". 최고 관리자 본인이면 "결재 생략 — 바로 승인됩니다".

## 4단계: 하단 액션 버튼 (Action Bar)
> (D-103) [임시저장] 버튼은 없앴다. 결의서 칸·영수증 모두 자동 저장되고, 하단 바에는 저장 상태(✓ 자동 저장됨 / 저장 중… / 저장 실패 · 다시 저장)와 [결재 상신]만 둔다.
- **좌측 [ 💾 임시저장 ]**: 영수증만 우선 찍어 두고 사무실에 돌아와 마저 쓰거나, 나중에 영수증을 더 추가해 한꺼번에 올리고 싶을 때. 임시저장은 **서버에 저장**되어 다른 기기(PC)에서도 이어서 작성할 수 있다(`draft`). 저장한 결의서는 E-01에 [📝 임시저장]으로 남는다.
- **우측 [ 🚀 결재 상신 ]**: "결재를 상신하시겠습니까? (3건 · 72,000원)" 확인 후 상신. 검증 실패 항목이 있으면 해당 행을 강조하고 첫 문제 항목으로 이동(`expense-lifecycle.md` §2). 분석 중인 항목이 있으면 비활성.
  - 상신과 동시에 결재 대상자(관리자 이상, 또는 사전 검토자)에게 카카오 알림톡(`notification-rule.md` 트리거 A), 직원 화면은 E-01로 돌아가 해당 건이 [ 🟡 검토 대기 ]로 바뀐다.
  - 반려 건이면 버튼명 [ 🚀 재상신 ].

## 5. 승인 이후 흐름 (결제수단별, D-047 — 정산은 결의서 단위)
- **💳 법인카드 항목만 있고 정산할 금액이 없는 결의서**: 관리자가 [ ✅ 승인 ]하는 순간 처리가 끝나(`paid`, "승인 완료(정산 없음)") 곧바로 월말 세무 마감 데이터로 들어간다.
- **🧾 개인(사비) 항목이 포함된 결의서**(법인카드와 섞여도 됨): 승인 이후 결의서 단위로 **[ 🟡 정산 대기 ➔ 💰 지급 완료 ]** 자금 집행 루프가 돈다. 지급액 = 결의서 안 사비 항목의 회사 지원금 합계(`worker-timeline.md`, `admin-payouts.md`).
- 법인카드 한도 초과분(직원 납부액)이 있으면 같은 정산 단계에서 "납부 n원"으로 함께 표시·처리한다.
- 어느 경우든 세무 마감 엑셀에는 영수증 1장 = 1행으로 들어간다(`tax-closing.md`).
