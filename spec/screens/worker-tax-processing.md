📱 [화면 E-02] 영수증 스냅샷 & 지출결의서 작성 화면 상세 스펙
1단계: 영수증 캡처 및 AI Vision 자동 채움 (Quick Capture & Auto-Fill)
직원이 메인 화면에서 [ 📸 + 영수증 찍고 지출 올리기 ]를 누르는 순간 진입하는 첫 번째 페이즈입니다.

입력 방식 선택 모달 / 화면:

[ 📷 카메라로 직접 촬영 ] (가장 빈번하게 쓰임: 식당 종이 영수증, 택시 영수증 등)

[ 🖼️ 갤러리에서 불러오기 ] (배달의민족 결제 완료 캡처, KTX 예매증, 모바일 영수증 PDF 등)

AI Vision 즉시 파싱 (Loading State):

이미지를 올리거나 찍으면 1~2초 동안 로딩 애니메이션(예: "AI가 영수증을 읽고 있어요... 🪄")이 뜬 후, 아래 항목들이 입력 폼에 자동으로 쏙쏙 박혀서 나타납니다.

사용 일자 (자동 세팅)

가맹점명 / 사용처 (자동 세팅, 예: "스타벅스 강남점")

공급가액 / 부가세 / 합계금액 (자동 세팅)

2단계: 결제수단 선택 (Default: 법인카드)
AI가 읽어낸 금액 정보 바로 아래에 직관적인 토글/선택지가 위치합니다.

결제수단 라디오/탭 버튼:

[ 🔘 법인카드 (Default) ] : 회사 명의의 법인카드로 결제한 경우 (별도 정산 불필요)

[ ⚪ 개인카드 (사비 정산) ] : 내 사비로 긁었기 때문에 회사로부터 돈을 돌려받아야 하는 경우 (클릭 시 월말 사비 정산 대기열에 자동 편입)

3단계: 필수 입력 항목 직접 작성 (신청자 작성 포인트)
AI나 회사의 기본 세팅으로 채워지지 않는, 반드시 직원이 채워 넣어야 하는 항목들입니다. 누락을 막기 위해 붉은색 별표(*)와 입력 유도 가이드가 제공됩니다.

지출결의서 제목 (*):

예: "클라이언트 미팅 간식 구입" (자동으로 "스타벅스 강남점 지출" 같은 기본값이 들어가되, 직원이 수정 가능)

지출 카테고리 선택 (*):

회사가 사전에 세팅해 둔 목록 중 터치해서 선택 (예: 식대, 교통비, 소모품비, 접대비 등)

적요 / 소명 내용 (*):

예: "A사 프로젝트 킥오프 미팅 시 참석자 음료 제공" (관리자나 사장님이 "이 돈을 왜 썼지?" 하고 물어볼 일이 없도록 한 줄 소명 작성)

[조건부 확장 항목] 출장비 등의 특수 양식:

만약 카테고리가 '출장비' 등으로 선택되면, 회사가 세팅한 템플릿 규칙에 따라 출발지/도착지, 출장 기간 같은 추가 입력 필드가 스르륵 나타남.

4단계: 하단 액션 버튼 (Action Bar)
작성이 완료되었을 때 화면 하단에 고정되는 듀얼 버튼입니다.

좌측 보조 버튼: [ 💾 임시저장 ]

영수증만 우선 찍어두고 사무실로 돌아와서 내용을 마저 쓰거나, 나중에 한꺼번에 묶어서 올리고 싶을 때 스마트폰 로컬에 임시 보관.

우측 메인 CTA: [ 🚀 결재 상신 ]

클릭 시 "결재를 상신하시겠습니까?" 팝업 확인 후 즉시 상신 완료.

동시에 트리거 발생: 백엔드에서 결재자(사장님/관리자)에게 카카오톡 알림톡이 쏜살같이 발송되며, 직원의 화면은 [화면 E-01] 대시보드로 돌아가 해당 건이 [ 🟡 검토 대기 ] 상태로 바뀜.
