# [Spec] 관리자 대시보드: 멤버 관리 (Team Members)

## 1. 개요 및 목적
- **목적**: 5~30인 소기업의 사장님(관리자)이 팀원들을 등록하고, 사내 지출 결재 권한을 부여하며, 퇴사자 및 신규 입사자를 손쉽게 관리하는 공간.
- **접근 경로**: 관리자 대시보드 좌측 메뉴 ➔ **[ 👥 멤버 관리 ]**

---

## 2. 화면 레이아웃 구조
- **상단 영역**: `[ + 신규 멤버 초대하기 ]` 버튼 및 현재 총 멤버 수(Active / Total) 표시.
- **메인 영역**: 등록된 팀원 목록 데이터 테이블 (검색 및 부서별 필터링 제공).

4. 컴포넌트별 상세 동작 규칙
A. 신규 멤버 초대 및 온보딩 ([ + 신규 멤버 초대하기 ])
초대 방식:

소기업의 빠른 온보딩을 위해 [카카오톡 알림톡 / 초대 링크 복사] 기능 제공.

초대 링크를 복사해 사내 톡방이나 개인 톡으로 전달하면, 직원이 링크를 통해 이름, 부서, 직급을 입력하고 가입 완료.

초대 대기 상태 (초대 대기):

가입 전 상태는 목록에 '초대 대기'로 표시되며, 필요시 [ 초대 링크 복사 ]를 통해 재발송 가능.

B. 멤버 역할 및 권한 체계 (Role-Based Access)
소기업 규모에 맞춰 권한은 딱 2가지로 단순화합니다:

관리자 (Admin / Owner):

사장님, 공동 대표, 총괄 경리 담당자.

모든 직원의 지출소명서 승인/반려 권한, 사내 정책 룰(admin-settings.md) 수정 권한, 세무 마감 데이터 다운로드 권한 보유.

일반 멤버 (Member):

일반 임직원.

모바일 웹앱을 통해 본인의 영수증 업로드 및 지출소명서 작성/상신만 가능.

C. 계정 상태 및 퇴사자 안전 장치 (비활성화)
활성 (Active): 정상 이용 중인 재직자.

비활성화 (퇴사 처리):

퇴사 시 계정을 완전히 삭제하면 세무 증빙용 영수증 이력이 증발하므로, '비활성화' 처리하여 과거 지출 내역은 안전하게 보존하되 로그인 및 신규 청구는 차단함.

퇴사 처리 시 미정산 건 방어 장치:

비활성화 처리 시, 해당 직원이 아직 정산받지 못한 미지급금이나 미완성 소명서가 있는 경우 시스템이 팝업 경고를 띄워 금전적 잡음을 사전 예방.

D. 핵심 운영 킥 (Kick) 기능
미제출자 카카오 알림톡 콕 찌르기 ([ 🔔 독촉 알림 ]):

월말 마감 시 영수증 미제출자에게 관리자 대시보드에서 원클릭으로 카카오톡 알림톡을 발송하여 빠른 제출 유도.

개인별 맞춤 예외 한도 설정 (Custom Limit Override):

멤버 편집 시 회사 공통 식대 한도(예: 1만 원)를 무시하고, 외근이 잦은 직책자나 영업직에게 개별 한도(예: 1만 5천 원)를 부여하여 오인 초과 경고 방지.
