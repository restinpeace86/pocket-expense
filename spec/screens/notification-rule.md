[Spec] 카카오톡 알림톡 연동 및 트리거 정책 (KakaoTalk AlimTalk Specification)
1. 개요 및 목적
목적: PC나 별도의 사내 그룹웨어를 켜지 않고도 스마트폰 카카오톡을 통해 지출결의서 상신, 승인/반려, 사비 정산 지급 완료 등의 핵심 이벤트를 실시간으로 전달하여 업무 리드타임을 제로(0)에 가깝게 단축한다.

원칙: 임시저장 상태의 건은 알림톡을 발송하지 않으며, 오직 확정된 액션(상신, 승인/반려, 지급 완료)에만 트리거를 작동시켜 피로도를 최소화한다.

2. 알림톡 발송 트리거 4대 시나리오
① [트리거 A] 지출결의서 상신 완료 ➔ [결재권자(사장님/관리자) 대상]
발송 시점: 직원이 [ 🚀 결재 상신 ] 버튼을 누르고 상신을 완료한 직후.

수신자: 사내 등록된 관리자(결재권자) 카카오톡.

알림톡 내용 구성 (템플릿 예시):

[PocketExpense] 새로운 지출결의서가 상신되었습니다.

상신자: 김개발 (개발팀)

제목: 거래처 미팅 식사 진행

금액: 45,000 원

결제수단: 법인카드

📱 [결재하러 가기 (모바일 뷰 바로가기)] (버튼 클릭 시 로그인 세션 유지된 상태로 관리자 승인 화면으로 직행)

② [트리거 B] 결재 승인 완료 ➔ [상신자(직원) 대상]
발송 시점: 관리자가 관리자 대시보드에서 해당 건에 대해 [ ✅ 승인 ] 처리를 완료한 직후.

수신자: 해당 지출결의서를 올린 직원.

알림톡 내용 구성 (템플릿 예시):

[PocketExpense] 지출결의서가 승인되었습니다. ✅

제목: 거래처 미팅 식사 진행

금액: 45,000 원

상태: 승인 완료 (법인카드 사용 건으로 정상 마감 처리되었습니다.)

📱 [내 내역 확인하기]

③ [트리거 C] 결재 반려 ➔ [상신자(직원) 대상]
발송 시점: 관리자가 [ ❌ 반려 ] 처리를 누르고 반려 사유를 입력한 직후.

수신자: 해당 지출결의서를 올린 직원.

알림톡 내용 구성 (템플릿 예시):

[PocketExpense] 지출결의서가 반려되었습니다. 🔴

제목: 거래처 미팅 식사 진행

반려 사유: 영수증 하단 부가세 부분이 잘렸습니다. 다시 촬영해 주세요.

📱 [수정 후 재상신하기] (버튼 클릭 시 해당 건의 편집 화면으로 바로 진입)

④ [트리거 D] 사비 정산 지급 완료 ➔ [직원 대상]
발송 시점: 관리자가 개인카드(사비) 결제 건에 대해 이체를 마친 후 관리자 모드에서 [ 💰 정산 지급 완료 처리 ]를 누른 직후.

수신자: 사비를 청구했던 직원.

알림톡 내용 구성 (템플릿 예시):

[PocketExpense] 사비 정산금이 지급되었습니다. 💰

항목: 고객사 방문 택시비

지급 금액: 28,000 원

지급 일시: 2026.10.16 14:30

📱 [나의 정산 타임라인 확인]

3. 기술 연동 및 운영 고려사항
API 연동: 비즈메이트(Bizmsg) 또는 솔라피(Solapi) 등 국내 표준 알림톡 API 게이트웨이 연동.

버튼 딥링크(Deep Link): 알림톡 하단 버튼 클릭 시 로그인 토큰을 포함한 모바일 웹 URL([https://app.pocketexpense.co.kr/workspace/](https://app.pocketexpense.co.kr/workspace/)...)로 다이렉트 연결하여, 앱 재로그인 번거로움 없이 1초 만에 확인/처리가 가능하도록 UX 최적화.
