# [Spec] 화면 E-03: 직원 개인 정산 내역 및 입금 타임라인 (Employee Settlement & Deposit Timeline)

라우트: `/workspace/[id]/employee/settlements` / 관련: D-010, D-047 / 짝 화면: 관리자 [정산 지급 관리](`admin-payouts.md`, A-02)
관리자 모드의 '정산 지급 관리' 화면과 짝을 이루는 직원 개인 뷰. **정산 단위는 지출소명서**다(D-047).

## 1. 상단 요약 카드 (Summary Banner)
- **좌측 — 입금 대기 중인 사비**: 142,000원 = 승인되었지만 아직 지급 완료되지 않은 내 소명서들의 사비 지급액 합계.
- **우측 — 이번 달 지급받은 정산금**: 350,000원 = 이번 달 지급 완료 처리된 지급액 합계.
- (보완) 법인카드 한도 초과로 회사에 납부할 금액이 있으면 "납부 필요 n원" 작은 칩을 함께 표시.

## 2. 정산 내역 리스트 (Settlement Cards)
개인(사비) 항목이 들어 있어 정산이 필요한 내 소명서가 최신순으로 쌓이는 피드. 카드를 펼치면 소명서 안의 사비 항목 내역이 보인다.
```text
┌────────────────────────────────────────────────────────┐
│ [교통비] 고객사 방문 택시비                 [ 💰 지급 완료 ] │
│ 2026.10.15  •  사비 1건                                │
│ 지급 28,000 원                                         │
│ └ 2026.10.16 14:30 관리자 지급 완료 처리                 │
└────────────────────────────────────────────────────────┘
┌────────────────────────────────────────────────────────┐
│ [출장] 10/15 부산 출장                       [ 🟡 정산 대기 ] │
│ 2026.10.14~10.15  •  사비 1건 (법인 2건은 정산 없음)      │
│ 지급 10,000 원                                ▼ 펼치기   │
│   └ 10/15 부산국밥  17,000원 → 10,000원 지급 (한도초과 7천원) │
└────────────────────────────────────────────────────────┘
```
- 법인카드 항목만 있고 정산할 금액이 없는 소명서는 이 목록에 나오지 않는다(E-01에서 "승인 완료(정산 없음)").

## 3. 상태 뱃지 및 실시간 연동 인터랙션 (Admin-Employee Sync)
- **[ 🟡 정산 대기 ]** (`approved`): 사장님이 [ ✅ 승인 ]을 눌렀지만, 아직 회사의 자금 집행일(금요일 이체 등)이 되지 않아 경리가 이체하지 않은 상태. 직원은 이 화면에서 대기 상태를 확인한다.
- **[ 💰 정산 지급 완료 ]** (`paid`): 관리자가 [정산 지급 관리]에서 해당 소명서를 체크하고 [ 정산 지급 완료 처리 ]를 누르는 순간 동시에 두 가지가 일어난다.
  1. 이 화면의 뱃지가 [ 🟡 정산 대기 ] → [ 💰 정산 지급 완료 ]로 바뀌고 지급 일시가 찍힌다(화면을 열어 둔 경우 새로고침 없이 반영, 실시간 구독 또는 재조회).
  2. 직원에게 카카오 알림톡이 발송된다("김개발님의 정산금 28,000원이 지급 완료되었습니다.", `notification-rule.md` 트리거 D).
- (보완) 정산 계좌가 등록되지 않았으면 상단에 "정산받을 계좌를 등록해 주세요 → 내 정보" 안내.
