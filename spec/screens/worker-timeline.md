📱 [화면 E-03] 직원 개인 정산 내역 및 입금 타임라인 (Employee Settlement & Deposit Timeline)
관리자 모드의 '정산 지급 관리 화면'과 완벽하게 짝을 이루는 직원 개인 뷰의 구조입니다.

1. 상단 요약 카드 (Summary Banner)
좌측 카드 (정산 대기):

타이틀: 입금 대기 중인 사비

금액: 142,000 원 (아직 경리가 통장 이체를 안 한, 승인된 개인카드 건들의 합계)

우측 카드 (이번 달 정산 완료):

타이틀: 이번 달 지급받은 정산금

금액: 350,000 원

2. 정산 내역 리스트 (Settlement Item Cards)
내가 개인카드로 긁고 승인된 건들이 차곡차곡 쌓이는 피드입니다. 관리자 화면에서 사장님이 보는 리스트의 '개인별 확대 버전'이라고 보시면 됩니다.

카드 아이템 구성 예시:

Plaintext
┌────────────────────────────────────────────────────────┐
│ [교통비] 고객사 방문 택시비                [ 💰 지급 완료 ] │
│ 2026.10.15  •  개인카드                                │
│ 28,000 원                                              │
│ └ 2026.10.16 14:30 관리자 지급 완료 처리                 │
└────────────────────────────────────────────────────────┘
3. 상태 뱃지 및 실시간 연동 인터랙션 (Admin-Employee Sync)
관리자 모드와 이 화면이 어떻게 맞물려 돌아가는지 그 흐름입니다.

[ 🟡 정산 대기 ] 상태:

사장님이 [ ✅ 승인 ]을 눌렀지만, 아직 회사의 자금 집행일(금요일 이체 등)이 되지 않아 경리가 이체를 안 한 상태.

직원은 이 화면에서 내 돈이 언제 들어올지 대기 상태를 실시간으로 확인 가능.

[ 💰 정산 지급 완료 ] 상태 (트리거 연동):

관리자가 관리자 대시보드에서 해당 건을 체크하고 [ 정산 지급 완료 처리 ] 버튼을 누르는 순간!

동시에 두 가지가 벌어짐:

직원의 [화면 E-03]에서 상태 뱃지가 [ 🟡 정산 대기 ] ➔ [ 💰 정산 지급 완료 ]로 실시간 변경되며 하단에 입금 일시가 찍힘.

직원에게 카카오톡 알림톡이 쏜살같이 꽂힘 ("김개발님의 정산금 28,000원이 지급 완료되었습니다.").
