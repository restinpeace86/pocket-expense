# [Spec] 관리자(기업) 회원가입 및 온보딩 플로우 (Admin Onboarding)

## 1. 온보딩 철학 (Design Principle)
- **Time to Value 최소화**: 가입 단계에서 복잡한 정책 세팅이나 양식 업로드를 강제하지 않고, 30초 만에 회사를 만들고 대시보드로 곧바로 진입(`Fast-track Entry`)하게 설계.
- **2단계 분리 구조**: 
  - **Phase 1 (초간단 생성)**: 대시보드 진입을 위한 최소한의 정보만 입력.
  - **Phase 2 (맞춤 세팅)**: 대시보드 안에서 필요할 때 천천히 정책 수정 및 AI 템플릿 양식 업로드.

---

## 2. [Phase 1] 30초 만에 끝내는 회사 생성 위저드
사용자가 랜딩 페이지에서 `[ 🏢 우리 회사 무료로 시작하기 ]`를 클릭했을 때 거치는 단계.

### Step 1: 관리자 소셜 로그인 (Admin Authentication)
- **목적**: 회사를 등록하고 관리할 대표님/담당자의 개인 계정 인증.
- **액션**: [카카오로 시작하기] 또는 [Google로 시작하기] 클릭 (Supabase Auth 연동).
- **결과**: `users` 테이블에 계정 생성 및 `role = 'admin'` 임시 세팅.

### Step 2: 최소 필수 기업 정보 입력 (Company Info & Basic Setup)
- **목적**: 세무사무소용 엑셀 출력 및 명의 표기에 필요한 최소 정보와 기본 부서 설정.
- **입력 필드**:
  1. **회사명 (`company_name`)**: 예) (주)포켓글로벌
  2. **사업자등록번호 (`business_number`)**: 예) 123-45-67890 (세무 엑셀 및 영수증 증빙 필수)
  3. **대표자/관리자 성함 (`admin_name`)**: 예) 홍길동
  4. **기본 부서 태그 설정**: 우리 회사 부서명을 가볍게 쉼표 또는 태그로 입력 (예: `개발팀, 마케팅팀, 경영지원팀`). *직원 가입 시 선택용*
- **기본값 자동 세팅 (Default Policies)**: 
  - 식대 한도: `10,000` 원
  - 유류비 단가: `200` 원/km
  - (위 정책들은 나중에 대시보드에서 언제든 수정 가능)

---

## 3. 워크스페이스 생성 직행 (Workspace Ready)
- 위저드의 Step 2가 완료되는 즉시 `companies` 테이블에 레코드가 생성되고, 관리자는 곧바로 **PC 관리자 대시보드 (`/workspace/[id]/admin`)**로 진입합니다.

---

## 4. [Phase 2] 대시보드 내 맞춤 설정 (Settings & AI Template Builder)
대시보드 상단 가이드 배너나 설정(`Settings`) 메뉴를 통해 점진적으로 진행.

1. **사내 정산 정책 수정**: 회사의 실제 식대 한도나 자차 유류비 단가 커스텀.
2. **AI 템플릿 양식 업로드 (Killer Feature)**:
   - *"우리 회사 기존 지출결의서 양식으로 쓰기"*
   - 관리자가 기존 엑셀 파일이나 종이 양식 사진(이미지/PDF)을 업로드.
   - Gemini Vision LLM이 필드를 자동 분석해 사내 맞춤형 `custom_schema` 구축.

---

## 5. 직원 초대 메커니즘 (Employee Invitation)
- 대시보드 메인 화면 상단에 큼직하게 노출되는 영역.
- **[ 🔗 직원 초대용 링크 복사 ]** 및 **[ QR코드 다운로드 ]** 버튼 제공.
- 사장님이 카카오톡 단톡방에 링크나 QR을 공유하면 끝.
