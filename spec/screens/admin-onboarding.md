# [Spec] 회사(Workspace) 생성 위저드 화면

규칙 원본: `spec/features/auth-onboarding.md` §2 / 라우트: `/onboarding/create-company`
진입: 랜딩(`landing-page.md`)의 [우리 회사 무료로 시작하기] → 로그인 → 이 화면.

## Step 1. 로그인
- 카카오 / Google 로그인. 이미 다른 회사 멤버인 계정이면 "이미 ○○회사에 소속되어 있습니다" 안내 후 진행 불가(D-004).

## Step 2. 회사 · 관리자 정보 (한 화면)
| 항목 | 필수 | 비고 |
|---|---|---|
| 회사명 | 필수 | |
| 사업자등록번호 | **필수** | 숫자 10자리(하이픈 허용). 국세청 상태조회는 모드에 따름 — 현재 `off`라 형식만 검사 (D-056, D-057, `spec/features/business-verification.md`) |
| 부서 목록 | 필수(1개 이상) | 태그 입력(예: 개발팀, 마케팅팀, 경영지원팀). 직원 가입 시 선택지가 됨 |
| 대표자/관리자 이름 | 필수 | |
| 휴대폰 번호 | 필수 | 결재 요청 알림톡 수신 번호(관리자는 결재 요청을 받으므로 필수) |
| 본인 부서 | 필수 | 위 부서 목록 또는 **"부서 없음 (대표·임원)"** 중 선택 (D-058) |
| 직급 | 선택 | |
| 이용약관·개인정보 동의 | 필수 | [필수] 서비스 이용약관, [필수] 개인정보 수집·이용 — [보기] 팝업 (D-059) |

## Step 3. 생성 및 대시보드 진입
- 서버에서 한 트랜잭션으로 회사, 부서, 최고 관리자 멤버(`super_admin`, `approved`, D-038), **기본 결재라인(사전 검토 없음 = 관리자 직통 승인)**, 기본 계정과목·매핑을 만들고 무료 크레딧 100장을 지급한다(D-036, D-039, D-046). 별도 결제 없이 가입이 끝난다.
- 생성 후 **Step 4(추천 정보, 선택)** 로 이동한다(D-147).

## Step 4. 추천 정보 (선택, `/onboarding/referral`, D-147)
- 회사를 만든 최고 관리자에게만, 회사당 한 번 보인다(이미 적었거나 최고 관리자가 아니면 관리자 홈으로).
- [추천 회사] / [추천인] 중 하나를 고른다.
  - 추천 회사: 회사 이름 2자 이상 입력 → 가입된 회사 중 이름이 맞는 곳 최대 8곳(자기 회사 제외, 이름만 보임) → 하나를 고른다. 없으면 "가입된 회사가 없어요 … 사람이 추천했다면 [추천인]에" 안내.
  - 추천인: 이름(1~50자) + 휴대폰 번호(010 형식).
- [저장하고 시작하기] → 저장 후 관리자 대시보드. [건너뛰기] → 저장 없이 관리자 대시보드. 저장한 뒤에는 고칠 수 없다.
- 이 화면을 건너뛰거나 닫으면 다시 묻지 않는다(주소로 다시 들어오면 적을 수는 있음).

## Step 5. 대시보드 진입
- 관리자 대시보드(`/workspace/[id]/admin`)로 이동한다. 대시보드 상단에 직원 초대 카드와 초기 설정 체크리스트를 보여 준다(`admin-dashboard.md` ①).
