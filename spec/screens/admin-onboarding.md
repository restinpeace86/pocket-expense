# [Spec] 회사(Workspace) 생성 위저드 화면

규칙 원본: `spec/features/auth-onboarding.md` §2 / 라우트: `/onboarding/create-company`
진입: 랜딩(`landing-page.md`)의 [우리 회사 무료로 시작하기] → 로그인 → 이 화면.

## Step 1. 로그인
- 카카오 / Google 로그인. 이미 다른 회사 멤버인 계정이면 "이미 ○○회사에 소속되어 있습니다" 안내 후 진행 불가(D-004).

## Step 2. 회사 · 관리자 정보 (한 화면)
| 항목 | 필수 | 비고 |
|---|---|---|
| 회사명 | 필수 | |
| 사업자등록번호 | 선택 | 형식 검증(10자리). 나중에 설정에서 입력 가능 |
| 부서 목록 | 필수(1개 이상) | 태그 입력(예: 개발팀, 마케팅팀, 경영지원팀). 직원 가입 시 선택지가 됨 |
| 대표자/관리자 이름 | 필수 | |
| 휴대폰 번호 | 필수 | 결재 알림톡 수신 번호(생성자가 기본 결재자이므로 필수) |
| 본인 부서 | 필수 | 위 부서 목록에서 선택 |
| 직급 | 선택 | |
| 개인정보 수집·이용 동의 | 필수 | |

## Step 3. 생성 및 대시보드 진입
- 서버에서 한 트랜잭션으로 회사, 부서, 관리자 멤버(`admin`, `approved`), **기본 결재라인(1단계 = 생성자)** 을 만든다(D-030).
- 생성 후 관리자 대시보드(`/workspace/[id]/admin`)로 이동한다. 대시보드 상단에 직원 초대 카드와 초기 설정 체크리스트를 보여 준다(`admin-dashboard.md` ①).
