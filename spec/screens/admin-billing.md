# [Spec] 화면 A-05: 요금제 및 구독 관리 (Billing & Subscription)

라우트: `/workspace/[id]/admin/billing` / 사이드바: [⚙️ 설정] › [요금제] / 정책 원본: `spec/common/pricing-policy.md` / 관련: D-046, D-054

## 1. 목적
결제 시스템이 있는 것처럼 요금제와 결제 화면을 정식 형태로 보여 주되, **현재는 한시적 무료 제공 기간이라 결제를 진행할 수 없게 막아 둔다.** 추후 PG 연동 시 화면 수정 없이 결제 API만 붙인다.

## 2. 현재 이용 상태 카드
- "무료 제공 중 — 영수증 **163 / 200장** 사용" 진행 막대, 남은 장수, "기본 100장 + 이벤트 추가 지급 1회(100장)".
- 안내: "현재 한시적 무료 제공 기간입니다. 이벤트 기간에는 100장을 모두 사용하면 추가 100장을 무료로 더 드립니다. 유료 플랜 결제는 준비 중입니다."
- 이벤트 추가 지급 직후: 상단에 "무료 영수증 100장을 모두 사용했습니다. 현재 이벤트 기간이라 추가 100장을 무료로 더 드립니다." 배너 + [확인].
- 남은 장수 20장 이하: 주황색 안내. 이벤트가 꺼진 상태에서 0장: 빨간색 "무료 사용량을 모두 사용했습니다. 영수증 업로드가 중지되었습니다."

## 3. 요금제 카드 (정식 플랜)
| 플랜 | 월 제공 장수 | ① 월간 자동결제 (공급가액, VAT 별도) | ② 연간 선결제 (10% 할인 총액) | 장당(월간) | 주요 타깃 |
|---|---|---|---|---|---|
| 스타터 (Starter) | 150장 | 월 30,000원 | 연 324,000원 (월 환산 27,000원, 연 36,000원 절약) | 200원 | 5인 미만 극초기 오피스·개발사 |
| **스탠다드 (Standard, 추천·주력)** | 400장 | 월 60,000원 | 연 648,000원 (월 환산 54,000원, 연 72,000원 절약) | 150원 | 5~15인 일반 소기업 |
| 프로 (Pro) | 800장 | 월 110,000원 | 연 1,188,000원 (월 환산 99,000원, 연 132,000원 절약) | 137.5원 | 영업·현장직이 많은 헤비 유저 |
- 스탠다드에 "추천" 표시(`is_featured`). 장당 가격과 연간 선결제 금액(`annual_price`)을 함께 보여 준다. 월간 연속 결제 보너스는 O-09 확정 전까지 표시하지 않는다(D-081).
- 플랜 값은 코드에 하드코딩하지 않고 `billing_plans` 데이터에서 읽는다(CLAUDE.md 제5장 제4조).
- 카드마다 [선택] 라디오와 [이 플랜으로 결제하기] 버튼이 있으나 **비활성(disabled)**: 회색 처리, 클릭·체크 불가, 마우스를 올리면 "무료 제공 기간에는 결제할 수 없습니다" 툴팁.

## 4. 결제 수단 영역
- 카드번호·유효기간·약관 동의 체크박스 등 결제 입력 폼 모양을 그대로 보여 주되 **전부 비활성**. 입력·체크가 되지 않는다.
- 폼 위에 잠금 배지 "🔒 결제 준비 중".
- 실제 카드 정보는 어디에도 받거나 저장하지 않는다.

## 5. 권한
- 관리자 이상이 볼 수 있다. 결제 기능은 누구도 실행할 수 없다(비활성).
