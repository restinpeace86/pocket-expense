# [Spec] 랜딩 페이지 (`/`)

라우트 규칙: 비로그인 사용자에게 보인다. 로그인 상태면 `spec/common/routes.md` §1의 분기를 따른다.

## 1. 디자인 컨셉
- **타겟**: 소기업 대표, 창업자, 비영리 단체 대표, 경리 담당자.
- **무드**: 모던 B2B SaaS(Stripe, Vercel 감성). 긴 설명 대신 미니멀한 그라데이션 배경, 글래스모피즘, 인터랙티브 애니메이션. 서비스 내부 화면은 `spec/common/ui-rules.md`의 톤을 유지하고, 랜딩만 이 무드를 쓴다.
- **메시지**: "무거운 그룹웨어 없이, 1분 만에 시작하는 가장 가벼운 정산."

## 2. 상단 내비게이션 (고정)
- 좌: 로고(`PocketExpense`) + 배지(`for Startups & SMBs`)
- 우: [로그인] → `/login` / **[🏢 우리 회사 무료로 시작하기]** → 로그인 후 `/onboarding/create-company`(`admin-onboarding.md`). 회사를 등록한 계정은 최고 관리자가 된다(D-038).
- 직원은 랜딩이 아니라 회사가 공유한 초대 링크/QR로 가입한다.

## 3. 히어로
- (7차 개선사항 2, 2026-10-27 확정 카피) 위 배지: "소기업·스타트업을 위한 AI 경비 정산"
- H1: **"복잡한 경비처리, 사진 한 장으로 끝."** — 두 줄 고정("복잡한 경비처리," / "사진 한 장으로 끝."), "사진 한 장" 강조색, 굵게·크게(휴대폰 40px, PC 56~60px), `break-keep`
- 서브: "영수증 등록부터 월말 세무회계용 엑셀 정리까지 한 번에." — 톤 다운(보조 글자색), 최대 폭 28rem, 바로 아래 CTA
- 히어로 비주얼은 **소개 동영상 또는 목업 애니메이션** 중 하나를 쓴다. 동영상은 자동재생·음소거·반복, 모바일 데이터 절약을 위해 포스터 이미지 먼저 표시 후 지연 로드. 영상 파일은 정적 자산으로 관리한다(코드에 데이터 하드코딩 아님).
- 시나리오(동영상·애니메이션 공통): 영수증 여러 장 촬영 → 1~3초 만에 가맹점·금액이 결의서 표에 자동 입력 → 대표 카카오톡으로 "부산 출장 3건 · 72,000원" 결재 요청 알림톡 도착(버튼 [결재하러 가기]) → 열린 결재 화면에서 [전체 승인]. 승인은 알림톡 안이 아니라 결재 화면에서 한다(D-013). 알림톡은 오픈 전에 연결한다는 전제로 카카오톡 표현을 쓴다(D-142)

## 4. 핵심 기능 (Bento Grid)
1. **우리 회사 양식 그대로**: 쓰던 지출결의서 사진 한 장이면 웹 양식으로 자동 변환.
2. **카카오톡 원클릭 결재**: 앱 설치 없이 알림톡 링크로 승인. (알림톡 연결 후 오픈 전제, D-142)
3. **월말 마감 원클릭**: 세무사무소에 넘길 지출내역 엑셀 + 영수증 원본 + 지출결의서 PDF 일괄 다운로드.
   - "더존/세무사랑 완벽 호환" 등 호환 보장 문구는 O-02 확정 전까지 쓰지 않는다.

## 5. 소기업 맞춤 (Why PocketExpense?)
- "팀장 결재, 복잡한 조직도… 5인 회사에 과하지 않나요?"
- 기본은 **사장님(관리자) 직통 승인**(D-039)이고, 필요할 때만 팀장 사전 검토 단계를 추가하는 가벼운 결재라인과 부서 구분을 강조한다.
- 개인카드·법인카드 모두 지원하며, 일반 식대 한도 초과분은 자동으로 나눠 계산하고 출장 중 비용은 출장비로 따로 묶인다는 점을 보여 준다.

## 6. 하단 CTA
- "엑셀과 영수증 지옥에서 벗어날 준비가 되셨나요?" + [🏢 우리 회사 무료로 시작하기].
- 그 아래 [💬 궁금한 점은 카카오톡으로 문의하기](D-142): 가입 전 방문자의 문의 창구. 관리자 1:1 문의와 같은 카카오톡 채널 채팅(`NEXT_PUBLIC_KAKAO_CHANNEL_CHAT_URL`), 주소가 없으면 숨김
- 푸터 사업자 정보(D-142, 전자상거래법 표시): 상호·대표·사업자등록번호·통신판매업 신고·주소·전화·이메일·호스팅. 운영자 정보(`OPERATOR`, 약관·처리방침과 같은 값)가 채워진 칸만 보이고, 상호가 비어 있으면 표시하지 않음
- 요금제 섹션(스타터·스탠다드(추천)·프로 3장, 장당 가격, 가격 옆 "(VAT 별도)", 카드 아래 남은 장수 이월 없음 안내, 연간 결제는 표시하지 않음, 연속 결제 보너스는 O-09 확정 전 미표시)을 보여 주고 상단에 "지금 가입하면 영수증 100장 무료"만 표시한다. 이벤트 추가 지급은 랜딩에 알리지 않고(앱 안 안내만, D-054), 요금 카드에 "결제 준비 중" 문구를 두지 않는다(D-078).

## SEO·공유 (D-129, 7차 개선사항 6)
- 루트 metadata: 제목·설명·키워드·OG(ko_KR, website)·트위터 카드, 기준 주소 = 운영 주소(`NEXT_PUBLIC_SITE_URL` → Vercel 운영 도메인). 랜딩 canonical `/`
- 공유 이미지: `/opengraph-image`(1200×630, 히어로 카피)
- 소유 확인: `GOOGLE_SITE_VERIFICATION`, `NAVER_SITE_VERIFICATION` 환경변수(서치 콘솔·서치어드바이저 "HTML 태그" 방식의 content 값). 비우면 태그 없음
- `/sitemap.xml`: `/`, `/terms`, `/privacy`. `/robots.txt`: 전체 허용 + `/workspace/`·`/onboarding`·`/app-admin`·`/api/`·`/auth/`·`/dev/`·`/join/`·`/share/`·`/push/` 막음

## AI 영수증 처리 미리보기 (D-131 → D-140 → D-141)
- 위치: 기능 카드 3개 아래. 배지 "단순 OCR이 아닌 AI LLM", 제목 "오타 투성이 구겨진 영수증도, AI LLM이 척척 정리하는 10초 컷 매직", 소개 "직원은 찍고 올리기만, 결재자는 알림 받고 승인만. 세무사무소에 넘길 엑셀은 저절로 쌓여요."
- 3단계 = 각 단계 "행동 → 결과" 두 장면(사용자 결정 2026-10-27):
  1. **찍고 AI 분석**(직원): 사진 올리기 → AI LLM이 읽어 낸 것 4줄(가맹점 구겨진 글자 보정 / 품목·금액 / 공급가액·부가세 분리 / 거래 맥락 → 소모품비), 영수증 위 스캔 줄
  2. **결의서 작성·상신**(직원): 지출결의서 칸 6개 자동 채움(자동 분리·AI 추천 표시) → [결재 올리기] → "대표님께 결재 요청 알림을 보냈어요"
  3. **승인·엑셀 추가**(결재자 휴대폰): 결재 요청 알림 → 알림을 눌러 연 결재 화면 [승인] → "세무사무실 제출용 엑셀에 한 줄 추가! 🎉"
- 표현: **"알림"** 이라고만 쓴다(앱 알림·카카오톡 어느 쪽이든 맞아 나중에 바꿀 필요 없음, D-141). 승인은 알림이 아니라 열린 화면에서(D-013)
- 화면에 35% 보이면 한 번 자동 진행(약 12초, 단계 끝 결과에서 1.5초 머묾), 단계 버튼은 그 단계만 처음부터, [처음부터 다시 보기]. `prefers-reduced-motion`이면 결과를 바로 보여 줌. 시연용(서버 호출·크레딧 없음). CTA → 회사 등록
