# [Spec] 랜딩 페이지 (`/`)

라우트 규칙: 비로그인 사용자에게 보인다. 로그인 상태면 `spec/common/routes.md` §1의 분기를 따른다.

## 1. 디자인 컨셉
- **타겟**: 소기업 대표, 창업자, 비영리 단체 대표, 경리 담당자.
- **무드**: 모던 B2B SaaS(Stripe, Vercel 감성). 긴 설명 대신 미니멀한 그라데이션 배경, 글래스모피즘, 인터랙티브 애니메이션. 서비스 내부 화면은 `spec/common/ui-rules.md`의 톤을 유지하고, 랜딩만 이 무드를 쓴다.
- **메시지**: "무거운 그룹웨어 없이, 1분 만에 시작하는 가장 가벼운 정산."

## 2. 상단 내비게이션 (고정)
- 좌: 로고(`PocketExpense`) + 배지(`for Startups & SMBs`)
- 우: [로그인] → `/login` / **[🏢 우리 회사 무료로 시작하기]** → 로그인 후 `/onboarding/create-company`(`admin-onboarding.md`)

## 3. 히어로
- H1: **"영수증 정산의 스트레스를 0으로."** / 소기업과 스타트업을 위한 가장 가벼운 AI 경비 정산
- 서브: "엑셀도, 무거운 그룹웨어도 필요 없습니다. 영수증 촬영 한 장과 카카오톡 결재로 끝내세요."
- 목업 애니메이션: 영수증 여러 장 촬영 → 1~3초 만에 가맹점·금액이 소명서 표에 자동 입력 → 대표 카카오톡으로 "부산 출장 3건 · 72,000원" 결재 요청 알림톡 도착 → [전체 승인].

## 4. 핵심 기능 (Bento Grid)
1. **우리 회사 양식 그대로**: 쓰던 지출결의서 사진 한 장이면 웹 양식으로 자동 변환.
2. **카카오톡 원클릭 결재**: 앱 설치 없이 알림톡 링크로 승인.
3. **월말 마감 원클릭**: 세무사무소에 넘길 지출내역 엑셀 + 영수증 원본 + 지출결의서 PDF 일괄 다운로드.
   - "더존/세무사랑 완벽 호환" 등 호환 보장 문구는 O-02 확정 전까지 쓰지 않는다.

## 5. 소기업 맞춤 (Why PocketExpense?)
- "팀장 결재, 복잡한 조직도… 5인 회사에 과하지 않나요?"
- 기본은 **대표 직통 결재**(D-030)이고, 필요할 때만 팀장 단계를 추가하는 가벼운 결재라인과 부서 구분을 강조한다.
- 개인카드·법인카드 모두 지원하며, 일반 식대 한도 초과분은 자동으로 나눠 계산하고 출장 중 비용은 출장비로 따로 묶인다는 점을 보여 준다.

## 6. 하단 CTA
- "엑셀과 영수증 지옥에서 벗어날 준비가 되셨나요?" + [🏢 우리 회사 무료로 시작하기].
- 요금제·결제 섹션은 넣지 않는다(D-027).
