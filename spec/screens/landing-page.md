- 버튼: 랜딩 주요 버튼(상단·히어로·미리 보기·끝 CTA) = 인디고→보라 그라데이션(`BRAND_BUTTON`). 보조 버튼은 흰 바탕 + 인디고 테두리
- 히어로: 흰 바탕 위 은은한 인디고·보라 빛, 이름은 그라데이션 글자, 휴대폰 목업에 구역색 태그 + [결재 올리기], 떠 있는 결과 카드 3개(영수증 3장 → 결의서 자동 채움 / QR 출근 09:02 / 세무사무소로 월말 전달 — 넓은 화면은 휴대폰 위·아래 바깥, 휴대폰은 목업 아래 줄)
- 다른 점: 구역색 벤토 4장(2열) + 카드 안 작은 화면 그림(`why-art.tsx`, HTML로 그림 — 사진·외부 이미지 없음). 문구는 0-1 그대로

- 섹션 제목 위에 작은 인디고 소제목(무엇이 다른가요 / 한곳에서 / 이어져서 편해요 / 경비·결재 / 한 달 흐름 / 누구에게)

## 4. 핵심 기능 (Bento Grid)
1. **우리 회사 양식 그대로**: 쓰던 지출결의서 사진 한 장이면 웹 양식으로 자동 변환.
2. **카카오톡 원클릭 결재**: 앱 설치 없이 알림톡 링크로 승인. (알림톡 연결 후 오픈 전제, D-142)
3. **월말 마감, 세무사무소에 바로**(D-181): 지출내역 엑셀 + 영수증 원본 + 지출결의서 PDF를 한 번에. 압축해 이메일로 보낼 필요 없이 세무사무소는 무료 전용 화면에서 보고 내려받는다.
4. **법인카드 내역 자동 대조**(D-181): 카드사 사용 내역 파일(엑셀·CSV)을 올리면 날짜·금액·카드 끝 4자리로 영수증과 맞춰 결의서 없는 카드 결제·사비로 잘못 올린 법인카드 결제를 찾는다.
   - 카드 4개, PC·태블릿 2칸(2×2), 휴대폰 1칸.
   - "홈택스 카드 내역" 대조 문구는 8-12(홈택스 대조) 구현 전까지 쓰지 않는다. "실시간"·"귀신같이" 같은 과장 문구도 쓰지 않는다.
   - "더존/세무사랑 완벽 호환" 등 호환 보장 문구는 O-02 확정 전까지 쓰지 않는다.

## 4a. 한 달이 이렇게 흘러가요 (D-200)
- 기능 카드 다음, AI 미리보기 앞. 4단계 카드(번호 · 언제 · 누가): ① 매일 · 직원 — 영수증을 찍으면 결의서가 채워져요 ② 수시로 · 대표·팀장 — 휴대폰에서 바로 승인(직통 승인 기본, 팀장 사전 검토 선택) ③ 월말 · 경리·관리자 — 정산 지급·법인카드 대조·세무 마감 파일 한 번에 ④ 마감 뒤 · 세무사무소 — 무료 전용 화면, 위하고 일반전표 엑셀. 지금 있는 기능만, 결재 알림(알림톡 연결 전)은 "알림을 받고"라고 쓰지 않는다.

## 5. 누구에게 좋은가요? (D-200, 이전 "소기업 맞춤")
- AI 미리보기 다음, 요금제 앞. 역할 카드 4장: 대표(직통 승인·계정과목별 지출) / 경리·관리자(취합 없이 정산·마감 파일) / 직원(앱 설치 없음·식대 한도 나눔·출장비 묶음) / 세무사무소(무료 화면·확인할 영수증 표시·영수증에 바로 질문). 아래 예전 문단은 대표 카드와 부제("5인 회사에도 과하지 않게")로 흡수.
- (예전)
- "팀장 결재, 복잡한 조직도… 5인 회사에 과하지 않나요?"
- 기본은 **사장님(관리자) 직통 승인**(D-039)이고, 필요할 때만 팀장 사전 검토 단계를 추가하는 가벼운 결재라인과 부서 구분을 강조한다.
- 개인카드·법인카드 모두 지원하며, 일반 식대 한도 초과분은 자동으로 나눠 계산하고 출장 중 비용은 출장비로 따로 묶인다는 점을 보여 준다.
