# PocketExpense 서비스 개요

## 1. 서비스 정의
- **서비스명**: PocketExpense — 소기업·스타트업용 초간편 AI 경비 정산 SaaS
- **형태**: 모바일 웹(직원·결재자) + PC 웹 대시보드(관리자). 앱 설치 없음.

## 2. 타겟 고객
- 직원 5~30인 규모의 소기업, 스타트업, 비영리 단체, 현장 중심 기업.
- 전문 회계 담당자가 없거나 1명이며, 대표가 직접 최종 결재하는 조직.
- 기장은 외부 세무사무소에 맡기고 월말에 증빙을 넘기는 조직.

## 3. 해결하는 페인포인트
- 그룹웨어(인당 월 1만5천 원 선)·금융망 연동 솔루션은 비용과 도입 장벽이 높다.
- 직원은 영수증을 보고 사내 지출결의서 양식을 손으로 채우는 반복 작업에 지친다.
- 결재자는 결재를 위해 PC 그룹웨어에 접속해야 한다.
- 월말마다 세무사무소와 증빙·엑셀을 주고받는 소통 비용이 든다.

## 4. 핵심 USP
1. **도입비 0원**: 금융망 연동·설치 없음. 고정 월 구독.
2. **사내 양식 그대로**: 회사가 쓰던 지출결의서 양식을 찍어 올리면 Vision LLM이 웹 양식으로 변환하고, 관리자는 노코드로 보정한다. 직원 영수증 데이터가 그 양식에 자동으로 채워진다.
3. **카카오 알림톡 결재**: 상신 즉시 결재자 카카오톡으로 알림이 가고, 링크를 눌러 바로 승인/반려한다.
4. **월말 원클릭 마감**: 세무사무소 전달용 엑셀 + 영수증 원본 ZIP + 지출결의서 PDF를 한 번에 내려받는다.

## 5. 핵심 사용자 흐름
```
[관리자] 회사 생성 → 규칙 설정(식대 한도, 유류비 단가) → 사내 양식 업로드·보정 → 부서·결재라인 설정 → 초대 링크/QR 배포
[직원]   초대 링크 → 카카오/Google 로그인 → 온보딩(이름·휴대폰·부서 등) → 관리자 승인 대기 → 사용 시작
[직원]   영수증 촬영 → AI 파싱(가맹점·금액·일자·부가세) → 확인/수정 → 카테고리별 추가 입력 → 사내 양식 자동 채움 → 상신
[결재자] 알림톡 수신 → 링크 → 로그인(세션 유지 시 생략) → 결재 화면에서 승인/반려
[직원]   최종 승인/반려 알림톡 수신 → 반려 시 수정 후 재상신
[관리자] 정산완료 처리 → 월말 세무 패키지 다운로드
```

## 6. 비즈니스 모델
- 도입비 0원, 인당 과금 없는 구간제 고정 월 구독 (LLM·알림톡 비용 방어).
- 예시: 5인 이하 소호 팩 월 3만 원 / 20인 이하 스탠다드 팩 월 7만 원 / 30인 이하 상위 팩.
- **구독 결제·요금제 제한 기능은 현재 Spec에 정의되어 있지 않으므로 구현 범위가 아니다.** (decision-log 미결 O-05)
