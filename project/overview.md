# PocketExpense 서비스 개요

## 1. 서비스 정의
- **서비스명**: PocketExpense — 소기업·스타트업용 초간편 AI 경비 정산 SaaS
- **형태**: 모바일 웹(직원·결재자) + PC 웹 대시보드(관리자). 앱 설치 없음.

## 2. 타겟 고객
- 직원 5~30인 규모의 소기업, 스타트업, 비영리 단체, 현장 중심 기업.
- 전문 회계 담당자가 없거나 1명이며, 대표가 직접 최종 결재하는 조직.
- 기장은 외부 세무사무소에 맡기고 월말에 증빙을 넘기는 조직.

## 3. 해결하는 페인포인트
- 그룹웨어(인당 월 1만5천 원 선)·금융망 연동 솔루션은 비용과 도입 장벽이 높다.
- 직원은 영수증을 보고 사내 지출결의서 양식을 손으로 채우는 반복 작업에 지친다.
- 결재자는 결재를 위해 PC 그룹웨어에 접속해야 한다.
- 월말마다 세무사무소와 증빙·엑셀을 주고받는 소통 비용이 든다.

## 4. 핵심 USP
1. **도입비 0원**: 금융망 연동·설치 없음. 고정 월 구독.
2. **사내 양식 그대로**: 회사가 쓰던 지출결의서 양식을 찍어 올리면 Vision LLM이 웹 양식으로 변환하고, 관리자는 노코드로 보정한다. 직원이 올린 영수증 여러 장이 그 양식(헤더 + 항목 표)에 자동으로 채워진 지출소명서 1건이 된다.
3. **카카오 알림톡 결재**: 상신 즉시 결재자 카카오톡으로 알림이 가고, 링크를 눌러 바로 승인/반려한다.
4. **월말 원클릭 마감**: 세무사무소 전달용 엑셀 + 영수증 원본 ZIP + 지출결의서 PDF를 한 번에 내려받는다.

## 5. 핵심 사용자 흐름
```
[관리자] 랜딩 → 회사 생성(부서·기본 결재라인=대표 자동 생성) → 대시보드 체크리스트(정책, 양식, 결재라인 보완) → 초대 링크/QR 배포
[직원]   초대 링크 → 카카오/Google 로그인 → 온보딩(이름·휴대폰·부서 등) → 관리자 승인 대기 → 사용 시작
[직원]   지출소명서 시작(출장이면 [출장 경비] 켜고 출장지·기간·목적) → 영수증 여러 장 촬영/선택 → AI 파싱(가맹점·금액·일자·부가세·카테고리 추천) → 소명서 표에 자동 채움 → 항목별 확인/추가 입력 → 결재 요청(소명서 1건)
[결재자] 알림톡 수신("부산 출장 3건 · 72,000원") → 링크 → 로그인(세션 유지 시 생략) → 소명서 전체 승인/반려
[대표 등 최종 결재자 본인 경비] 상신 즉시 결재 생략 승인
[직원]   최종 승인/반려 알림톡 수신 → 반려 시 수정 후 재상신
[관리자] 정산 지급 관리에서 사비 지급 완료 처리 → 월말 세무 패키지 다운로드(영수증 1행 + 계정과목: 복리후생비·여비교통비·기업업무추진비 등)
```

## 6. 비즈니스 모델 (D-046, `spec/common/pricing-policy.md`)
- 도입비 0원, 인당 과금 없는 영수증 장수 기준 월 구독: 베이직 월 40,000원(300장) / 스탠다드 월 70,000원(600장) / 프로 월 100,000원(1,000장).
- **현재(결제 연동 전)**: 가입한 회사에 영수증 100장을 한시 무료 제공하고, 이벤트 기간에는 100장을 다 쓸 때마다 100장을 자동 추가 지급한다. 결제 화면은 정식 형태로 보이되 결제는 막아 둔다. 운영자 수동 크레딧 지급은 하지 않는다.
