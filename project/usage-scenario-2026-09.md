## 1. 준비 — 8월 넷째 주 (가입 · 설정 · 연결)

### 1-1. [관리자] 8/24(월) 김대표 — 회원가입과 회사 등록
1. 랜딩(`/`)에서 [무료로 시작하기] → **로그인** 화면 → [카카오로 3초 만에 시작하기] 또는 [Google로 로그인].
2. 처음이면 **"어떻게 시작할까요?"** → [회사 만들기] 선택.
3. **"우리 회사 정보를 입력해 주세요"**
   - 회사명: 한빛인테리어
   - 사업자등록번호: 10자리. **국세청에 바로 조회**해서 폐업·미등록이면 막힌다(D-155). 틀리게 넣어도 적은 내용은 남는다.
   - 부서 목록: "현장팀, 디자인팀, 경영지원" (Enter로 추가) — 직원 가입 때 선택지가 된다.
   - 대표자/관리자 정보: 이름, 휴대폰 번호(결재 알림 받을 번호), 본인 부서(대표는 "부서 없음"), 직급(선택).
   - 이용약관·개인정보 처리방침 동의(필수).
4. [회사 만들기] → **"PocketExpense를 추천받으셨나요?"**(선택) — 추천 회사 검색 또는 추천인 이름·휴대폰. [건너뛰기] 가능. 한 번만 묻는다(D-147).
5. **관리자 홈**으로 이동. 무료 영수증 **100장**이 들어와 있다(결제는 아직 비활성화된 화면만).

### 1-2. [관리자] 같은 날 — 관리자 홈의 "초기 설정 체크리스트"
홈 맨 위에 남은 할 일만 보인다: **직원 초대 · 부서 만들기 · 정산 정책 확인 · 사전 검토 결재라인(선택)**.

**① 설정 › 지출 한도·정책** (`/admin/settings`)
- **회사 정보**: 회사명·사업자번호 확인.
- **식대 한도**: [1인 한도 적용] 1인 10,000원 → 초과분 처리: [초과분은 개인 부담(절사)] 또는 [그대로 지원하고 표시만(자율 승인)]. 또는 [한도 없이 전액 지원].
- **자차 유류비**: [자차 유류비 지원] → km당 단가(고정, 예: 200원) 또는 오피넷 유가 연동. [출발·도착 계기판 사진 받기]를 켜면 직원 자차 항목에 계기판 사진 2장이 필수가 된다.
- **출장 일비**: 쓰면 1일 금액(예: 30,000원).
- **마감 일정**(확인용, 고칠 수 없음): "직원 청구 마감 · 매월 2일 / 세무 마감 · 매월 5일, 쉬는 날이면 앞 영업일" + 이번 달 실제 날짜.
- 맨 위 **[이 기기에서 알림 받기]** 켜기(관리자 마감 알림·결재 대기 알림을 받으려면).
- [저장] → 홈 체크리스트의 "정산 정책 확인"이 지워진다.

**② 설정 › 부서** — 온보딩에서 넣은 부서 확인·추가.

**③ 설정 › 사전 검토 결재라인**(선택) — "현장팀 결의서는 박팀장이 먼저 검토 → 관리자 최종 승인". 기본은 사전 검토 없이 관리자 직통.

**④ 설정 › 법인카드** — 카드 별칭 "대표 법인카드", 카드번호 앞 6자리·뒤 4자리(전체 번호는 저장하지 않음).

**⑤ 설정 › 회사차량**(있으면) — "현장 1호차 12가3456". 직원이 회사차 주유·통행료를 올릴 때 고른다.

**⑥ 설정 › 정기 결제** — 매달 나가는 SaaS 구독료 목록(예: 캐드 프로그램 월 55,000원, 매월 10일, 법인카드, 담당 이경리, 카드 내역 가맹점 이름 "AUTODESK"). 결제일에 결의서를 미리 만들지 않고, 월말 카드 내역 대조에서 실제 결제와 맞으면 그때 결의서를 만든다(D-171). 개인카드 정기 결제는 결제일에 담당자에게 "결제 내역 올려 상신" 알림만.

**⑦ 설정 › 지출결의서 양식** — 회사 종이 양식을 사진으로 올리면 그 모양으로 PDF가 만들어진다(선택).

**⑧ 설정 › 세무사무소** — 1-4에서.

**⑨ 설정 › 요금제** — 지금은 무료 100장 이벤트. 결제 버튼은 비활성화(사업자등록·PG 계약 후).

> 메뉴 구성(D-159·D-160): 메인 = 홈 / 지출 승인 관리 / 정산 지급 관리 / 멤버 관리 / **월별 지출 현황** / 세무 마감 / 설정. 사내 공지·알림 이력은 메뉴에서 숨겨져 있고, 계정과목은 [월별 지출 현황]에서 들어간다.

### 1-3. [관리자 → 직원] 8/25(화) — 직원 초대
1. 관리자 홈 또는 **멤버 관리**의 **초대 링크 카드** → [링크 복사] → 회사 단톡방에 붙여 넣기. (개별 초대는 이름·휴대폰으로 1인용 링크.)
2. **[직원]** 최직원: 휴대폰에서 링크 열기 → 카카오 로그인 → **"직원 정보 입력"**
   - 이름(실명), 휴대폰 번호, 부서(현장팀), 직급·사번(선택)
   - 정산 계좌(은행·계좌번호·예금주)는 **선택 동의**를 해야 입력 가능 — 사비 정산을 받으려면 넣는 게 좋다.
   - 약관 동의 → 제출 → **"관리자 승인 후 이용할 수 있습니다"** 화면.
3. **[관리자]** 이경리: 홈 할 일 "가입 승인을 기다리는 직원 1명" → **멤버 관리 › 가입 승인 대기** → [승인]. (자기가 받은 링크가 아닌 사람이면 [거절].)
4. 멤버 상세에서 필요하면: 역할(관리자 지정은 최고 관리자만), 식대 한도 개인 예외, "자가운전보조금 받음"(체크하면 그 직원은 자차 유류비 항목을 만들 수 없음, D-070).
5. **[직원]** 승인되면 앱 홈으로. 첫 화면 안내대로 **홈 화면에 추가**(앱처럼 쓰기, 아이폰은 이렇게 해야 알림 가능) + **[이 기기에서 알림 받기]**.

### 1-4. [세무사무소] 8/26(수) — 사무소 등록과 고객사 연결

**(가) 회사가 사무소를 지정** — [관리자] 이경리
1. 설정 › **세무사무소** → 세무사무소명 "바른세무회계", 사무소 대표 이메일, 담당 세무사 이름·이메일·휴대폰(선택) → 저장.
2. 저장하면 우리 회사 전용 **연결 링크**(`/for-tax-office/코드`)가 생긴다. 담당 세무사 휴대폰이 있으면 그 링크가 **카카오 알림톡**으로 간다("고객사 한빛인테리어가 PocketExpense를 쓰고 바른세무회계를 세무대행 사무소로 지정했어요… 무료"). [세무사무소 안내 복사]로 같은 링크를 직접 보낼 수도 있다(D-173). 알림톡은 솔라피 연결 전까지는 기록만.

**(나) 사무소 등록** — [세무사무소] 정세무
1. 알림톡·안내 링크를 열면 **세무사무소 소개 페이지**(로그인 전): "한빛인테리어의 세무 자료가 정리돼 있어요" + 받는 자료·무료 안내 → [세무사무소로 시작하기].
2. 카카오·Google 로그인 — **어떤 계정이든** 이 링크로 들어오면 한빛인테리어와 연결된다(회사가 적은 이메일과 같은 계정으로 로그인해도 연결). 링크 없이 랜딩 맨 아래 [세무사무소]로 들어와도 된다.
3. **세무사무소 등록(대표·관리자)**: 사무소명, 사업자등록번호(국세청 조회), 이름, 휴대폰(선택), 동의 → [세무사무소 등록하고 시작하기]. **사무소는 무료**.
4. 등록 즉시 한빛인테리어 세무 자료 화면으로 이동한다(이후 다른 회사의 연결 링크로 들어오거나 같은 이메일을 넣어도 고객사가 쌓인다).
5. [사무소 관리]에서 **[이 기기에서 알림 받기]** — 고객사 마감 완료·자료 요청 답변을 받는다.

**(다) 소속 세무사 합류와 배정** — 정세무 → 윤세무
1. **사무소 관리** → 초대 링크 복사 → 윤세무에게 전달.
2. 윤세무: 링크(`/tax-join/코드`)로 로그인 → 이름 입력 → 합류(또는 사무소 첫 화면에서 초대 코드 8자리 입력).
3. 정세무: **고객사** 목록에서 한빛인테리어의 담당 세무사를 **윤세무**로 지정. → 관리자는 모든 고객사, 소속 세무사는 **배정된 고객사만** 본다.

**(라) 사무소 준비** — 정세무
1. **결산 양식**: 사무소 회계 프로그램(위하고 등) 업로드용 엑셀 양식(.xlsx / .xls)을 올리면 머리글 칸을 찾아 "거래일자·거래처명·공급가액…"으로 연결해 저장. 이후 고객사 자료를 **이 양식에 채운 엑셀**로 받는다(회사도 자기 세무 마감 화면에서 같은 양식으로 받을 수 있다).
2. **계정과목**: 한빛인테리어 → [계정과목] 화면에서 사무소 기준으로 이름·코드·분류 연결(식대→복리후생비 811 등)을 맞춘다. 이 순간부터 **한빛인테리어는 계정과목을 고칠 수 없고 보기만** 한다(D-152). 바뀐 내용은 회사 [월별 지출 현황] 아래 **변경 이력**과 홈 알림으로 보인다.
3. [이 회사 설정을 사무소 기본값으로 저장] → **모든 고객사에 자동 적용**, 새로 연결되는 고객사도 연결되는 순간 적용(D-167). 업종이 달라 특정 회사만 다르게 고치면 그 회사는 "개별 설정"으로 빠지고, [사무소 관리 › 기본 계정과목]에서 [기본값으로 되돌리기].

> 회사 화면과 사무소 화면 사이에는 링크가 없다(서로의 화면을 오가지 않는다, D-152).

   - **회사에 자료 요청**: 영수증(선택)·내용 → [요청 보내기] → 회사 관리자에게 알림, 답변이 오면 사무소에 알림 → [해결](D-169)
