## 글쓰기 원칙
1. **정보가 먼저, 다모온은 맨 아래에 살짝.** 글 본문은 우리 앱과 상관없이 사람들이 궁금한 정보를 제대로 알려 준다(주제 제한 없음). 맨 아래에 "이런 일을 줄이고 싶다면 다모온을 써 보세요" 2~3줄 + damo-on.com 링크. 비율은 정보 9 : 소개 1
2. **제목 = 사장님이 네이버에 실제로 치는 말**
3. **다모온을 소개할 때만 — 실제로 있는 기능만 말한다.** 맨 아래 소개 부분에서 아직 없는 기능을 있는 것처럼 쓰지 않는다: 자동 승인(없음 — 우리는 카드 내역 대조), 부서별 예산(없음 — 회사 전체 예산). "1초 만에"·"80% 줄였다" 같은 과장·가짜 사례도 금지(광고법·PG 심사 위험). 정보 본문에서 부서 예산 같은 주제를 다루는 건 괜찮다. 카카오톡 알림톡은 **있는 기능**(D-295·B-3, 2026-11-25 실제 발송 확인): 결재 요청·반려·완료 3종, 프로 요금제 이상, 회사가 설정에서 켬 — 소개할 때 '프로 요금제 이상'을 함께 적는다
4. **세무 내용은 정확하게.** 법 근거를 적고, 글 끝에 "자세한 건 담당 세무사와 확인하세요" 한 줄
5. 고객 사례 글은 **실제 고객이 생긴 뒤** 진짜 숫자로만

## 이미지 원칙 (글만 쓰지 않는다)
1. **글 하나에 이미지 5~10장.** 문단 2~3개마다 1장. 네이버는 직접 만든 이미지가 많은 글을 더 좋게 본다
2. **대표 이미지(썸네일) 1장 필수.** 제목 글씨가 크게 들어간 카드(정사각형 1080×1080). 검색 결과에 이것이 보인다
3. **이미지 종류**
   - 요약 카드: 핵심 3줄·체크리스트·비교표를 그림으로(예: "영수증 잃어버렸을 때 3가지 방법")
   - 순서 그림: 1 → 2 → 3 단계(예: 월말 마감 순서)
   - 화면 캡처: 홈택스 메뉴 찾는 법 등(개인정보·사업자번호는 가림)
   - 다모온 화면: 맨 아래 소개 부분에 1~2장. **시험 회사 데이터로만 캡처**(실제 회사 데이터 절대 금지)
4. **남의 이미지 금지.** 인터넷 검색 이미지·다른 블로그 그림은 저작권 문제 → 직접 만든 것만. 무료 사진은 출처 확인된 것만
5. **같은 모양으로.** 다모온 색·글꼴을 맞춰 블로그 전체가 한 브랜드로 보이게
6. 이미지마다 설명 글(대체 텍스트)을 넣는다 — 검색에도 잡힌다
