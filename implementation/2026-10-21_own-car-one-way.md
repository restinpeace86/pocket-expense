# 자차 유류비 기본 편도, 왕복은 금액 × 2 (D-089)

- 구현 대상: 사용자 결정 — 교통비는 편도 거리 × 단가가 기본, 그 금액을 직원이 [왕복으로 계산]을 골라 × 2
- 구현 일시: 2026-10-21

## 변경 사항
- migration 042: `recompute_claim` 자차 금액 = round(편도 km × 단가) × (왕복 2), 새 항목·값 없을 때 기본 편도(`create_own_car_item`, `set_own_car_route`, `apply_route_distance`).
- `src/lib/expense/route.ts`: `fuelAmount(편도km, 단가, 왕복)`, 계산식 "편도 377km × 200원 = 75,400원 × 2(왕복) = 150,800원".
- `own-car-editor.tsx`: [왕복] 체크 상자 삭제 → 경로 카드 계산식 아래 [왕복으로 계산 (× 2 = 150,800원)] / [편도로 되돌리기] 버튼.
- 스펙 `trip-expense.md` §4.2, 결정 D-089(D-069 대체). 세무사무소 질문 10 추가(`tax-upload-format.md` §4, O-02): 자차 경로 요약 이미지를 ZIP으로 받을지 회사 보관만 할지.

## 검증
- DB `023_trip_own_car.sql`: 기본 편도, 단가 205원·편도 100.3km → 편도 20,562원, 왕복 41,124원(200.6km × 205 = 41,123원이 아님 — 계산 순서 확인). 예전 계산(040)에서는 이 테스트가 실패하는 것 확인. `test:db` 24개 통과.
- 로그인 E2E(360폭, 실제 Kakao): 판교역 → 부산역 기본 "편도 377km × 200원 = 75,400원" → [왕복으로 계산] 0.86초(화면 체감, 저장 포함) "… × 2(왕복) = 150,800원" → [편도로 되돌리기] 75,400원 → 다시 왕복 → DB 150,800원 → 상신 → 관리자 패널 같은 계산식.
- 단위 테스트 111, tsc / lint / build / check:responsive 통과.

## 추가 (같은 날) — 왕복 버튼 즉시 반영
- [왕복으로 계산]·[편도로 되돌리기]는 화면에서 바로 × 2 계산해 보여 주고(0.05초, 화면 체감), 저장은 뒤에서 한다. 저장 실패 시 화면을 되돌리고 안내. 저장 중에는 [저장하고 완료]를 잠가 저장 전에 화면을 떠나지 않게 한다. 금액 최종값은 DB가 같은 식으로 다시 계산.
