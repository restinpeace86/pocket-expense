## 발견 → 고침
| 상황 | 전 | 후 |
|---|---|---|
| 없는 주소·지운 결의서·다른 사람 결의서·없는 멤버 등 | 영문 "404 This page could not be found." | "찾는 화면이 없어요" + [홈으로]·[이전 화면]. 워크스페이스 안은 메뉴 유지(`admin`·`employee`·`approvals`의 not-found) |
| 운영자 화면(운영자 아님)·개발 미리보기 | 영문 "Not Found" 글자 | 같은 한국어 화면(404, proxy가 없는 경로로 바꿔 그림) |
| 로그인이 풀린 채 저장·상신 | proxy가 버튼 요청을 로그인으로 돌려 화면 전체가 영문 "This page couldn't load" | 버튼 요청은 돌리지 않음 → "로그인이 풀렸거나 이용이 중지된 계정이에요. 화면을 새로고침해 주세요." (적은 내용 유지) |
| 인터넷 끊김 중 상신 | 화면 전체가 영문 오류 화면(작성 내용 사라짐) | "인터넷 연결이 끊겨 저장하지 못했어요…" 안내, 입력 유지, 연결 뒤 [다시 저장] → 저장되고 안내 사라짐 |
| 인터넷 끊김 중 영수증 올리기 | 실패 뒤 화면 새로 받기 → 페이지 전체 재로딩 → 빈 화면 | 끊겼을 때는 새로 받지 않음 → "올리지 못했어요. 인터넷 연결을 확인하고…" |
| 예상 못 한 오류 일반 | Next 기본 영문 화면 | `error.tsx`·`global-error.tsx`: "화면을 불러오지 못했어요"/"인터넷 연결이 끊겼어요" + [다시 시도]·[홈으로] |
| 이미 소속된 계정이 다른 회사 초대 링크(공용·개인) | 말없이 내 회사 홈으로 | "이미 다른 회사에 소속된 계정이에요"(D-004) + [내 회사로 가기]·[로그아웃]. 같은 회사 링크는 그대로 이동 |
| 이름만 .pdf인 깨진 파일 | AI로 보내 크레딧 1장 차감, 빈 항목 생김 | 올리기 전에 막음("올릴 수 없는 파일이에요…"), 크레딧·항목 없음 |
| 계정과목 삭제 불가 버튼 읽기 이름 | "복리후생비은 분류에…" | "복리후생비: 분류에…" |

## 이미 정상이던 것(그대로 둠)
- 다른 회사·다른 직원 결의서는 어떤 주소로도 보이지 않음(찾는 화면 없음), 다른 회사 워크스페이스·직원의 관리자 화면 주소는 내 홈으로
- 승인 대기·비활성·소속 없음 → 각 안내 화면, 잘못된/취소된 초대 → 안내, 로그인 취소·잘못된 콜백 → 로그인 화면 안내, 외부 next 무시
- 영수증 없이 상신·두 탭 상신/삭제·비활성화 뒤 저장·두 관리자 동시 처리·가입 신청 중복 처리 → 각각 안내 문구
- 사진 아닌 파일·빈 파일·10MB 초과 → 안내, 크레딧 0장 → 이벤트 추가 지급 안내, 미래 날짜 → 안내, 금액은 숫자만·9자리까지
- 반려 사유 5자 미만이면 버튼 꺼짐, 소속 있는 부서 삭제는 확인 창에 "소속 멤버 N명은 '부서 없음'", 내역 없는 달은 마감 버튼 꺼짐 + "이 달에 승인된 지출이 없어요", 최고 관리자는 강등·비활성화 버튼 없음
