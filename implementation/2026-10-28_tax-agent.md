# 2026-10-28 담당 세무사(외부 열람자) 연결 + 세무사 화면 (todo_improvement 개선사항 2, D-148)

## 구현 대상
- 사용자 결정: 세무사는 직원과 다른 별도 계정, 한 계정 한 회사(D-004)와 별개, 관리자 워크스페이스에서 세무사무소를 세팅하면 외부 열람자
- 관리자 [설정 › 담당 세무사] → 세무사 로그인 시 자동 연결·여러 회사 누적 → 세무사 전용 화면(회사 전환·세무 자료·엑셀·계정과목 수정)

## 변경 사항
- DB(migration 075): `tax_agent_links`(회사당 1행, RLS 강제), `set_tax_agent`·`clear_tax_agent`(관리자), `my_tax_agent_companies`·`tax_agent_month_export`(세무사), `private.current_verified_email`·`tax_agent_company_ids`·`require_tax_agent`. 세무 마감 행 계산을 `private.tax_month_export_for(회사, 달)`로 옮기고 관리자 `tax_month_export`도 이것을 부름(관리자·세무사가 같은 행). 계정과목·분류 연결에 세무사 정책(조회·추가·수정)
- 관리자: `/workspace/[id]/admin/tax-agent`(`tax-agent-form.tsx`), 설정 메뉴 [담당 세무사]

- 처리방침: 담당 세무사 정보 항목, 고객사가 지정한 세무사의 열람은 고객사 처리(지시)
- spec: `spec/screens/tax-office.md`(새), roles-and-permissions §2, admin-settings §4, routes, schema 2.1a5

## 특이 사항
- 연결은 요청 원문대로 **승인 절차 없이 즉시**. 이메일 오타 위험은 저장 전 안내 + 이메일 변경 확인 창 + [연결 끊기]로 줄임. 로그인 계정의 **확인된 이메일**만 인정
- 초대 메일은 메일 발송 수단이 없어 [세무사 안내 복사](로그인 주소 + 이메일)로 대신. 가입 전이어도 그 이메일로 처음 로그인하면 바로 연결
- 엑셀은 관리자 세무 마감 장부 그대로(회사 마감 달은 정식, 아니면 미리보기). 회계 프로그램별 양식은 O-02(양식 파일 입수 후)
- 세무사 다운로드 기록은 요청 범위 밖이라 넣지 않음(제안 문서 4-1 ①)
- 영수증 사진: 세무사는 저장소 권한이 없어, 연결을 확인한 함수가 준 행의 그 회사 폴더 사진만 서버가 10분 링크 발급
