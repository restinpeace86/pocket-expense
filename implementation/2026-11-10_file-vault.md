## 변경 사항
- DB(migration 134_vault.sql)
  - `billing_plans.vault_storage_mb`(스타터 1GB·프로 3GB·비즈니스 10GB, 채팅 한도와 따로), 비공개 버킷 `vault-files`(20MB)
  - 표 `vault_files`(보관한 사람·공개 범위 private/company·원본·미리보기·출처 방/메시지), RLS: 회사 공유 = 같은 회사, 나만 보기 = 보관한 사람만. 파일 읽기 정책 `vault_can_read`
  - 함수: `vault_status`, `vault_keep_check`(방 참여자·사진/파일·지워지지 않음·중복·한도), `vault_set_scope`(보관한 사람), `vault_delete`(보관한 사람·관리자는 회사 공유만), `vault_member_usage`(관리자: 직원별 개수·용량만)
  - 서버 전용: `vault_add`(한도 재확인·70%/90% 처음 넘을 때 관리자 [알림]방), `vault_leaver_files_due`(퇴사 23일째 '7일 뒤 삭제' 안내, 30일 지난 나만 보기 목록), `vault_files_remove`, `storage_total_bytes`
  - 퇴사 감지 트리거: 비활성이 되면 기록 + 나만 보기 파일이 있으면 관리자 안내, 다시 활성화되면 기록 삭제
- 서버 `src/lib/vault/server.ts`: 보관 = 사용자 권한 확인 → chat-files → vault-files 저장소 안 복사(트래픽 없음) → 기록(실패하면 복사본 삭제), 지우기, 새벽 작업(퇴사자 파일 삭제·전체 저장 용량 70% 넘으면 운영자 디스코드)
- 화면
  - 채팅 메시지 메뉴(길게 누르기·오른쪽 클릭) [영구 보관] → 시트(나만 보기 기본·회사 공유, 보관 기간 일수, 개인정보·관리자 사용량 안내, 공간 막대, 다 찼을 때 안내), 보관된 메시지 "보관됨", 이미 보관한 파일은 [보관됨 · 파일 보관함에서 보기]
  - 직원 홈 [파일 보관함](채팅 쓰는 회사, 주변 버스 앞): 회사 공유/나만 보기 탭·검색·미리보기 목록·공간 막대, 파일 메뉴(열기·받기·공개 범위 바꾸기·올라온 채팅으로·지우기 확인)
  - 기기 저장: 한 번 받은 원본은 Cache Storage(`vault-files-v1`)에 두고 다시 열 때 서버에 가지 않음, 볼 수 없게 된 파일은 목록 때 지움, 로그아웃하면 전부 지움
  - 관리자 설정 › [파일 보관]: 영구 보관함 사용량 + 사람별 사용량 표(퇴사자 삭제 예정일), 도움말에 [영구 보관] 안내
  - 요금 카드: "파일 영구 보관 1GB/3GB/10GB" 줄
  - 저장 용량 표시: 조금이라도 쓰면 "0MB" 대신 "1MB 미만"
