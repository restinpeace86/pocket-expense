# 업로드 진행 단계 표시 · 계정과목 변경 속도 · 입력 사라짐 버그

- 구현 일시: 2026-10-21
- 계기: 사용자 피드백(계정과목 변경이 느림, 업로드 중 멈춘 것처럼 보임) + 로그인 상태 재현 점검

## 변경 사항
- **계정과목 변경**: 고르는 즉시 화면에 반영하고 저장은 뒤에서(실패하면 되돌림). 서버 액션이 화면 전체를 다시 그리지 않고 바뀐 계정과목만 돌려줌. 실측(로그인 상태, 개발 서버): 화면 반영 2.2초 → **0.02초**, 저장 완료 0.33초, 새로고침 뒤에도 유지
- **업로드 진행 단계**: 영수증 행마다 "차례 기다리는 중 → 1/3 사진 최적화 중 → 2/3 사진 업로드 중 → 3/3 AI가 영수증을 읽는 중 · 보통 2~5초 → 다 읽었어요 · 목록에 넣는 중" + 진행 막대 + 2초 넘으면 경과 초. 휴대폰에서 목록이 화면 아래에 있어도 보이도록 하단 버튼 위에 한 줄 요약("영수증 2장 · 1장 완료 · AI가 읽는 중 · 5초" + 막대)
- **버그 1 — 업로드 중 입력이 지워짐**: 새 소명서(?add=1)에서 주소를 몰래 바꾸던 코드 때문에 업로드 뒤 화면 갱신 때 Next가 화면을 새로 만들어, AI가 읽는 동안 입력한 제목·소명 내용이 사라졌다. 주소를 바꾸지 않게 수정(재현 → 수정 후 유지 확인)
- **버그 2 — 업로드 직후 상신하면 제목이 비는 문제**: 진행 행이 끝나자마자 사라지고 목록 갱신 전 약 1초 동안 영수증이 0장으로 보여, 그때 누르면 자동 제안 제목이 빈 값으로 저장됐다. 진행 행을 목록에 나타날 때까지 "목록에 넣는 중"으로 남기고(그동안 상신 버튼 비활성, 10초 안전장치), 제목이 비어 있으면 자동 제안을 계속 쓰게 수정
