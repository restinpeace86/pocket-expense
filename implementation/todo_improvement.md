## [Feature Update / Bugfix] 모아온(Moa-on) 관리자 설정 - '회사 위치' 입력 UX 개선

### 1. 요건 개요
- 기존 관리자 설정 화면의 '회사 위치' 입력 방식은 사용자가 임의의 텍스트를 입력하고 찾기 버튼을 누르면 주변 정류장 등이 엉뚱하게 조회되는 문제가 있음.
- 대한민국 실무 환경에 맞추어, 사용자가 **도로명뿐만 아니라 익숙한 '지번'이나 '건물명'으로도 자유롭게 키워드 검색**을 할 수 있고, 가장 보편적인 표준 우편번호 서비스를 통해 정확한 주소를 원클릭으로 선택·입력할 수 있도록 UI/UX를 전면 개선함.

### 2. 상세 요구사항 (Technical & UI/UX Specs)
- **주소 검색 인터페이스:**
  - [주소 검색] 버튼 또는 입력 필드 클릭 시, 대한민국 표준 **'카카오/다음 우편번호 검색 서비스 API (Daum Postcode Service)'** 또는 이와 동등한 표준 팝업/모달 UI가 화면 중앙에 팝업 형태로 호출되도록 구현.
- **검색 유연성:**
  - 사용자가 도로명 주소(예: "판교원로 3")뿐만 아니라, 오프라인 실무에서 훨씬 자주 쓰는 **지번 주소**(예: "삼평동 670")나 **건물명**(예: "대왕빌딩")으로 키워드를 입력해도 정확한 주소 목록이 실시간으로 필터링되어 노출되도록 지원.
- **데이터 바인딩 및 저장:**
  - 검색 결과 리스트에서 사용자가 올바른 주소를 마우스로 원클릭 선택하면, 팝업이 자동으로 닫히면서 시스템 입력란에 아래 데이터가 깔끔하게 자동 완성 및 저장되도록 처리:
    1. 표준 도로명 주소
    2. 지번 주소
    3. 우편번호
  - (선택/확장 대비) 향후 모바일 GPS 출근 체크 등 위치 기반 기능 연동을 고려하여, 해당 주소의 **위도(Latitude) 및 경도(Longitude) 좌표 데이터**가 백엔드/DB에 함께 매핑되어 저장될 수 있도록 데이터 구조 준비.

## [Refactoring / Branding Update] 서비스명 'WORKON' 전면 'Moa-on' 변경 요청

### 1. 작업 개요
- 프로젝트 전체에 적용되어 있는 기존 서비스명 및 표기(`WORKON`, `WorkOn`, `workon` 등 대소문자 변형 포함)를 **`Moa-on`**으로 일괄 변경합니다.
- 대소문자 규칙: **첫 글자 'M'만 대문자**로 하고, 하이픈 뒤의 **'on'은 소문자**로 고정합니다. (올바른 표기: `Moa-on`)

### 2. 치환 및 적용 대상 (전수 조사 필수)
프로젝트 소스 코드 전체(Frontend, Backend, Database 연동 파일, 환경 변수, 설정 파일 등)에서 아래 규칙에 따라 누락 없이 치환해 주세요.

- **UI 텍스트 및 화면 표기:**
  - 헤더, 로그인/회원가입 화면, 사이드바, 푸터, 관리자 설정 페이지 등에 노출되는 모든 "WORKON", "WorkOn" 문구를 **"Moa-on"**으로 수정.
- **브라우저 메타데이터 및 설정:**
  - `index.html` 등의 `<title>` 태그 및 웹앱 메타 태그(`manifest.json` 내 앱 이름 등)의 서비스명을 **`Moa-on`**으로 변경.
- **코드 내부 식별자 및 변수명 (필요 시 확인):**
  - 컴포넌트명, CSS 클래스 접두사, 상수 등에 hard-coding된 `workon` 관련 네이밍이 있다면 일관성 있게 `moaon` 또는 `moa-on`으로 정비.

### 3. 주의사항
- 대소문자 오타가 발생하지 않도록 반드시 **`Moa-on`** 정확한 포맷을 유지해 주세요.
- 코드 치환 후 빌드(Build) 시 에러가 발생하는 부분이 없는지 함께 검수해 주세요.

Moa-on을 바탕으로 로고라던가 세련된걸로 제안해줘.

## '회사 위치' 기반 주변 정류장 지도 시각화

### 1. 요건 개요
- 기존 관리자 설정의 '회사 위치' 화면에서 텍스트로만 제공되던 반경 200m 내 버스 정류장 정보를, 직관적으로 확인할 수 있도록 **인앱 웹 지도 기반의 시각화 컴포넌트**로 고도화합니다.

### 2. 상세 요구사항 (Technical & UI/UX Specs)
- **지도 연동 (Web Map API):**
  - 회사 위치(위도/경도 좌표)를 중심으로 하는 인터랙티브 웹 지도(예: Naver Maps API, Kakao Maps API 또는 가벼운 Leaflet 오픈소스 지도)를 화면 내에 렌더링.
- **마커(Marker) 시각화:**
  - **회사 위치 마커:** 지도 중앙(또는 설정된 좌표)에 눈에 띄는 메인 마커 배치.
  - **주변 정류장 마커:** 회사 위치 반경 200m 내에 위치한 정류장 최대 3개소에 서브 마커(버스 아이콘 등)를 지도 위에 동시 렌더링.
- **인터랙션 및 정보 연동:**
  - 사용자가 지도 위의 정류장 마커를 클릭할 경우, 해당 정류장 명칭 및 거리(예: "중계주공4단지, 46m")가 인포윈도우 또는 하단 리스트 형태로 하이라이트되어 연동되도록 구현.
  - 현재 노원구 한글비석로 위치기준 3개 나오는데 이와 지도에서의 정류장 눌렀을때 하이라이트로 표시하면 직관적으로 이해하기 쉬울 것으로 보임.

- **정류장 리스트 및 인라인 아코디언 인터페이스 (핵심 UX):**
  - 지도 하단(또는 측면)에 주변 정류장 리스트 카드 배치 (예: "중계주공4단지 - 46m").
  - 사용자가 리스트 항목이나 지도 위의 정류장 마커를 클릭할 경우, **페이지 전환 없이** 해당 영역이 **아코디언 형태로 부드럽게 펼쳐지며(Expand/Collapse)** 실시간 버스 도착 정보(예: `[102번] 3분 후 도착`, `[1140번] 12분 후 도착`)가 즉시 노출되도록 구현.
  - 다시 클릭하거나 다른 정류장을 누르면 깔끔하게 접히는 토글 구조 적용.

즉 인앱으로 상단쪽에 보여주고 맵에 있는 정류장 누르면 하단에 정류장 하이라이트되며 정류장 누를경우 아코디언 형태로 버스 도착정보가 펼쳐지는구조.

### 1. 요건 개요

### 2. 상세 요구사항 (Technical & UI/UX Specs)
- **가이드 데이터 아카이브 (Knowledge Base):**
  - 관리자 설정 7대 그룹, AI Vision 문서 엑셀 변환 유틸리티, 출퇴근 인증, 나의 신청함 등 Moa-on의 모든 핵심 기능별 상세 사용 설명글을 체계적으로 작성하여 시스템 내에 탑재.
- **AI 검색 바 (Natural Language Search):**
  - AI FAQ 리스트화면 검색창을 홈화면 하단에 두어 사용자가 일상적인 문장(예: "영수증 올렸는데 단가 수정은 어떻게 해요?")으로 검색 시, LLM/RAG 연동을 통해 가장 연관성 높은 가이드 본문을 매칭하여 요약 답변과 함께 제공.
- **카테고리별 매뉴얼 탭:**
  - 검색창 하단에 [기본 설정], [AI 엑셀 변환], [근태/신청] 등의 카테고리 탭을 두어, 사용자가 클릭 한 번으로 상세 가이드 문서(마크다운 뷰어 형태)를 정독할 수 있도록 UI 구현.
- **바로가기 링크 연동:**
  - 가이드 내용 하단에 관련 기능 페이지로 곧바로 이동할 수 있는 [해당 메뉴로 이동 ➔] 버튼을 배치하여 실무 동선 최적화.
