[개선사항 1] 직원용 워크스페이스 모바일 홈 화면 내 **[임시저장된 지출결의서 목록] UX를 아래 요건에 맞춰 개선해줘.**

1. 홈 화면 리스트에서 직접 삭제 기능 추가
- 현재는 임시저장된 건을 삭제하려면 상세 화면으로 진입하여 맨 아래로 스크롤해야 하는 번거로움이 있음.
- 이를 개선하여, 직원 홈 화면의 임시저장 리스트 항목에서 모바일 친화적인 **'스와이프하여 삭제(Swipe-to-Delete)'** 인터랙션을 구현해줘.

2. 세부 동작 방식 (UX Flow)
- 사용자가 홈 화면의 임시저장 리스트 중 특정 항목을 좌측(또는 우측)으로 손가락을 밀어 스와이프하면, 옆에 **[삭제] 버튼**이 노출되도록 함.
- 노출된 [삭제] 버튼을 터치하면, "임시저장된 문서를 삭제하시겠습니까?" 같은 가벼운 확인 팝업(또는 즉시 삭제)과 함께 해당 리스트가 깔끔하게 지워지도록 처리할 것.
- 상세 화면으로 이동하지 않고도 홈에서 바로 불필요한 임시저장을 정리할 수 있게 만들 것.

- 사용자가 이 뾰족한 토글 버튼을 터치하면, 해당 영수증 카드 하단 영역이 부드럽게 슬라이드되며 **숨겨져 있던 상세 수정 필드들이 인라인으로 쫙 펼쳐지도록** 구현함.

3. 펼쳐진 영역(아코디언 내부)에서 수정 가능한 항목

- 지출 카테고리 (일반 식대 / 출장비 / 외부 미팅비 / 회사 물품 구매 등)

- 수정이 끝나면 토글을 다시 눌러 깔끔하게 접을 수 있게(Collapse) 처리할 것.

4. 메인 화면과의 데이터 연동
- 원페이지 안에서 여러 장의 영수증이 각각 펼쳐져서 수정되더라도, 최종 상신 시 이 모든 데이터가 메인 지출결의서 데이터와 실시간으로 완벽하게 동기화되어 한 번에 상신될 수 있도록 구조를 완성해줘.

2. 수정 요구사항
- 초대 링크 및 카카오톡 공유 URL을 생성할 때, 하드코딩된 `localhost` 대신 **현재 배포된 실제 운영 환경 도메인 주소(Environment Variable, 예: `NEXT_PUBLIC_SITE_URL` 또는 동적 `window.location.origin`)를 바라보도록 코드를 전면 수정**할 것.

✅(D-100, 2026-10-22) [개선사항 7] PocketExpense SaaS 프로젝트의 **[영수증 증빙 구분] 처리 로직을 AI 자동 판별 및 투명한 근거 제공(Explainable AI) 방식으로 구현**해줘.

1. 직원 수동 선택 폐지 및 AI 자동 판별 도입
- 일반 직원들이 영수증을 올릴 때 "이게 카드전표인가, 현금영수증인가"를 직접 고민하고 수동으로 고르지 않도록 함. 일반 직원들은 이 증빙구분에 대하여 잘 모름..
- 영수증 업로드 시 AI 파싱 엔진이 텍스트와 패턴을 분석하여 **증빙 구분(카드매출전표 / 현금영수증 / 세금계산서 / 간이영수증 등)을 자동으로 지정**해 줄 것.

2. 스마트 디폴트 (Smart Default) 적용
- 소기업 지출의 대다수가 카드로 이루어지므로, 시스템의 기본값(Default)은 무조건 **[카드매출전표]**로 설정할 것.

3. AI 판별 이유(근거) 텍스트 노출 (Explainable AI)
- 증빙 구분 UI 영역 하단이나 옆에, 아주 연한 작은 회색 글씨(Sub-text)로 **AI가 왜 그렇게 판단했는지에 대한 근거(이유)**를 직관적으로 함께 표기해 줄 것.
- **예시 포맷**:
  - `[카드매출전표]` 👉 └ ✨ 카드 승인번호를 확인했어요
  - `[현금영수증]` 👉 └ ✨ 현금영수증 번호가 확인되었어요
  - `[세금계산서]` 👉 └ ✨ 세금계산서 항목으로 확인했어요
  - `[간이영수증]` 👉 └ ✨ 별도 승인번호가 없어 간이 영수증으로 분류했어요
- 사용자가 판별 근거를 보고 AI의 정확도를 신뢰할 수 있게 하고, 드문 오인식 시 직관적으로 수동 변경(Override)할 수 있도록 UI를 구성할 것.
