다음 3가지 UI/UX 수정 사항을 현재 Next.js 프로젝트에 반영해줘.

1. 관리자 워크스페이스 모바일 설정 기본값 변경
- 모바일 화면에서 관리자 설정 메뉴/아코디언의 기본 상태가 접혀(folded) 있는 것을, 무조건 '펼치기(Expanded)' 상태로 고정해줘. 스마트폰으로 들어갔을 때 한눈에 펼쳐져 보이게 수정할 것.

2. 직원 초대 화면에 '카카오톡 공유' 버튼 추가
- 직원 초대 페이지에 기존 '링크 복사', 'QR 이미지 저장'과 함께 [카카오톡으로 공유하기] 버튼을 추가해줘.
- 카카오 JS SDK를 연동해서 버튼을 누르면 카카오톡 공유 창이 뜨고, 초대 링크가 예쁜 카드로 전송될 수 있게 해줘.
- 카카오 자바스크립트 키는 환경 변수 `NEXT_PUBLIC_KAKAO_JS_KEY`를 사용하도록 처리해줘.

3. 직원 영수증 상세 화면(ItemEditor) 레이아웃 겹침 현상 전면 개선
- 현재 모바일 화면에서 영수증 이미지 크기 때문에 가맹점, 사업자번호, 사용일, 합계 등의 입력 폼 영역과 이미지 영역이 서로 겹쳐서 글자가 안 보이는 문제가 있음.
- "한 화면에 다 우겨넣으려 하지 말고, 필요하면 아래로 스크롤해서 볼 수 있게" 구조를 전면 개편해줘.
- 상단에는 영수증 이미지가 잘림 없이 깔끔하게 보이고(클릭하지 않아도 전체 구조가 눈에 들어오게), 하단에는 입력 폼 영역을 완전히 분리해서 스크롤하며 자연스럽게 입력할 수 있도록 레이아웃을 정돈해줘.
