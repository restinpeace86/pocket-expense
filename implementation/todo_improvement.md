[개선사항 1] # [PocketExpense] 기능 및 로직 스펙 정의서 (월말 마감 & 알림 자동화)

## 1. 마감 일정 및 룰 (고정 표준)
- **마감일**: 매월 **5일** (전월 데이터 마감)
  - 예시: 10월 5일 마감 시, 대상 기간은 9월 1일 ~ 9월 30일.
- **설정 제한**: 회사별 커스텀 마감일 설정 기능은 제공하지 않으며, **매월 5일 고정 룰**로 강제함. (여기에 대하여 타당한지 이렇게 가는게 나은지에 대하여 검토해줘)

---

## 2. 주체별 역할 및 데이터 업로드 플로우
1. **현장 직원 (평소)**
   - 현장에서 발생하는 영수증(식대, 자재비, 간이영수증 등)을 모바일 앱으로 상시 촬영 및 업로드.
2. **관리자 (매월 초)**
   - **2일 ~ 5일**: 국세청 홈택스에서 전월 세금계산서 및 카드 매입 엑셀 파일 다운로드 및 우리 앱에 해당 파일 업로드.
3. **시스템 자동 처리**
   - 관리자가 업로드한 홈택스 파일 + 직원들이 올린 현장 영수증 + 사전 등록된 정기 구독(SaaS) 템플릿을 대조하여 **[전월 통합 지출결의서]**를 자동 생성.
4. **마감 확정 (매월 5일)**
   - 관리자가 최종 확인 후 마감 완료 시, 데이터가 B2B2B 세무사무소 워크스페이스로 전달됨.

---

## 3. 관리자 대상 알림 자동화 (카카오 알림톡 + 앱 푸시)
시스템은 관리자가 홈택스 파일을 제때 올리고 마감할 수 있도록 아래 일정에 맞춰 카카오 알림톡과 앱 푸시를 자동 발송함:
- **매월 2일 (마감 주간 시작)**
  - 대상: 전체 관리자
  - 내용: "지출 마감 주간이 시작되었습니다. 5일까지 홈택스 파일을 업로드해 주세요."
- **매월 3일 (D-2 1차 리마인드)**
  - 대상: 홈택스 파일을 아직 업로드하지 않은 관리자
  - 내용: "지난달 홈택스 파일이 아직 업로드되지 않았습니다. 5일까지 등록을 완료해 주세요."
- **매월 5일 자정 (D-Day 마감 최종 경고)**
  - 대상: 마감을 완료하지 않은 관리자
  - 내용: "오늘 밤 12시는 지난달 지출 마감 최종일입니다. 누락 내역 확인 후 마감을 완료해 주세요."
- 매월 1일 3일 5일로 되어 있지만 유동적으로... 이 알림 보내는 일자가 주말이라면, 일자를 당겨서 금요일에 보낼 수 있도록...(ex. 10월 1일이 토요일이라면 9월 30일 금요일 오전 9시에 보내도록?) 워킹데이 판단해서 해당일자가 워킹데이가 아니라면 워킹데이에 보낼것.

#  월말 마감 및 청구 기한 시스템 기능 스펙 정의

## 1. 마감 일정 및 핵심 룰 (시스템 고정 표준)
- **전월 경비 청구 기한 (직원용)**: **매월 2일 자정 (시스템 자동 고정, 변경 불가)**
  - 의미: 직원들은 전월에 사용한 현장 영수증(식대, 자재비, 간이영수증 등)을 늦어도 매월 2일 자정까지는 반드시 청구(등록) 완료해야 함. (이후 전월 건 추가 청구 제한)

- **홈택스 마감일 (관리자용)**: **매월 5일 (전월 데이터 최종 마감 및 세무사 토스)**
  - 의미: 관리자는 매월 2일~5일 사이에 홈택스에서 전월 세금계산서/카드 매입 파일을 다운로드하여 업로드하고, 직원들이 올린 영수증과 대조 후 마감 확정.
- **제약 사항**: 회사별 커스텀 마감일이나 청구 기한 변경 기능은 세무 일정 충돌 및 데이터 단절 방지를 위해 전면 배제함.

- 위의 일자도 경비 청구기한에 대하여 매월 2일까지로 하더라도 2일이 토요일이나 일요일이면 사실상 경비 청구 마감일자는 일하는 주중인 금요일까지임. 이걸 고려하여 마감일정은 고정이지만 working day인지 아닌지를 시스템에서 확인하고 마감일이 working day가 아니라면 마감일 이전 워킹데이로 할것.

## 2. 주체별 역할 및 데이터 크로스체크 플로우

   - **매월 2일 자정**에 전월 청구 기능이 자동으로 닫힘.

[개선사항 2] # [PocketExpense] 관리자 워크스페이스 메뉴 및 설정 화면 간소화 스펙 정의서

## 1. 개요
소규모 현장 중심 사업장(5~10인 미만)의 사용 편의성과 직관성을 높이기 위해, 관리자 워크스페이스(일반 사장님/관리자용)의 설정 및 메뉴 구성을 대폭 간소화하고 권한에 따라 기능을 분리함.

---

## 2. 주요 변경 사항 및 처리 지침

### ① 사내공지 기능
- **처리 방침**: 일반 관리자 워크스페이스에서 **UI 숨김 처리** (메뉴 노출 비활성화).
- **이유**: 소규모 현장 조직에서 앱 내 공지사항 활용도가 낮고 화면을 복잡하게 만듦. (기존 코드 및 DB는 유지하되 화면상에서만 보이지 않게 처리)

### ② 알림 이력 및 실패 사유 확인 기능
- **처리 방침**: 
  - **일반 관리자 워크스페이스**: **숨김 처리**. (사장님들은 알림톡 전송 성공/실패 로그나 상세 실패 사유를 직접 조회할 일이 없음)
  - **앱 관리자(슈퍼 어드민) 대시보드**: **이관 및 배치**. (운영자/개발자가 CS 응대를 위해 '회사별 알림 발송 이력 및 실패 사유'를 조회할 수 있는 관리자 전용 기능으로 재배치)
