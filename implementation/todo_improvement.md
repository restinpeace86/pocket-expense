[개선사항 1] 하기 가격정책 검토해줘
- 현재 우리 가격정책은 영수증 장수에 따른 가격 정책으로 보여짐.
- 우리 앱의 전체 프로세스와 가치를 고려했을때 현재 영수증 장수로 인한 업그레이드는 하나의 가치지 우리 앱의 전체의 가치를 보여줄 수 없다고 판단되어 가격정책에 대한 문구나 밸런스 조정이 필요하다고 생각됨.
- 이에 대하여 우리앱의 가치와 이점 등등을 고려해서 하기 내용 검토하고 추가제안도 해줘
- 
- 현재 홈택스 법인카드 실시간 연동 API에 대하여서는 비용때문에 안해놨지만 이를 원하는고객이 있을껀데... 일단 가격정책에 반영안되는 별도 문의로 빼놓았어. 무조건적으로 안되는거보단 상담해보고 이거를 위하여는 얼마를 더 내야한다는 식으로...
- 이에 대하여 법인카드 실시가 API 연동 비용이 어떻게 되는지 알려줘 그쪽 가격정책... 그리고 이걸 붙이는게 나은지 아니면 지금처럼 법인카드 실시간 API 자동연동은 빼는게 나은지 분석 및 제안해줘.
