[개선사항 1] 다음 3가지 UI/UX 수정 사항을 현재 Next.js 프로젝트에 반영해줘.

1. 관리자 워크스페이스 모바일 설정 기본값 변경
- 모바일 화면에서 관리자 설정 메뉴/아코디언의 기본 상태가 접혀(folded) 있는 것을,  '펼치기(Expanded)' 상태로 변경해줘. 스마트폰에서 네비게이션 바 열었을때 설정 메뉴 내 화면 이름들이 보이도록 펼쳐져 보이게 수정할 것.

2. 직원 초대 화면에 '카카오톡 공유' 버튼 추가
- 직원 초대 페이지에 기존 '링크 복사', 'QR 이미지 저장'과 함께 [카카오톡으로 공유하기] 버튼을 추가해줘.
- 카카오 JS SDK를 연동해서 버튼을 누르면 카카오톡 공유 창이 뜨고, 초대 링크가 예쁜 카드로 전송될 수 있게 해줘.
- 카카오 자바스크립트 키는 환경 변수 `NEXT_PUBLIC_KAKAO_JS_KEY`를 사용하도록 처리해줘. ( 관련하여 현재 되어있는 kakao key가 있는지 확인 ,.env.local )

3. 직원 영수증 상세 화면(ItemEditor) 레이아웃 겹침 현상 전면 개선
- 현재 모바일 화면에서 영수증 이미지 크기 때문에 가맹점, 사업자번호, 사용일, 합계 등의 입력 폼 영역과 이미지 영역이 서로 겹쳐서 글자가 안 보이는 문제가 있음.
- "한 화면에 다 우겨넣으려 하지 말고, 필요하면 아래로 스크롤해서 볼 수 있게" 구조를 전면 개편해줘.
- 상단에는 영수증 이미지가 잘림 없이 깔끔하게 보이고(클릭하지 않아도 전체 구조가 눈에 들어오게), 하단에는 입력 폼 영역을 완전히 분리해서 스크롤하며 자연스럽게 입력할 수 있도록 레이아웃을 정돈해줘.

[개선사항 2] 모바일 직원 워크스페이스의 하단 네비게이션 바와 화면 구성 간의 UX 중복 및 동선 문제를 정리하고 싶어. 현재 상황과 고민 중인 대안들을 검토해서 가장 깔끔한 방향을 제안하고 코드를 수정해줘.

1. 현재 상황 및 문제점
- 모바일 직원 워크스페이스 하단 바에 4개의 버튼(홈, 정산, 결재함, 내정보)이 있음.
- 그중 '결재함'을 누르면 뜬금없이 관리자 워크스페이스 페이지로 튀어나가며 하단 바가 소실되는 심각한 동선 결함이 있음. (이건 무조건 제거해야 함)
- 그런데 이미 **'홈' 화면**에 [전체 / 임시저장 / 검토대기 / 반려됨 / 완료] 상태별 필터와 영수증/소명서 간략 리스트가 모두 구현되어 있음.

2. 검토 중인 대안 (클로드의 전문적인 판단으로 더 나은 방향을 선택/제안해줘)
- [대안 A: 하단 바를 3개로 축소 (홈, 정산, 내정보)]
  - 홈 화면에서 이미 모든 상태별 리스트와 요약을 제공하므로, 중복되는 4번째 탭을 없애고 미니멀하게 가는 방식.
- [대안 B: 역할을 명확히 분리 (홈은 퀵 대시보드, 4번째 탭은 '전체 내역/보관함')]
  - 홈 화면은 최근 내역 요약 위주로 가볍게 두고, 4번째 탭의 이름을 '전체 내역(또는 신청함)'으로 바꿔서 과거의 모든 소명서를 날짜별·기간별로 깊게 파고들어 검색·조회하는 전용 공간으로 용도를 확실히 쪼개는 방식.

- 바텀버튼 중 결재함을 빼는 제안을 할 경우 하기 바텀버튼에 그러면 어떤게 더 필요할 지에 대하여서도 제안해줘.
 
3. 요청 사항
- 위 두 대안 중 모바일 B2B SaaS 관점에서 가장 직관적이고 완성도 높은 UX 방향을 선택해서 설명하고, 그에 맞게 코드를 깔끔하게 수정해줘. (하단 바가 소실되는 현상이나 엉뚱한 페이지로 튀는 라우팅은 완전히 제거할 것)

[개선사항 3]직원용 워크스페이스의 테마 색상(개인화) 설정할 수 있는 기능이 누락되었음.  직원용 워크스페이스에 대하여 아래와 같이 수정해줘.

1. 관리자 워크스페이스 영역: **변경 금지 (현재 상태 그대로 유지)**

2. 직원용 워크스페이스 (모바일 퍼스트 환경)
- 직원용 화면에는 현재 상단 네비게이션 바가 없는 상태고 색상 변경 기능 때문에 넣기에는 UX를 깨트리는 것임.
- 대신, 직원용 워크스페이스의 바텀버튼 중 **[내 정보] 버튼을 눌렀을 때 나오는 탭 내부**에 개인화 테마(색상)를 선택하고 변경할 수 있는 메뉴를 깔끔하게 배치해줘.
- 사용자가 [내정보]에서 테마 색상을 변경하면 즉시 화면에 반영되고 저장되어 재접속 시에도 유지되도록 처리해 줄 것.

[개선사항 4] 법인카드 등록 화면과 영수증 카드 번호 매칭 로직을 보안성과 실무 환경(영수증 마스킹 현실)에 맞춰 아래와 같이 수정/구현해줘.

1. 보안 및 컴플라이언스 원칙 (전체 16자리 저장 금지)
- 카드 번호 전체 16자리를 데이터베이스에 평문으로 저장하는 것은 보안 및 개인정보/금융정보 규제상 리스크가 크므로 절대 지양할 것. (CVC나 유효기간은 애초에 받지 않음)

2. 관리자 법인카드 등록 화면 스펙 변경
- 관리자가 관리자 워크스페이스의 메뉴 중 법인카드에서 법인카드 번호를 등록할 때 현재의 끝자리 4자리만 받는 구조 변경.
- 대신 **[앞 6자리 (BIN 번호)]**와 **[뒤 4자리]**만 입력받아 DB에 저장하도록 폼(Form)과 스키마를 수정해줘. (카드 별칭이나 소유자 이름 등 메타데이터와 함께 저장)
- 카드번호 받을때 ㅁㅁㅁㅁ-ㅁㅁ**-****-ㅁㅁㅁㅁ 이런식으로 포맷되어있고 숫자입력할때마다 저 칸이 한칸씩 다음칸으로 넘어가는구조.. 현재 범용적으로 카드 번호 입력받는 구조 참조해서 만들어줘)

3. 영수증 파싱 및 카드 매칭 로직 개선
- 영수증 인쇄 특성상 중간 6자리는 애초에 별표(`******`) 등으로 마스킹되어 출력되므로 비교 데이터가 존재하지 않음.
- 따라서 AI가 영수증에서 읽어낸 카드 번호 조각(노출된 앞부분과 뒷부분)을, DB에 등록된 **[앞 6자리] 및 [뒤 4자리]** 데이터와 대조하여 우리 회사 법인카드를 정확히 식별하고 매칭(또는 추천)할 수 있도록 매칭 알고리즘을 구현/수정해줘.
- 다만 우리가 받은 앞 6자리 및 뒤 4자리에 대하여 숫자가 아닌 마스킹으로 표시되는 영수증도 있을 수 있음 ex) 뒤 4자리가 432* 로 되어있을 경우도 있으니 이경우 숫자만 매칭해. * (마스킹 제외)
- 이렇게 등록되면 .. 지출소명서 작성할경우 결제수단을 법인카드인지 개인카드인지에 대하여 현재 작성자가 선택하게 되어있는데 이걸 초기에 자동 선택하도록 가능할거같은데?

[개선사항 5] 프로젝트 내의 문서 명칭과 용어를 전면 수정하려고 해.
- 기존에 '지출소명서'로 표현되었거나 구현되어 있던 모든 UI 텍스트, 컴포넌트명, 변수명, 데이터베이스 스키마 관련 용어를 **'지출결의서 (Expense Report)'**로 일괄 변경해줘.
- '소명서'라는 독립된 개념 대신, 전체 지출 정산의 기본 뼈대는 **'지출결의서'**로 통일하고, 주말/심야 등 예외 건에 대한 해명 내용은 지출결의서 내부의 **[예외 소명 사유 (Memo)]** 필드로 통합해줘.

[개선사항 6] PocketExpense SaaS 프로젝트의 '출장 경비' 정산 기능을 아래 요건에 맞춰 새롭게 기획 및 구현해줘. 직원들의 수기 입력과 증빙 노가다를 없애고 자동화하는 것이 핵심 목표야.
현재는 출장지와 출장일자 from / to , 출장 목적만 작성하도록 되어있던거 같은데 ? 아닌가 ?
1. 출장 기간 선택 (Date Range Picker)
- 기존처럼 날짜 창을 두 번 여는 방식이 아니라, 모바일에서 한 번의 터치/드래그로 시작일과 종료일을 묶어서 선택할 수 있는 **날짜 범위 선택형 캘린더(Date Range Picker)**를 구현해줘.
- 시간(시/분)은 제외하고 오직 **날짜(연월일)** 단위로만 처리함.

2. 이동 수단 선택 및 분기 처리
- 출장 신청 폼 상단에 이동 수단을 선택할 수 있게 함 (`[자차]` vs `[대중교통/KTX]`).
- '대중교통/KTX' 선택 시: 기존과 동일하게 교통편 영수증 첨부형으로 처리.
- '자차' 선택 시: 아래 3~5번의 자동 계산 로직이 활성화됨.

3. 출발지 / 도착지 지도 API 연동 및 자동완성 검색
- 사용자가 출발지와 도착지 입력란에 키워드를 입력하면, 외부 지도 API(예: 카카오/네이버 로컬 API 등)를 연동하여 **실시간 주소 자동완성 및 장소 추천 목록**이 뜰 수 있도록 구현해줘.

4. 자차 주행 거리 자동 산출 및 유류비 자동 계산
- 출발지와 도착지가 확정되면, 시스템이 경로 API를 통해 **실제 주행 거리(km)**를 자동으로 산출하게 함.
- 사전에 설정된 단가(예: **1km당 200원**)와 자동 곱셈하여 총 청구 금액이 원클릭으로 계산되도록 구현해줘.

5. 디지털 증빙 자료 자동 생성 (캡처 대체)
- 직원이 카카오내비나 티맵 화면을 캡처해서 이미지로 올릴 필요가 없도록 함.
- 시스템이 산출해 낸 **[출발지 ➔ 도착지, 총 주행 거리(km), 산출된 정산 금액]이 깔끔하게 담긴 '출장 경로 및 거리 산정 요약 디지털 카드'**를 자동으로 생성하여, 해당 지출결의서의 공식 증빙 자료로 자동 첨부되도록 구현해줘.

6. 지출결의서(Expense Report) 데이터 통합
- 위에서 산출된 출장 경비 데이터(기간, 이동수단, 출발/도착지, 거리, 자동 계산된 금액, 디지털 증빙)가 기존에 정의된 '지출결의서' 데이터 모델 및 화면과 자연스럽게 연동되도록 마감해줘.
