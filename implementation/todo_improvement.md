[개선사항 1] PocketExpense 서비스에 회원가입 온보딩과 관리자 대시보드를 연동하는 **[레퍼럴(추천인/추천회사) 시스템]**을 구현해 주세요.

### [1. 회원가입 온보딩 단계 (유저 화면)]
- 소셜 로그인(구글/카카오) 직후 진행되는 온보딩 과정에 **선택형(Optional)**으로 [추천인 / 추천회사 입력] 단계를 추가해 주세요.
- 사용자는 라디오/탭을 통해 둘 중 하나를 선택할 수 있습니다.
  - **추천회사 선택 시**: 회사명 입력 시 우리 DB에 가입된 회사 목록이 실시간으로 검색/자동완성(Autocomplete)되게 해주세요.
  - **추천인 선택 시**: '이름'과 '휴대폰 번호'를 입력하는 간단한 input 필드가 나오게 해주세요.
- 필수가 아닌 옵셔널이므로 입력하지 않고 [건너뛰기/다음]을 눌러도 정상적으로 넘어가야 합니다.

### [2. 관리자 대시보드 (앱 관리자 전용 화면)]
- 앱 관리자 페이지만의 전용 탭이나 섹션에 **[레퍼럴(추천) 현황 관리]** 페이지를 만들어 주세요.
- 해당 화면에는 다음 정보가 테이블(Table) 형태로 깔끔하게 조회되어야 합니다.
  - 가입한 기업명 / 유저 정보
  - 선택한 추천 유형 (추천회사 또는 추천인)
  - 추천받은 대상 (추천 회사명 또는 추천인 이름/번호)
  - **첫 결제 여부 (결제 완료 / 미결제)** -> 첫 결제가 완료된 건들이 한눈에 띄도록 표시해 주세요.
- 앱관리자가 매일 들어가서 확인하고 직접 보상을 챙겨줄 수 있도록, 복잡한 자동화 기능 없이 **조회 및 리스트업 기능**에 집중해 주세요.

현재 프로젝트의 데이터베이스 스키마와 UI 컴포넌트 구조에 맞춰 깔끔하게 구현해 주세요.


[개선사항 2] PocketExpense 서비스에 B2B 바이럴과 세무사무실 락인을 위한 **[세무사무소 및 담당 세무사 지정형 멀티 테넌트 워크스페이스와 자동 연동 시스템]**을 구현해 주세요.

현재 앱의 기본 기능 및 관리자 워크스페이스는 이미 구현되어 있으며, 여기에 세무사무소 관점의 확장 뷰와 연동 로직을 추가하는 작업입니다.

---

### [1. 일반 기업 관리자 설정 (Client Workspace Settings)]
- 기업 관리자 설정 화면에 **[담당 세무사 정보 입력란]**을 추가해 주세요.
  - **입력 항목**:
    1. `세무사무소명` (예: OO세무사무소)
    2. `담당 세무사/직원 이름` (예: 홍길동 세무사)
    3. `담당자 이메일` (세무사무실 실무 담당자의 로그인 계정 및 초대용)
    4. `담당자 연락처` (선택 사항)
- 사장님이 이 정보를 입력하고 저장하면, 백엔드에서 해당 담당자 이메일 기반의 세무사 워크스페이스 매핑 트리거가 작동합니다.

### [2. 세무사 워크스페이스 및 자동 초대/누적 로직 (Tax Accountant Workspace)]
- **권한 체계**: 유저 권한(Role)에 `tax_accountant`를 추가하고, 담당 세무사 이메일로 로그인 시 전용 대시보드로 라우팅해 주세요.
- **최초 등록 및 초대 플로우**:
  - 입력된 담당자 이메일로 가입된 계정이 **없는 경우**: 해당 이메일로 "OO기업에서 세무 정산 연동을 요청했습니다"라는 초대(가입) 안내가 가거나, 회원가입 시 자동으로 해당 기업과 매핑되게 설계해 주세요.
  - 가입된 계정이 **있는 경우**: 별도의 승인 절차 없이 즉시 해당 세무사의 워크스페이스에 해당 기업이 연결됩니다.
- **멀티 기업 자동 누적 (Multi-Company Auto-Append)**:
  - 이미 워크스페이스를 이용 중인 담당 세무사에게, 다른 고객사가 추가로 동일한 세무사무소/담당자 정보를 등록할 경우, 담당 세무사의 별도 조작 없이 **대시보드의 '담당 기업 리스트'에 자동으로 새 기업이 누적**되도록 관계형 데이터 구조(N:1)를 구현해 주세요.

### [3. 세무사 전용 대시보드 UI 및 기능]
- **담당 기업 셀렉터**: 좌측 또는 상단에 연결된 소규모 기업들의 리스트가 노출되며, 클릭 시 페이지 새로고침 없이 즉시 해당 기업의 컨텍스트로 전환되어야 합니다.
- **세무 데이터 조회 및 엑셀 다운로드**:
  - 선택된 기업의 월말 정산 내역, AI 영수증/지출 증빙 데이터, 계정과목별 리스트를 테이블 뷰로 제공해 주세요.
  - 세무사무실 회계 프로그램 포맷에 맞춰 일괄적으로 뽑아갈 수 있는 **[세무용 엑셀 다운로드]** 버튼을 배치해 주세요.
- **계정과목 / 세무 설정 매핑**:
  - 해당 기업의 계정 코드나 세무 관련 항목을 세무사무실 기준에 맞게 수정·매핑할 수 있는 설정 권한을 제공해 주세요.
