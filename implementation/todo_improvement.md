[개선사항 1] 직원용 워크스페이스 모바일 홈 화면 내 **[임시저장된 지출결의서 목록] UX를 아래 요건에 맞춰 개선해줘.**

1. 홈 화면 리스트에서 직접 삭제 기능 추가
- 현재는 임시저장된 건을 삭제하려면 상세 화면으로 진입하여 맨 아래로 스크롤해야 하는 번거로움이 있음.
- 이를 개선하여, 직원 홈 화면의 임시저장 리스트 항목에서 모바일 친화적인 **'스와이프하여 삭제(Swipe-to-Delete)'** 인터랙션을 구현해줘.

2. 세부 동작 방식 (UX Flow)
- 사용자가 홈 화면의 임시저장 리스트 중 특정 항목을 좌측(또는 우측)으로 손가락을 밀어 스와이프하면, 옆에 **[삭제] 버튼**이 노출되도록 함.
- 노출된 [삭제] 버튼을 터치하면, "임시저장된 문서를 삭제하시겠습니까?" 같은 가벼운 확인 팝업(또는 즉시 삭제)과 함께 해당 리스트가 깔끔하게 지워지도록 처리할 것.
- 상세 화면으로 이동하지 않고도 홈에서 바로 불필요한 임시저장을 정리할 수 있게 만들 것.

---

[개선사항 2] PocketExpense 모바일 웹/앱 환경의 '임시저장된 지출결의서 상세 화면'에서 발생한 레이아웃(CSS) 겹침 버그를 수정해줘.

1. 버그 현상
- 상세 화면 최하단에 있는 [지출결의서 삭제] 버튼이, 그 위에 있는 안내 문구("임시저장했어요. 다른 기기(PC)에서도 이어서 쓸 수 있어요.")와 겹치거나 가려져서 버튼의 절반밖에 보이지 않는 현상이 발생함.

2. 수정 요구사항
- 스크롤 가능한 컨테이너의 하단 여백(padding-bottom)을 충분히 확보하거나, 하단 안내 문구와 삭제 버튼의 구조(Flexbox / Fixed Positioning)를 재정리해줘.
- 안내 문구 때문에 **[지출결의서 삭제] 버튼이 잘리거나 가려지는 일 없이, 100% 온전하게 노출되고 원활하게 터치(클릭)될 수 있도록** 레이아웃을 깔끔하게 수정할 것.

---

- [개선사항 3] PocketExpense 모바일 웹/앱의 영수증 목록 및 수정 화면 구조를 서브 페이지 이동 방식에서 **'원페이지 아코디언(One-Page Accordion) 인라인 편집'** 구조로 전면 개편해줘.

1. 서브 페이지 이동 방식 전면 폐지
- 기존에 영수증 리스트를 눌러 별도의 상세 수정 페이지로 이동하던 구조를 없앰.
- 모든 영수증 데이터와 수정 항목은 하나의 메인 화면(원페이지) 안에서 처리되도록 변경할 것.

2. 리스트 카드 내 인라인 펼치기/접기 (Accordion) 구조
- 각 영수증 카드(리스트 아이템)의 하단 중앙 또는 적절한 위치에 **'약간 뾰족하게 튀어나온 형태의 토글 탭(예: 아래/위 화살표 혹은 탭 브래킷 스타일)'**을 시각적 인디케이터로 배치해줘.
- 사용자가 이 뾰족한 토글 버튼을 터치하면, 해당 영수증 카드 하단 영역이 부드럽게 슬라이드되며 **숨겨져 있던 상세 수정 필드들이 인라인으로 쫙 펼쳐지도록** 구현함.

3. 펼쳐진 영역(아코디언 내부)에서 수정 가능한 항목
- 증빙구분 (카드매출전표 / 현금영수증 / 세금계산서 / 간이영수증 / 기타)
- 결제수단 (법인카드 / 개인(사비))
- 지출 카테고리 (일반 식대 / 출장비 / 외부 미팅비 / 회사 물품 구매 등)
- 인원수 및 AI 파싱 결과(가맹점명, 금액 등) 수정 필드
- 수정이 끝나면 토글을 다시 눌러 깔끔하게 접을 수 있게(Collapse) 처리할 것.

4. 메인 화면과의 데이터 연동
- 원페이지 안에서 여러 장의 영수증이 각각 펼쳐져서 수정되더라도, 최종 상신 시 이 모든 데이터가 메인 지출결의서 데이터와 실시간으로 완벽하게 동기화되어 한 번에 상신될 수 있도록 구조를 완성해줘.

- [개선사항 4] PocketExpense 모바일 웹/앱의 **'출장 경비' 처리 및 '자차 유류비 계산' UI/UX를 원페이지(One-Page) 기반으로 전면 개편**해줘.

1. 토글과 카테고리의 중복/충돌 제거
- 지출결의서 상단의 **[출장 경비 여부] 토글**과, 영수증 카테고리 선택지에 있던 **'출장비' 카테고리가 서로 혼선**을 주지 않도록 구조를 정리해줘.
- '출장 경비'는 단순 카테고리가 아니라, 상단 토글(또는 별도 모드)을 통해 기간, 이동수단, 장소 데이터가 확장되는 **독립적인 특수 정산 프로세스**로 명확히 분리할 것. (일반 카테고리 목록에서 '출장비' 항목은 제외)

2. 자차 유류비 계산 및 경로 입력 페이지 이동 전면 폐지
- 현재 자차 유류비 계산(경로 입력)을 누르면 별도의 상세 페이지로 이동하는 구조를 **완전히 없애줘.**
- 대신, 이동 수단으로 [자차]를 선택하거나 관련 버튼을 누르는 순간, **현재 페이지(원페이지) 안에서 하단으로 관련 입력 폼들이 부드럽게 슬라이드되며 펼쳐지도록(Inline Accordion)** 구현할 것.

3. 원페이지 내부에서 처리되어야 할 자차 정산 인터랙션
- **출발지 / 도착지 입력**: 키워드 입력 시 지도 API 기반 자동완성 추천 목록이 인라인 레이어로 노출됨.
- **주행 거리 및 유류비 자동 산출**: 출발/도착지가 확정되면 실시간 주행 거리(km)와 설정 단가가 곱해져 총 금액이 그 자리에서 즉시 계산됨.
- **디지털 증빙 카드 자동 생성**: 별도 캡처본을 올릴 필요 없이, 산출된 내역이 담긴 '출장 경로 및 거리 산정 요약 디지털 카드'가 해당 영역에 즉시 생성되어 박히도록 할 것.
- 모든 과정에서 페이지 전환(Page-hop)이 단 한 번도 일어나지 않도록 완벽한 원페이지 흐름으로 완성해줘.

- [개선사항 5] PocketExpense SaaS 프로젝트의 **[지출 카테고리] 설정 위치 및 [지출결의서 제목 자동 생성] 로직을 회계 실무 기준에 맞춰 전면 개편**해줘.

1. 지출 카테고리 설정 위치 변경 (메인 단위 통합)
- 기존에 개별 영수증 항목별로 설정되어 있던 '지출 카테고리(일반 식대, 외부 미팅비, 회사 물품 구매 등)' 셀렉터를 영수증 항목에서 **제거**해줘.
- 대신, **지출결의서 메인 작성 화면 상단(대표 영역)에 [지출 카테고리]를 단 1개만 선택**하도록 배치할 것.
- 회계 장부 기장 표준상 하나의 지출결의서(전표)에는 하나의 계정과목(카테고리)만 들어가야 하므로, 전체 결의서의 성격을 여기서 대표로 정하는 구조로 통일할 것.

2. 지출결의서 제목 자동 조합 로직 수정
- 상단 메인에서 선택한 **[카테고리명]**과 영수증의 **[가맹점명]**이 결합되어 지출결의서 제목이 실시간으로 자동 생성되도록 구현함.
- **적용 포맷**:
  - 영수증 1장: `[카테고리명] 가맹점명` (예: `[회의비] 메가커피 판교점`)
  - 영수증 2장 이상: `[카테고리명] 대표가맹점명 외 N건` (예: `[회의비] 메가커피 판교점 외 1건`)
- 자동 생성된 제목은 사용자가 필요할 경우 직접 수정(Overwriting)할 수 있도록 입력 필드로 제공할 것.

3. 영수증 원페이지 아코디언 항목 정비
- 앞서 구현한 원페이지 아코디언(인라인 펼치기) 영수증 카드 내부에서는 카테고리 선택을 없애고, **[증빙구분]**과 **[결제수단(법인카드/개인사비)]**, 그리고 영수증별 필수 세부 항목들만 깔끔하게 남겨서 UI 혼선을 완전히 해소해 줄 것.
