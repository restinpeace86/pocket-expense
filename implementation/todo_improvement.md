[개선사항 1] 현재 Next.js 기반으로 소기업용 지출 정산 SaaS (PocketExpense)를 개발 중입니다. 
카카오톡 공유하기 기능을 구현했는데 문제가 발생하여 이를 수정하고자 합니다.

### 📌 현재 카카오 디벨로퍼스(Kakao Developers) 설정 상태
- JavaScript SDK 도메인에 아래 주소들이 모두 정상 등록되어 있습니다.
  1. http://localhost:3000
  2. https://pocket-expense-ruby.vercel.app
- 카카오 로그인 리다이렉트 URI는 현재 사용하지 않아 비어 있습니다.

### ⚠️ 현재 문제 상황
- 앱 내에서 '카카오톡 공유하기' 버튼을 눌러 다른 사람에게 링크를 전송했을 때, 상대방이 채팅방에서 링크를 누르면 배포 주소가 아니라 `localhost:3000`으로 연결되어 페이지가 열리지 않습니다.
- 카카오 콘솔 설정은 완료되었으나, 코드 내에서 `Kakao.Share.sendDefault`를 호출할 때 링크 주소(`webUrl`, `mobileWebUrl`)가 `localhost:3000`으로 하드코딩되어 있거나 환경 변수 처리가 잘못된 것으로 추정됩니다.

### 🛠️ 요청 사항
1. 프로젝트 내에서 카카오 공유하기 관련 코드(`Kakao.Share.sendDefault` 등을 사용하는 파일)를 찾아주세요.
2. 하드코딩된 `localhost:3000` 부분을 실제 Vercel 배포 주소(`https://pocket-expense-ruby.vercel.app`) 또는 `process.env.NEXT_PUBLIC_SITE_URL` 같은 환경 변수를 활용하여 동적으로 처리되도록 코드를 수정해 주세요.
3. 관련 컴포넌트의 전체 수정된 코드를 보여주세요.

[개선사항 2] 지출결의서 작성 화면의 UI/UX 완성도를 높이기 위해 다음 2가지 핵심 디자인 및 레이아웃을 수정하고자 합니다.

### 1. 🗂️ 지출 카테고리 뱃지/버튼 영역 2열 그리드(2-Columns Grid) 정렬
- 현재 카테고리 목록(일반 식대, 외부 미팅비, 회사 물품 구매, 출장비는 2열로 잘 정렬되어 있습니다.
- 그 외 카테고리들은 하나로 묶여서 회식비, 경조사비, 세미나/컨퍼런스 등)이 중구난방으로 나열되어 있어 지저분합니다.
- 모바일과 웹 화면 모두에서 대칭을 이루며 깔끔하게 보이도록, **2열 그리드** 형태로 반듯하게 정렬되도록 UI를 수정해 주세요.
- 선택된 카테고리와 선택되지 않은 카테고리의 스타일(배경색, 테두리 등) 구분이 명확해야 합니다.
- 

### 2. ✨ 제목 및 지출 사유 입력창 포커싱(Focus) 시각적 강조
- 흐름: 영수증 업로드 ➡️ AI OCR 자동 파싱 ➡️ 지출결의서 작성 화면 진입 (최상단에 카테고리, 그 아래에 AI가 자동 채워준 제목/지출 사유 표시)
- 문제점: AI가 자동으로 채워준 제목이나 지출 사유를 사용자가 수정하려고 할 때, 현재 입력창인지 수정 가능한 상태인지 직관적으로 와닿지 않습니다.
- 요구사항: 사용자가 제목이나 지출 사유 입력창을 터치(클릭)하여 **포커싱(Focus)했을 때**, 눈에 띄게 시각적 피드백이 오도록 수정해 주세요. 
  - 예시: 굵은 테두리(예: `focus:ring-2 focus:ring-blue-500`), 입력창 배경색 미세한 변화 등을 적용하여 "지금 수정 중이구나"를 사용자가 확 느낄 수 있게 만들어 주세요.

### 🛠️ 요청 사항
위 2가지 요구사항이 반영된 지출결의서 작성 컴포넌트의 수정된 코드(Tailwind CSS 활용)를 작성해 주세요.

[개선사항 3] 지출결의서 작성 화면에서 UX를 대폭 개선하기 위해, **[동적 추가 정보 필드 위치 조정]**과 **[스마트 초안 연동 로직]** 두 가지 핵심 기능을 상세히 구현하고자 합니다. 아래 요구사항에 맞춰 코드를 수정해 주세요.

### 1. 📐 동적 추가 정보 필드 위치 및 Layout Shift 방지 구조
- **현재 문제**: 카테고리 항목을 누르면 카테고리별 필요로하는 항목들이 바로 아래에 동적으로 생기고 있음 ex) 출장비 관련 필드(출장지, 기간, 이동 수단 등) 같은 동적 필드가 생기면서, 아래에 있던 '제목'과 '지출 사유' 입력창을 밀어내는 레이아웃 밀림(Layout Shift) 현상이 있습니다.
- **수정 요구사항 (UI 레이아웃 순서)**:
  1. 최상단: 카테고리 선택 영역
  2. 중간 고정 영역: **지출 제목 및 지출 사유 입력 영역** (어떤 카테고리를 선택하든 항상 이 자리에 고정되어 있어야 함)
  3. 하단 동적 영역: 선택된 카테고리에 따라 동적으로 나타나는 추가 정보 필드 영역 (예: 출장비 선택 시에만 나타나는 필드들)
- 사용자가 카테고리를 이리저리 바꿔도 '제목/지출 사유' 입력창은 카테고리 바로 아래로 고정되어 있고, 부가 정보 영역만 아래쪽에서 자연스럽게 나타나거나 사라지도록 컴포넌트 구조를 잡아주세요.

### 2. 🧠 스마트 초안 연동 로직 (카테고리 변경 시 지출 사유 처리)
- **흐름**: 영수증 업로드 ➡️ AI OCR 분석 ➡️ 최초 카테고리 설정 및 지출 사유 초안 자동 입력.
- **지능형 연동 요구사항 (상태 관리 구현)**:
  - `isUserModified`(사용자 수정 여부) 같은 상태(state)를 두어 관리해 주세요.
  - **상태 A (미수정 상태)**: 사용자가 아직 지출 사유 입력창을 직접 건드리지 않았다면(AI 초안 유지 중), 상단의 카테고리를 다른 것으로 변경했을 때 **지출 사유 초안도 그에 맞춰 자동으로 업데이트**되도록 해주세요.
  - **상태 B (수정 완료 상태)**: 사용자가 본인 손으로 직접 지출 사유를 타이핑하여 수정했다면, 이후에 상단 카테고리를 변경하더라도 **사용자가 작성한 사유가 덮어씌워지지 않고 그대로 유지**되도록 사용자 입력에 우선권을 부여해 주세요.

### 🛠️ 요청 사항
위 두 가지 요구사항(Layout Shift 방지 레이아웃 구조 및 스마트 초안 연동 state 로직)이 완벽히 반영된 컴포넌트의 수정된 코드(TypeScript / React / Tailwind)를 작성해 주세요.
