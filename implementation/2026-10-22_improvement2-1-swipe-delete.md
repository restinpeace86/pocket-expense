## 변경 사항
- `swipe-row.tsx`: 임시저장 카드를 왼쪽으로 밀면 오른쪽에 [삭제](88px). 터치만 반응, 세로 스크롤은 그대로(가로·세로 방향을 처음 8px로 판정). 열린 상태에서 카드를 누르면 닫힘(이동 안 함). PC는 마우스를 올리면 작은 휴지통 버튼.
- 홈(`employee-home-view.tsx`): 임시저장(draft) 카드에만 적용, [삭제] → 확인 시트("임시저장된 결의서를 지울까요?") → 목록에서 바로 사라짐. 상신·반려 건은 그대로.
- `deleteDraftClaimAction(claimId, { stayOnPage })`: 홈에서는 이동 없이 결과만(기존 편집 화면 삭제는 그대로 홈으로 이동). 크레딧 쓴 영수증 보관(D-080)·사진 삭제 규칙 그대로.

## 검증
- 로그인 E2E(390폭, 실제 터치 이벤트로 밀기): 카드 -88px 이동·[삭제] 보임 → 확인 창 → 삭제 0.9초(화면 체감) 뒤 목록에서 사라짐, 주소 그대로 → DB에 나머지 2건만 → 상신 건은 밀기 없음 → 밀지 않고 누르면 편집 화면. 스크린샷 확인(닫힌 카드 모서리에 빨간색 비치던 것 고침).
