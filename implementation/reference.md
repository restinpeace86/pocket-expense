4. 랜딩페이지도 이 기준으로 바꾸자
내가 생각하는 구성은 다음과 같아.
1. 메인 비주얼: 회사를 운영하는 일이 더 쉬워지도록.
2. 문제 제시: 작은 회사의 업무는 왜 이렇게 복잡할까?
3. 통합 업무관리: 일정, 협업, 경비, 결재를 하나로.
4. 세 가지 워크스페이스: 직원 / 관리자 / 세무사무소
5. 핵심 차별화: AI 경비처리와 세무사무소 연계
6. 실제 서비스 화면: 각 워크스페이스의 주요 기능
7. 요금제 및 도입 안내
기존 랜딩페이지의 AI 경비처리 내용을 없애는 게 아니라, 전체 운영관리 솔루션 안의 핵심 기능으로 위치를 조정하는 거야.

5. 다음은 브랜드 이름을 정할 차례야
나는 기존 PocketExpense처럼 특정 기능을 이름에 넣는 방식보다는, 회사의 운영과 업무를 포괄하는 독립적인 브랜드 이름을 추천해.

이름의 방향은 크게 두 가지로 나눌 수 있어.
- 브랜드형: 짧고 독창적인 이름. 향후 서비스가 확장되어도 제약이 적음.
- 의미 전달형: WORK, BIZ, OFFICE 등의 단어를 활용해 업무관리 서비스임을 쉽게 전달.
