# 카카오 키 설정 따라하기 (카카오톡 공유 버튼 · 자차 거리 계산)

> 2026-10-21 작성. 순서대로 따라 하면 됩니다. 코드 변경은 필요 없습니다.

## 먼저 알아 둘 것 — 키는 두 종류

| 환경변수 이름 | 넣을 키 (카카오 콘솔 이름) | 쓰는 곳 | 공개돼도 되나 |
|---|---|---|---|
| `KAKAO_REST_API_KEY` | **REST API 키** | 서버: 출발지·도착지 검색, 길찾기 거리 계산 | ❌ 절대 안 됨 (서버에만) |
| `NEXT_PUBLIC_KAKAO_JS_KEY` | **JavaScript 키** | 브라우저: [카카오톡으로 공유하기] 버튼 | ⭕ 됨 (등록한 도메인에서만 동작) |

- 두 키는 **같은 카카오 앱 안에 있는 서로 다른 값**입니다. REST 키를 JavaScript 키 자리에 넣으면 공유 버튼이 동작하지 않고, REST 키가 브라우저에 노출됩니다.
- `KAKAO_REST_API_KEY`는 이미 `.env.local`에 있습니다(local-open-spaces와 같은 앱의 키). 이번에 새로 할 일은 **JavaScript 키 등록**과 **Vercel 확인**입니다.

---

## 1단계. 카카오 콘솔에서 JavaScript 키 복사

1. https://developers.kakao.com 접속 → 오른쪽 위 로그인 (local-open-spaces 키를 만든 카카오 계정)
2. 상단 **[내 애플리케이션]** 클릭
3. 앱 목록에서 local-open-spaces에서 쓰던 앱을 클릭
   - 어떤 앱인지 헷갈리면: 앱을 눌러 **[앱 키]** 화면의 REST API 키가 `22c2…1a70`으로 시작·끝나는 앱이 맞습니다.
4. 왼쪽 메뉴 **[앱 설정] › [앱 키]** (화면에 따라 **[앱] › [플랫폼 키]**) 를 엽니다.
5. **JavaScript 키** 값을 복사해 둡니다. (REST API 키 바로 위나 아래 줄에 있습니다)
6. (확인) `.env.local`의 `NEXT_PUBLIC_KAKAO_MAP_API_KEY` 값과 같으면, 지도용으로 이미 쓰던 그 키가 JavaScript 키입니다. 같은 값을 쓰면 됩니다.

## 2단계. 카카오 콘솔에 사이트 도메인 등록

JavaScript 키는 **등록한 주소에서만** 동작합니다. 이 단계를 빼면 공유 창이 열리지 않습니다.

1. 같은 앱에서 왼쪽 메뉴 **[앱 설정] › [플랫폼]** (또는 **[앱] › [플랫폼]**) 을 엽니다.
2. **Web** 칸에서 **[Web 플랫폼 등록]** (이미 있으면 **[수정]**) 을 누릅니다.
3. **사이트 도메인**에 아래를 한 줄씩 추가합니다. (local-open-spaces 도메인은 지우지 말고 그대로 둡니다)
   ```
   https://pocket-expense-ruby.vercel.app
   http://localhost:3000
   ```
   - 나중에 PocketExpense 전용 도메인(예: `https://pocketexpense.co.kr`)을 연결하면 그 주소도 추가합니다.
   - 주소 끝에 `/`는 붙이지 않습니다.
4. **[저장]**

> 카카오톡 공유는 별도 신청·심사가 필요 없습니다. (카카오 로그인 활성화도 필요 없음)

## 3단계. 내 컴퓨터(.env.local)에 넣기

1. VS Code에서 `D:\workspace\pocket-expense\.env.local` 을 엽니다.
2. 맨 아래에 한 줄 추가합니다. (따옴표 없이, `=` 앞뒤 띄어쓰기 없이)
   ```
   NEXT_PUBLIC_KAKAO_JS_KEY=1단계에서_복사한_JavaScript_키
   ```
3. 저장 후, 켜 둔 개발 서버가 있으면 **끄고 다시** `npm run dev` 합니다. (`NEXT_PUBLIC_` 값은 서버를 다시 켜야 반영됩니다)

## 4단계. Vercel(운영)에 넣기

1. https://vercel.com 로그인 → **pocket-expense** 프로젝트 클릭
2. 상단 **[Settings]** → 왼쪽 **[Environment Variables]**
3. **JavaScript 키 추가**
   - Key: `NEXT_PUBLIC_KAKAO_JS_KEY`
   - Value: 1단계의 JavaScript 키
   - Environments: **Production, Preview, Development 모두 체크**
   - Sensitive: 꺼도 됩니다(브라우저에 공개되는 키라 의미 없음)
   - **[Save]**
4. **REST 키 확인** — 목록에 `KAKAO_REST_API_KEY` 가 있는지 봅니다.
   - 없으면 추가: Key `KAKAO_REST_API_KEY`, Value `.env.local`에 있는 값, Environments 모두 체크, **Sensitive 켜기** → [Save]
   - 이게 없으면 운영에서 자차 거리가 자동 계산되지 않고 "직접 입력"으로만 됩니다.
5. **다시 배포 (꼭 해야 함)** — `NEXT_PUBLIC_` 값은 빌드할 때 박히므로, 넣기만 하고 배포하지 않으면 반영되지 않습니다.
   - 상단 **[Deployments]** → 맨 위(가장 최근) 배포 오른쪽 **[⋯]** → **[Redeploy]** → [Redeploy]
   - 상태가 **Ready** 가 될 때까지 1~3분 기다립니다.

## 5단계. 잘 되는지 확인

**카카오톡 공유**
1. 휴대폰(카카오톡 깔린 폰)으로 https://pocket-expense-ruby.vercel.app 로그인 (관리자 계정)
2. 관리자 모드 › **[멤버 관리]** → "직원 초대 링크" 카드에 노란 **[카카오톡으로 공유하기]** 버튼이 보여야 합니다.
3. 버튼을 누르고 → **나와의 채팅** 을 골라 보냅니다.
4. 카톡에 "OO에서 경비 정산에 초대했어요" 카드가 오고, **[가입하기]** 를 누르면 초대 링크(가입 화면)가 열리면 성공입니다.

**자차 거리 계산**
1. 직원 모드에서 새 결의서 → [출장 경비] 켜기 → 이동 수단 **[자차]** → [경로 입력하고 유류비 계산]
2. 출발지 "판교역", 도착지 "부산역"을 검색해 고르면 몇 초 안에 "출장 경로 및 거리 산정 요약" 카드(약 377km × 2)가 나오면 성공입니다.
3. 확인용 결의서는 상신하지 말고 [결의서 삭제]로 지웁니다.

## 안 될 때

| 증상 | 원인 | 해결 |
|---|---|---|
| 공유 버튼이 아예 안 보임 | `NEXT_PUBLIC_KAKAO_JS_KEY`가 빌드에 안 들어감 | 4단계 5번 Redeploy 했는지 확인. 내 컴퓨터면 개발 서버 다시 켜기 |
| 버튼을 눌러도 창이 안 뜨거나 "도메인" 관련 오류 | 사이트 도메인 미등록·오타 | 2단계 다시 확인 (`https://` 포함, 끝에 `/` 없이) |
| "유효하지 않은 앱 키" 류 오류 | JavaScript 키가 아니라 REST 키 등 다른 키를 넣음 | 1단계에서 **JavaScript 키** 줄의 값인지 다시 확인 |
| 카드 그림이 안 나옴 | 카카오가 그림을 처음 가져오는 중이거나 캐시 | 몇 분 뒤 다시 보내 보기 (그림 없어도 링크는 동작) |
| 자차 거리가 "직접 입력해 주세요"로만 나옴 (운영) | Vercel에 `KAKAO_REST_API_KEY` 없음 | 4단계 4번 → Redeploy |
| 자차 거리가 안 됨 (내 컴퓨터) | 카카오모빌리티 길찾기 사용 설정 꺼짐 | 카카오 콘솔 해당 앱에서 **카카오맵/카카오모빌리티(길찾기) 사용 설정**을 켜기 (오늘 테스트에서는 이미 동작함) |

## 참고
- 두 프로젝트(local-open-spaces, PocketExpense)가 같은 카카오 앱을 쓰므로 **하루 호출 한도도 같이** 씁니다. 실제 고객이 늘면 PocketExpense 전용 앱을 새로 만들어 키를 바꾸는 것을 권장합니다. (바꿀 때는 이 문서 1~4단계를 새 앱으로 똑같이 하면 됨)
- REST 키는 채팅·문서 등에 붙여 넣은 적이 있으면, 걱정될 때 카카오 콘솔 [앱 키]에서 **재발급** 후 두 프로젝트의 `.env.local`과 Vercel 값을 함께 바꾸면 됩니다.
