# 알림 진동 길게 + 홈 화면 추가 안내 반복 방지 (D-227)

- 구현 일시: 2026-11-06
- 구현 대상: 사용자 지시 "채팅 알림 진동이 너무 약하고 짧게 두 번 · 이미 설치했는데 채팅 들어갈 때마다 홈 화면 추가 팝업"

## 변경 사항
- `public/sw.js`: 진동 `[120,80,120]` → `[500,200,500,200,500]`(길게 세 번).
- `src/components/push/push-toggle.tsx`: 안내 문구 "짧게 두 번" → "길게".
- `src/components/push/install.ts`: 홈 화면 아이콘(앱)으로 열면 쿠키 `pe_app`(2년) 기록, 휴대폰 추가 창에서 [추가]해도 기록. `installed` = 이번 추가 또는 `pe_app`.
- `src/components/push/push-auto-prompt.tsx`: 홈 화면 단계로 안내를 띄우는 조건을 '추가 가능 신호가 있음(prompt)·아이폰'으로 좁힘. 보이는 순간 `pe_push_ask`(7일) 기록.

## 원인
- 이미 추가한 기기를 크롬 탭으로 열면 크롬이 '추가 가능' 신호를 주지 않아 "신호 없는 안드로이드"로 보고 매번 안내했다.
- 안내는 [X]·[나중에]를 눌러야만 기억해서, 그냥 다른 화면(채팅)으로 가면 다음에 또 떴다.

## 특이 사항
- 안드로이드 8 이상 크롬은 웹 알림의 진동 값을 무시하고 휴대폰의 알림 채널 설정을 쓴다. 진동 세기는 웹에서 조절할 수 없다(휴대폰 설정 › 애플리케이션 › WORKON › 알림 › 카테고리 › 진동 패턴, 설정 › 소리 및 진동 › 진동 세기).
- 카카오톡의 가운데 토스트는 네이티브 앱의 '다른 앱 위에 표시' 기능이라 웹 앱에서는 불가.
