# T10-3b 지출결의서 PDF (D-092)

- 구현 대상: 세무 마감 ZIP의 `지출결의서_{YYYY-MM}.pdf` (`tax-export.md` §3.5, `form-template.md` §5, `template-configuration.md` §2 기본 양식)
- 구현 일시: 2026-10-22

## 변경 사항
- `src/app/api/fonts/kr/route.ts`: 로그인 멤버만, 글자 400자까지 Noto Sans KR TTF(쓰는 글자만)를 Google Fonts에서 받아 넘긴다.
- `src/lib/tax/claim-docs.ts` + `taxClaimDocsAction`: 패키지에 든 결의서마다 결의서 전체 항목·마지막 회차 결재 단계·청구자(관리자 RLS, 50개씩).
- `src/lib/tax/pdf-client.ts`(pdf-lib + fontkit, 브라우저): 글자를 400자씩 나눈 여러 글꼴로 그리기·줄바꿈, 결의서 문서 쪽(결재란, 헤더, 항목 표 + 쪽 넘김 시 머리줄 반복, 합계, 정산), 영수증 쪽(JPG/PNG 그림, PDF 영수증은 첫 쪽, 자차 경로 요약), 쪽 번호.
- `zip-client.ts`: 영수증을 다 받은 뒤 같은 바이트로 추가 파일을 넣는 `extra`. `tax-closing-view.tsx`: 진행 단계 "지출결의서 PDF 만드는 중", 결과 문구에 "+ 지출결의서 PDF", 실패 시 안내(ZIP은 저장).
- 라이브러리 추가: `pdf-lib`, `@pdf-lib/fontkit` (PDF 만들 때만 불러옴).
- 스펙 `tax-closing.md`, `tax-export.md` §3.5, 결정 D-092.

## 검증
- 로그인 E2E(실제 영수증 파일, 임시 회사·파일 삭제 확인): [마감하고 다운로드] → ZIP 저장 2.7초(화면 체감, 마감·장부·영수증 3장·PDF 포함, 개발 서버). ZIP 안 `지출결의서_2026-09.pdf`(약 400KB) 5쪽 = 결의서 2건 문서 + 영수증 3쪽. pdf.js로 쪽마다 그려 확인: 한글 정상, 결재란(김대표 승인 9/26), 헤더·항목 표·합계 43,000원·정산 문구, 영수증 원본 쪽, 자차 경로 요약 쪽, 쪽 번호. [다시 받기]도 같은 파일 구성.
- 처음 시도에서 결의서 합계가 결의서 칸 값(테스트 데이터에서 0)으로 나와 표 항목 합으로 바꿈.
