# WORKON 알림톡 템플릿 6종 — 솔라피(카카오) 심사용 (D-226)

> 코드의 고정 글(`src/lib/notify/templates.ts` `ALIMTALK_TEMPLATES`)과 **글자 하나까지 같아야** 한다. 심사에서 문구를 고치라고 하면 코드도 같이 고친다.
> 공통: 메시지 유형 **기본형** · 강조 표기 없음 · 카테고리 아래 표 · 버튼 1개(웹링크) · 변수는 `#{이름}`.
> 버튼 주소(모바일·PC 같게): `https://{도메인}/#{링크}` — 지금 도메인은 `pocket-expense-ruby.vercel.app`. **도메인을 바꾸면 버튼 주소 수정 심사를 다시 받아야 하므로, 도메인을 먼저 정하고 넣는 것을 권장.**
> 심사 통과 뒤: 템플릿 ID를 Vercel 환경변수 `ALIMTALK_TEMPLATE_<코드>`에 넣는다(예: `ALIMTALK_TEMPLATE_APPROVAL_REQUEST`).

## 1. INVITE — WORKON 회사 초대
- 카테고리: 회원 › 가입 안내(또는 서비스 이용 › 이용 안내)
- 버튼: [가입하기] → `https://{도메인}/#{링크}`
```
[WORKON] 회사 초대 안내

#{회사명}에서 #{이름}님을 WORKON에 초대했습니다.
WORKON은 #{회사명}의 경비 정산·결재·사내 소통을 위한 업무 서비스입니다.

아래 버튼을 눌러 가입을 마쳐 주세요.
```
- 예시 변수: 회사명 = 다모은랩 · 이름 = 홍길동 · 링크 = join/i/AbC123

## 2. TAX_OFFICE_INVITE — WORKON 세무사무소 연결
- 카테고리: 서비스 이용 › 이용 안내
- 버튼: [세무사무소로 시작하기] → `https://{도메인}/#{링크}`
```
[WORKON] 세무사무소 연결 안내

#{세무사}님, 고객사 #{회사명}이(가) 지출·증빙 관리에 WORKON을 사용하며 #{사무소명}을(를) 세무대행 사무소로 지정했습니다.

무료 세무사무소 워크스페이스에서 승인된 지출 장부·영수증·지출결의서·홈택스 자료를 한곳에서 받으실 수 있습니다.
```
- 예시 변수: 세무사 = 김세무(없으면 "담당 세무사") · 회사명 = 다모은랩 · 사무소명 = 한빛세무회계 · 링크 = for-tax-office/XY12

## 3. APPROVAL_REQUEST — WORKON 결재 요청
- 카테고리: 업무 알림 › 승인 요청(또는 서비스 이용 › 처리 안내)
- 버튼: [결재하러 가기] → `https://{도메인}/#{링크}`
```
[WORKON] 결재 요청

새로운 지출결의서가 상신되었습니다.

상신자: #{상신자}
제목: #{제목}
금액: #{금액}
사용처: #{사용처}
결제수단: #{결제수단}
```
- 예시 변수: 상신자 = 김개발 (개발팀) · 제목 = 부산 출장 · 금액 = 72,000 원 (영수증 3장) · 사용처 = 코레일 외 2곳 · 결제수단 = 법인 2 · 사비 1 · 링크 = workspace/…/approvals/…

## 4. APPROVAL_REJECTED — WORKON 결재 반려
- 카테고리: 업무 알림 › 처리 결과
- 버튼: [수정 후 다시 올리기] → `https://{도메인}/#{링크}`
```
[WORKON] 결재 반려

지출결의서가 반려되었습니다.

신청자: #{신청자}
제목: #{제목}
금액: #{금액}
사용처: #{사용처}
반려 사유: #{반려사유}

내용을 고쳐 다시 상신해 주세요.
```
- 예시 변수: 신청자 = 김개발 · 제목 = 점심 식대 · 금액 = 15,000 원 · 사용처 = 김밥천국 · 반려사유 = 영수증이 흐려요. 다시 찍어 주세요. · 링크 = workspace/…/employee/claims/…/edit

## 5. REMINDER — WORKON 결의서 제출 안내
- 카테고리: 업무 알림 › 리마인드(또는 서비스 이용 › 이용 안내)
- 버튼: [제출하러 가기] → `https://{도메인}/#{링크}`
```
[WORKON] 지출결의서 제출 안내

#{회사명}에서 보내 드리는 안내입니다.
아직 제출하지 않은 지출결의서가 #{건수}건 있습니다(작성 중·반려).

확인 후 상신해 주세요.
```
- 예시 변수: 회사명 = 다모은랩 · 건수 = 2 · 링크 = workspace/…/employee
- 보내는 때: 관리자가 직접 [독촉]을 누를 때만(광고·대량 발송 아님)

## 6. TAX_REQUEST — WORKON 세무 자료 요청
- 카테고리: 업무 알림 › 요청 안내
- 버튼: [요청 확인하기] → `https://{도메인}/#{링크}`
```
[WORKON] 세무 자료 요청

#{사무소명}에서 #{월} 세무 자료를 요청했습니다.

요청 대상: #{대상}
요청 내용: #{요청내용}

세무 마감 화면에서 답변해 주세요.
```
- 예시 변수: 사무소명 = 한빛세무회계 · 월 = 10월 · 대상 = 영수증 3번(없으면 "전체 자료") · 요청내용 = 10/15 주유 영수증 원본을 올려 주세요. · 링크 = workspace/…/admin/export?month=2026-10#tax-requests

## 심사 팁
- 모두 **정보성**(회원이 쓰는 서비스의 처리·요청 안내) — 광고 문구·할인·이벤트를 넣지 않는다.
- 초대(1·2)는 "회사(고객사)가 그 사람을 지정해 보내는 안내"라고 설명란에 적는다(받는 사람이 아직 회원이 아님).
- 반려 사유·요청 내용처럼 사람이 쓴 글이 들어가는 변수는 "업무 처리 사유(관리자가 입력)"라고 설명한다.
- 이모지·강조형(큰 글씨)은 쓰지 않았다(심사 반려가 잦음).
